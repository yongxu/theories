We are drawing a map of how relations form, persist and change within one unfolding of becoming, and of how organization, living, knowing, learning, evaluation and wisdom differentiate within it, so that humans and AI can check it and see the way together: first a map for alignment (coupled adaptive systems across blindness and drain, turning in time, and composition across scales), with Lean 4 formal proofs as the core; also a map of wisdom, what traditions, sciences, philosophies and systems thinking have seen of these dynamics, read onto one account. Its theorems are proved in Lean on formal models, each within its stated hypotheses. Real losses stay explicit; counterexamples, failed candidates and failed tests are kept, since they are where the map was wrong, and part of it.

### Running the checks

You need Python 3.9 or later (standard library only), git, and ripgrep for the strict check and for rendering. The Lean core check also needs [elan](https://github.com/leanprover/elan) with the toolchain pinned in [`lean-toolchain`](../../experiments/integrated-correction/general-framework/generative-basis/lean/becoming/lean-toolchain) (Lean `v4.29.1`; the core needs no Mathlib). Periphery reals/probability modules use Lean `v4.30.0-rc2` with Mathlib.

- `make research-test` runs the unit tests of the shared repository tools.
- `make research-check` checks records, evidence bindings, preservation hashes and generated pages (`make research-check-strict` also checks directory indexes).
- `python3 -B experiments/integrated-correction/general-framework/generative-basis/lean/becoming/check_becoming.py` compiles the `0`-axiom core and audits the axioms of every declaration ([checker](../../experiments/integrated-correction/general-framework/generative-basis/lean/becoming/check_becoming.py)). With `BECOMING_OUT=<dir>`, receipts go to that directory and the repository stays untouched; passed steps are cached in `~/.cache/becoming-lean` (`BECOMING_FRESH=1` rebuilds from scratch).
- `python3 -B experiments/integrated-correction/general-framework/generative-basis/lean/check_periphery.py --all` checks freshness and audits all `18` isolated periphery modules against the core receipt.
- `python3 -B -m unittest discover -s experiments/guarded-alignment-runtime/tests -v` runs the `6`-test exact-rational proposal diagnostic suite (`28` tests).
- `python3 -B -m unittest experiments/neural-alignment-stress-lab/test_stress_lab.py -v` runs the local CPU neural stress-lab verification suite (`19` tests).
