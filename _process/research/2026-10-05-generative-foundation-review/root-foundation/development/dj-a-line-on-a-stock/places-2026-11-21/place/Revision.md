- **laws where something comes to be registered**: Built example: controlled_revision (l256). General law: RevisionRuns.history_gains (l412). Premises: any run r, any obs, obs(state 0) x = obs(state 0) y, obs(state 1) x ≠ obs(state 1) y, 1 ≤ t. Conclusion: some select is through AlikeUpTo r t and not through the reading at the start. Handed in: obs and the difference at step 1. General law: keeps_through_iff (l41). Premise: old is an equivalence. Conclusion: every selection through old stays through new iff new ⊆ old.
- **cost and keeping**: Rebuild draws one unit (rebuild_enabled_iff l178); correction needs the link and one unit (l183). opens_without_correction (l210, built): forming can use up the last support for using it. feasible_iff (l337): a course is feasible exactly where the link admits it and the stock covers it. covered_not_enacted (l344), linked_not_enacted (l350). The link stays under replenish and correct, so keeping it costs nothing and using it costs stock.
- **a registering lost**: lost_choice (l56, general). Premises: old an equivalence, new x y, ¬old x y. Conclusion: ∃ select through old and not through new. closes_choice (l224, built): closing destroys a distinction even with stock left. It can be undone by rebuild true given stock (rebuild_then_close l204, built).
- **tied to what it rests on**: Only as cost: forming the link draws stock, and the controller reads the stock but is supplied. No statement makes the stock's fall the cause of a change in what is registered.
