## Decisions the design left to me

- **A theorem of the print is a name with a row, at both ends.** A listed name that a row uses but that has no row is not shown and sits under `not_read`. This cannot arise while the print covers every receipt module.
- **`not_read` keys:** `theorems_of_the_receipt_without_row`, `receipt_declarations_not_theorems`, `not_in_the_receipt_as_written`. The receipt lookup is exact too, so a name listed without `Becoming.` falls in the third.
- **Order:** other dynamics in atlas order, used theorems in their dynamic's declaration order, using theorems in this dynamic's. A listing's duplicates count once.
- **Chains:** the data has one per pair of ends, with every other dynamic the far end is listed under. The page shows one per used theorem (shortest, then first by names) and is not capped.
- **No chain to an already-shown theorem** means any theorem this dynamic's `uses` already has, whichever dynamic it is under.
- **"Told above as a case"** is marked on the using theorem when the (law, case-of law) pair is exactly that use, not whenever a case row names the used theorem.
- **Caps:** four used theorems per other dynamic, then "and n more in the data file"; four using theorems named, then "n more". The reverse direction has no cap on dynamics and no total.
- **Short forms** carry no heading sentence, only the link to the terrain's section. The "None found" form adds that a chain ending here is shown where it starts, since the far end of a chain would otherwise read as nothing found.
- **Behind sentences in a section:** besides the modules of the theorems listed here (A6), a section names behind modules whose rows its lines were read from (theorems between a chain's ends, using theorems elsewhere). This is slightly wider than A6; the words reader asked for it.
- **Bound print with a receipt theorem lacking a row:** the terrain says so as an anomaly ("no line can be computed for it"); sections say nothing.
- **Index digest differs but no module hash does:** a separate sentence says the print "has not been set against this receipt".
- **Shared-listing wording:** the terrain and section sentences state the rule exactly (the two dynamics that both list the theorem). The words reader's shorter sentence said more than A2 does.
- **Left off the pages:** "about a tenth" is replaced by the computed "n of the N theorems in the print", and the index's `about` text is in the data file only.
- **`spine.py`:** its sentence is about the picture ("Two pictures … drawn … an arrow a count of exits"), and `terrain.svg` is unchanged, so I judged it still true and left it.
