**DECISIONS THE DESIGN LEFT TO ME**

1. `printer_sha256` is of `PRINTER` as it stands in the file, placeholder `@MODULES@` included. The module list is written into the Lean text as a `List String` literal; the index binds the list separately through its `modules`.
2. The printer's output is `ROW {"module","name","uses"}` lines, then a last line `COUNT rows=N uses=M`. Both numbers are checked.
3. A Lean warning line is kept aside and shown on stderr; any `error:` line, a non-zero exit, a missing or misplaced count line, a malformed row, a row of a module outside the receipt, or a name printed twice stops the run.
4. Every receipt module gets a file, empty where it has no theorem. The atlas reader in the worktree requires a file for every module the index names, so this agrees with it.
5. Clean-tree rule: `git status --porcelain -z --untracked-files=all` on the package folder plus the receipt's three sources outside it.
   - A tracked `.lean` in any state refuses.
   - An untracked `.lean` refuses only if it is a receipt source.
   - So the receipt JSON and the untracked `becoming-checks/<utc>/` copies left by a core run do not refuse.
6. The stub is `tmp/proof-uses-tree/ProofUsesStub.lean`; the printer and its raw output go to `tmp/proof-uses-tree/.printer/`, a dot folder that `scratch_build.overlay` skips. A non-blocking flock on the tree refuses a second run at once.
7. The run refuses a stray `.lean` in the tree and removes nothing there.
8. The build is a subprocess call of the package's `scratch_build.py TREE ProofUsesStub`. Before it, the tool builds the same plan through `check_becoming` to count the steps the cache lacks, restoring and hashing nothing.
9. It also refuses when:
   - the stub's import closure is not exactly the receipt's modules;
   - the toolchains differ;
   - HEAD or the sources moved while Lean ran (checked again before writing).
10. Write order: module files, then removals, then `INDEX.json` last. A file is removed only if the earlier index named its module.
11. `--check` exits 0 only when bound and `damage` is empty. `status()['bound']` stays the two equalities of the brief.
12. `sources_digest` is defined locally so the gate imports no measure tools; a test holds it equal to `shared_laws.sources_digest`.
13. The run's summary also gives `receipt_theorems_without_row` and `rows_the_receipt_scan_lacks`, as told counts only; neither goes in the index.
