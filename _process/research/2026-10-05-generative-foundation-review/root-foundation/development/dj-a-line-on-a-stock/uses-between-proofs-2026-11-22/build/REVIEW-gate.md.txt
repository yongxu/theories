1. **MUST, `tools/research/gate.py:983-990`: a `status()` that returns `None` passes the check silently.** If `status(ROOT)` returns `None`, the `if found is not None` branch is skipped and no error is added. I ran a probe on the test's temp repo: an index was present, `status` returned `None`, and the result was `{'errors': [], 'bound': None, 'note': None}`, a pass that gives no reason. A non-dict result has a second problem: a list raises `AttributeError` at `found.get`. That line is outside the `try`, so the gate crashes and `GATE_PROOF_USES` cannot pass it. Fix: move the reading of the result into the `try` and refuse anything that is not a mapping:
   ```python
   try:
       found = status(ROOT)
       if not isinstance(found, dict) or 'bound' not in found:
           raise TypeError(f'status() returned {type(found).__name__}, not a mapping with "bound"')
       bound = found['bound'] is True
       problems = [str(p) for p in found.get('problems') or []]
       behind = sorted(str(m) for m in found.get('modules_behind') or [])
   except Exception as exc:
       errors.append(f'{PROOF_USES_TOOL} status() failed: {exc!r}; {RUN_PROOF_USES}')
   else:
       if not bound: ...
   ```
   Using `is True` also stops a string `'false'` from counting as bound. Add a test for a `status()` that returns `None`, and one for a list.

2. **MUST, `gate.py:940-946`: an error raised while importing the tool crashes the check, so the escape cannot let it pass.** `proof_uses_status` catches only `ImportError`. My probe raised a `SyntaxError` from the import with `GATE_PROOF_USES='printer wrong'` set, and the check raised instead of passing with the reason. The writer's claim that "the escape covers every failure" is therefore false. The design's case is "a day the printer is wrong", and the printer is text inside the tool. There is a second fault: when the tool exists but one of its own imports is missing, the `ImportError` is reported as "the tool or its status() is absent", which points at the wrong cause. Fix:
   ```python
   def proof_uses_status():
       try:
           module = importlib.import_module('tools.research.proof_uses')
       except ModuleNotFoundError as exc:
           if exc.name in ('tools.research.proof_uses', None):
               return None
           raise
       return getattr(module, 'status', None)
   ```
   In `proof_uses_check`, wrap the call in `try: status = proof_uses_status() except Exception as exc: errors.append(f'{PROOF_USES_TOOL} does not import: {exc!r}; ' + RUN_PROOF_USES); status = False`, and skip the comparison when `status is False`.
