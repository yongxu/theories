# Exactly what a reading must distinguish on the mixed Drain class

**Suppose equality of reading values is decided. At every horizon of two steps or more, `mixed` is kept exactly when the reading gives different values to the two possible first steps of move `false`.** Every reading keeps `mixed` for one step. A reading that distinguishes those two steps keeps it for every finite horizon.

The starting class consists of `(true, 2)` and `(false, 1)`. The guard requires a nonzero level, and every move is allowed. Move `true` takes `(false, 1)` to zero, so the first move must be `false`. Its two possible steps both end at level 1.

| Start | Move | End | Reading value |
|---|---|---|---|
| `(true, 2)` | `false` | `(true, 1)` | `sense (true, 2) false (true, 1)` |
| `(false, 1)` | `false` | `(false, 1)` | `sense (false, 1) false (false, 1)` |

### The exact condition

The following statements use `Drain.process`, `Drain.above` and `everyMove`. A reading of steps has type `sense : Bool × Nat → Bool → Bool × Nat → O`, with `O : Type`.

**`mixed_kept_two_implies_values_ne`** gives necessity for any such reading. It has no equality-decision premise.

```lean
KeptFor Drain.process sense Drain.above everyMove 2 mixed →
  sense (true, 2) false (true, 1) ≠ sense (false, 1) false (false, 1)
```

If the two steps give the same value, the class seen at that value contains both lanes at level 1. By `KeptFor.mono`, keeping that class for a further step would keep `ones`, contradicting `ones_not_kept_one`.

**`mixed_kept_of_values_ne`** takes the explicit hypothesis `eqOrNot : ∀ x y : O, x = y ∨ x ≠ y`. If the two displayed values differ, it proves `∀ n, KeptFor Drain.process sense Drain.above everyMove n mixed`.

The proof takes the starting guard directly from `code_within` and chooses move `false` using `usable_all`. It compares the observed value with the value of the true-lane step. If equal, every endpoint seen lies in the true lane because the false-lane step gives a different value. If unequal, every endpoint seen lies in the false lane. This includes an observation reached by neither step, whose seen class is empty. In both branches `KeptFor.mono` restricts `ones_in_lane_kept` to the seen class for the remaining horizon.

**`mixed_kept_add_two_iff_values_ne`** takes the same `eqOrNot` hypothesis and any `n : Nat`.

```lean
KeptFor Drain.process sense Drain.above everyMove (n + 2) mixed ↔
  sense (true, 2) false (true, 1) ≠ sense (false, 1) false (false, 1)
```

Forward, the proof applies `KeptFor.shorter` once for each of the `n` extra steps, then calls `mixed_kept_two_implies_values_ne`. Backward, it calls `mixed_kept_of_values_ne` at `n + 2`.

### General statements in `Becoming.Viability`

**`keptFor_one_iff`** holds for any process `P : Process S A`, reading of steps `sense : S → A → S → O`, guard `guard : S → Prop`, allowed moves `allowed : S → A → Prop`, and class `B : S → Prop`. The types of configurations, moves and values have independent universes.

```lean
KeptFor P sense guard allowed 1 B ↔
  (∀ s, B s → guard s) ∧
    ∃ a, Usable P allowed B a ∧ ∀ s t, B s → P.step s a t → guard t
```

The proof uses `KeptFor` and `Seen` by definition. Forward, for a step from `s` to `t`, it applies the guard at the actual value `sense s a t`. Backward, each member of a seen class supplies a starting configuration in `B` and a step to its endpoint, so the endpoint condition gives the guard there. Both directions retain the same usable move.

**`keptFor_one_iff_change_reading`** holds with the same process, guard, allowed moves and class, for any second reading of steps `sense' : S → A → S → O'`. The value types `O : Type w` and `O' : Type z` may inhabit different universes.

```lean
KeptFor P sense guard allowed 1 B ↔ KeptFor P sense' guard allowed 1 B
```

The proof calls `keptFor_one_iff` once for each reading and composes the first equivalence with the reverse of the second.
