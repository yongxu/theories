def Carries (P : Process S A) (g : S → Prop) (Q : Process T B) (h : T → Prop)

**The clock and the ending bridge.** `whileProcess can next` uses `Law.stepWhile can next` as its unit-move step. The clock takes `i` to `i + 1` while `i < N`.

```lean
-- Induction on n using the enabled tick, the viable tail, Nat.succ_add, and Eq.subst.
theorem clock_budget {N : Nat} : ∀ {n i}, i ≤ N → Viable (clock N) (fun _ => True) n i → i + n ≤ N

-- Calls Horizon.carried, horizon_iff_viable, clock_budget, Nat.zero_le,
-- Nat.zero_add, Eq.subst, and Nat.not_succ_le_self.
theorem Horizon.clock_bound {U : Type v} {P : Process X U} {g : X → Prop} {R : X → Nat → Prop} {N s}
    (carry : Carries P g (clock N) (fun _ => True) R) (start : R s 0) :
    ¬ Horizon P g (N + 1) s

-- Induction on n using split and Law.stepWhile_none_iff.
theorem Horizon.stepWhile_end {can : X → Prop} {next : X → X} (split : ∀ s, can s ∨ ¬ can s) :
    ∀ {n s}, (¬ Horizon (whileProcess can next) (fun _ => True) n s) →
      ∃ k t, k < n ∧ «迭» (Law.stepWhile can next) k s t ∧ ∀ v, ¬ Law.stepWhile can next t v

-- Induction on path length using «迭之末步» and the supplied carry.
theorem clock_endpoint {can : X → Prop} {next : X → X} {R : X → Nat → Prop} {N s}
    (carry : Carries (whileProcess can next) (fun _ => True) (clock N) (fun _ => True) R)
    (start : R s 0) : ∀ n {t}, «迭» (Law.stepWhile can next) n s t → R t n

-- Calls Horizon.clock_bound and horizon_iff_viable.
theorem clock_bound {R : S → Nat → Prop} {N s}
    (carry : Carries P g (clock N) (fun _ => True) R) (start : R s 0) :
    ¬ Viable P g (N + 1) s

-- Calls Horizon.stepWhile_end and horizon_iff_viable.
theorem stepWhile_end {can : S → Prop} {next : S → S} (split : ∀ s, can s ∨ ¬ can s) {n s}
    (fails : ¬ Viable (whileProcess can next) (fun _ => True) n s) :
    ∃ k t, k < n ∧ «迭» (Law.stepWhile can next) k s t ∧ ∀ v, ¬ Law.stepWhile can next t v
```

## 3. Evidence against the frozen criteria

**L1.** At a related pair the left guard supplies the right guard. Matching is needed only inside the left guard. There, for every enabled left move, the right move must be enabled and fixed before its successor is known. Given any particular right successor, the proof opens an existential for one related left successor and applies the induction hypothesis there. It needs neither a decision about which successor occurred, a function choosing witnesses across successors, coverage of every left successor, nor reverse simulation.

**L2.** `closed_same` and `kept_same` both close by `rfl`. For the second case, a usable move from class `C` can step to every `Seen P sense C a o` and to the empty class. The latter gives an enabled successor even for an empty observation type. The move itself witnesses the premise of `keptFor_empty`, so adding that successor costs no horizon. With only observation-indexed successors, an empty observation type would disable every move, even a usable move on the empty class. The proved equivalence needs no inhabitance, decidability, or choice premise. To apply comparison, the point is related to each subclass of a family member. This includes the empty successor, and `Seen.mono` keeps real observation successors inside the corresponding family member.

**L3.** `locked_same` closes by `rfl` with both universes explicit. Each enabled step meets the positive need, so the level is unmarked and the invariant gives `i ≤ hi`. The hypotheses `outside` and `more` advance the orbit equality and the lower bound on use. At `i = hi`, use covers the entire level. Natural subtraction leaves zero and `nothing` keeps it zero. Comparison therefore excludes `hi + 2` steps. The bridge uses the decision for natural-number order to find an end by `hi + 1`. The endpoint lemma uses the same move matching to recover the way there.

The domain lemmas called directly by the lock proof are `TurningInTime.locked_alone_not_below`, `TurningInTime.kept_within`, `Becoming.sub_eq_zero_of_le`, and `TurningInTime.locked_alone`. The proof also applies its supplied hypotheses, natural-number order and addition lemmas, and equality transport. The bridge calls `Law.stepWhile_none_iff`, and endpoint tracking calls `«迭之末步»`. No old ending proof supplies the deadline.
