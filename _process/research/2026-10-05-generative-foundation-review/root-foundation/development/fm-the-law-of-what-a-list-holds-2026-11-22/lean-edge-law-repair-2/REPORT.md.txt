```lean
givesStep Ψ G X z := Ψ (fun t => X t → G) z → G

CommutesWithImplication Ψ G :=
  ∀ (W : S → Prop) z, Ψ (fun t => (W t → G) → G) z → (Ψ W z → G) → G
```

I used `CommutesWithImplication` because the package already defines `Becoming.Commutes` for a different property.

### (i) Relational reach

`reach_commutes G : CommutesWithImplication (reachStep R W₀) G` holds for every relation, target, and proposition. If the target holds here, the conclusion follows immediately from the supplied implication. A related successor supplies the other alternative. Neither case needs a decision.

Write `reaches := iter (reachStep R W₀) W₀`. Under `every : ∀ x, x ∈ all` and `len : all.length = n + 1`, the following two statements hold.

```lean
reach_within_length     : ∀ m, reaches m y → reaches n y
closure_iff_reach_within : (∃ t, «所闭» R y t ∧ W₀ t) ↔ reaches n y
```

The first calls `iter_within_pred_length` once, with `reach_mono`, `reach_commutes`, and the first-step equivalence obtained by opening the reach disjunction. This accounts for the earlier bound without the special reach bridge.

The closure is **forward**, from `y` to `t`. The grammar composes relations in that order. Its closure contains each related pair, is reflexive and transitive, and agrees with taking some finite number of steps. For the forward implication above, the closure carries the predicate `fun z => ∀ m, reaches m z → reaches n y` from `y` to the target. The converse calls `closure_of_reach`, which uses reflexivity, inclusion of a single step, and transitivity.
