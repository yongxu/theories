**(5) Questions 4 to 7**

**Q4.** Write G := `reaches N y`. The premise gives two things: every state outside the target is listed, and if G holds then every state is listed. The conclusion `∀ n, reaches n y → G` says nothing when G holds. So a user who does not already know whether G holds, the only case where the theorem says anything, can meet the premise only with `fun x _ => every x`, or by also listing the target. In effect it is `every`. Its one honest weaker use is when ¬G is already known: then a list of the states outside the target suffices. That is better stated as itself (not built): `(outside : ∀ x, ¬ W₀ x → x ∈ all) (short : ¬ reaches N y) : ∀ n, ¬ reaches n y := fun n r => short (reach_within_length (fun x h => outside x (fun w => short (h w))) n r)`. Land the theorem with `every`, and add this corollary if wanted.
