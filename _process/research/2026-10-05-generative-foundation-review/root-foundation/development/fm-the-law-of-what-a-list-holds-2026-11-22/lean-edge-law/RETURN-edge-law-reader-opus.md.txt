**Q4. Each case calls the law once, except the reach result.**
- `held_iff_iter` calls `iter_largest`.
- `kernel_iff_iter` and `kernel_iff_lasts_length` go through `held_iff_iter`.
- `continues_persists_case` and `viable_persists` call `iter_persists`.

- `rise_not_not` calls `iter_persists` at the dual step.
- The bridges (`iter_iff_*`, `iter_region_iff_lasts`) are inductions on n, not on places.

`reach_shorten_at_places` alone is an induction on places. It is a case, at a step on predicates built from G, not at the dual. Write F_n z := (reaches n z → G). Two constructive facts give F_{n+1} z ↔ (W₀ z → G) ∧ ∀ t, R z t → F_n t:
- (A ∨ B → G) ↔ (A → G) ∧ (B → G);
- ((∃ t, R z t ∧ X t) → G) ↔ ∀ t, R z t → X t → G.

So F_n is the n-th iterate of `regionStep R (fun x => W₀ x → G)` from `fun x => W₀ x → G`. Sketch, not built:

```lean
theorem reach_imp_iff_iter (G : Prop) : ∀ n z,
    (reaches n z → G) ↔ iter (regionStep R (fun x => W₀ x → G)) (fun x => W₀ x → G) n z
  | 0, _ => Iff.rfl
  | n + 1, z =>
    ⟨fun h => ⟨fun w => h (.inl w),
       fun t r => (reach_imp_iff_iter G n t).mp fun p => h (.inr ⟨t, r, p⟩)⟩,
     fun ⟨here, later⟩ path => path.elim here
       fun ⟨t, r, p⟩ => (reach_imp_iff_iter G n t).mpr (later t r) p⟩

theorem reach_rise_shortens (every : ∀ x, x ∈ all) {y : S} :
    reaches (all.length + 1) y → reaches all.length y :=
  (reach_imp_iff_iter (reaches all.length y) _ y).mpr
    (iter_persists (region_mono R _) (fun _ h => h.1) (fun x _ => every x)
      ((reach_imp_iff_iter (reaches all.length y) _ y).mp id))
```

- `reach_shorten_at_places` is `extend_at_places` at that step, read through the bridge, with the old cover. Its cover is stronger than the new law needs.
- It does not come at the dual step. The dual of `reachStep` matches `¬ reaches` only up to the double negation that `iter_dual_iff` pays for with `every`, and it gives only ¬¬.
- The bridge is exact because `reachStep` is built from ∨ and ∃ only. For `loseStep`, `(… ∀ a, Enabled → ∃ t, …) → G` is not a function of `X → G` without a decision. That is consistent with `lose_edge_decides` (argued), and it is the reason the kinds differ in (c).
