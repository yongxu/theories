```lean
theorem remove_place {y : S} : ∀ {l : List S}, y ∈ l →
    ∃ rest : List S, l.length = rest.length + 1 ∧ ∀ z, z ∈ l → z = y ∨ z ∈ rest

theorem horizon_pred : ∀ {n s}, Horizon P guard (n + 1) s → Horizon P guard n s

theorem extend_at_places : ∀ (n : Nat) (left : List S), left.length = n →

theorem horizon_persists {all : List S} (every : ∀ x, x ∈ all) {y : S}
```

**Part 3 · The course theorem as a case.** An enabled pair `(a, z)` has exactly the outcome `z`.

```lean
def pairProcess (P : Process S A) : Process S (A × S) :=
  ⟨fun y p z => P.step y p.1 z ∧ z = p.2⟩

theorem continues_iff_horizon : ∀ n s, Lasting.Continues P n s ↔
    Horizon (pairProcess P) (fun _ => True) n s

theorem continues_iff_viable {S A : Type} {P : Process S A} (n : Nat) (s : S) :
    Lasting.Continues P n s ↔ Viable (pairProcess P) (fun _ => True) n s

theorem continues_persists_case {all : List S} (every : ∀ x, x ∈ all) {y : S}
    (continues : Lasting.Continues P all.length y) :
    ∃ a z, P.step y a z ∧ Lasting.Continues P all.length z

theorem continues_same : @continues_persists_case.{u,v} = @Parting.continues_persists.{u,v} := rfl
```

**Part 4 · Through a reading.** States, moves, observations and codes have independent universes. These are the auxiliary process, the transfer theorem and the exact closed-family condition.

```lean
def codeProcess (P : Process S A) (sense : S → A → S → O) (allowed : S → A → Prop)
    (decode : C → S → Prop) : Process C A :=
  ⟨fun c a d => Usable P allowed (decode c) a ∧
    (d = c ∨ ∃ o, ∀ s, decode d s ↔ Seen P sense (decode c) a o s)⟩

theorem code_horizon_of_kept : ∀ {n c}, KeptFor P sense guard allowed n (decode c) →
    Horizon (codeProcess P sense allowed decode) (fun d => ∀ s, decode d s → guard s) n c

def InClosedFamily (P : Process S A) (sense : S → A → S → O) (guard : S → Prop)
    (allowed : S → A → Prop) (B : S → Prop) : Prop :=
  ∃ F : (S → Prop) → Prop, F B ∧ (∀ D, F D → ∀ s, D s → guard s) ∧
    ∀ D, F D → ∃ a, Usable P allowed D a ∧ ∀ o, F (Seen P sense D a o)

variable {all : List C} (every : ∀ c, c ∈ all)
  (updates : ∀ c a, Usable P allowed (decode c) a → ∀ o,
    ∃ d, ∀ s, decode d s ↔ Seen P sense (decode c) a o s)

include every updates

theorem coded_kept_iff_closed {c : C} :
    KeptFor P sense guard allowed all.length (decode c) ↔
      InClosedFamily P sense guard allowed (decode c)

theorem coded_kept_iff_every_horizon {c : C} :
    KeptFor P sense guard allowed all.length (decode c) ↔
      ∀ n, KeptFor P sense guard allowed n (decode c)
```

| Theorem | What it calls |
|---|---|
| `code_horizon_of_kept` | Recursion on `n`. The same-code successor witnesses enabledness even for an empty observation type. `KeptFor.shorter` handles this successor and `KeptFor.mono` handles a represented observation. |
| `coded_kept_iff_closed` | `code_horizon_of_kept`, `horizon_persists`, `updates` and `Seen.mono` forward, `keptFor_of_closed` backward |
| `coded_kept_iff_every_horizon` | `coded_kept_iff_closed` and `keptFor_of_closed` forward, evaluation at `all.length` backward |

## 4. What blocked

Parts 1–4 have no outstanding blocker. Build 3 flagged an unused binder. Build 6 exposed two elaboration issues in Part 4. The proof now includes the section hypotheses explicitly and extracts the guard by matching on a general horizon.

For optional Part 5, the filed `Drain` case gives the following classification.

- **Reading the level puts the two starts in a closed family.** Take subclasses of the starts together with classes confined to one lane above zero. From the starts, move `true` leaves the true lane at level 2 and the false lane at level 1. Each observed successor is therefore confined to one positive lane. Matching that lane preserves its level thereafter. A closed family containing the starts would keep them for three steps by `keptFor_of_closed`, contradicting `together_not_kept_none`.
