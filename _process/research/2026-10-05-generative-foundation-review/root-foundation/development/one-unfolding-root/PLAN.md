## 一、目标

**总的志向**：查明古文是否提供了一种可重构、可推广的生成文法。五月的工作说：“Lean 是 framework verifier / 古文 是 framework 的本身”（[README](../../../../../../theories/jian-and-wenyan-as-formal-language/README.md)）。这是要检验的假设，不是前提。

**问题**：找出一种最小的组合语言，由它可以重构任一可辨之样式的生、住、异、灭，并保留其解释可被检验的条件（来源二篇之一的表述，略改）。

**为什么以续为中心，以及为什么续必须相对于类**：

- **四个位置是一条续的四种读法。** 续之始为生，续之中为住，续中所异为异，续之尽为灭。这样，生住异灭就是同一件事从不同的位置读出，不是四件事、四套解释。这一历时的读法，最近于《俱舍论》卷五以相续说四有为相（待核原文，仓库尚无此书）。
- **位置不自立，而相对于类。** 同一事，在一个类下是生，在另一个类下是住。《起信论》说“以四相俱時而有，皆無自立”：在它的原意里，四相是一念之中同时具有的心相，属于不觉，而“念念相續”是无始无明。所以这里只取一个结构上的对应：位置依于类，不能单独成立。这是 AI 重构，原意（心相、不觉）在这一对应中丢失，记下。
- **成与坏是同一些事在粗细两类下的读法。** 《金师子章》（法藏本文）说“諸根合會是成相，諸緣各住自位是壞相”：在粗的类下诸根合为一（成），在细的类下诸根各住其位（坏）。这是一时之中的两读，不是先成后坏。
- **续不要求成分不变。** 《庄子·养生主》说“指窮於爲薪，火傳也，不知其盡也”。《荀子·正名》（仓库本作简体）说“状变而实无别而为异者，谓之化。有化而无别，谓之一实”：这是制名之法。处所用来计二实（“状同而为异所者……谓之二实”）；一实由“化而无别”定义，并没有说“同所故一实”；同异之据在“缘天官”与“约定俗成”。用本计划的话说：在“实”之类下为续，在形状之类下为异；“实”之类由命名之约定给出，这支持“载体之相等是模型之承诺”（§二）。
- **续而复生是递归。** 一条续的事是另一条续之始的缘；在粗的粒度上，这是同一个关系的另一种读法（§4.6）。二阶与多阶、元吸引、选择之被选择，都从这里来。

**中观之两难与本计划的回答。** 《中论》青目释说“若一則無緣，若異則無相續”：因果若是一，就无所谓缘；若是异，就无所谓相续。《观成坏品》把“因果相續故，不斷亦不常”列为对方之说，而以“三世中求有，相續不可得”作结。

本计划的回答（AI 读法）分两层：

- **非一非异。** 续是相对于两个类而说的：在类 E 下为同，在更细的类 F 下为异。这样，一与异都只是相对于类的。中观所破的，是有自性的相续；相对于类的续，是一种依类而立的说法，近于“眾因緣生法……亦為是假名，亦是中道義”（《观四谛品》）。
- **缘不要求同在。** 两难中的另一问是“為滅已相續？為不滅相續？”（《观业品》青目释）：相续之时，缘是已灭还是未灭？本计划的缘是事与事之间的关系，不是一种要求缘与果同在的作用。这是一个建模的承诺。它是否答复了这一问，列为开放。

《中论》的第七、十七、二十一品登记为反读（§三 己类）。归类所见更直接：本计划的回答，正是《观成坏品》中的对方之说，“生滅故不常，相續故不斷”（ZL-21-120），龙树以“滅更不生故，因即為斷滅”（ZL-21-122）破之；同在之两难最清楚之形在“若至若失”一段（ZL-21-088 至 092）；《观三相品》并破互生与同时生（ZL-07-051、066），针对 §4.1 的“缘可以互相、同时”。所以本计划的回答之成败，系于“缘不要求同在”这一建模之承诺能否站住，列为开放，并在 OU2 中写成形式之问。第二轮归类又见：《观业品》中“非一非异”也是对方之说（ZL-17-141、146），本计划的粒度之读亦然（ZL-17-041）；龙树自己的“雖空亦不斷，雖有亦不常”立足于空（ZL-17-097），不立足于续。所以本计划之续所站的位置，是《中论》所破的那一边（有部、经部、唯识之相续）；“相对于类的说法”与“空”是否同义，列为开放，不说二者相同。另一方面，《观四谛品》（ZL-24-181、185）与“有常则续不尽”“有亡之续则不有常”同形：若法有常，即无生灭。《因灭而续》（`Becoming.GrammarReadings`）只把这一回答在相等之类与较粗之类之间写成定理，不处理同在之问。

**根是什么**：古文自身的文法，写成无点的关系演算；其定理对每一个载体与关系成立。中心是相对于类的续；际以缘为主义。Lean 的作用是检验，不是提供框。

**两项检验**：

- **可重构**：冻结的语料中每一句归入 §三 之一类，并给出其在文法中的形式；读不进的，记下原因。
- **可推广**：文法之定理与有条件之律，在古文之外的模型中有实例：火焰、细胞、机构、信念系统、无清楚边界的系统、放射衰变；生态、学习、集体与旧理论的各模型。

**现在不做的**：伦理暂缓；评价之句照样计数。

## 二、为什么根不能是框，以及载体是什么

- 先选一个框，再在框上定义一切，本身就是一种二元：先有配置，再有其间的关系。
- 形式陈述不需要先选一个框：关系演算的等式对每一个关系模型成立。在 Lean 中，这写成对任意载体类型、任意关系的全称量化。
- **载体是陈述的参数，不是本体的承诺。** 全称量化仍然要用载体；载体的元素是什么，不由量化给出。所以本计划把“事”当作在一个所述粒度上的、由其关系定位的位置（§4.1）。载体上的相等（Lean 的 `=`）是模型的承诺，与离散一样写明。文法中的每个谓词，都标明它是“在核下不变的”（只依赖关系），还是“依赖载体的”（例如时，§4.1）。

## 四、根：相对于类的续

### 4.1 原语

- **一**：根不是事，而是一。文法的定理对一的每一种分法都成立。
- **际**：关系，是文法中唯一一类基本符号。“辨、相、化”是际的三种用法：类、组合、被迭代的有向之际。
- **缘**：际的主义。`缘 x y` 读作“x 为 y 之缘”：y 之成，有 x 在其中。
  - 缘可以多对多。
  - 缘可以互相、同时：《成唯识论》“三法展轉因果同時……亦如蘆束更互相依”。
  - 这里的缘不取“所缘缘”（认识之所对），也不取《荀子》“缘天官”（依）、《庄子》“緣督以爲經”（循）之义。
- **两种读法，明写。** 在一个实有之缘网（一段历史）中，一事之诸后继是同时实有的诸果。在一个可能之网中，诸后继是可选之途，需要一个冲突关系（#：二者不能俱有）。有常与核在两种读法下是同一个公式；但验（“开窗之后”）是反事实的，只在可能之网中有义。每个模型声明它用哪一种。
- **类**：取等价角色的际（自反、对称、传递）。类是复数的：《墨经》之四同（重、體、合、類，MJ-S-089）中，重同（二名一实）本身是等价；体同、合同、类同要先固定所依之整体、处所或方面，才成为类；类同（“有以同，類同也”）一般不传递。所以每一种同，固定其所依之方面后，是一个类。
- **位**：两事同位，当且仅当在类之内、在前后两个方向的一切缘之下都不可分（双向之核，§4.4）。
  - 平稳进程的两刻同位而不同时（审查者草稿 `stationary_one_place`）。所以时与四位置，是由载体之相等区分事，不只是由关系区分事：载体之相等是模型的承诺。
  - 五月诸稿的“凡位之是其位，由其际之凡然定”是新撰的仿古之句，不是古文。
- **化与理**：同一展开的两种说法：化是它之进，理是它之类（有常之核）。
  - 理不在事之上，它本身是事与事之间的一个际（一个类），与缘同种。
  - 这与华严的理事两层不同：那里“金”在“师子”之外（《金师子章》本文“師子雖有生滅，金體本無增減”）。本计划的理事之分登记于 §5.4，并说明其别。
- **时**：
  - 可及（缘之传递闭包，`及`）一般只是预序：有互相之缘则成环。
  - 时是它的严格部分；环为同时之聚（俱有）；无环是一个丙一之条件。
  - 不可比不等于同时。
  - 下闭之集（切面）可以定义；极大反链要求无环，在无穷之网中还要求选择。

```lean
def «续» (R E : «际» α) : «际» α := «合» R E           -- 以缘相连，而同于类 E
def «相续» (R E : «际» α) : «际» α := «及» («续» R E)
def «生» (R E) y := ¬ ∃ x, «续» R E x y ;  def «亡» (R E) x := ¬ ∃ y, «续» R E x y
def «住» (R E) x := (∃ w, «续» R E w x) ∧ (∃ y, «续» R E x y)
def «异» (R E F) x y := «续» R E x y ∧ ¬ F x y      -- F 是较细之类：则 F E
```

**四处修正，按审查重写**：

1. **辨、时、续由际得出。** 时与续的定义是规定；检验在于够不够用（§三 立言）。
2. **续必经缘：这是必要条件，不是充分条件。**
   - 缘多对多。蜡烛甲之热是蜡烛乙初火之缘之一，所以在“火”之类下，甲之火续入乙之初火；乙之初火有两个续之前者（审查者草稿 `candle_splice`）。
   - 更一般地，任何一条缘，在某个二点之类下都成为续（`any_edge`）。
   - 文法把甲乙的情形表示为一个合，与分叉对偶，不替它决定。
   - 若要只取“维持”之缘，就把一个子关系 R′（含于缘）明写入判据，即以 (R′, E) 为所述之类。
   - “等无间缘”之说删去：《中论》所引的次第缘只属心法（“次第緣除……阿羅漢最後心心數法，餘過去現在心心數法”），且为其所破（“滅法何能緣？故無次第緣”）。
3. **续是关系，不是同一。**
   - 分叉之下，“同一”不传递（`«分叉»`，已检查）。
   - 同族（续之等价闭包）合并分叉之枝，是比同一更粗的说法，用作粗网之事（§4.6），不称“同一”。
4. **类是复数的；有常是相容，不是根据。**
   - 缘为全关系时，每一个类都有常（astra 审查）。所以有常只说一个类与缘相容，不说这个类有根据。
   - 一个类的根据，在于它本身由关系读出（例如某一耦合之读的核）、它的预言之效与稳健。这是丙一与验的工作，不由规定。

**新定理：有常则续不尽。** 若类 E 对缘有常，则凡有续之前者，必有续之后者；E 甚至不必对称（审查者草稿 `steady_continues`，已检查）。

- 所以一条会终了的续，其类必不有常。“这条续有没有自己的理”，不能用“类自身有常”来问。
- **续之理是其类之核**（`核 R E`）：核总存在，总有常。要问的是核有多深、分几类。火之续，其理按剩余之寿而分。
- 类自身有常，是核之零深的特例：其续永不终了。
- 先前“续之核”一说的更正保留：以核为类，火便无续（`«以核为判据则火无续»`，已检查）。

**四个位置**：

- 构造上可证：生与住不并、住与亡不并。
- 孤立之事既生又亡（一现即灭）。
- 四分（只生、住、只亡、生而亡）只在可判定之时成立：“每一事或生或有前，对一切模型”恰是排中律（`«四相之定当且仅当排中»`，已检查）。
- **四相无自立**（乙）：在一个无自环之缘网中，有前有后之事，在“一”之类下是住，在“静”（相等）之类下是生而亡。同一事同时居不同之位，位依于类。
- 《起信论》之“俱時”属于文本的登记（§5.4），不是这条定理的出处。

**灭与补。** 只对测试 p 而言：x 在 p 之续中亡，且有 R x y，则只得 ¬p y；不得“y 是 ¬p 之续之生”（审查者草稿 `end_not_beginning`）。旧 `Change.CeasesToBe` 只有一个方向（`not_comes`），另一方向要双重否定之稳定，照原样引用。

### 4.4 有常、核、闭合与验

```lean
def «有常» (R E : «际» α) : Prop := «则» («而» («逆» E) R) («而» R («逆» E))   -- E˘;R ⊆ R;E˘
def «核» (R E : «际» α) : «际» α := fun u u' => ∃ S, «则» S E ∧ «则» S («逆» S) ∧ «有常» R S ∧ S u u'
def «位核» (R E : «际» α) : «际» α := …   -- 对 R 与 «逆» R 皆有常者：双向之核
```

- **根定理**（`«根»`，已检查）：核在 E 之内，有常，对称，并且包含 E 之内每一个对称而有常的关系。所以它是最大的这样的关系。它是最大者，即能分者之最细：二事在核中，当且仅当缘不能分开它们。
- **类则核亦类**（`«核».«类»`，已检查）。
- **闭合**（`«闭合当且仅当有常»`，已检查）：对一个类 E，有常当且仅当 `E;R;E ⊆ R;E`。这正是互拟等价（Park、Milner）。Kemeny–Snell 之并类是概率的，Rosas 等之计算闭包关乎 ε-机；本条是它们的关系类比，对应未证，不称“即是”。
- **双向之核**（`«位根»`，已检查）：
  - 它定位，也就是 §4.1 的“位”。
  - 亡在核下不变（审查者草稿 `cease_invariant`）。
  - 生只在双向之核下不变（`arise_invariant2`）。
  - 生住异灭因此在双向之核下不变，在单向之核下不都不变。
- **验**：在缘网之内说，不设外来的干预者。
  - 与之有缘的诸观察之关系，也写在同一个网中。
  - 可分（在某一有穷之步上分开）则不在核中：这是定理（`within_stage`，[review-checks/Root.lean](review-checks/Root.lean)）。
  - 反之，不在核中则可分：这是 Hennessy–Milner 之向，要求像有穷，其极限形式蕴涵 LLPO（[review-checks/HM.lean](review-checks/HM.lean)，该证明用了 `propext` 与 `Quot.sound`，是外围之果，待核心之证）。只作标定。
  - “开窗之后”是反事实，只在可能之网中有义（§4.1）。“可得之关系”改为“与之有缘之关系”。

### 4.5 自持、相须、因于

```lean
def «自持» (R E) : Prop := «有常» R E
def «相须» (R E₁ E₂) : Prop := «有常» R («合» E₁ E₂) ∧ ¬ «有常» R E₁ ∧ ¬ «有常» R E₂   -- 对称，非自反（已检查）
def «因于» (R E₁ E₂) : Prop := «有常» R («合» E₁ E₂) ∧ «有常» R E₂ ∧ ¬ «有常» R E₁
```

由“有常则续不尽”，这三者只适用于不终了之续：环、平稳之样式、往复。会终了之续，其相须要比较核：`核 R (合 E₁ E₂)` 与 `核 R E₁`、`核 R E₂`。这一比较是 OU2 之项，现列为开放。审查者的旧说“火之理在火与燃料之合”因此撤回，待以核重述。

### 4.6 续而复生、粗网与阶

- **粗网取类与类之间的缘**：对一个类 L，粗网是 `L ; (R ⊓ ¬L) ; L`。
  - 不取 `L;R;L`：类内之缘会在粗网中成环，使该类既不能生也不能亡（审查者草稿 `coarse_loop`、`coarse_no_arise_no_end`）。
  - 粗之事是 L 之类。对线而言，取 L 为同族。
  - 粗网中所用之类 E′ 须满足 `L;E′;L ⊆ E′`，使粗网之谓词是类之谓词。
- **复生**：x 为某一事 y 之缘，而 y 是一条续之生，且这条新续住（不是一现即灭）。
  - 在“一”之类下无复生（`«一之下无复生»`，已检查）；在“静”之类下，凡有后继者皆复生。
  - 所以复生依于类，要连同其类一起说，不能单说。
- **二阶**：`(L;R) x y ∧ 生 R E y`：粗之一族中有一事为细之一续之始的缘。这是同一个关系在两种粒度上的读法。不说“粗决定细”：粗由细而来，细在粗中被读。
- **生生**（只作续与复生之说）：一族之事，每一事都为一续之生之缘，而那条续又到达此族。生生是这样之族中最大者（最大不动点，`«生生».greatest`，已检查）。在“一”之类下无生生（已检查）。
  - 它还分不开维持生命之更新与毁灭之更替；这要比续更多的内容（§七）。
  - 《中论·观三相品》论“生生”（本生、生生）之无穷倒退。本计划的递归是谓词在逐级粗化中的重读，不是“相”自身另有其“相”，所以不入此倒退。这是 AI 读法，记下。
- **息**：正面定义（OU2），与复生在同一族、同一量词域上说。不以“非复生”为息，因为“或复生或息”要排中律。
- **深**：从类 E 看去，自递归细化最早稳定之步；“极限即核”在只有有限分支时蕴涵 LLPO，只作标定。**神**另立：无前缀能定下一值，与深互不蕴涵。

### 4.7 文法有多强：配对、幂、不动点；与 Lean 互译

（第八版 §4.6 的论述保留，见 [history/PLAN-v8.md](history/PLAN-v8.md)。）按审查改：

- 配对与幂只是猜想。《墨经》“體，分於兼也”与“體，若二之一，尺之端也”说的是部分与整体、度之端，不是函数性的投影；“兼三材而兩之”是合三者。“各指其所之”的“所之”是所趋之向；《荀子》之“所”是处所。要有一处语料用例给出函数性的投影，猜想才成立。
- 不动点：及（最小）、核与生生（最大）、系含系（μ）。不穷要用依赖选择才得无穷之串，接旧的 `runs_iff_dependentChoice`。
- 互译以明确的片段为目标，不说“文为 Lean 奠基”。

## 五、古文已有的文法：句式、链、语料

### 5.1 句式与“相 X”

定义、一 X 一 Y、X 则 Y、X 而 Y 生、由一而分、反复、两者同出而异名；《墨经》的“X，Y 也”；“相 X”逐一分类。孔疏《序卦》记周氏的六门之分，又说“故不用周氏之義”：周氏之分只作材料，不作依据。

### 5.2 链

第八版的链保留（§5.2，[history/PLAN-v8.md](history/PLAN-v8.md)）。新增与改正：

- **相续**（立）：《成唯识论》“「恒」言遮斷，「轉」表非常，猶如瀑流”（CWS-P4-017）；“非斷非常是緣起理”（CWS-P4-023）；种子“恒隨轉……一類相續”；“三法展轉因果同時……亦如蘆束更互相依”。其论证从关系之续走到所藏之处：经部之续因无阿赖耶持种而被斥为不成（CWS-P4-059）。理由在于空缺：中间无事承载样式时，样式之再现在本文法中是新的生，除非缘网中有事在某类下连起两端；阿赖耶即被立为这样的类。本计划不立所藏之处，而把“空缺之后的再现何时是续”写成丙一之问（OU2）。其“恒”至阿罗汉位而舍（CWS-P4-062），所以“恒”不是 «有常»。同在之第三种答法：因灭果生在同一时，“如秤兩頭”（CWS-P4-032）；并分俱有之缘（种子生现行）与次第之缘（种子生种子，CWS-P3-018）。
- **相续**（破，己类）：《中论·观业品》“如芽等相續……不斷亦不常”为对方之说，青目问“為滅已相續？為不滅相續？”；《观成坏品》“因果相續故，不斷亦不常”为对方之说，结以“三世中求有，相續不可得”，青目“有有相續，皆從愚癡顛倒故有，實中則無”；《观三相品》“云何於一處，一時有三相？”。
- **四相**（共时，心相）：《起信论》“念念相續，未曾離念故，說無始無明。若得無念者，則知心相生住異滅，以無念等故……以四相俱時而有，皆無自立”；“心起者，無有初相可知”（一个模型性质：无事为生）。
- **《五教章》之六相**（`FO2-FQ.txt`，已冻结）：坏是“諸義各住自法”，不是后来之灭（WJZ-P1-024、118）；“秖由異故，所以同”（WJZ-P1-093）；成依于坏（WJZ-P1-107）。这些比本文法更强，不是文法之定理，要写成前提。
- **六相**（法藏本文）：“師子是總相，五根差別是別相；共一緣起是同相，眼耳各不相到是為異相；諸根合會是成相，諸緣各住自位是壞相”。《五教章》“壞相者，諸義各住自法，不移動故”，舍与椽之喻，“椽是因緣，由未成舍時無因緣，故非是緣”（缘因果而成缘，见下）。
- **缘因果而成**：《中论·观因缘品》“因是法生果，是法名為緣”，青目“緣成由於果”。这与本计划的“缘是事与事之间的关系”相合：缘不先于其所缘之果而成其为缘。
- **火传**：《庄子·养生主》“指窮於爲薪，火傳也，不知其盡也”；郭象之注（待核）；《中论·观燃可燃品》（燃与可燃）。
- **一实**：《荀子·正名》“物有同状而异所者，有异状而同所者，可别也。状同而为异所者，虽可合，谓之二实。状变而实无别而为异者，谓之化。有化而无别，谓之一实。此事之所以稽实定数也。此制名之枢要也”；“验之所缘以同异”（待核）。
- **《墨经》**：“化，徵易也”（說：“若鼃爲鶉”）；“久，彌異時也”；“宇，彌異所也”；“始，當時也”（說：“始當無久”，待核）；“同，異而俱於之一也”；“同，重、體、合、類”（待核）；“體，分於兼也”；“有以同，類同也”。化在“爲，存、亡、易、蕩、治、化”之列，而“爲”由知与欲来定义：化在墨经中有作为之义，记下。多义登记：“生，刑與知處也”（生为“活着”）；“已，成、亡”（一词兼成与亡）；“盡，莫不然也”（量词）；“窮，或有前不容尺也”（处所之极）。
- **王夫之《周易外传》卷五**（`sources/zhouyi-yizhuan/commentary/waizhuan-5.json`）：“萬變之理，相類相續而後成乎其章”，近于“续 = 缘 ∧ 类”与“成文”；“繼之則善矣，不繼則不善矣”属伦理之读，暂缓，计数。在那里续是正面之价，与《起信论》以念念相续为无明相反。
- **位依于类之例**：《金师子章》“但是金生”（P-05-002），在师子之读下为生、在金之读下为住；法藏以金之读为正见，并把“緣生念念生滅”（最近于本计划之续）列为五教之最低（P-06-003），登记。《墨经》：同一事自前为“且”、自后为“已”（MJ-S-033）；“已，成、亡”随所追踪者而读（MJ-J-078）。《老子》“死而不亡者壽”（LZ-33-006）合于“亡于细者不必亡于粗”。

每条链在第 0 步按 §三 逐句归类。

- **《金师子章》**：
  - 本文之相分：“以金收師子盡。金外更無師子可得”；“師子雖有生滅，金體本無增減”。
  - 本文之不二：“主伴交輝，理事齊現”。二者同在一篇，都记下。
  - 注之句（“金喻一真之性，師子喻緣起事法”“理本無生”“顯法界中無孤單法”）属承迁，单独登记。
- **《起信论》**：
  - 不二之形：“依一心法，有二種門……二門不相離”。
  - 所依之不对称：“依如來藏故有生滅心”（待核）。
  - 唯心之域（“三界虛偽唯心所作”）：登记为定域。
  - 其书以念念之相续为无明、以“滅相續心相”为所向：与本计划对续的中性之用反向，登记为反读之一种；但只限于念之相续，“以體不滅，心得相續”（JS-167）与无尽之净相续不是无明，其据是体，不是类。
  - 四种觉逆知四相而得“無初相”（JS-041 至 046）：在这部书里，生之位没有实例。
- **《中论》**：
  - 第七、十七、二十一品为反读（己类）。
  - 二谛为定域，并记下青目以“世間”与“聖人”分之，是知者之分。
  - 刹那用以破次第缘与住，记下；刹那与离散之时是两个承诺，分别登记。
- **本计划自己的一对**：理（核）与事。须说明它与华严之理事不同：本计划的理是事之一类，是与缘同种的一个际，不是在事外不增不减之体。本计划把这一点作为论证写出，同时登记为待审之对。

## 六、模型：诸框

| 模型 | 是什么 | 它的性质 |
|---|---|---|
| **实有之缘网**（主） | 一段历史中的事与缘：出现网、因果集合一类 | 诸后继是同时实有之果；时为可及之严格部分，须无环；切面为下闭之集；载体之相等为模型之承诺 |
| **可能之网** | 带冲突关系之事件结构；一步展开（态与一步之关系）是其一种 | 诸后继为可选之途；验在其中有义；一步展开另有离散、整体之步、当前态定其后诸性质 |
| 旧 World | 一种关系项，八个字段 | 以上，另加取与、水平之自然数 |

| 生态与集体诸模型 | 旧理论的 RegimeMargin、Optimum、联合超出等 | 量为整数或实数；平衡；耗散 |
| 连续模型 | 实数时间（外围） | 非离散 |

## 七、地图：生成与退化

地图的谓词写成续与缘的无点之形；它们在哪些模型类上取到哪些值，是丙一的工作。

- **通**：从 x 起之续不穷（“往来不穷谓之通”）。由有常则续不尽，凡有常之类，其有前之续皆通。
- **穷**：续不能继（亡），而其缘已尽；**息**：正面定义，见 §4.6；**相病**：“賁盡致剝，進極致傷”；**物壮则老**。
- **复生与息**：在同一族、同一量词域上定义，不重叠由构造给出，不由否定给出；“或复生或息”只在可判定时成立。“生成”不指任何新组织：只指为一条新续之始之缘，且这条新续住。
- **生成与退化**：要比续与复生多出的内容（维持生命之更新与毁灭之更替之分），在 OU2 中由旧理论的定律（宽与窄、所及之得失、联合超出）在缘网上重述后给出，现列为开放。
- **一步之得失**（可能之网）：辟——一步之后一步可及之类，有前所无者；阖——前有而今无者。所及沿一步只会收窄。
- **势**：一个测试 p，其后继仍在 p 中，且其盆中每条进程都进入它；归纳定义，“每条进程”之形为标定。**势之五问**、**元吸引**（粗网之续，其缘与细网之续之生住相连；与旧工作定义的对应要证明）、**几与定**同第九版。
- **生生之阶**：§4.6。

**地图的完成**：由谓词生出的每一个相容之格，在每个模型类上要么有见证，要么被证明为空；相邻格之间的边界是“Y 当且仅当 Z”；每种过渡证明可能、不可能，或列为开放。

## 十、工作规则

1. **古文先行**：运算从古文自身的句式读出；不先选框。
2. **对一切模型证明**：乙类不借任何模型的性质；用了的是丙类（丙一或丙二）。不翻译旧定理。
3. **古义与形式双向校验**：
   - 每条读法标“AI 重构”，注明所从注疏；义之所失如实记下；相分与反读不回避。
   - 新撰的仿古之句，包括来源二篇的“文理六则”与五月诸稿的新撰句，只作文风草稿，不当作古文。
4. **版本纪律**：每部文本用 §5.3 所定之本；引文照仓库本之字形（《荀子》作简体）；注与本文分开引，引注必注明为注。
5. **一词一物；逐点等价；不先断言对应**（“X 即 Y”在二者都定义并证明之前只写作待证；与外部文献的对应写作“类比，未证”，直到证明）。
6. **一元检查**：新定义过三问；中英文都查二元之词。已改：判据改为类，载体改为域或参数，观法改为说法，主读法改为主义，可得改为与之有缘。
7. **外部文献先行**：已有的不重证，只写对应；不把他们没说的归给他们。
8. **零公理**：只用 prelude；概率与连续只在外围；用了 `propext` 等的检查（如 HM.lean）标为外围之果。
9. **一条线**：在工作板上认领，经队列落地；冻结新的应用项目。
10. **先检查后写字。**
11. **名**：文法之词在 Lean 中用 «中文» 名，模块头给出中英绑定表，docstring 用英文。
12. **续必经缘**；类明写；需要“维持”之缘时，子关系一并明写。
13. **核下不变与依赖载体**：每个谓词标明属于哪一种。
