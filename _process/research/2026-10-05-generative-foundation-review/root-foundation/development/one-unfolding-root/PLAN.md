## 一、目标

**总的志向**：查明古文是否提供了一种可重构、可推广的生成文法。五月的工作说：“Lean 是 framework verifier / 古文 是 framework 的本身”（[README](../../../../../../theories/jian-and-wenyan-as-formal-language/README.md)）。这是要检验的假设，不是前提。

**问题**（按两篇来源之一的表述，略改）：找出一种最小的组合语言，由它可以重构任一可辨之样式的生、存、变、亡，并保留其解释可被检验的条件。

**为什么以续为中心**：

- 生、存、变、亡若各立一名、各有其律，就是四种现象，四套解释。它们其实是一条续的四个位置：续之始为生，续之中为存（住），续中所异为变，续之尽为亡。这是同一件事从不同区间读出，不是四件事。古文已经这样说：《大乘起信论》“以四相俱時而有，皆無自立”；《金师子章》“諸根合會是成相，諸緣各住自位是壞相”。
- 续不要求成分不变：薪尽而火传（“指窮於爲薪，火傳也，不知其盡也”，《庄子·养生主》）；状变而实无别（“狀變而實無別而為異者，謂之化；有化而無別，謂之一實”，《荀子·正名》，仓库本作简体）。
- 续而复生：一条续，在更粗的粒度上，本身是更粗之缘网中的一件事；已成之文复为他文之缘。二阶与多阶、元吸引、选择之被选择，都由这一递归给出。
- 第八版的根（有常与有常之核）不被取代：它成为“这条续有没有自己的理”的判据（§4.4）。

**根是什么**：古文自身的文法，写成无点的关系演算；其定理对每一个框成立。以“续”为中心，以“缘”为际之主读法。Lean 的作用是检验，不是提供框。

**两项检验**：

- **可重构**：冻结的语料中每一句，归入 §三 的类之一，并给出其在文法中的形式；读不进文法的，记下原因。
- **可推广**：文法之定理与有条件之律，在古文之外的模型（火焰、细胞、机构、信念系统、无清楚边界的系统、放射衰变；生态、学习、集体与旧理论的各模型）中有实例。

**现在不做的**：伦理暂缓；评价之句照样计数，不从分母中删去。

## 二、为什么根不能是框

- 先选一个框（态的类型、一个一步关系），再在框上定义一切，本身就是一种二元：先有载体，再有关系（P69 已指出“配置先于其间的关系”）。
- 形式陈述并不需要先选定一个框：关系演算中的等式对每一个关系模型都成立。在 Lean 中，这写成对任意载体类型、任意关系的全称量化。
- 这样，每条律依赖什么就看得见：“有无相生”不依赖任何框的性质；“穷则变”只在满足某些条件的模型中成立；某条静止之律只在离散、量为整数的模型中成立。

## 四、根：以续为中心的文法

### 4.1 原语

承五月工作（[README](../../../../../../theories/jian-and-wenyan-as-formal-language/README.md) “One primitive”“Two duals”两节）：

- **一**：根不是事，而是一。文法的定理对一的每一种分别都成立。
- **际**：关系；文法中唯一一类基本符号。
- **缘**：际的主读法。载体是事（发生），`缘 x y` 读作“x 为 y 之缘”：y 之成，有 x 在其中。缘可以是多对多的，不必是线性的因果之链（来源二篇之二已说明）。
- **位**：由其际定（“凡位之是其位，由其际之凡然定”）：位是什么，完全由它的全部关系决定；位的同一，就是关系上的不可分（有常之核，§4.4）。
- **化**与**理**：一个现象的两种观法，进程与其不变式；在根上，理就是有常之核。
- **时**：不是原语。在缘网中，时是缘的传递闭包所给的先后（因果集合的“由因果之序得时间”）；在指定了一个标准进程的模型中，时以它计。

**辨、相、化**（来源二篇之二的生成之最简）都是际：辨是取等价角色的际（分别），相是际的组合，化是被迭代的有向之际。三者是一种符号的三种用法，不是三种原语。

五月工作自己标明的限度一并承接：一元是“规定的而非证明的”；文法与本体对齐不证明本体为真；“claim strength exceeded proof strength”；跨领域的对应要逐一核。

### 4.3 续：中心

```lean
-- 设计草图。载体 α 是全称量化的变元；R 读作缘，E 为分别（判据）。
abbrev 际 (α : Type) := α → α → Prop
def 合 (R S : 际 α) : 际 α := fun x y => R x y ∧ S x y

def 续 (R E : 际 α) : 际 α := 合 R E                 -- 以缘相连，而同于 E
inductive 相续 (R E : 际 α) : 际 α                    -- 续之不穷：传递闭包
  | one  : 续 R E x y → 相续 R E x y
  | more : 续 R E x y → 相续 R E y z → 相续 R E x z

def 有前 (R E) (y : α) : Prop := ∃ x, 续 R E x y
def 有后 (R E) (x : α) : Prop := ∃ y, 续 R E x y
def 生 (R E) (y : α) : Prop := ¬ 有前 R E y          -- 续之始
def 亡 (R E) (x : α) : Prop := ¬ 有后 R E x          -- 续之尽
def 住 (R E) (x : α) : Prop := 有前 R E x ∧ 有后 R E x  -- 续之中（存）
def 异 (R E F : 际 α) : 际 α := fun x y => 续 R E x y ∧ ¬ F x y   -- 续中所变：较细之分别 F 有异
```

**四处修正**（来源二篇的形式脚手架改为一元，且不空）：

1. **辨、时、续都由关系得出。** 时是缘的传递闭包之序；续是“以缘相连而同于一分别”；辨是分别（等价之际），其最细者由缘自身给出（有常之核）。所以立言之最简包含在成文之最简里（来源自己也疑此：“temporal order may be encoded…continuity might be definable”）。这一可定义性在第 2 步证明；删去缘或删去分别之所失，以反模型示之。
2. **续需要事与事之间的缘，只有整体之态不够。** 蜡烛甲灭、蜡烛乙点着，整体之态的读法“有火”是连续的，却不是同一团火；“火传”与“一火灭、一火生”之分，在于前者的事是后者之缘（佛典称等无间缘）。所以际以缘为主读法，载体是事；整体之态与整体之步是缘网的切面，由缘得出。第七版公开的“每一步都是整体之步”这一承诺因此去掉，同时之事（“日月相推”）也自然有了。
3. **续是关系，不是同一。** 分裂与合并（变形虫、河流分汊、机构一分为二）之下，“同一”不传递（Parfit）。续允许分叉；“同一个”要相对于一个分别与一条谱系来说；在分叉处，生、亡本有歧义，文法把歧义表示出来，不替它决定。
4. **判据不能任意，但也不只一个。** 来源的警告（不受约束的规则能拟合任何序列）也适用于续的判据 κ。约束有二：其一，续必经缘（续含于缘）：不以缘相连者，不得称续；其二，判据就是分别 E，物质的、功能的、制度的判据是不同的 E，都在同一个缘网中，各给出一组续；一个样式在细的 E 下亡，在粗的 E 下可以存（文明亡而语言续）。至于这条续**有没有自己的理**（在 E 的粒度上自成动态），由 E 是否有常来定，不由选择来定（§4.4）。

  **更正本会话先前的一句**：先前说“续之核”即“沿缘有常的最大延续”，并以续为“缘与有常之核的合”。这不对：一个会终了的样式，其相邻两事一般不在同一个有常之核类中（剩余寿命不同，未来不互拟）；以核定义续，续会近乎为空。所以续只用分别 E 定义，有常只用来判定续有没有自己的理。草稿反例：三刻之火 f₀→f₁→f₂→灰，E 分“火/非火”，则 f₁ 与 f₂ 不在 `核 R E` 中（第 1 步写入 Lean）。

**草稿中的定理（待 Lean，乙类）**：

- 续含于缘；相续含于时（缘之传递闭包）。
- 粗化：E ⊆ E′ 则 续 R E ⊆ 续 R E′；故在 E′ 下亡者在 E 下亦亡，在 E 下住者在 E′ 下亦住；反之不然（反模型）。
- 取 E 为一（全关系），续即缘：一之续就是整个缘网；大化以此为续。
- 分叉：存在模型使“同一”（相续之自反对称闭包）不传递。
- 四相之定：“每一事或生或有前”对一切模型成立，当且仅当排中律（取 α 为单元、R 为常值命题即见）。所以四相俱时而有，而每一事落在哪一相，构造上并不总可判定；在有穷、可判定的模型中可判定。这是一条标定，与旧的 `law_iff_em` 同形。
- 亡与生：某分别之亡即其补之生（旧 `Change.CeasesToBe` 已对任意命题陈述，无前提），在缘网中的对应形式待写。

### 4.4 有常与有常之核：续之理与验

```lean
def 而 (R S : 际 α) : 际 α := fun x z => ∃ y, R x y ∧ S y z
def 逆 (R : 际 α) : 际 α := fun x y => R y x
def 则 (R S : 际 α) : Prop := ∀ x y, R x y → S x y
def 有常 (R E : 际 α) : Prop := 则 (而 (逆 E) R) (而 R (逆 E))        -- E˘;R ⊆ R;E˘
def 核 (R E : 际 α) : 际 α := fun u u' => ∃ S, 则 S E ∧ 则 S (逆 S) ∧ 有常 R S ∧ S u u'
theorem one (R E : 际 α) :
    则 (核 R E) E ∧ 有常 R (核 R E) ∧ 则 (核 R E) (逆 (核 R E)) ∧
    ∀ S, 则 S E → 则 S (逆 S) → 有常 R S → 则 S (核 R E)
```

- 第七版的 `Carries` 正是“有常”的点式写法；二者等价已在草稿中证明，公理报告为空（`PF.carries_iff`，[review-checks/PointFree.lean](review-checks/PointFree.lean)）；审查者检查过根定理（[review-checks/Root.lean](review-checks/Root.lean)）。
- **续之理（闭合）**：对一个等价的 E，粗之缘网是 `E ; R ; E`（一类之事为另一类之事之缘，当且仅当其中有一事为另一事之缘）。草稿定理：E 有常，当且仅当 `E;R;E ⊆ R;E`，即粗网之缘只看本事之缘便定，不必看同类之他事。这是非确定情形下的 Kemeny–Snell 并类，也是 Rosas 等之“计算闭包”的关系形式。续有自己的理，就是其分别有常、粗网闭合。
- **验**：恒温器与热平衡，开窗之前历史相同，开窗之后分开。一元的写法里没有外来的干预者：开窗是一个更宽的缘网的一部分。两种机制可分，当且仅当在那个更宽的关系下它们不互拟（不在同一有常之核类中）；不可识别，就是在一切可得的关系下互拟。Pearl 的干预在这里是“更宽关系下的比较”。作为方法，验留在根之外（来源亦言“观·验”是方法，不是构成）；作为形式，它就是根定理之所言。
- “动静有常，刚柔断矣”：有常则分别可定。所有结论写成逐点等价，不用 `propext` 与 `funext`。草图中的中文名在 Lean 中写作 «…»（§十 规则 11）。

### 4.5 自持、相须、因于

```lean
def 自持 (R E) : Prop := 有常 R E
def 相须 (R E₁ E₂) : Prop := 有常 R (合 E₁ E₂) ∧ ¬ 有常 R E₁ ∧ ¬ 有常 R E₂   -- 对称，非自反
def 因于 (R E₁ E₂) : Prop := 有常 R (合 E₁ E₂) ∧ 有常 R E₂ ∧ ¬ 有常 R E₁   -- E₁ 因于 E₂
```

火焰的续，其理不自持，而与燃料、空气之分别相须或因于之：火之续有理，在“火”与“燃料”之合上，不在“火”单独上。

### 4.6 续而复生：递归、深与阶

- **复生**：一事为某续之生之缘，谓之复生（`复生 R E x := ∃ y, R x y ∧ 生 R E y`）。“既成之文，复为他文之缘”：一条续（或其所成），是他续之始之缘。
- **粗化**：以分别 L 并类，得粗网 `L;R;L`；粗网中又有续、生、亡、有常。一条细续在粗网中是一事；粗网之续是“续之续”。
- **阶**：五月工作的“系含系”（μX. F(X)）是定义性的递归：分别之中有分别。生生之阶以此递归定义：一阶是细网中续之持续与复生；二阶是粗网之续，其缘决定细网中哪些续得生、得存（选择之被选择）；k 阶依次。不与“深”混用。
- **深**：从分别 E 看去，自递归细化最早稳定之步；有常之核在每一步之内；E 对称时稳定即核；只有有限分支时“极限即核”蕴涵 LLPO（[review-checks/HM.lean](review-checks/HM.lean)），只作标定。
- **神**另立：无前缀能定下一值，与深互不蕴涵。

### 4.7 文法有多强：配对、幂、不动点；与 Lean 互译

（第八版 §4.6 全文保留，略。）要点：纯关系代数只相当于三个变元的一阶逻辑；加一对配对足以写出 ZF（Tarski、Givant 1987）；加幂相当于高阶直觉主义逻辑（Freyd、Scedrov 1990）；带选择公理的 Lean 与 ZFC 加可数多个不可达基数等强（Carneiro 2019）。候选：配对——兼、两（“兼三材而两之”）；投影——“體，分於兼也”；幂——所（“各指其所之”）；不动点——不穷、相续、系含系、有常之核。检验在第 0、1 步；互译以明确的片段为目标；不说“文为 Lean 奠基”。经典逻辑以文句的形式出现：`law_iff_em` 与 §4.3 的四相之定都是例。

### 5.2 链

- **六相**：《金师子章》“師子是總相，五根差別是別相；共一緣起是同相，眼耳各不相到是為異相；諸根合會是成相，諸緣各住自位是壞相。顯法界中無孤單法”。成与坏是同一些成分的两种读法。

## 七、地图：生成与退化

地图的谓词写成续与缘的无点形式；它们在哪些模型类上能取到哪些值，是丙一的工作。

- **通**：相续不穷：续中每一事都有后（无亡）；“往来不穷谓之通”。
- **穷**：续不能继（亡）而其缘已尽；**息**：交替止；**相病**：“賁盡致剝，進極致傷”；**物壮则老**。
- **复生与息之分**：一条续在其亡之前或之时，为他续之生之缘者，属生生；亡而不为任何生之缘者，属息。二者是对同一缘网的两种读法，不重叠；“生成”不指任何新组织（只有为续之生之缘者）。
- **一步之得失**（一步展开模型）：一步之后一步可及之类的得失（辟：有前所无者；阖：前有而今无者）；所及沿一步只会收窄，所以“开”不定义为所及的扩大。
- **势**：一个测试 p，其后继仍在 p 中（p 而 R 含于 R 而 p），且其盆中每条进程都进入它；归纳定义，“每条进程”之形为标定。
- **势之五问**：成势或无势；自续（通）或死寂；困（入易出难，出口如“困，穷而通”）或可出；耗（同一余地上联合超出）或和；积化（穷则变）或守。另有往复、迁、多势并存。
- **元吸引**：粗网之续，其缘决定细网中哪些续得生、得存；它与相须之分别、旧工作定义（[10月8日](../../../../../../theories/meta-attractor/GENERATIVE-REGIMES.md)）的对应要证明，不预设。
- **几与定**：相对于一个结局与一个耦合的分别；定是此后每条进程都到达结局的最早之步；几是结局已在所记之分别中初显、而仍可改的最早之步。
- **生生之阶**：§4.6。

**地图的完成**：由谓词生出的每一个相容之格，在每个模型类上要么有见证，要么被证明为空；相邻格之间的边界是“Y 当且仅当 Z”；每种过渡证明可能、不可能，或列为开放。凡能对一切模型证明的，记为乙类。

第六版的三份审查及其采纳，见 [reviews/](reviews/) 与 [review-checks/](review-checks/)；第七、八版采纳的各条，凡仍适用者，第九版都保留（关系形式为主；有常之核与所及分开；相须、因于、自持；根定理加对称与逐点等价；极限即核只作 LLPO 标定；神与深分立；一步之得失取代所及之扩大；阖辟不评价；地图由谓词生出；势归纳定义；几与定分开；一词一物；古文引文与读法诸更正；评价之句计数；剥前提；配对、幂与互译）。

**第九版新解决的**：

- 生、存、变、亡统一为一条续的四个位置（来源二篇的核心洞见，古文中有《起信论》《金师子章》《庄子》《荀子》《墨经》的对应）。
- 递归（续而复生）给出二阶与多阶，元吸引有了一元的定义之所（粗网之续）。
- 形式审查 F2 的 (c)（每一步都是整体之步）由“缘为主读法”去掉。
- 来源二篇的形式脚手架中的二分（构形 W 与条件 C、随时变的规则 Φ_t、机制 M 与干预 do()）都化入一个缘网：条件是一个样式之缘的另一端；律从缘网中读出，律之变是递归；干预是更宽关系下的比较。

**第九版新带来的风险**，须在再审中查：

- 以事为载体是否又立了一种“原子”（有部之法的多元论）：须示事之同一是关系上的（位由际定），且事可再分（粗化与细化）。
- 续 = 缘 ∧ 分别：判据仍可多种；“有自己的理”交给有常。是否足以排除任意拼接，须以反例检验（例如把无关之事以一个人为的 E 连成一续：它含于缘这一条已排除无缘之接，但同一缘网中人为的 E 是否仍可造出“续”？）。
- 佛典之引入带来理事两层、一心本觉、刹那等承诺；须逐段登记，不让它们以一元之名混入。
- 四相之定是排中律之强：在纯核心中，四相分类只对可判定之模型成立；文中凡说“每一事属于四相之一”，须带此条件。
- 先前“续之核”一说之更正（§4.3）须在 Lean 中以反例落实。

第九版交 Opus（形式、古文两份）与 GPT astra 审查，审查后修订为第十版。

7. **剥前提**：旧理论的每条定理经依赖审计；“续”之族与五条主律、中心声明提升为乙或丙一；旧 `World` 的表示定理两个方向在 Lean 中证明（或其失败处写明）；旧工作中不留丙二，定域逐条计数；

9. **可推广**：乙类与丙一类在古文之外至少一个模型类中有实例；§六 所列检验系统各有其模型；
10. **续**：续、相续、四相、异、复生、粗网与闭合在 Lean 中定义，§4.3–4.6 的草稿定理证明或改正，四相之定的标定落实；
11. **三最简**：立言之最简的可定义性证明（或其失败写明）；穷理之最简中验之互拟形式在至少一个模型例上证明；成文之最简的总描述长度与 Pareto 报告；

## 十五、本计划不做的

- 伦理（暂缓，但其句计数）。
- 不选定任何框作为根。
- 不重做外部已完成的数学；凡已有，引用并写对应。
- 不证明整体的必然性，也不证明一元为真。
- 不把古文的贴切当作证明；丙类的“则”要有精确条件。
- 不逐条翻译旧定理；不声称 Lean 的全部可以入文，也不说“文为 Lean 奠基”。
- 不把现代的推导归给古人（来源二篇亦言）；佛典的救度论、本觉论不承接。
- 不删除任何数据，不改写 Ren 本人语气的文字，不重开已落地的结果。
- 不声称新的数学。我们的部分是：以续为中心的文法之核及其形式检验、语料逐句的归类、乙类在一切模型上的证明、丙一在模型类上的精确条件、生成与退化的地图、生生之阶、三最简之检验。
