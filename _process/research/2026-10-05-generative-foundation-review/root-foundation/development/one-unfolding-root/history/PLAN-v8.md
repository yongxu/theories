## 一、目标

**总的志向**：查明古文是否提供了一种可重构、可推广的生成文法。Ren 的判断（10月23日，本会话）是古文已经是这样一个系统，有大量现成的表达；五月的工作说得更直接：“Lean 是 framework verifier / 古文 是 framework 的本身”，以及“我认为 Chinese already is the framework，因此……我们先找是不是已经有”（[README](../../../../../../theories/jian-and-wenyan-as-formal-language/README.md)）。这是要检验的假设，不是前提。

**根是什么**：古文自身的文法，写成一种无点的关系演算。它不先给出态，不先选定一个一步关系，也不先定时间；它的定理对每一个框（每一个解释其关系符号的结构）都成立。Lean 的作用是检验，不是提供框。

**两项检验**：

- **可重构**：冻结的语料中每一句，归入五类之一（§三），并给出其在文法中的形式；定义句写成定义式的等式，文法之定理在 Lean 中对一切模型证明，有条件之律写成“Y 当且仅当 Z”、条件 Z 用文法写出，并给出 Z 不成立时的反例；读不进文法的，记下原因。
- **可推广**：文法之定理与有条件之律，在古文之外的模型（生态、学习、集体、旧理论的各模型）中有实例；生成与退化的地图（§七）在各模型类上完成。

**现在不做的**：伦理暂缓；评价之句照样计数，不从分母中删去。

## 二、为什么根不能是框

- 第一至七版都先选一个框（态的类型、一个一步关系），再在框上定义一切。这本身是一种二元：先有载体，再有关系，正是 P69 指出的“配置先于其间的关系”。古文审查说“根先定，引文后配”，原因就在这里。
- 形式陈述并不需要先选定一个框。代数定律对每一个群都成立，不必先说是哪个群；同样，关系演算中的等式对每一个关系模型都成立。在 Lean 中，这写成对任意载体类型、任意关系的全称量化：这不是选定一个框，而是声明对每一个框都成立。
- 这样，每条律依赖什么就看得见：“有无相生”不依赖任何框的性质；“穷则变”只在满足某些条件的模型中成立；某条静止之律只在离散、量为整数的模型中成立。第七版把它们一律放在一个离散、马尔可夫的框上，看上去好像都依赖那八条承诺，其实不然。

## 三、语料中每一句的归类

| 类 | 是什么 | 在文法中的形式 | 例（待第 0 步核） |
|---|---|---|---|
| 甲 定义 | 一个词由其他词规定 | 定义式的等式（逐点等价） | 一阖一辟谓之变；往来不穷谓之通；复命曰常；知常曰明；归根曰静 |
| 乙 文法之定理 | 由定义与文法的运算律推出，对一切模型成立 | Lean 中对任意载体与关系证明的定理，公理报告为空 | 若通是往来不穷、久是不息，则“通则久”由定义推出（待检）；“有无相生”“长短相较”作为相待之对 |
| 丙一 有条件之律 | 只在满足条件 Z 的模型中成立，而 Z 本身用文法的运算写出（一条关系性质） | 对一切模型证明“Y 当且仅当 Z”（或“Z 则 Y”），并给出 Z 不成立时的反例 | 穷则变（反例：困，穷而通；穷而息）；物壮则老；柔弱者生之徒；敝则新 |
| 丙二 模型之律 | 条件是“属于某个模型”，而该模型的成分是分别给定的（如旧 `World` 的八个字段） | 只是过渡：按 §九 剥前提，移入丙一或乙；移不动的登记为**定域**（只在那个模型里成立），写明它用到哪个分别给定的成分 | 旧理论的大部分定律；古文之句预计少有此类（第 0 步核） |
| 丁 评价 | 以吉凶、悔吝、利害、善作结 | 暂缓，计数 | 文不当，故吉凶生焉；爱恶相攻而吉凶生 |
| 戊 相分 | 古文自身确是二分或等级 | 登记为对“古文是一元文法”之假设的反证 | 天尊地卑；爻有等（贵贱之等）；刚柔者立本者也，变通者趣时者也 |
| 未读出 | 读不进文法 | 记下原因（词义不定、句式不明、需要文法所无的运算） | 第 0 步统计 |

归类是 AI 重构，每一句注明所从的注疏；甲、乙之分要由 Lean 来定（能否由定义推出），丙一、丙二之分也由 Lean 来定（条件能否用文法写出），不凭判断。

有条件本身不是二元：古文满是丙一。二元出在丙二，即条件指向分别给定的成分。所以目标是旧工作中不留丙二：凡留下的二元成分，都是证明确实用到的，那条定理就是关于这一分的，明写。

## 四、根：古文自身的文法

### 4.1 原语

五月的工作给出了一元的原语及其理由（[README](../../../../../../theories/jian-and-wenyan-as-formal-language/README.md) “One primitive”“Two duals”两节）：

- **一**：根不是事，而是一（“根位非事，而是一也”）。一不是一个载体，而是“整体”这一说法本身；文法的定理对一的每一种分别都成立。
- **际**：关系；虚词在文法层面实现的就是际。际是文法中唯一的一类基本符号。
- **位**：一个位“由其际之凡然定”（“凡位之是其位，由其际之凡然定”）：位是什么，完全由它的全部关系决定。这是 Yoneda 引理的形式，正好消解第七版的第 4 条承诺（态先于关系、态的同一不由变来定）：位不先给出，它的同一就是关系上的不可分。
- **化**与**理**：一个现象的两种观法，进程与其不变式（“化 : 理”即 `term : type`）。在根上，理就是有常之核（§4.3）。
- **时**：不是另一个原语，而是一个被指定为标准的进程，其余以它计其节律。离散的步数因此不是根上的承诺，而是相对于一个被指定之进程的计数，只在需要它的模型与定律里出现。

五月工作自己标明的限度一并承接：一元是“规定的而非证明的”；文法与本体对齐不证明本体为真；“claim strength exceeded proof strength”；四个名的互相规定略带循环，由“系含系”底部的良基性来断开，跨领域的对应要逐一核。

### 4.2 运算：从古文自身的句式读出

| 古文的形式 | 运算（AI 重构，待检） | 来源 |
|---|---|---|
| X 而 Y | 先 X 后 Y：有时序的、不可交换的复合 | 五月：“而 is sequential composition with time” |
| 一 X 一 Y | X 与 Y 交替：先 X 后 Y 的复合，可迭代 | 一阖一辟谓之变 |
| 相 X | 逐一分类（§五 2.2）：对逆、对称、同一分别两值之交替、比较、相须、单向之因、相病 | 第七版 §2.2 |
| 往、来；反、复 | 一关系与其逆；回返 | 往来不穷；反者道之动；各复归其根 |
| 不穷 | 无穷迭代 | 往来不穷谓之通 |
| 归、静 | 测试：停在原处的变（关系的一部分，属于恒等） | 归根曰静 |
| 者 | 由开放之句得一谓词（λ 之约束） | 五月：“者 is the λ-binder” |
| 之、其、所 | 位置（变元）；可编译为无点之组合 | 五月 |
| 也、矣 | 定：已成为事实；完成 | 五月：“也 is a settling marker”，“矣 is perfective” |
| X 谓之 Y；X 曰 Y；X 者，Y 也 | 定义式的等式 | 句式 |
| X 则 Y | 包含 | 句式 |
| 不、无 | 否定；构造上只取可用的形式（不用排中律） | |
| 两者同出而异名 | 一者，从两端名之：一关系与其逆 | 《老子》一章 |

古文有变元与约束（之、其、所、者），所以文法不是纯无点的；但带约束的式子可以编译为无点的组合（组合逻辑、带逆的关系代数），无点的形式就是它“对每一个框成立”的语义。这一编译在第 1 步写出并检验。

### 4.3 有常与有常之核，都是无点的

```lean
-- 设计草图。载体 α 是全称量化的变元，不选定任何框。
abbrev 际 (α : Type) := α → α → Prop

def 而 (R S : 际 α) : 际 α := fun x z => ∃ y, R x y ∧ S y z   -- 先 R 后 S
def 逆 (R : 际 α) : 际 α := fun x y => R y x
def 则 (R S : 际 α) : Prop := ∀ x y, R x y → S x y              -- 包含
def 谓 (R S : 际 α) : Prop := ∀ x y, R x y ↔ S x y              -- 定义式的逐点等价

-- 有常：分别 E 相对于变 R 有常，当且仅当 E 之逆而 R，含于 R 而 E 之逆（模拟的条件）
def 有常 (R E : 际 α) : Prop := 则 (而 (逆 E) R) (而 R (逆 E))

-- 有常之核：E 之内最大的、对称的、有常的关系（最大不动点）
def 核 (R E : 际 α) : 际 α := fun u u' =>
  ∃ S, 则 S E ∧ 则 S (逆 S) ∧ 有常 R S ∧ S u u'

theorem one (R E : 际 α) :
    则 (核 R E) E ∧ 有常 R (核 R E) ∧ 则 (核 R E) (逆 (核 R E)) ∧
    ∀ S, 则 S E → 则 S (逆 S) → 有常 R S → 则 S (核 R E)
```

- 第七版的 `Carries` 正是这里的“有常”，写成无点的形式（E˘ ; R ⊆ R ; E˘），所以它从一开始就不依赖框。本会话已在草稿中证明二者等价，公理报告为空（`PF.carries_iff`，[review-checks/PointFree.lean](review-checks/PointFree.lean)）；审查者也检查过点式版本的根定理（[review-checks/Root.lean](review-checks/Root.lean)）。
- 草图中的中文名在 Lean 中须写作 «…»（Lean 不接受不加括号的汉字名），或按 D4 用绑定表。
- “动静有常，刚柔断矣”（《系辞上》）在这里有形式：有常则分别可定。
- 根定理对一切载体、一切关系成立，所以是文法之定理（乙类）。
- 所有结论写成逐点等价；关系的相等需要 `propext` 与 `funext`，不用。

### 4.4 自持、相须、因于（无点）

由同一关系“合之而有常”读出，按哪一端单独有常而分（第七版 §4.4，审查后的定义）：

```lean
def 合 (E₁ E₂ : 际 α) : 际 α := fun x y => E₁ x y ∧ E₂ x y
def 自持 (R E) : Prop := 有常 R E
def 相须 (R E₁ E₂) : Prop := 有常 R (合 E₁ E₂) ∧ ¬ 有常 R E₁ ∧ ¬ 有常 R E₂   -- 对称，非自反
def 因于 (R E₁ E₂) : Prop := 有常 R (合 E₁ E₂) ∧ 有常 R E₂ ∧ ¬ 有常 R E₁   -- E₁ 因于 E₂
```

### 4.5 深与阶

- **深**：从分别 E 看去，自递归细化最早稳定之步（第七版 §4.5，`Step`、`Stage` 亦可无点地写）。已检查：有常之核在每一步之内；E 对称时稳定即核。只有有限分支时“极限即核”蕴涵 LLPO（[review-checks/HM.lean](review-checks/HM.lean)），只作标定。古文自身的“深”（“极深而研几”）第 0 步对照。
- **阶**：五月工作的“系含系”（凡系即系系，μX. F(X)）是一个定义性的递归：分别之中有分别。生生之阶以此递归定义，不与“深”混用。
- **神**另立：无前缀能定下一值，与深互不蕴涵。

### 4.6 文法有多强：配对、幂、不动点；与 Lean 互译

文能否写出 Lean 所证的一切，归结为文法中有没有三种运算。已有的结果（第 0 步读原文核对）：

- 纯关系代数只相当于三个变元的一阶逻辑，比一阶逻辑弱；加一对“配对”（两个投影，quasi-projections），就足以写出 ZF 集合论，即几乎全部数学（Tarski、Givant 1987）。
- 无点的关系演算加“幂”（把关系 R 转为“x 之所 R 者”之全体，power allegory），与 topos 等价，即高阶的直觉主义逻辑（Freyd、Scedrov 1990）。不用选择公理，与纯核心最近。
- 归纳与共归纳要不动点。
- Lean 本身比 ZFC 强：带选择公理的 Lean 与 ZFC 加可数多个不可达基数等强（Carneiro 2019）。纯核心不用这些公理，但用归纳类型、宇宙与非直谓的 `Prop`。

**候选**（AI 重构，第 0 步与注疏双向校验）：

| 运算 | 候选 | 依据 |
|---|---|---|
| 配对 | 兼、两 | “兼三材而两之，故六”（《系辞下》） |
| 从配对取一端（投影） | 分于兼 | “體，分於兼也”（《墨经》，第二批） |
| 幂（关系之转置） | 所 | “辭也者，各指其所之”（《系辞上》）：“其所之”即“它所往者之全体” |
| 最小不动点 | 系含系（μ）；不穷（无穷迭代） | §4.5；往来不穷谓之通 |
| 最大不动点 | 有常之核 | §4.3 |

**检验**（第 1 步）：

1. 第 0 步在语料中找这三种运算的实际用例，按 §三 归类；找不到的，记为缺。
2. 第 1 步把找到的写成文法的运算，并证明其律（配对：两投影之律，按 Tarski、Givant 的条件；幂：转置之律，按 Freyd、Scedrov）。
3. 由此得文法之强：有配对则至少及于一阶逻辑；有幂则及于高阶直觉主义逻辑。缺哪一种，文法之强就止于何处（如无配对，止于三个变元的逻辑）；这本身是一个结果，照实报告。

**互译目标**，两个方向：

- **文入 Lean**：文法在 Lean 中形式化（§4.3–4.5），本计划本来就做。
- **Lean 入文**：把一个明确的逻辑片段（一阶逻辑；若有幂，高阶直觉主义逻辑；再加归纳类型）编译进文法，并在 Lean 中证明编译保持可证性：片段中可证的，编译后在文法中可证。

两个方向都成，文法与那个片段就**互相可解释**：谁也不在谁之下，是一套逻辑的两种写法；Lean 机械地检验，文用它自己的语言说出来。所以不说“文为 Lean 奠基”，那会造出一个新的上下层。Lean 的全部（宇宙、全部归纳类型、选择）能否入文，列为开放，不预设。

**边界**：

- 互译说的是可表达，不是由文推出。旧定理译入文后仍带其前提；去掉前提靠 §九 的剥前提，不靠翻译。
- 消去变元的译文会急剧变长，不求可读。文的价值在少数短句与乙类之网络，不在抄写每条证明。
- 任何够强的系统都不完备；“所证的一切”指 Lean 能检验的，不是一切真理。
- 经典逻辑以文句的形式出现，而不是自动包含在内：`law_iff_em`（§9.1）说的是，往来之句“起之复当且仅当止之复”若对一切有穷者成立，恰好等价于排中律。要不要普遍接受这类往来之句，是一个公开的决定；纯核心不接受。

## 五、古文已有的文法：句式、链、语料

第七版 §二的内容整体保留，作为第 0 步的材料，只改其地位：它们不再是要配到一个框上的句子，而是文法本身的条文。

### 5.1 句式与“相 X”的分类

同第七版 §2.2：定义、一 X 一 Y、X 则 Y、X 而 Y 生、由一而分、反复、两者同出而异名；“相 X”逐一分类（相推、相生、相随、相摩、相荡、相易、相攻、相取、相较、相感、相须、相因、相病），周氏之分类见孔疏《序卦》（`sources/zhouyi-yizhuan/commentary/zhengyi-10.json`）。

### 5.2 链

同第七版 §2.3（阖辟变通；化、变、道、器；穷变通久；生与息；聚散死生；有常而断；通而成文；深、几、神；唯变所适；复常明；物壮则老；柔弱坚强；朴散为器；势成之；未兆；敝则新；有无相生；由一而分；反）。每条链在第 0 步按 §三 逐句归类；预计多数链是甲类定义与丙类律的交织，第 0 步报告其比例。

### 5.3 语料

## 六、模型：诸框

框是文法的模型：一个解释“际”及诸运算的结构。文法之定理在每个模型中成立；有条件之律只在满足其条件的模型中成立。

| 模型 | 是什么 | 它的性质（原第七版的承诺，现为该模型的性质） |
|---|---|---|
| 一步展开 | 态的类型与一个一步关系（第七版的“形式之框”） | 离散；模态；非语境；态先于关系（以位之定消解）；律不随时变；整体之步；当前态定其后；不计次数概率 |
| 旧 World | 一种关系项，八个字段 | 以上，另加：形成与条件两种角色、取与、水平之自然数 |
| 卦象 | 六爻之系统（Y1–Y5） | 有穷、可判定；爻有等（相分） |
| 瓮 | Tria 等的推广 Pólya 瓮 | 计数、随机（概率对应在外围） |
| 生态与集体诸模型 | 旧理论的 RegimeMargin、Optimum、联合超出等 | 量为整数或实数；平衡；耗散 |
| 并发模型 | 局部变化可以同时（为“日月相推”“刚柔相推”之同时） | 无整体之步；并发 Kleene 代数之类 |
| 连续模型 | 实数时间（外围） | 非离散 |

- 每条丙类律都要说明在哪一类模型上成立，以及在哪个模型上失败。
- 旧理论的定律（约 13,900 条）多是旧 `World` 这个模型上的丙二；它们按 §九 剥前提，移入丙一或乙，移不动的登记为定域。
- 第七版对“一步展开”所做的工作（承诺之公开、两种呈现定理、一步之得失、势与几的定义）都保留，作为这个模型上的工作。

## 七、地图：生成与退化

地图的谓词尽量写成无点的形式，从而在文法上定义；它们在哪些模型类上能取到哪些值，是丙类的工作。

- **通**：往来不穷，即一关系可以无穷迭代下去的那些位。
- **穷**：交替无以为继；**息**：交替止；**相病**：“賁盡致剝，進極致傷”；**物壮则老**。
- **一步之得失**：在“一步展开”模型中，一步之后一步可及之类的得失（辟：有前所无者；阖：前有而今无者）；两条进程之间的比较另为损益。阖与辟不评价，二者都属于生成（“其静也翕，其动也辟，是以广生焉”）。所及沿一步只会收窄，所以“开”不定义为所及的扩大（审查者草稿 `reach_narrows`）。
- **势**：一个测试 p，其后继仍在 p 中（p 而 R 含于 R 而 p），且从其盆中每条进程都进入它；归纳定义，“每条进程”之形为标定（有限分支时与扇定理相关）。
- **势之五问**：成势或无势；自续（通）或死寂；困（入易出难，出口如“困，穷而通”）或可出；耗（同一余地上联合超出）或和；积化（穷则变）或守。另有往复、迁、多势并存。
- **元吸引**：相须的若干分别，其合有一个势，自续，且跨细分；再按得失分类。旧工作定义（[10月8日](../../../../../../theories/meta-attractor/GENERATIVE-REGIMES.md)）与它的对应要证明，不预设。
- **几与定**：相对于一个结局与一个耦合的分别；定是此后每条进程都到达结局的最早之步；几是结局已在所记之分别中初显、而仍可改的最早之步（“君子见几而作”；“其未兆易谋”）。
- **生生之阶**：一阶是通之持续；二阶是相须之势使一阶成立；k 阶由“系含系”的递归定义；各阶有非生成之对应；瓮上的见证（现在辟多却使以后的交替无以为继，与现在辟少却使交替持续，两种比较判断相反）。

**地图的完成**：由谓词生出的每一个相容之格，在每个模型类上要么有见证，要么被证明为空；相邻格之间的边界是“Y 当且仅当 Z”；每种过渡证明可能、不可能，或列为开放。凡能对一切模型证明的，记为乙类。

## 八、次第

施工的先后，不是实在的层次。

1. **文法的核**：际与诸运算（而、逆、则、谓、合、测试、无穷迭代）；有常、有常之核、根定理；自持、相须、因于；深与阶；带约束之式到无点之组合的编译；配对、幂、不动点之律（§4.6，凡语料中有用例者）。全部对任意载体与关系证明。
2. **甲、乙两类与互译**：第一批语料中的定义句写成定义式的等式；能由定义与运算律推出的，在 Lean 中证明为乙类。互译的第二方向：一阶片段（有配对时）编译进文法，证明编译保持可证性；高阶片段视幂之有无。
3. **模型与剥前提**：一步展开、旧 World、卦象、瓮、并发、连续（外围）；每个模型解释文法的诸符号。旧理论的定律按 §九 剥前提：依赖审计的分组（第 0 步已出）、主律与中心声明之提升、旧 World 的表示定理。
4. **丙类**：每条有条件之律在其模型类上写成“Y 当且仅当 Z”，给出反例。
5. **地图的谓词**：通、穷、息、相病、一步之得失、势、五问、元吸引、几与定。
6. **地图的完成**：§七。
7. **生生之阶**：以“系含系”的递归；瓮上的见证。
8. **化与理、时**：进程与其不变式；时作为被指定之进程；学习是一分别跟踪另一分别之理（旧学习诸定律经 §九 剥前提）。
9. **生命、演化、集体**：作为模型。

## 九、旧工作怎么处理：剥前提，不翻译

旧定理译成文，只会变成“在旧 `World` 中，若八条前提成立，则 Y”：前提一条不少地跟过来，内容仍是二元的。换成文的用词不会让内容变成一元，中华本就是这样出的问题。只按模型登记也不够：登记保留了丙二。所以不逐条翻译，而是剥掉每条定理没有用到的东西。

现在的 `World` 已只有一种关系项（`Relatum`，W 重根时形成与条件已合为一类）；二元留在八个字段里：状态的五个（level、active、requires、need、draws）与交换的三个（present、take、give），以及八条前提。

### 9.1 依赖审计（机械，只读，放在第 0 步）

- 扩展 [`THEOREM-CONNECTIVITY.py`](../../THEOREM-CONNECTIVITY.py)：它已能从编译结果导出每条定理之类型与证明所用的全部常量。对每条定理，记下它实际用到 `World` 的哪几个字段、八条前提中的哪几条、哪几条主律。
- 按所用字段之集分组，报告每组的定理数：多少只用一两个字段，多少真要用到全部八个。这一步给出 9.2、9.3 的真实工作量。
- 例：`law_iff_em`（[Space.lean](../../../../../../experiments/integrated-correction/general-framework/generative-basis/lean/becoming/Becoming/Space.lean)）说“凡有穷之 `World`，起之复当且仅当止之复”对一切有穷者成立，等价于排中律。其陈述所用的 `Arises`、`Ceases`（`Arising.lean`、`Change.lean`）只读 `active` 沿历史之取值，不碰 level、取与与需求；证明中构造反例之 World 时用到哪些字段，待审计核实。`Change.CeasesToBe` 已对任意 `p : Nat → Prop` 陈述，提升有现成的起点。
- 产出 JSON 与报告，放在本目录；不改任何旧模块；不是新结论，只是度量。

### 9.2 提升

- 对每一组，找出证明真正用到的那条关系性质 Z，用文法的运算写出（§四）；对一切模型证明“Z 则 Y”或“Y 当且仅当 Z”；再证明旧 `World` 满足 Z，旧定理成为一个实例。
- Z 由定义（甲类）给出时，Y 升为乙类；Z 是文法写出的条件时，Y 为丙一类。
- 旧证明尽量重用：只是把“`World` 的字段”换成“满足 Z 的任意关系”。
- 例（续）：`law_iff_em` 提升后应为：任意展开、任意一个二值的分别，在有穷而列得尽之位上，“入之复当且仅当出之复”普遍成立，等价于排中律。其中没有关系项之种，也没有取与（待 Lean）。
- 次序：先提五条主律与 127 条中心声明（其中 64 条经由主律），其余经由它们成为推论；审计的分组决定剩下的怎么办。不逐条提升全部约 13,900 条。
- 提升后的命题可能近乎平凡；这不坏，乙类的价值在其网络。

### 9.3 表示定理

- 证明旧 `World` 是一元展开的一种看法：从展开 R 与若干分别，定义出八个字段；反之，每个 `World` 都由这样得出。两个方向都写成逐点的“当且仅当”，在有常之核（互拟）的意义下成立，不取商（取商要 `propext`）。
- 于是八个字段与八条前提各落入一类：甲（由 R 定义）、乙（文法之定理）、丙一（文法写出的条件）或定域（消不掉的建模选择）。
- **已有的一半**：
  - E1（`Becoming.ExchangePremises`）：八条前提中五条是一次交换的读法，三条（耗散、具身、有界传递）是律之状态；
  - FL2（`Becoming.Continuity`）：沿关系的平衡，等价于每个闭族上的守恒；
  - `Labelled` 的 `withMove`、`Shown`：步先与态先两种写法有相同的历程，律是其历程所示的最小之律；
  - P107（`Becoming.Reading`、`Becoming.Readings`）：前提从交换读出，`World` 是粘合之情形。
- **差的一半**正是 XR 计划失败之处：这些工作都从“交换”出发，而交换先给了两端。新的表示只从 R 与分别出发：取与是一个关系的消长相当，从其两端读；取者与所取是相须或因于的两端（§4.4）。
- **可能不成之处**，如实记下：
  - 方向：有些定理确要方向（谁取谁与）。表示成立，则方向是一个关系的两端，可以接受；不成立，则登记为定域。
  - 量：level 是自然数，计数是建模选择。FL2 使平衡成为关系性质，但量本身仍用 ℕ；除非把它读作一个加法性的分别（数），否则留在定域。这一项最可能剩下。
  - 只到互拟：两个方向若只在互拟意义下成立，就照此陈述，不声称相等。

**剥完之后**：旧工作中不留丙二。凡留下的二元字段，都是证明确实用到的；那条定理就是关于这一分的，明写为定域，并计数。

### 9.4 其余

1. 旧定理全部保留，不删；被提升取代的旧模块按规则移入 `history/`（`research.py move`，先 `--plan`）。
2. 伦理模块暂不迁移，保持原样；审计照样计入，提升暂缓。
3. 应用环照常检查，移出中心覆盖；其定律同样经审计，可提升者提升。
4. 标定（`Resolution`、`Likeness`、`Sensitivity`、`Tail`、`Decidedness`、`InAmounts` 等）按其所证接上；凡标定一个经典原则的，提升后看它在文法中是哪一句（如 `law_iff_em` 之为往来之句，§4.6）。
5. 中华本留作旧模块的读法层；新的文法上重做 FC1 之测，加“二元指称”的计数。
6. 五月的“間与文言作为形式语言”诸稿、文理生生 v0.4、HANZI 与 PRE-QIN 两章、YI-ZHUAN 的逐段判断，作为文法之条文、句式与见证的来源。
7. 记录更正：`Learning.no_prefix_fixes_next`（旧名 `no_record_fixes_next`）；`how-fast-a-rule-may-change` 说的是至多 N 个态、定其进程。

## 十、工作规则

1. **古文先行**：文法的运算从古文自身的句式读出；不先选框。
2. **对一切模型证明**：乙类的定理对任意载体与关系证明，不借任何模型的性质；凡用了某个模型的性质的，就是丙类，写明条件。条件能用文法写出者为丙一；条件是分别给定的模型成分者为丙二，须按 §九 剥前提。**不翻译旧定理**：译入文不去掉前提。
3. **古义与形式双向校验**：每条读法标“AI 重构”，注明所从注疏；义之所失如实记下；相分不回避。新撰的仿古文只作文风草稿。
4. **版本纪律**：《老子》用王弼本经文；不混用他本；语料外之出处标明。
5. **一词一物**；**逐点等价**；**不先断言对应**（“X 即 Y”在二者都定义并证明之前只写作待证）。
6. **一元检查**：新定义过三问；二元词检查英文与中文都查。
7. **外部文献先行**：已有的不重证，只写对应；不把他们没说的归给他们。
8. **零公理**：只用 prelude；概率与连续只在外围。
9. **一条线，一个整合者**：在工作板上认领，经队列落地；冻结新的应用项目；EC 并入（与 line D 商定）。
10. **先检查后写字**。

- 地图由谓词生出；元吸引一个谓词；势归纳定义；几与定分开；一词一物。
- 古文方面：引文版本改正（长短相较）；角色一栏；漏掉的链补入；乾坤、阴阳、刚柔、天尊地卑、形而上下、爻有等登记为相合、定域或相分；固改困；势取《老子》五十一章；道不立为一名；不用“体用不二”；读法皆标 AI 重构；评价之句计数。

**第八版新解决的**：古文审查的总批评“根先定，引文后配”，以及形式审查的 F2（态先于关系、律先于历史两条未公开的分裂）。根上不再有我们先选的框；位由其全部之际定，态不先给；律是文法之等式，不是一个先于历史的一步关系；时是被指定之进程。

**第八版新带来的风险**，须在再审中查：

- 虚词与句式对应于哪种运算，是一种读法；它来自古文自身，但仍须与注疏双向校验。
- 乙类句子单拿出来近乎平凡；文法的价值在其网络（互相推出、压缩），以及把丙类分离出来。
- 地图的大部分是丙类，模型上的工作仍然很重。
- “对一切模型”在 Lean 中指一切关系模型（任意类型上的关系）；抽象的、不可表示的关系代数（Lyndon 1950）不在内，这一点要写明。
- 五月工作的若干强断言（近于全局最优、ZFC 写成文言即“完备”之类）不承接；只承接其运算之核、一元原语与两对偶，并核对。

**第八版修订新带来的风险**：

- 表示定理可能不成，最可能卡在量（自然数之水平）与方向（谁取谁与）；那时旧工作的相应部分是定域，不是一元的。
- 依赖审计看的是证明项中的常量；经由别名、实例或展开的定义所用之字段可能看不见，审计工具须先在已知的例子上核对。
- 配对（兼、分于兼）与幂（所）的读法是 AI 重构；“分於兼”出自《墨经》（第二批），不是第一批语料。
- 互译只及于明确的片段；Lean 的全部能否入文是开放的。

第八版尚未再审。建议第 0 步完成后，把第八版连同第 0 步的产出再交同样的审查。

## 十三、完成判据

1. 第一批语料的每一句都归入 §三 的五类之一或“未读出”，注明所从注疏；
2. 甲类全部写成定义式的等式；
3. 乙类全部在 Lean 中对任意载体与关系证明，公理报告为空；
4. 丙一类全部写成“Y 当且仅当 Z”、Z 用文法写出，并有 Z 不成立时的反例；
5. 戊类全部登记，作为对一元假设的反证计数；丁类计数；
6. 地图（§七）在各模型类上完成：每一相容之格有见证或被证为空，边界是“Y 当且仅当 Z”，过渡可能、不可能或开放；
7. **剥前提**：旧理论的每条定理经依赖审计；五条主律与中心声明提升为乙或丙一；旧 `World` 的表示定理两个方向在 Lean 中证明（或其失败处写明）；八个字段与八条前提各归甲、乙、丙一或定域；旧工作中不留丙二，定域逐条计数并写明所用之成分；
8. **文法之强与互译**：配对、幂、不动点各有语料用例与 Lean 中的律，或记为缺；互译的两个方向到达哪一个片段（三个变元的逻辑、一阶、高阶直觉主义、加归纳类型），在 Lean 中证明编译保持可证性；未到达的写为开放；
9. **可推广**：乙类与丙一类在古文之外至少一个模型类中有实例；
10. **报告**：各类的句数与比例；未读出之句的原因；文法之运算是否够用；一组未定义之词（“最少”须有不可定义之证）；审计、提升与定域的计数。

只为提高计数而改道证明不算。

## 十五、本计划不做的

- 伦理（暂缓，但其句计数）。
- 不选定任何框作为根。
- 不重做外部已完成的数学；凡已有，引用并写对应。
- 不证明整体的必然性，也不证明一元为真：文法与本体对齐不证明本体为真（五月工作已明言）。
- 不把古文的贴切当作证明；丙类的“则”要有精确条件。
- 不逐条翻译旧定理，不把翻译当作一元化；不声称 Lean 的全部可以入文，也不说“文为 Lean 奠基”。
- 不删除任何数据，不改写 Ren 本人语气的文字，不重开已落地的结果。
- 不声称新的数学。我们的部分是：从古文自身句式读出的文法之核及其形式检验、语料逐句的五类归类、乙类在一切模型上的证明、丙类在模型类上的精确条件、生成与退化的地图、生生之阶。
