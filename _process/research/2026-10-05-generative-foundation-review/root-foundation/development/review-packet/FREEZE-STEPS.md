## The steps

Run from the root of a worktree of your own, outside `/private/tmp`, which a restart wipes:

```bash
git worktree add -b freeze <path> main
KIT=_process/research/2026-10-05-generative-foundation-review/root-foundation/development/review-packet
```

Call C the commit of main you read the dossiers against, at first this branch's start. Keep your reports outside the tree.

**1. Report each dossier's drift (run).** The pin is the table's second column, but for those re-read since: every dossier's, now `0ccf7fa82`, which edition 3 read them against. Under half a minute for all six.

```bash
python3 -B $KIT/resync_report.py 3f294b01c theories/becoming/review/CLASSICAL-TEXTS.md --out <scratch>/CLASSICAL-TEXTS.md
```

The report gives, item by item, each quotation whose paragraph changed, each linked section that changed as its changed spans, each linked file or folder that changed or is new since the pin, and the results new in the dossier's main chapters that it does not link. Whatever its summary counts gets a line, under each item that links it. An anchor it cannot follow is listed: read those by hand. The cover and the codebook cite little: read them whole.

**2. Read every flagged item against its chapter (run for all six).** The dossier says what the chapter now says and no more. Three rules from the rehearsal:

- A report line is not a fault. Open the chapter and decide. A long insertion is cut in the report, so never judge one from the report alone.
- A new result goes in only where it bears on what the item asks this reader. Philosophy took the result on self-concern and C; it left holding for a reading to alignment, which already carries it. State every hypothesis the chapter states: the independent read of this step found two dropped.
- If a chapter has answered a dossier's question or removed a known weakness, say so in the item, with the date. Do not delete it silently.

Copy new Lean statements by script ([`lean_statements.py`](../rp2-philosophy/lean_statements.py); `Web.*` names need their full dotted form), since the checker compares every declaration in a Lean block with the sources, a definition whole and a theorem up to its proof. Run `python3 -B $KIT/check_dossiers.py` after each dossier. Record the pass in the dossier's *How this dossier was made* where it has one (philosophy, alignment, sciences), and record its new pin in the paragraph under this page's table and in step 1, whose counts stay as the rehearsal measured them.

**3. An independent read of each changed dossier (run for the same six).** One AI reader per dossier, read-only and with no part in the writing, given the diff, the chapter and the Lean; every finding taken or its refusal recorded. That is up to six agents, so state the count to the coordinator first. Check a reader's findings against the sources before taking them.

**4. Re-measure, and correct what the dossiers state (run for the same six).**

```bash
python3 -B _process/research/2026-10-05-generative-foundation-review/root-foundation/development/aj4-alignment-readers/kit/measure_layers.py
```

A moved time changes in three places: the dossier's own statement of its time, the row in `README.md` and in `README.zh.md`, and [READING-BUDGETS](../aj4-alignment-readers/READING-BUDGETS.md) lines 32 and 35. A front over budget keeps what amendment 1 says may not be cut and moves the rest down a layer; what it keeps beyond that it records, with the reason.

**5. If main has moved, merge it and re-run step 1 with the last C as the pin (run at the landing of 3 November 2026).** The commit of main it brought is the new C. Repeat until nothing landed since is unread. The coordinator can shorten this by holding landings that change the chapters.

**6. Set the one pin a dossier states (run at the same landing; it comes again at the freeze).** `CLASSICAL-TEXTS.md` line 5 names the version it was checked against. Set it to C, with C's date. No other dossier states a commit it was checked against, and this goes last because C can move.

**7. Freeze which sampled units the dossiers quote (run).** This reads the final dossiers, so it comes after them, and its file belongs to the frozen commit.

```bash

```

At `2cab11114` it wrote 23 units. [`FREEZE.md`](../../../../../../theories/becoming/review/recoding/FREEZE.md)'s three sha256 sums, for the sheet in its two forms and the key, matched; check them with `shasum -a 256`.

**8. Take the head and make D (run on the scratch branch; the head not taken).** Commit the dossiers, `QUOTED.txt` and the kit's pages on the branch with `git commit -m … -- <paths>`. Put the clause on the board's Queue line. Merge main into the branch: it must bring only the clause, and if it brings more, go back to step 5. Run the render through `python3 -B tools/research/gate.py hold -- make research-render` and commit the views. The branch's tip is D. Because the landing is a fast-forward, D's hash does not change when main takes it, so the edition can be built before landing, and a defect stops the landing rather than a sent file.

**9. Run the gate on D in a clean detached worktree (run on the scratch commit, the full tests at `2cab11114`; the gate at edition 2).** `git worktree add --detach <path2> D`, and from there:

```bash

An edition ends a phase, so the full set runs once, reusing what passed on the same tree. `restated` lists the live lines that link a home the landing changed; for an edition it should list none, and any it lists are read.

**10. Confirm the dossiers were read against what D contains (run on the scratch commit, and at the freeze of 3 November 2026).** The first command must print nothing but what a dossier's joining changed: the pages whose links to it `research.py move` re-pointed, differing by those links alone; a sentence that lists the packet's dossiers, which no dossier quotes or links; and the records bound to those pages, re-pointed after reading and differing by those hashes alone. Read what the second lists: dossiers, the board, rendered indexes and the kit's pages, and for a joining also the move's receipt, the rebinds log, the repository's map and the builder; nothing else.

```bash
git diff --name-only C D -- theories/becoming experiments sources GLOSSARY.md ':!theories/becoming/review'
git diff --name-only C D
```

**11. Build the edition from D, in the same worktree (run on the scratch commit).**

```bash
python3 -B tools/publishing/build_review_packet.py --release
```

It refuses a dirty tree, a failing dossier check and an earlier release of another commit. It builds every part apart and refuses the edition if any part has a defect: checker markup left, a stray `*`, a link to nowhere (a link to a section needs that section's `<a id>` line: the build takes ids from those lines alone, so a heading's slug passes the links check and fails here), a glyph in the box font, a radical in the text layer, a local path. It warns if the one page runs past one sheet, and does not refuse for length (amendment 2). Only then does it write thirteen PDFs, `SHEET.xlsx`, `SHEET.tsv` and a `MANIFEST.txt` of sha256 sums to `output/pdf/review-packet/`. Each part names D under its title and at the foot of every page; the codebook alone does not point to the repository. Then look with your own eyes at the first page of each file and at one page with Chinese and Lean, and confirm that the key is not among the files.

**12. Land, and keep what was sent (the sent files tested on the scratch commit; main not touched).** Tag D locally with `git tag -a review-packet-N D -m "…"`. In your branch's worktree, copy the folder over from step 9's worktree and commit it with the board's landed clause and the render, so that what readers cite by page stays in the history (7 MB; it leaves the views as they were). Run `make gate` on that commit, re-read the Queue line and fast-forward main to it, past D in one move; edition 1 moved main to D first. A later edition first moves this folder to a `history/` beside it, and the builder refuses until it has; the move leaves the emptied folder, which is removed (`rmdir`) before the new edition is copied in. Pushing main and the tag follows [the board's line on the push](../../../../../BECOMING-WORKBOARD.md#decisions-pending-ren).
