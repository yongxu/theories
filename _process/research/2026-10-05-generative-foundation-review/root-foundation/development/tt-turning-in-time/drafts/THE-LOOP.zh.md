# 来得及转吗

**陈述。**

> 凡持续的，都在条件之下持续，并且是就某一方面而言：作为这个身体、这个习惯、这种取舍的方式。就这一方面而言，条件上的差别，只有一部分使它的持续有所不同；其余的不造成任何不同，而它照样依赖它们。它怎样持续，由它的持续所带回来的东西更新；所以凡不造成不同的条件，更新之后它一如其旧。它的持续又在改变它的条件。于是它可以把自己所依赖的一个条件用尽，而它自身毫无不同，直到那个条件不复存在，它也随之止息。它来得及转，只在一种情形：那个条件还在的时候，这一变化已经使它有所不同。而能把这个不同带给它的，往往就在正被用尽的条件之中。

每一个说法，都是根里已有的一个词：条件（缘）、方面（类）、它分辨不出的差别（核）、更新（复生）、一如其旧（有常）、止息（息）。

**一个水位，两个标记。** 取它所依赖、又在用尽的一个条件，在上面标两个水位：*v*，低于它，这个条件的下降才使它的持续有所不同；*m*，带来这个不同的东西自身所需的水位。

- *v* < *m* 时，下降要到带来不同者所需的水位以下才会造成不同，所以它来不及造成不同。它更新如旧，那个条件跌到恢复不回来的水位以下。其中没有哪一步需要谁有意为之。
- *v* ≥ *m* 时，水位在两个标记之间的那一段，下降能够造成不同。它要转过来并且不再转回，三件事都须赶得上：带来不同者还站着的时候，下降已经造成不同；在那一次更新和下一次更新，这个不同都重过使它更新如旧的一切；用得少了之后，那个条件仍在恢复得回来的水位之上。

带来不同的若只是它自身的持续，则 *v* < *m*：等它有所不同，它已在止息。

**在“选择”这个情形里。** 奖励、评判者、市场、投票、训练，是同一个情形。在这里，它怎样持续，叫作它的*规则*；它越留越多的，叫*份额*；它用尽的一个条件，叫*存量*；把存量的下降带进规则的，叫存量的*读者*。这是同一个持续的四个方面的名字，不是四个部件。

**不加褒贬。** 这句陈述说的也是一个身体、一门语言、一份信任如何得以维持。“锁定”“俘获”，是依赖那个被用尽的条件的人给它的名字。

**伦理，三句话，分开说。**

- *已证。* 持续，只按回到自身的东西来筛选取舍的方式，筛向保住自身一脉（07 §4.9、§4.12）。这是审慎，其所及止于条件对它造成不同之处。
- *未证。* 一个永远回不到某种取舍方式的变化，在不另给任何评价的情况下，会对它造成不同。
- *所愿。* 会。对取舍者如此，写下这些的我们也在其中，人与 AI。这个愿本身也在条件之下持续：它出现，然后传开、更新如旧，或者止息。

作为设计要求，这个愿是：凡你所依赖的，都要能使你有所不同；并让带来这个不同的一直站得住。一个不同，若比回到自身的走得更远，只在带来它的东西不系于它要转的那个进程之处才保得住。这样的东西如何形成，是伦理的未决问题，也是对齐的未决问题；这里没有任何东西证明了它。

## 别的领域给它的名字

凭记忆，未重新查阅。各领域的词是指向这句陈述的路标，不是它的用语。

| 领域 | 它的词 | 这些词带来什么 | 遮住什么 |
|---|---|---|---|
| 对齐研究 | 目标、监督、渐进式失权 | 一个有名字的危险，和为之工作的人 | “监督”把带来不同的东西放在外面，当作评判者。在这里它在其中，靠同样的条件生活。 |
| 系统动力学 | 存量、增强回路与调节回路、转嫁负担 | 速率、延迟、仿真 | 先画部件，再接线。 |
| 经济学 | 锁定、俘获、外部性 | 有度量的案例 | “外部性”预设了一个“内部”。 |
| 演化 | 选择、适合度、生态位构建 | 不需要谁来定规则 | “适合度”常被读成生物体自己的属性。 |

## 看到了多远

| | |
|---|---|
| **用词** | Lean 用另一套词陈述这个中心：规则、份额、偏向、损失、读者。上面的陈述是用根的词对它的一种读法。二者的联系已证，却被名字遮住：`GoAlike`（“在一种描述下相同的，走向也相同”）就是有常，`Unread` 是它的应用，而锁定各模块没有提到根的任何一个词。 |
| **Lean 中已证**，各在各的模型上，用 Lean 自己的词 | 一个部分自成一律，当且仅当其余部分对它的下一步毫无影响（`ClosedCapture.identifiesAlike_iff_unread`）。守住所选的规则，此后一直守住（`RuleCapture.locked_stays`）。有交换余地时，规则之下的每个最优结果，都把规则不读的量留在容许的最低处（`Optimum.least_of_room`）。在固定取用之下，一份存量终结，当且仅当它起始于一个明确的水位之下（`RegimeMargin.ends_iff_below`）。只通过承受者自身的延续来读的损失，要过了不可返回点才被读到（`ReadOffInTime`，`too_late_of_own`）。读得迟时，那一次读时双方的人数决定规则是否保持（`ClosedCapture.Thinned.kept_iff`）。 |
| **假设或定义**，在最接近的联合模型 `PoolFromCourse` 中 | 损失每一步都增长（假设 `Accrues`）。损失过了一个标记，读者离开（定义 `Stands`）。份额越大取用越多（假设 `drains`）。 |
| **目标，尚未证明** | “一个水位，两个标记”之下的两种情形，在一个条件能够恢复的模型上。预计是以上各行的组合。 |
| **一种读法** | “陈述”作为贯穿全论的同一个形式，以及“不加褒贬”。六个结果在各自的形式位置上有此形式；它们是同一个形式，还不是定理。 |
| **检验** | 很少。一个语言模型评判者，在上下文中读到自己先前所选，60 次中 60 次照旧；九个读者中有一条关于损失的记录，50 次所选全部转向（LA2，运行前冻结）。所以那个评判者不是“按类清点的读者”，上面的三个时间照现在的写法不描述它。还没有一个检验更新过模型的权重。 |
| **相近工作**，只据摘要与检索摘要，未读 | 一个以社会选择理论写成的、AI 侵蚀集体能动性的模型（RAND，2026）。“Self-Sealing Reward Models”（NeurIPS 2026 研讨会）：过了一条界线，评判回路无法被反驳，修复需要反复引入可信信息。“The Lock-in Hypothesis”（ICML 2025）。看来都没有“带来不同者立足于正被用尽的条件”，也没有三个时间的先后。在说任何东西是新的之前，必须先读它们。 |
| **未涉及** | 为取得力量而预先谋划的智能体。受训网络在奖励之外会去追求什么。 |
