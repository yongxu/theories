## The commands behind the counts

**Counted.** From repository root, with `L=experiments/integrated-correction/general-framework/generative-basis/lean`, I used `git ls-files -s -- "$L"` for paths and blob identity, `git cat-file --batch-check='%(objectname) %(objectsize)'` for logical bytes, and `git show` for dated comparisons. The graph and family counts reduce to this read-only Python:

```python
import json, os, re
from pathlib import Path

L = Path(os.environ["L"])  # export L first
r = json.loads((L / "becoming/becoming-verification.json").read_bytes())
g = json.loads(Path("theories/becoming/results/data/theory-graph.json").read_bytes())
region = {n["name"]: n["region"] for n in g["nodes"] if n["type"] == "module"}
src = {k: (L / r["source_paths"][k]).read_bytes() for k in region}
deps = {k: set(re.findall(r"^import (Becoming\.\w+)", b.decode(), re.M))
           & region.keys() for k, b in src.items()}
print(sorted(region.keys() - set().union(*deps.values())))
for family in sorted(set(region.values())):
    ms = [m for m in r["modules"] if region.get(m["module"]) == family]
    print(family, len(ms), sum(src[m["module"]].count(b"\n") for m in ms),
          sum(len(m["declarations"]) for m in ms))
```
