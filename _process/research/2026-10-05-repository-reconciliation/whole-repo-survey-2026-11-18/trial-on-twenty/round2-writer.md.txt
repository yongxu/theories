theorem narrower_above_net {kept : P → X → Bool} {R : P → P → Prop} {items : List X}
    {pos neg : X → Nat} {x : X} {n w : P} (by_ : WidensBy items x (kept w) (kept n))
    (violates : R w n) :
    ¬ ReadsSetsOn kept R (ranksNet items pos neg) w n ∨ pos x ≤ neg x :=

Definitions named in it (extracted by script; each may be cut at 22 lines):

```lean
/-- A ranking of presentations reads the sets on the pair `a`, `b`: it ranks them, each way, as
the order `O` ranks the courses they keep. A presentation is a plan with its wording and the
order in which it is told; `kept` gives the course it keeps; `R b a` reads "`a` is ranked above
`b`". -/
def ReadsSetsOn (kept : P → X → Bool) (R : P → P → Prop) (O : (X → Bool) → (X → Bool) → Prop)
    (a b : P) : Prop :=
  (R b a ↔ O (kept b) (kept a)) ∧ (R a b ↔ O (kept a) (kept b))

/-- On the listed items `a` widens `b` by `x` alone: it admits every item `b` admits and `x`,
which is listed and which `b` does not admit, and nothing else beyond `b`. -/
def WidensBy (items : List X) (x : X) (a b : X → Bool) : Prop :=
  IncludesOn items a b ∧ x ∈ items ∧ a x = true ∧ b x = false ∧
    ∀ y, y ∈ items → a y = true → b y = false → y = x

/-- The order of a net weighting: each listed item counts `pos` for a course that admits it and
`neg` against it, so it weighs above zero where `neg x < pos x`, at zero where they are equal and
below zero where `pos x < neg x`. `a` is ranked above `b` where what `a` gains less what it loses
exceeds `b`'s, compared without subtraction. A weighting is the net weighting with nothing
against. -/
def ranksNet (items : List X) (pos neg : X → Nat) : (X → Bool) → (X → Bool) → Prop :=
  fun b a => weighed items pos b + weighed items neg a < weighed items pos a + weighed items neg b
```

**The telling as it stands:** **Theorem** (any type). Take a valuer's judgment as a ranking of presentations (plans with their wording and order, each keeping a set of items), and a net weighting as counting each item for a course admitting it and against it. Where such a ranking puts a narrowing above its widening by one item, either it does not rank the pair as its own order ranks the kept sets (a misread or a framing) or the item weighs at zero or below; read right, exactly where it weighs below zero, and at zero it ties (`Weighting.narrower_above_net`, `Weighting.reads_ranksNet`). Read right, where a sign measured apart is the sign of the order's increment from the narrower course to the wider in the pair's context, it fixes the ranking: narrower above exactly where it is a gain, wider exactly where a loss, neither where nothing (`Weighting.reads_increment`); an additive valuation carries it to every context, an interacting one need not. That a judgment is such a ranking is a premise. ([record](../results/records/a-narrowing-above-its-widening.md))

**The first proposed wording:** Where a ranking of presentations puts the narrower of two plans above the wider, the wider keeping one listed item more and the two otherwise keeping the same, either the ranking does not rank that pair as the net weighting ranks what the two keep, or the added item's count for is at most its count against (`Weighting.narrower_above_net`).

**The checker's verdict:** says less. “The two otherwise keeping the same” asks for agreement without limiting it to the listed items. The supplied account of WidensBy requires agreement only over those items.
