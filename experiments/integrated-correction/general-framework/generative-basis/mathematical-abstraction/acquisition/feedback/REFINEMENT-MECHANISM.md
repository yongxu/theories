# Acquired consequences can require a finer application distinction

6 October 2026. AI-authored continuation under the [nondual method](../../../../../../../theories/becoming/history/NONDUAL-METHOD.md). Named connection: **acquired evidence of an application dependency → refinement of the operative application distinction → subsequent activity governed by that refinement**. This is a local construction with explicit contact, memory and revision laws. It does not establish an assumption-free foundation or ethical necessity.

## What must actually be retained

The previous feedback controller retains an outcome indexed by the predicted sensor bit. For the learned machine `H110`, learned states zero and one have that same bit. A record saying only “output one, nonarrival” cannot later identify which state produced it. The new construction must retain the learned-state tag while the original issued command is still available, derive it through the retained transition table, and account for its storage and later reading. It must not restore discarded command history from the audit.

Initially the application partition is the sensor-output projection: states zero and one share one class, and state two occupies another. A supplied diagnostic strategy can test another learned state in the same class. After a first failed reset-and-empty-word use at learned state zero, the shortest such test is `a`, reaching learned state one. The learned state is a coordinate derived from the retained model and issued command; it is not a hidden physical phase delivered by the environment.

Suppose two faithful, correctly bound records give different arrival outcomes at these two states. Any deterministic application map defined on the original shared class would have to assign it both zero and one. Such a map cannot fit both records. Every consistent replacement must therefore distinguish the encountered states, unless another premise—binding, stability or faithful contact—is withdrawn. This is the conditional reason for refinement; a successful outcome alone does not establish every application relation.

Splitting the witnessed class while retaining prior distinctions supplies one constructive repair. The third state's arrival remains unknown unless actually learned. The sensor machine and its all-word prediction claim remain unchanged: this is a finer distinction for application, using states the sensor learner already distinguished through their future readings. The [earlier acquisition mathematics](../../../../../../../_process/research/2026-10-05-generative-foundation-review/history/root-foundation/ABSTRACTION-ACQUISITION-MATH.md#3-acquired-distinctions-and-warranted-composition) already credits conventional refinement methods. The present factorization argument is not claimed as a new theorem or learning algorithm.

**Scoped uniqueness lemma.** On these three learned states, let the old partition be `{{0,1},{2}}`. Among refinements that preserve its previous separations and admit a deterministic class-output map fitting the acquired records `(0,0)` and `(1,1)`, the only partition is `{{0},{1},{2}}`, up to class-label renaming.

**Proof.** The unequal recorded outcomes require states zero and one to lie in different classes. Refinement preserves the old separation of state two from each of them. Thus every pair is separated, which is exactly the discrete partition. It can fit both records; the output assigned to state two remains unconstrained. The implemented labels `[1,2,0]` and the static comparator's `[0,1,2]` describe that same partition. This identifies the required partition within the declared refinement problem, not a unique physical implementation or an observed value for every class.

Preserving previous separations is part of that problem's scope, not an additional fact learned from the two outcomes. If arbitrary repartitioning were allowed, `{{0,2},{1}}` would also fit the observed records and the actual `010` readiness law. The sensory model is separately preserved in either case. The lemma therefore establishes neither unique global application granularity nor a uniquely necessary ontology.

## The refined partition actually controls later use

The `consumer_masked` arm has the same acquired records, actual audit income and completed partition `[1,2,0]`. It also matches the primary's first eighteen extension events, including the charge for reading that partition. The intervention changes only the final read view to the old sensor grouping `[1,1,0]`. That view places the observed zero and one in the same class, so no state has nonempty unanimously positive class evidence. It selects no third use and preserves source ten. The primary reader instead makes only state one eligible and issues `a`. This excludes the explanation that the last success alone, or merely storing a split, produced the final action.

The static-phase comparator supplies `[0,1,2]` from installation, follows the same audit and obtains the same two productive effects. It is cheaper by `3659/32768`, because it does not acquire this split. This credits the ordinary state-sensitive alternative: the result identifies acquired granularity and its consumption, not superiority over every controller that already represents the relevant distinction.

The readiness `011` arm gives exactly the same observed records and primary outcome as `010`. The procedure never tests state two. Its successful use therefore does not establish the complete readiness map. Eligibility in this construction requires nonempty unanimous evidence within the read class; without representative coverage that is not a universal guarantee for unobserved members. In the primary refined partition, the selected state one is individually observed.

## Preserved limits

The fixed handoff/planner controls isolate the resource composition. Exposure eight with the shortest first word leaves three packets after that failure but cannot fund reader installation. Exposure nine with the old novel-word planner acquires its first tagged record but cannot fund selection of the audit or final retention. Both exposure-ten variants acquire and retain the split and select a third word, but the native source guard denies the third extraction. Their packet is not restored by further knowledge.

Under the original readiness `001`, the audit at state one fails. The retained records `(0,0),(1,0)` warrant no split, no supported response is selected, and source ten remains. The blocked `000` arm is observationally identical on those acquired records. This procedure does not investigate the still-unobserved state two, where the original `001` port could be productive. Its particular same-output audit and subsequent use rule are supplied, and its failure is not silently repaired by choosing a different test afterward.

A lost first contact retains only the installed initial partition; it acquires no outcome. A false-negative second receipt suppresses a warranted split despite actual arrival. A false-positive second receipt under `001` creates a misleading split and selection, then lacks funding to execute the next extraction or complete final retention. Misbinding the second receipt to the first state gives contradictory outcomes for one state: the procedure marks the correspondence invalid instead of splitting one state into labels that merely memorize reports. A false first receipt and a late readiness change are likewise exposed by subsequent same-state conflict. An invalid evidence record may itself be retained; `retained` does not certify its truth.

These are the sixteen prospectively specified finite comparisons, not empirical frequencies. The handoff, first-use/audit policies, contact opportunity, phase repertoire, split recipe and legitimate scope of risk remain supplied. The result demonstrates one actual connection between acquired application evidence, operative refinement and later action; it does not derive those supplied relations or the whole foundation.
