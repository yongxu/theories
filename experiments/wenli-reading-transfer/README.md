# Reading transfer: does a classical relational code help a reader reconstruct structure? (WL)

Board item WL, 22 October 2026. AI-written (a Claude Code session). The reading test has not been run; the fidelity measure was run as board item FC1 ([results](FIDELITY-RESULTS.md)).

The question comes from the 文理生生 project ([sources](../../sources/wenli-shengsheng-v0.4/research/README.md)), whose hypothesis H2 says that understanding compositional classical concepts improves the reconstruction, explanation and transfer of structure to unseen cases ([plan §1.1, §八](../../sources/wenli-shengsheng-v0.4/research/references/01_文理生生_以古文为基的最小概念文法_研究总计划_v0.1.md)). In this repository it bears on one claim: that the 中华本's classical code ([THE-THEORY-OF-BECOMING-ZHONGHUA](../../theories/becoming/chapters/THE-THEORY-OF-BECOMING-ZHONGHUA.md)) reads the frozen core better than a controlled English code of equal length. The claim is untested; the chapter [WENLI-AND-BECOMING](../../theories/becoming/chapters/WENLI-AND-BECOMING.md) states what is and is not established.

- [DESIGN-H2.md](DESIGN-H2.md): a pre-registered design for the reading test (humans decide H2; language models a separate family). To freeze it, commit it unchanged before any material is shown to a reader and name the commit here.
- [FIDELITY.md](FIDELITY.md): a measure on the two editions: for each 條 of the 中华本 and the English statement of the same law, the referents (relata, agents, entities) the wording introduces that the Lean statement lacks. Run as FC1: [FIDELITY-RESULTS.md](FIDELITY-RESULTS.md).
- [CONTROLLED-ENGLISH.md](CONTROLLED-ENGLISH.md): the 經 of every 條 rendered into English under an English name table with the same discipline (board item ZE), one source with the Chinese; it is also a candidate for the reading test's controlled English code. The fidelity measure run on it: [CONTROLLED-ENGLISH-RESULTS.md](CONTROLLED-ENGLISH-RESULTS.md).

The fidelity result (FC1) favours the classical code on these two texts: the 經 introduce fewer excess referents and agents than the English clauses, with one coder on both sides of the main set and both coders agreeing in direction on the calibration set. It is LLM-coded and provisional. The control ZE then separated language from the name table's discipline: under the Claude coder a controlled English in the same discipline and register does as well as the 經, and the GPT coder leaves a smaller residual for the 經 on 60 pairs; see both results for their limits. As designed, a fidelity win supports "the most exact reading code" for this core, not "the best language"; the reading test, not run, could refute the stronger claim.
