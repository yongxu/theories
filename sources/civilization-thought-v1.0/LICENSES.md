# 文本来源、署名与使用范围

本项目含研究编排、程序及第三方古籍电子转录。第三方材料不因进入项目而改为项目自有内容，也不因古籍本体进入公有领域而自动消除电子转录、编辑、图版或平台附文的权利与使用约定。

- CBETA 原始 TEI XML、题署、版本、发布与许可头随冻结材料保留。所用文件中的非商业使用等条款以各文件头为准；分发时不得去除它们。
- 维基文库等公开转录保留来源网址与实际页面/版本说明；并不冒称学术校勘定本。网页导航、现代序文和古典正文的研究身份分别说明。
- 从旧项目继承的快照保留原来源及哈希；同一见证的派生分层文本明确记录母本，不能算成新的独立版本证据。
- 本项目的释义、认知解释和图谱编排须与所引原文区分。若另行公开发布或商业使用，请依具体来源许可处理；本文件不代替各原始许可。

来源清单在规范模型的 sources 数组和网页来源入口，原始材料在 evidence。冻结材料用于让读者复核实际读到的文字，哈希只证明文件一致性，不证明版本学上的可靠或绝对正确。
