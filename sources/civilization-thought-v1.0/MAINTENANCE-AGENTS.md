# 中华思想脉络：维护约定

本目录是可独立使用的研究项目。用户的新指示优先；先读 `README.md`、`docs/数据与关系.md`、`tools/README.md`，再读取有关记录，不必把整个模型放进上下文。

## 先查再改

- 规范记录在 `data/model.json`。用 `tools/query.py` 或 `data/index.sqlite` 定位 ID；单字、短词查询采用子串检索，不能假设 FTS trigram 能匹配短串。
- `evidence/` 是冻结来源，`lineage/` 是父代与本轮审定输入。原文件及原有 ID 不静默改写；修订另开版本并保存原因、前后值及来源。
- 已审查包是研究结果。作者的临时生成脚本不是审定稿，不能运行它覆盖审查修正。
- 旧网页和用户的探索笔记可以提供线索，不能自动提升为原典证据。

## 内容规则

- 先分辨文本、说话者、时代、原典/注释层次和具体义项，再判断是否同义。同字不自动合并，复词和音译不机械拆字。
- 每个新增义项须有具体释义、其在该论证中的认知功能、必要限制，以及可定位的连续原文。不得用“本篇的某概念”循环定义，也不以数量作为提取目标。
- 每条判断保留全部前项、后项、合取/择取方式、否定、情态、条件和中介。不能把对照项画成因果，把“若无 A 则无 B”偷换成“A 产生 B”，或以免责声明补救错误拓扑。
- 原典所述、后代解释、现代比较分别记录。引文证明某作者说过什么，不自动证明其历史叙述或经验因果为真。
- 历史交涉必须有明确引用、批评、改释或会通证据。相似性、同字和年代先后不足以证明影响。所批评对象的形象属于批评者的陈述，不替代该对象自身的文本。
- 佛教保留印度来源、汉译与中国解释层次；诸子宽类标明后起编目属性。儒释道或任何三分法都不是全库唯一分类。
- 登记、全文取得、实际核读、选择性映射分别计数；缺篇、疑字、未读和注疏未处理必须保留。不能声称绝对全集。

## 接续流程

1. 在独立分区建立 `bundle.json`，记录稳定 ID、来源 URL、版本说明、冻结正文和原始响应哈希。
2. 实际阅读全文或明确选段，保留阅读账本；作者自查后由另一审查者回读原文，修复释义和关系结构。
3. 冻结最终包及独立审查报告哈希。跨分区比较须使用双方已经冻结的完整判断，带全部端点和实际阅读单位。
4. 通过 `merge_bundles.py` 的父哈希及包哈希校验生成新版本；执行验证、派生图、索引与网页构建。完整命令见 `tools/README.md`。
5. 检查真实浏览器中的搜索、目录、局部判断、跨体系比较、文献交涉、返回与导出。记录自动检查和实际观察的不同范围。
6. 更新范围说明、审查记录及文件清单，最后生成发布归档。不要在生成清单后修改被清单追踪的文件。

## 图的含义

语义图保存“概念义项 → 完整判断 → 概念义项”的角色连接。文献、交涉、比较和编目有各自边型；共享来源不会产生原典蕴涵。全量图保留孤立记录，连通分量不是学派，节点度数不是思想重要性。

不要为了让整张图连通而制造语义边。可以用问题对读与文献交涉连接不同论证，但必须保留连接的性质和各方不相容之处。
