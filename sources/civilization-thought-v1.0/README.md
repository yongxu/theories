# 中华思想脉络 · 1.0.0

从儒、佛、道扩展到庄学、墨家、名辩、兵学、法术政治及后起思想分类。每个入口都能回到具体论证和原文；相互引用、批评、改释、会通与现代比较分层保存。

打开 [中华思想.html](中华思想.html)。网页内置规范数据，可从目录、全库检索、完整网络、原文、思想交涉、跨体系对读和阅读路线进入。浏览器若限制本地页面，可在本目录运行 `python3 -m http.server 8107 --bind 127.0.0.1`，再打开 `http://127.0.0.1:8107/中华思想.html`。

## 怎样使用

1. **脉络入口**：按传统、文本、明确署名或主题浏览全量目录，点数量进入完整成员列表。
2. **全库网络**：看已有论证的分布和全部连通分量；选择具体判断后进入可读的局部结构。
3. **全库检索**：搜单字、短句、概念、来源或稳定编号，再按语境与记录类型筛选。同字义项分别列出。
4. **思想交涉**：查看谁在什么文本中引用、批评或重释谁。分类矩阵与年代编排只是导航；不能当成历史因果图。
5. **跨体系对读**：从共同问题并读各方完整判断，连同差异、不可等同处和证据阅读。
6. **导出**：导出当前完整筛选范围及引用附录，保留完整断言的全部端点；分页不会截断导出。

## 可继续研究的项目

- [范围与未完成事项](docs/本轮覆盖.md)：登记、核读与映射分开，缺篇、未读篇和待校问题明确保留。
- [数据与关系](docs/数据与关系.md)：概念、判断、文献交涉与比较怎样分层。
- [维护约定](AGENTS.md)：供接续研究者与 agent 使用。
- [工具接口](tools/README.md)：离线查询、严格增量合并、验证与构建。
- `data/model.json` 是规范库；`data/index.sqlite` 提供可查询索引。
- `data/graph.json`、`data/multilayer_graph.json` 及对应 GraphML 保留完整关系和类型。
- `evidence/` 保存冻结原文与原始响应；`audit/` 保存实际审查范围与结果。
- `lineage/` 保存父代与审定输入，能在没有原工作目录、没有网络的情况下复验继承。

本项目不声称“中华文明思想绝对全集”。全篇核读仍不等于提取全部可能关系；选段不等于整部典籍。原典、解释、现代认知分析分别保留，历史分歧不会为了连通而被抹平。电子转录与实际引用版本的限制见各来源记录，使用条件见 [LICENSES.md](LICENSES.md)。
