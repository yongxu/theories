## 本轮特定边界
规范父库 outputs/three-teachings-v1.0/data/model.json SHA256 b0500e836f15935e893187b1fcfc394dfbcb13dc9025a2bb4efe225beab150f6。此前所有输出与用户repo只读。旧综合库 outputs/chinese-thought-atlas-v9.1 可供发现线索；不能不复核直接提升为本轮严格数据。每个新分区有自己的唯一来源ID、冻结文件、连续原文和阅读账本。
每个节点必须有实际具体释义，不用“本段中的X”“此章定义”等循环模板代替内容；原典未解释则准确注明未定义。cognitive必须说明该义项在这一论证中的作用，现代解释明确标记，不能给全篇所有节点同一空泛句。
传世篇章题署、说话者与历史人物分开。庄子内外杂篇不全归庄周亲著；韩非篇章说法不是现代机制设计的实证规律；《孙子》不是一切人际关系的行动指南；墨辩校勘疑字保留；名家分类是后起编目，不把惠施、公孙龙和后期墨者混成一个说话者。中国佛教纳入译介、解释、争辩与本土转化的脉络，不能把印度源流抹去。
modern_comparison须有至少两侧节点、完整断言与原段定位，且不可当历史影响。跨分区比较由根代理待双方冻结后做；各研究分区可使用父库稳定ID，但必须明确引用已经读到的记录，不猜ID。
覆盖是有限边界：尽量完整登记所选作品章篇；已阅读全文/选段/仅登记必须分别标记。严禁为了数量机械映射每句；提取能够解释认知、判断、组织、争辩、修养、制度和策略的完整结构。
交付 bundle.json、self-review.json（作者审查，不能冒称独审）和实际阅读账本；根将交另一代理独审并冻结哈希。作者脚本不覆盖独审后版本。

## 封版时补充的范围规范

当覆盖记录按篇组织、阅读单位仍保留整部作品的 `work` 时，必须提供 `coverage_unit_ids`。它是同一新增分区真实阅读单位的非空、无重复列表，不改变原文作品身份。已映射单位按 `node_ids` 或 `relation_ids` 任一非空计算：只有概念、没有新增判断的段落仍计入映射。登记、实际完整核读、映射三种计数分别推导。

`coverage_basis` 只接受“完整作品”“完整章”“选段”；整章中一个段落用“选段”，具体段落或目录身份写在 `coverage_detail`。亡篇目录仍保留 `source_only`，不能因此算全文核读。完整章的实际通读范围由覆盖单位集合与阅读账本另行证明。

独审完成后应先严格预验，再冻结发布哈希。发生范围字段修补时，保留逐字段差异，重新绑定独审报告、依赖比较与导航目录的最终哈希。机械核验通过不等于语义核读；两者均须完成。
