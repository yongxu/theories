# 一页导读｜文·合·化 v7.0：依观判守

**核心问题：** 高阶比较映射 $\chi:U\to V$ 不可逆时，我们究竟能保留什么？能否精确说明指定查询下的保真程度，并把局部误差传播到复合系统？

**核心发现：** 「可比」不等于「相同」，「结构不同」不等于「每项观察都不同」。**同与守必须相对于明确的查询、接口、条件和误差尺度。**

## 四项有证明的受限命题

1. **最小像失配：** 给定非空有限 $U$、$\chi:U\to V$、全局分布 $\mu$ 和观察 $q:V\to O$，局部任何概率提升可达到的最小总变差，恰等于全局分布落在 $\mathrm{im}(q\chi)$ 之外的观察质量。
2. **观察粗化单调：** 若 $q_2=h\circ q_1$，则最小像失配 $\delta_{q_2}\le\delta_{q_1}$。**观测等价始终是依查询而定。**
3. **众观共同提升：** 各查询分别可被满足，不保证存在一份局部分布同时满足；即使所有边缘共同满足，也未必保留联合相关性。有限问题化为凸包可行性。
4. **近似随机组合：** 类型相容的有限 Markov 核，其串联误差与独立张量误差，在按输入行取最大总变差的度量下，受各段误差之和的上界约束。
