# CHANGELOG

## v7.0 — 2026-11-24

**主题：依观判守：查询索引的弱交换、精确失配、联合可行和误差预算。**

- 以第六阶段的有限弱交换比较 $\chi$ 为基础，证明查询像缺失质量等于最佳可实现 TV 误差；给出达到下界的有理数局部提升。
- 证明粗化查询不会增加最佳像缺失误差，并检验小规模全部观测组合。
- 区分单查询可解、众查询共同可解与联合查询可解；新增有限凸可行性精确算法和反例。
- 为有限 Markov 核加入串联与独立张量的误差上界证书，附穷举测试。
- 在 31→81 的非平凡四阶段谱系例子上检验左／右结合的比较一致性，保留非可逆性。
- 新增 48 条概念精注（六个语义族）、两张理论示意图及七篇新研究文稿。
- 新增 45 项测试，累计 232 项通过；所有旧核心成果与 PDF 继续保留。
- **明确限制：** 此处不是普适双范畴已证、自然概率提升或因果保真自动成立的宣言。
