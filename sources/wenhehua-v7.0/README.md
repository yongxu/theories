# 文·合·化｜最小生成文法研究 v7.0

**阶段七：依观判守——查询索引的高阶比较、最佳失真、共同解释与误差预算。**

> 文以辨，合以成，化以易；观有所取，守有所据。相通不强同，生生不失其别。

## 本版核心

v5–v6 已经将「合」和「化」统一到有限类型化共界见证的有向高阶比较中，并将它们分别与概率、连续流、资源、因果与粗粒化语义做了初步连接。v7 解决的是进一步的**判定问题**：给定全局见证和我们关心的观察，局部解释是否能够精确保真？如果不能，最小不可恢复的观察误差是多少？多个查询是否能由**同一个**解释一起满足？近似随机组件的误差如何随组合传播？

本版保留旧研究全部核心材料和历史 PDF；新材料包括数学命题、程序、精确证书、反例、研究计划和概念精注。

## 学术与工程边界

v7 的 G.1–G.4 有明确的有限数学假设与书面证明；四阶段高阶组合测试属于受限相干性切片；其他物理与因果语义有独立条件。这仍不是普适现实本体论的已证最小公理系、完整 intercategory 机器化证明，也没有现实领域上的经验保真保证。关于学术归属与失效条件，务必参阅 `sources/51_第七阶段文献与数学归属.md` 与 `review/48_依观判守_反例审查与边界.md`。
