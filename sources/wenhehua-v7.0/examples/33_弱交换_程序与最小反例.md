```bash

```

## F2. 正例：比较映射可逆

三个阶段的接口与左右网络各包含单个同类型节点；两步变化各自都有左右及共享接缝的完整相容见证。

- 局部先续再合：1 个谱系见证；
- 整体先合再续：1 个谱系见证；
- 比较映射是双射。

该例表明：变界演算允许严格相容，而不是必然走向信息丢失。

## F3. 反例：跨界接力

保持三个阶段的结构连接不变，但对关联历程只作部分声明：

- 第一步只有左边提供一个历史 token；
- 第二步只有右边提供一个历史 token；
- 两步均没有共界历史 token。

各侧独立接续均为空，然而两段整体见证因中间推积的公共节点而可相续。

```text
局部时间接续 → 沿界相合: 0 个见证
沿界相合 → 整体时间接续: 1 个见证
χ : ∅ → {(u,v)}，不是同构
```

**此例只说明形式上的合成空间存在更多路径，不证明现实中的跨系统传递。** 这一区分是本轮改进的关键。

## F4. 两条不同路径不应自动视为一条

考虑 $a$ 经 $b_1$ 或 $b_2$ 到 $c$，两条路径的首末状态相同：

```text
a → b1 → c
 \→ b2 →/
```

通过跨度拉回得到两个见证 $(x,p)$ 和 $(y,q)$。若立刻压成普通布尔关系 $aRc$，这两个见证被不可逆地合成一条 `true`。

在软件中：

```text
完整谱系路径：2
去掉来源后可辨的首末关系：1
```

因此同一「关系」至少有两种不同强度：存在性、来源可追踪性。需要按任务选择，而不是擅自抹平。
