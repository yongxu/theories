# 第六阶段实验：逐项验证每一条桥

**运行：** `cd software && PYTHONPATH=. python -m unittest discover -s tests -q && PYTHONPATH=. python demo_v6.py`

使用 Python 标准库，数值运算采用 `fractions.Fraction`，所以本例没有浮点比较容差误差。v6 的新验证为 50 项，连同 v5 的 137 项共 187 项（以最终测试日志为准）。

## 一、统一可复现表

| 桥梁 | 输入实例 | 精确结果 | 失败模式 |
|---|---|---|---|
| 类型→确定性 | `flip∘flip` | 恒等映射 | 类型不符、缺少生成元语义则拒绝 |
| 确定性→随机 | `flip` 后接 3/4 可靠的 `noise` | `P(output=1\|input=0)=3/4` | 行和不为 1、接口不匹配则拒绝 |
| 资源→守恒 | `2H2+O2→2H2O` | H/O 两种守恒残差都为 0 | 错误权重、不兼容计量单位报错或非零残差 |
| 资源→连续 | `A→B→C`，线性速率 | `(-2,0,+2)`，总导数 0 | 负浓度和未知物种报错；开放源项不保守 |
| 空间→度量 | 3m 接 4m 的唯一接缝 | 7m | 米/千米无显式变换则拒绝 |
| 观测→因果 | `X→Y` 对 `Y→X` | 观测分布相同；do 后 1 对 1/2 | 由观测直接声称因果被反例否定 |
| 微观→宏观 | 三状态 Markov 链压缩 AB | `P(AB→C)=1/4` | 同宏观类转移分布不同则拒绝 |
| 弱比较→权重 | v5 非满射 χ | 未覆盖全局路径权重为 1 | 负权重、漏报全局见证则拒绝 |

### 两个应当被读作反例的数值结果

1. **观测相同，因果不同：** `causal_observational_equal: true`，`causal_doX1_forward_Y1: 1`，`causal_doX1_reverse_Y1: 1/2`。
2. **结构存在，权重不可无损回送：** `lineage_comparison_lax`: `local_paths: 0`，`global_paths: 1`，`extra_global_paths: 1`。只要该额外全局路径被赋予正权重，就不能是某个局部见证权重沿 χ 的推前。

## 三、这些测试不意味着什么

- 运行测试不是 formal proof assistant 的一般证明；论文中的定理有独立的数学证明步骤。
- 无效输入被拒绝只证明软件约束在对应测试样例有效；不证明所有未知错误都不可能发生。
- 线性反应的原子守恒不能替代更真实的反应热、电荷、空间扩散与外部通量。
- 概率核是描述抽象随机过程的数学对象，不保证其参数来自可信观测。
- 结构因果模型是受明确机制假设约束的例子，不能由“找到一条结构路径”就认为因果识别成功。
- 空间测试仅为有向非负路径代数，不是物理运动学与碰撞模拟。

## 四、测试与文献的证据等级

- 代数或初等推导：F1–F6 中明确给出证明的有限命题。
- 既有成熟结果：structured cospans、开放反应网的动力学语义、Markov 范畴、双范畴/跨度相容性等。需要引用原文与严格假设。
- 有限代码实验：通过测试脚本复现；用于验证实现，不能外推超出支持的模型。
- 长期研究命题：跨所有语义的动态接口双函子及高阶自然性，目前仍开放。
