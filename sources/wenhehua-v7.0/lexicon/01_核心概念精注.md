# 文之字义：精注核心词谱

> 共 84 个去重后的核心概念，系对原始389条广义候选的**强化解释和可构造前提**；并非这些词全部具有已核证的先秦义。

**证据分级**：此表「工作定义」属于本项目提出的形式语义，不是古字训诂。古典书证需另列出处和释读争议；没有可靠书证时不推测「本义」。

## 层级说明

- **核**：第一层构造候选（文、合、化）。
- **元律**：语法、等价与性质的规则层（则、理、约等）。
- **派生**：可由给定关系图或重写等结构构造。
- **语义**：引入时间、动力学、几何、概率、因果等额外解释。
- **规范**：价值、权利和制度评价，依赖显式的社会规范。

## 核（3 词）

| 词 | 工作定义 | 构造路径/前提 | 误用警示 |
|---|---|---|---|
| 文 | 有类型开放关系配置 | 签名、顶点、关联、端口 | 不可当作宇宙的最小实体 |
| 合 | 沿可相容共同界面粘合 | 离散边界推积 | 类型相同不足以保证物理相容 |
| 化 | 合法局部重写 | 匹配、保留子图、悬挂条件 | 不等于任意数值变化 |

## 元律（8 词）

| 词 | 工作定义 | 构造路径/前提 | 误用警示 |
|---|---|---|---|
| 则 | 类型、相容、等价及性质约束 | 给定推导语境与规则版本 | 不等于自然规律必然成立 |
| 理 | 模型中可说明和证明的关系规律 | 定理、方程、模型律 | 勿把模型定理宣称宇宙真理 |
| 法 | 规定运行或构造的规则 | 公理、类型检查 | 自然与社会法须区分 |
| 约 | 约束满足与相容条件 | 谓词、SMT、合约 | 需声明约束对象 |
| 允 | 某操作在给定规则下被允许 | 类型与条件检查 | 合法不等于善 |
| 禁 | 明确阻止一种转变 | 不可达性/权限 | 可能是人为规则 |
| 证 | 对命题提供可检查的论证 | 证明对象/验证器 | 证明正确依赖规格 |
| 错 | 不满足指定规范或与事实不符 | 反例/错误见证 | 需明确规范 |

|---|---|---|---|
| 观 | 给配置与变化赋予特定解释或观察 | 观察映射、尺度和查询 | 不保证完全可逆 |
| 耦 | 相互影响而成联合动力学 | 耦合方程 | 局部稳定不保证整体稳定 |
| 应 | 对输入有条件的响应 | 反应函数或概率核 | 不自动蕴含主体意向 |

| 时 | 给过程引入时间结构 | 离散/连续/事件时 | 无统一默认时钟 |
| 因 | 干预下后续变化受其影响 | 结构因果模型 | 相关性不足以推出因果 |

| 流 | 持续或离散传递 | 动力系统/流量 | 涉及守恒则需添加方程 |

| 长 | 规模或组织随时间增长 | 重写序列与测度 | 增长不等于进步 |

| 阈 | 某条件使规则启停的边界 | 阈值或守卫谓词 | 不都是线性阈值 |
| 常 | 在指定变化族中保持 | 不变量 | “保持”需说明范围 |

| 守 | 资源、性质或约束在变化中保留 | 守恒量/不变量 | 不能从图结构自动得出 |
| 衡 | 平衡、定点或流量相抵 | 方程、均衡概念 | 均衡不一定稳定 |
| 形 | 指定几何或拓扑性质 | 几何/拓扑后端 | 图连接不自动给长度 |
| 位 | 配置中的位置或相对次序 | 坐标/几何解释 | 坐标选择依情境 |
| 域 | 结构存在或变化允许的范围 | 空间、定义域、状态域 | 与物理领地不等同 |
| 场 | 在连续或离散域分布的量 | 场论语义 | 不是所有系统有场 |
| 孔 | 拓扑空洞或缺口 | 同调/拓扑性质 | 图中的圈与连续洞不同 |
| 闭 | 拓扑闭性或交互闭合 | 拓扑/系统边界 | 封闭系统仍可有内部变化 |
| 群 | 可逆变换的合成及逆 | 群公理 | 任意过程并非可逆 |
| 逆 | 特定变换有双侧逆 | 同构/可逆映射 | 时间反演不总合法 |
| 对称 | 特定变换保持结构 | 自同构或群作用 | 对称依据指定语义 |
| 同构 | 保结构的双向可逆对应 | 范畴中的同构 | 不同语义可能非同构 |
| 等价 | 给定判据下互可替代 | 等价关系/双向行为等价 | 不等于同一 |
| 映 | 把一种描述映成另一种 | 函子/态射/观测映射 | 未必保因果 |
| 象 | 选定观察下得到的呈现 | 表示/抽象 | 不必是视觉图像 |
| 知 | 依据观察形成可使用的表征 | 认识论/信息语义 | 不可直接等于主观感受 |
| 记 | 在变化中保留可读信息 | 存储状态/事件日志 | 记录可失真 |
| 学 | 依据经验改变参数、策略或结构 | 学习算法/更新规则 | 不是所有适应都为学习 |
| 悟 | 产生新的概念或解释的变化 | 模型建构/抽象更新 | 很难用单一测试判定 |

| 词 | 工作定义 | 构造路径/前提 | 误用警示 |
|---|---|---|---|
| 别 | 根据指定可观察属性作区分 | 谓词、等价关系 | 观察不尽则不等于真不同 |
| 异 | 在比较准则下不相同 | 同一、同构或观测等价 | 需声明比较准则 |
| 同 | 在选定等价下相同 | 等价关系或同构 | 勿混淆字面相等 |
| 间 | 两配置之间或之内的相对空间/接口 | 几何或边界模型 | 不默认是度量距离 |
| 界 | 对某次交互选定的开放端口 | 边界态射 | 边界可能随互动变化 |
| 端 | 可接入或输出的接口部位 | 端口类型 | 需方向与资源约束 |
| 通 | 在指定机制下可连接或可达 | 关系与可达性 | 连接不等于通信成功 |
| 隔 | 在某种交互方式下不可达 | 可达性否定 | 换语义可能消失 |
| 联 | 存在指定的二元关联 | 图边或关系 | 须区分因果与相关 |
| 交 | 有共同参与者或交互事件 | 接口连接或超边 | 语义可能为非对称 |
| 互 | 存在两个方向或相互依赖 | 双向映射或反馈 | 双向不等于互惠 |
| 并 | 沿空界或独立接口的组合 | 余积/幺半积 | 不总能任意交换 |
| 叠 | 在同一位置或接口进行多层配置 | 层叠、覆盖 | 需明确重叠判据 |
| 嵌 | 一配置成为另一配置的子配置 | 单射或包含 | 并非所有子系统独立 |

| 组 | 将若干结构组织为可操作单位 | 复合与封装 | 只是结构上的统一 |
| 事 | 一次变化或事件集合 | 重写轨迹 | 未必唯一归因 |
| 迁 | 配置位置或结构的改变 | 重写或动力学 | 位置需额外几何语义 |
| 变 | 在选定比较下产生不同配置 | 重写及观察 | 微观变不一定宏观变 |
| 易 | 一类可替代的转换 | 重写规则或同态 | 不要求可逆 |

| 开 | 开放接口或拓扑开集 | 边界或拓扑解释 | 两个义项须区分 |
| 修 | 对不满足性质的配置进行更正 | 重写+验证 | 修复过程可能有副作用 |

## 规范（6 词）

| 词 | 工作定义 | 构造路径/前提 | 误用警示 |
|---|---|---|---|
| 共 | 某种结构可被多人共同参与或分享 | 产权/访问/治理模型 | 不是推积自然推出的价值 |
| 善 | 对人和生态福祉有益的评价 | 明确价值准则及事实 | 不是数学连通性 |
| 义 | 正当性、责任与相互承认 | 道德/政治哲学 | 不能从形式语法直接推出 |
| 和 | 多方关系的协调与可持续相处 | 冲突解析与多目标模型 | 协调非同质化 |
| 自由 | 真实可行的行动选择与免于支配 | 能力、权利、资源约束 | 不能只数选项数量 |
| 多样 | 差异得以持续存在和演化 | 多样性度量/保护条件 | 不等于无秩序 |
