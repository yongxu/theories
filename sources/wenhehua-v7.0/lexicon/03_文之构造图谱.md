# 文之构造图谱：从最小文法到具体形式

> **这是生成模式图鉴，不是古汉语辞典。** 下列「点文、流文、界文、观文」等以「文」命名的多数词语，是研究中为方便表达而设的**构造标签**，不能当作历史固定术语或先秦原义。

## 一、从什么生成什么

最简逻辑骨架：

```text
领域签名 Σ ──赋型──→ 文（可辨配置）
                         │
                  ┌──────┴──────┐
              沿界相合        合法重写
                  │               │
               复合文          文之变化
                  └──────┬────────┘
                    则：合法性与不变量
                    观：赋义与抽象映射
                         │
       ┌──────────┬──────────┬─────────┬─────────┐
      形/拓扑     动力/时间    信息/因果  资源/伦理等领域
```

**层级警告**：图中的领域签名、则、观并不全是由「文」在无任何前提下导出的。可推导概念必须标明所依赖的签名、变换、性质与解释。

## 二、连接与图式（12 类）

| 标签 | 数学构造候选 | 直观用途 | 必要前提 |
|---|---|---|---|
| 点文 | 单顶点图 | 最小可辨标记 | 选择顶点类型 |
| 边文 | 单有向边及端点 | 相互关联 | 端点类型与边类型 |
| 链文 | 路径图 | 流程与依赖 | 端口方向及可达性 |
| 枝文 | 树形连接 | 分支与模块层级 | 无环条件 |
| 环文 | 有向闭路 | 循环网络 | 图上闭路不等于稳定反馈 |
| 网文 | 一般连接图 | 复杂系统拓扑 | 节点/边语义 |
| 超文 | 多端点超边 | 多元反应与协作 | 边的有序端点及角色 |
| 重文 | 多条平行边 | 多重关系 | 边具有独立身份 |
| 辐文 | 星形连接 | 枢纽网络 | 中心节点的建模选择 |
| 桥文 | 连接不同子网的结构 | 接口与中介 | 连通判据 |
| 断文 | 给定连接语义下的不连通 | 隔离与故障 | 指定可达定义 |
| 邻文 | 邻接关系或邻域族 | 局部环境 | 图或拓扑语义 |

## 三、相合与组织（12 类）

| 标签 | 数学构造候选 | 直观用途 | 必要前提 |
|---|---|---|---|
| 并文 | 沿空界连接 | 并置与独立模块 | 空图与并合存在 |
| 接文 | 沿单一相容端口粘合 | 串联模块 | 类型与界面相容 |
| 汇文 | 多个输入共用指定接口 | 汇入与汇聚 | 复制/合流约束须另立 |
| 分文 | 从组织中显露多个子接口 | 分工与分流 | 不能自动复制线性资源 |
| 嵌文 | 配置作为另一配置的子图 | 嵌套与封装 | 保结构映射 |
| 叠文 | 若干配置叠置到共同域 | 多层结构 | 同一域或坐标体系 |
| 织文 | 多种关系交错成网络 | 系统互依 | 多类关系的签名 |
| 合文 | 指定多个接口的推积式连接 | 模块组成 | 推积条件 |
| 复文 | 复合过程再作为构件 | 多尺度工程 | 抽象后的接口 |
| 隐文 | 对外遮蔽内部结构 | 封装 | 外露接口与隐藏语义 |
| 显文 | 暴露原本内部的特定接口 | 观测和调试 | 不破坏隐私和安全 |
| 枢文 | 把交互集中在特定节点/过程 | 控制与协调 | 枢纽失效与资源瓶颈 |

## 四、变化与历程（14 类）

| 标签 | 数学构造候选 | 直观用途 | 必要前提 |
|---|---|---|---|
| 迁文 | 节点/边/属性的合法迁移 | 迁居与工作流转移 | 定义位置或属性 |
| 易文 | `L←K→R` 重写 | 局部替换 | DPO 匹配及保留条件 |
| 新文 | 加入新的节点或边 | 生长 | 类型、资源预算 |
| 消文 | 删除节点或边 | 消亡 | 悬挂边、开放端口约束 |
| 续文 | 合法重写的路径 | 历程 | 事件排序 |
| 循文 | 配置经过若干步返回等价类 | 周期 | 等价标准 |
| 蜕文 | 局部更换累积为整体改变 | 演化 | 距离或相异度 |
| 裂文 | 一个配置的连接或主体分成部分 | 分化 | 割集、资源归属 |
| 融文 | 多个组织通过额外联系形成整体 | 融合 | 不与同质化混淆 |
| 换文 | 规则或实现的可替换组件 | 软件热更新 | 对外合同与状态迁移 |
| 折文 | 轨迹在条件下转向 | 分支、折返 | 动力学或守卫规则 |
| 跃文 | 状态跨越离散阈值 | 相变/切换 | 事件与阈值语义 |
| 演文 | 规则驱动的持续历程 | 自组织与演化 | 时间及转移语义 |
| 元化文 | 重写规则自身的合法变化 | 自修改与学习 | 规则表示和可信验证 |

## 五、时间、反馈与动力（10 类）

| 标签 | 数学构造候选 | 直观用途 | 必要前提 |
|---|---|---|---|
| 时文 | 事件索引或时间参数 | 事件与时间模型 | 时钟、偏序或连续时间 |
| 序文 | 事件偏序 | 并发执行依赖 | happens-before 定义 |
| 同时文 | 事件不具指定因果先后 | 并行 | 不代表物理绝对同时 |
| 延文 | 具有一步或一定时延的连接 | 反馈回路 | 延迟与初始状态 |
| 馈文 | 输出影响后续输入的回路 | 控制与调节 | 有意义的反馈语义 |
| 流文 | 状态随时间连续变化 | 连续系统 | ODE/PDE/边界条件 |
| 稳文 | 在扰动下保持某性质 | 稳定与恢复力 | 度量、扰动、动力学 |
| 趋文 | 轨迹朝某类状态的趋势 | 吸引子、趋势 | 吸引域及定量模型 |
| 岔文 | 参数改变带来质变 | 分岔 | 参数化动力学 |
| 适文 | 根据环境反馈调整结构或策略 | 学习与适应 | 经验与更新准则 |

## 十、哪些构造不在最小核心内

**观测、时间、拓扑、几何、信息、概率、逻辑、因果、生命与价值**都不必在一个纯粹的图组合核里成为独立「实体」，但它们也不可能仅由三个字自动、无损地推出。它们是需要相容语义的数学结构或经验领域。

所谓最小，不是把所有复杂性折成同一个词，而是让每个不可少的区别出现在最恰当的层级。

## 十一、一个文字上的概念网络

> 别则有文，接则有界，界随接立。  
> 相接而合，因合见网；相易而化，因化见序。  
> 续而为脉，循而为环；常存变化，势寓其间。  
> 观有所取，法有所据；异观可通，同名未必同理。  
> 所成可再成，所化可再化；文以成文，不穷于一形。

这段是项目原创的概念文字，用以辅助思考，而不是取代形式证明。

## 十二、跨尺度与涌现（10 类，项目命名）

| 标签 | 数学构造候选 | 直观用途 | 必要前提 |
|---|---|---|---|
| 微文 | 低层解析后的精细配置 | 细胞、节点、进程 | 对应的解析模型 |
| 宏文 | 通过抽象获得的整体配置 | 组织、系统、群落 | 宏观闭合或误差估计 |
| 层文 | 多尺度配置及层间关系 | 系统层级 | 不是必然树状层级 |
| 涌文 | 复合后出现的整体性质 | 涌现行为 | 定义整体性质与不可约判据 |
| 集文 | 由统计聚合形成的配置 | 群体动力学 | 统计量与抽样 |
| 共演文 | 两种以上组织相互影响其变化规则 | 生态/技术协同演化 | 联合动力学与环境反馈 |
| 扩文 | 保留接口、扩大内部组织 | 模块扩容 | 状态迁移与资源约束 |
| 缩文 | 在指定尺度合并或删减细节 | 简化和抽象 | 需要保留的查询集合 |
| 衡续文 | 维持功能同时更新内部构成 | 稳态更新系统 | 明确功能与稳定性指标 |
| 生生文 | 新组织成为后续组织的组成者 | 递归生成 | 分层、递归与终止/生产性条件 |
