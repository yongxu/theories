# 文之词林：界变·时流·观守概念增注（v3.0）

**88 条精注工作词条，覆盖 11 个语义族。**

此表不是古汉语字典，也不是对古代原典思想的归属声明。「古字今释」表示借用古字作现代工作定义；「新拟复合」表示研究命名。各条都必须服从形式规格，不能单凭字面暗示证明。原有389词、84重点精注、79高阶增注均保留在项目中。

## 界与辨

| 词与术语身份 | 工作定义 | 对应 | 审查要点 |
|---|---|---|---|
| **界**（古字今释） | 相对于连接或观察指定的可交互边界 | boundary object | 并非物体固有的墙 |
| **端**（古字今释） | 被指定为一次交互的端点出现 | port occurrence | 同节点可以有多个角色 |
| **门**（研究性转义） | 接口许可某类作用进入或离开的条件 | admissibility predicate | 端口存在不保证权限 |
| **别**（古字今释） | 在所选观察下可区分的情况 | distinction | 不等于本体绝对分离 |
| **域**（古字今释） | 构造或规律适用的配置范围 | domain | 不可偷偷外推 |
| **型**（研究性转义） | 约束接口和构造可相接的类别 | type | 字符串同型未必语义同型 |
| **界序**（新拟复合） | 有序界面端口出现的排列 | ordered interface | 重排要有显式迹 |
| **界型**（新拟复合） | 界面各端口所携带的类型信息 | typed boundary | 可能还需单位和协议 |

## 续与身份

| 词与术语身份 | 工作定义 | 对应 | 审查要点 |
|---|---|---|---|
| **续**（古字今释） | 改变前后共同保持的身份见证 | preservation witness | 不等于时间连续实测 |
| **迹**（古字今释） | 旧界面出现到新界面出现的部分对应 | partial injection | 同名并不自动成迹 |
| **承**（研究性转义） | 前一配置中某部分由后一配置接续 | span inclusion | 必须指定映射 |
| **守**（古字今释） | 指定属性在变化中保持 | invariance | 需说明所守的性质 |
| **常**（古字今释） | 某类变化下可持续成立的规律或性质 | invariant / stability | 常并非不变动 |
| **身份**（现代用语） | 用于判断前后是否为同一端口的标准 | identity criterion | 依观察和物理证据 |
| **断续**（新拟复合） | 身份轨迹在某步中断又重出现 | partial trace composition | 重出现非连续 |
| **界迹**（新拟复合） | 记录端口增减与延续的可检查数据 | InterfaceTrace | 不提供物理时间 |

## 连接与适配

| 词与术语身份 | 工作定义 | 对应 | 审查要点 |
|---|---|---|---|
| **合**（古字今释） | 沿相容界面构成新的整体组织 | pushout composition | 非任意加法 |
| **接**（古字今释） | 两个接口按约束建立连接 | gluing | 应明确连接位置 |
| **通**（古字今释） | 关系中的可达可传或可作用 | reachability / communication | 通不等于完全可替代 |
| **纽**（研究性转义） | 使多局部关系关联的共享位置 | junction | 共享资源可能冲突 |
| **转接**（现代用语） | 通过明确过程适配不完全相容的两端 | adapter | 需要额外语义验证 |
| **共界**（新拟复合） | 连接两份开放文的明确共享接口 | seam boundary | 变界时需共同认可 |
| **合迹**（新拟复合） | 组合前后保留接口身份的配对 | horizontal evolution | 仅在限定接缝成立 |
| **互接**（研究性转义） | 两个系统具有互补或双向接口作用 | bidirectional wiring | 不是对称关系必然成立 |

## 变化与重构

| 词与术语身份 | 工作定义 | 对应 | 审查要点 |
|---|---|---|---|
| **化**（古字今释） | 组织或互动可能性的有据变更 | rewriting / change | 不指定变化速度 |
| **易**（古字今释） | 一个配置改变成另一配置 | transition | 不等于可逆 |
| **变界**（新拟复合） | 接口数量类型角色或排列发生变化 | interface evolution | 旧身份要有踪迹 |
| **显**（古字今释） | 将原来未外露之部分开放为接口 | exposure | 不一定新生节点 |
| **隐**（古字今释） | 将原来外露之部分改为内部不可见 | encapsulation | 不必删除内部结构 |
| **增**（古字今释） | 增加可辨组件或端口出现 | extension | 应区分新显与新生 |
| **撤**（古字今释） | 撤去外露身份或连接 | withdrawal | 撤口不等于销毁 |
| **重排**（现代用语） | 对外露端口排列进行可追踪改变 | permutation | 若类型不同不能强制互换 |

## 时间与行为

| 词与术语身份 | 工作定义 | 对应 | 审查要点 |
|---|---|---|---|
| **时**（古字今释） | 变化被解释为先后或连续演进的参数 | time parameter | span 不自带时间 |
| **序**（古字今释） | 事件之间的先后或依赖 | order / partial order | 不要求单一全序 |
| **步**（现代用语） | 离散更新的一个事件阶段 | discrete step | 不能代替连续时间 |
| **流**（古字今释） | 状态在连续时间中的变化 | ODE flow | 需存在唯一性条件 |
| **历程**（现代用语） | 由多次状态与接口变化构成的序列 | trajectory | 过程记录与生成律不同 |
| **回环**（研究性转义） | 结果回入自身后续输入的组织 | feedback | 无延迟可能不良定义 |
| **迟**（研究性转义） | 输出作用经过指定步或时长后生效 | guard / delay | 可能改变系统行为 |
| **触发**（现代用语） | 某条件满足引发相应变化 | event guard | 必须明写条件 |

## 方法说明

一、严格区分「语言组织之优雅」与「数学命题之成立」。二、不能因为两个术语在不同领域都能用，就认定两个领域满足相同定律。三、如果形式系统发生修订，应连带修订每个词的解释和反例。四、古典考据需要独立阅读原文，不能把本表标为已完成的训诂。
