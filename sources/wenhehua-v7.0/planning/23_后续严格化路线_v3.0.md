# v3.0 之后：从有限变界到可发表的统一理论

本计划区分**本轮已实现**、**理论上有数学先例**和**本项目尚未完成**的任务，不把愿景当成果。

## 完成基线

- M1：文—合—化作为可操作的开放网络生成语法（v1）。
- M2：组合、重写、同构与跨尺度失真的可复现反例（v1.2）。
- M3：固定界面下 monic spans of cospans 的有限高阶构造（v2）。
- M4：外部界面可变、接缝持续的受限变化见证；Finite ModeMachine / Kernel / MassFlow；接口保真与随机粗粒化检验（v3）。

## 第一优先级：真正可变的公共接缝（P1）

**待做**：实现可增减的共享界、显式适配器、接口态射方格。对拆分、合并、连接冲突、端口变型提供严格合法性与拒绝规则。

**验收**：形式定义四种组成对象（界、开放文、变界见证、适配方格），给出一个新的非平凡相容定理与最小反例；证明不依赖仅有固定接缝的旧命题。

## 第二优先级：依赖时间/界面的过程语义（P2）

**待做**：将 `ModeMachine` 的 mode 显式赋值为 `OpenGraph` 和合法端口模式，令状态转移与 `Evolution` 的结构变化配对，检查自然性。随后对接 polynomials / coalgebras / guarded trace 等成熟结构。

**验收**：至少一个「结构变更—模式转移」共同可执行案例，以及合法模式转移但结构见证不相容的反例。

## 第三优先级：形式证明（P3）

**待做**：Lean 4 / Rocq / Agda 的有限有类型节点连接、接口部分单射及垂直组合；逐步对 stable-seam horizontal pasting 与 interchange 证明。

**验收**：能编译的证明脚本、无 `sorry` / 未验证占位；与 Python 有限枚举实例交叉比对。**本版没有该成果。**

## 第四优先级：跨尺度查询与因果（P4）

**待做**：给定明确的观察查询族 $Q$、微观/宏观干预映射，在有限 SCM 模型上计算自然性方格与失败见证。允许近似误差但必须提供误差上界及适用分布。

**验收**：相同统计预测但干预不相容的反例，与真正保留指定因果查询的一项正例。

## 第五优先级：连续时空、并发与资源（P5）

**待做**：开放 ODE 的时间依赖接口、离散/连续混合系统、并发临界对、类型化物理量与质量/能量计量。所有模型需写明求解域与条件。

**验收**：一条能够在局部组合下证明守恒/非负/可达性等性质的有限系统；以及一条表明仅凭结构组合无法保证该性质的反例。

## 第六优先级：跨域和人类评价（P6）

**待做**：用至少两个真正不同的领域模型（例如机器人与生化网络）复用相同的语法构造；规范性体系另行声明目标、权利与评价标准，不通过结构术语偷推价值判断。

**验收**：真实数据或可复现实测；与不共享数学假设的基线方法比较；开源审查、贡献与失效记录。

## 判断文法是否「完整」的工作标准

完整不是「无论输入什么都说得通」，而是：给定一个明确领域，能够表达其必要结构，规定含义，生成系统，检查不变量，报告不能表达的现象，给出失败或误差证据。对所声明的范围做到这一点，即是领域内可用的完整性；一般世界本体的完整性仍是独立、开放的问题。
