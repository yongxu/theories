# 下一阶段计划：从可检验片段到高阶自然性

## 研究目标

寻找既能解释界面生成、撤回与身份变化，又能够对严格可合成子类建立定理的数学结构。比继续缩短「文、合、化」三个字更重要的是：明确何种语义使不同合成次序真正交换。

| 阶段 | 要解决的问题 | 可交付与验收条件 |
|---|---|---|
| P1 · 全面定义 | 提出适当的动态接口对象和态射类别 | 给出全部对象、一胞、二胞与边界的严格定义；提供反例库 |
| P2 · 接续律 | 证明变界见证垂直接续符合结合律和单位条件 | 明确可适用的同构/transport；形式证明优先 |
| P3 · 横向相容 | 给出可横向合成的必要及充分判据 | 测试临时合并与分裂、外侧身份混用及悬挂引用 |
| P4 · Interchange | 证明一种有条件、可自然选择的交换律，或证明做不到 | 精确写出类别/装备结构与 coherence，标注失败条件 |
| P5 · 语义函子 | 将结构投向概率、控制、连续流与资源模型 | 每种语义给出真实保留量及反例，阻止“万能保真”口号 |
| P6 · 证明工程 | 核心构造 Lean/Rocq/Agda 化 | 确定性可重放证明，版本锁定，无未承认公理 |
| P7 · 研究公开 | 形成同行可复现、可挑战的技术报告 | 独立评审、公开代码与不确定性声明 |

## 不做什么

- 不把新造的古汉语复合词冒称经典原义；
- 不为达到“最简三字”而放弃可表征性与形式前提；
- 不将软件测试数量等同于数学证明强度；
- 不将结构上可用的复制、合并解读为物理或社会规范上的许可；
- 不以任何一个范畴论术语替代具体的因果解释、实验模型或验证器。

## 技术决策

1. **保持最小核**：`文` 为具有类型及当前界面的可辨配置，`合` 为合法接合，`化` 为有见证的改变；`续` 是二胞中的证据内容，`则` 是约束，`观` 决定解释方式。
2. **将 weak witness 看作信息顺序而非平凡等号**：候选不同的合法见证可以按包含的身份关系比较强弱，从而研究是否存在自然的最佳选择或仅有部分序的极大选择。
3. **引入规范化接口身份对象**：解决同一个内部节点同时处于多侧界面、端口多角色与同构名称等问题。
4. **领域法则单独声明**：资源类型要定义复制/丢弃能力，协议类型要定义调适，社会制度需额外的权利及正当性规范。

## 最小验收实例

- 接缝 $1\to2$ 且延续其中一个端口；
- 接缝 $2\to1$ 且只保留一个端口；
- 接缝 $0\to1$ 时旧局部节点可能被整体识别；
- 接缝 $1\to0$ 时旧共享点可能分离；
- 改变中外侧端口与接缝别名冲突；
- 两阶段临时接合及拆分，检验高阶不交换；
- 类型不匹配经显式适配器后可在语法层连接；
- 相同结构但不同资源语义，检查一个模型可合、另一个不可合。

**评价标准**：严格前提越少越好，但不能删去必要前提；语言越短越好，但不能丢失正反例；实现越通用越好，但不掩盖领域差别。
