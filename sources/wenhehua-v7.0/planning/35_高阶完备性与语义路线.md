# 研究路线 H：从有限比较演算到高阶可验证系统

**原则：最小不等于偷藏假设。既要少本原，也要清楚交代每一种语义的构造和证据。**

## H1. 已完成的可复现基线

- [x] 有限类型化集，严格类型检查；
- [x] 推积连接与拉回接续；
- [x] 独立保留关联见证与路径重数；
- [x] 变界相容方格和首末端点可比；
- [x] 严格相容正例与不可逆的跨界接力反例；
- [x] 从 v4 回归到 v5 的全套测试与样例输出。

## H2. 优先级 P0：一般有类型超图版本

把当前 `FinSet/T` 的节点接口扩展至完整的多排序超图、端口角色与超边；定义显式的范畴、态射、拉回与推积。必须补齐：边级冲突、类型的变化与角色映射、超边的路径来源、多重边保持、重写匹配与 DPO/SqPO 的差别。

**验收**：可以展示两个真正改变超图拓扑的例子与最小反例；代码对映射、边与连接都做严格检查；明确哪些实例满足 monic 约束。

## H3. 优先级 P0：lax interchange 的 coherence

定义对象、一胞、二胞、两种组合、恒等与比较胞。进一步区分「有一个候选比较函数」和「高阶结构满足全部自然性/coherence 公理」。最好选取一个已经严谨建立的 intercategory / double category 框架，通过明确函子或嵌入使本项目成为其受限模型。

**验收**：至少给出交换比较的自然性方块、单位相容、三重水平和垂直组合的相干图；标明不能推广到非单态的结论。

## H4. 优先级 P1：语义函子的可守性

先建立 4 种*互相不同*的解释，绝不把同一张图当成所有领域的语义：

1. **集合／关系语义**：什么来源路径被保留，什么被压缩？
2. **资源语义**：哪些 token 可复制、丢弃或合并？哪些满足守恒？
3. **概率语义**：见证重数是否被正规化、是否对应条件概率？
4. **因果／时序语义**：哪些形式路径真能表达可干预或可发生的传递？

**验收**：为各语义提供具有否定性的测试；不允许从结构自然性直接推导物理或社会性质。

## H5. 优先级 P1：规范与自然语言层

审查「文、合、化、界、迹、续、观、守、同、异」之间的必要性。目标不是制造更多本原，而是让这些字成为不同数学角色的可理解名称。将经典词义、研究工作定义、数学谓词分别分栏。

**验收**：每个核心词都有最小例子、一个反例、与邻近概念的区别；每一处古典引文需独立核对原文与版本，未经核对者不得伪称古义。

## H6. 优先级 P2：交互式工作台与审稿

开发让研究者可连接节点、修改共界、指派见证、在「先合再化 / 先化再合」之间切换并检查比较映射的交互式工具。然后邀请范畴论、图重写、形式化验证与复杂系统的独立审查者尝试推翻命题。

**验收**：明确失败证书；随机测试与形式证明分开；文档可复现；每一阶段保留变更说明及先前错误的更正。

## H7. 不作为当前成功条件的目标

- 不声称已找到唯一最小的宇宙本体论。
- 不声称所有现实过程都是有限离散集合。
- 不把人类身份、意识或正当性化约成形式对应关系。
- 不把 137 项自动测试等同于高阶数学的机器验证。
