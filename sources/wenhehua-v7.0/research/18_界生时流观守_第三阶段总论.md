# 界因相接而立：从合化同体到界变、时流与观守

**文·合·化研究 v3.0 · 主论 · 2026-11-24**

> 文以辨，合以成，化以易；界由所接，随化而移。  
> 续者见其常，观者知其取；可合未必可守，可守须明所守。  
> 所成复可合，所化复可化；理不离其境，言不逾其证。

## 一、本轮真正要解决的矛盾

上一阶段找到了严格的高阶数学锚点：开放网络作为余跨度（cospan）可以沿界连接；保持共同部分的改变可以表达为单态跨度（monic span）；在规定数学条件下，两种组合满足二维交换相容律。它使「合」「化」不是隔绝的动作，而是一个高阶结构的两个方向。

然而 v2.0 的具体实现仍要求一次变化前后的外部接口**类型与数量保持完全一致**。现实中的许多关键过程都不是如此：传感器失去通道、细胞获得受体、机器人换装接口、智能体获得工具、组织增减协作入口。

因此，新问题不是再发明一个形而上的本原，而是给文法增加一种**可追踪的界面变化**，同时澄清三种完全不同的断言：

1. **语法可构造**：变化之前和之后都有明确的可用接口，记录哪些接口身份持续存在；
2. **动力学可解释**：在给定时间、概率或物理语义下，变化具有明确的行为；
3. **观察可保真**：从细尺度到粗尺度的映射，确实保持了我们声称保持的接口、预测、约束或因果性质。

这三件事不能互相替代。合法的结构重写可以改变可达性；一个良好定义的概率模型可以在粗粒化后不再具有马尔可夫性；两个拓扑同构的系统可能具有不同的资源守恒或社会意义。

本版不是「万物数学已完成」的宣告，而是一套范围明确、可运行、可证伪的中间理论。

## 二、核心概念：文、合、化、界、续、观、则

严格说，这七个字**不全属于同一逻辑层级**：

| 字 | 在本研究中的角色 | 数学或工程对应 | 是否新本原 |
|:--|:--|:--|:--|
| 文 | 在某语义下可辨的组织配置 | typed open graph、状态化模型、diagram | 核心表达对象 |
| 合 | 沿相容界面进行连接 | pushout、水平复合、monoidal wiring | 核心生成动作 |
| 化 | 组织或其可交互方式的改变 | span、rewrite、状态转移 | 核心生成动作 |
| 界 | 相对于连接、观察与使用规定的外露接口 | boundary object、port、interface type | 类型化数据，不独立宣称本原 |
| 续 | 两次变化中被识别为持续的部分 | partial interface trace、preservation witness | **本版新增的见证**，不是时间本体 |
| 观 | 从组织到所关心现象的解释 | functor/semantics、observation、quotient | 语义与验证层 |
| 则 | 构造、等价与约束遵循的规律 | typing、equations、invariants、proof obligations | 规则，不是新实体 |

**关键修订：界不是封闭容器的墙。** 它是为了某次连接、解释或行动而标定的可交互部分。一个节点可以在一种观测中是内部，在另一种观测中是接口。接口可以因重构而增减，但其更替需要具体的身份见证。

**另一个关键修订：续不是「存在一条相似的路径」。** 在 v3.0 的有限模型里，「续」要求接口身份由共同保留子图中的单态见证支持。两个接口同名或类型相同，不代表它们有可证的持续身份。该定义严格，但也有意限制：真实身份可能需要物理连续轨迹、统计证据或制度规则才能判定。

## 三、从一体二向到随界而化

固定界面的文可以由开放网络表示：

\[
I\xrightarrow{i}D\xleftarrow{o}O.
\]

两份文沿界 $K$ 连接，得到 $A\amalg_K B$。「合」只在相容边界上发生；没有连接义务时可并置，有明确共同界面时可粘合。连接本身不自动带来物理或社会意义上的合作。

固定界面的改变由 $D\leftarrow C\rightarrow D'$ 表示：$C$ 是前后都保留的部分。原 v2.0 要求所有外部端口在 $C$ 中保留，并在前后对应同一类型、同一位置。

v3.0 将这一要求改成一个有类型的**部分接口迹**：

\[
\tau_I\colon I\rightharpoonup I',\qquad
\tau_O\colon O\rightharpoonup O'.
\]

这里 $\rightharpoonup$ 是位置间的**部分单射**，不是任意函数。若旧端口 $i$ 对应新端口 $j$，则二者类型必须相同，并由共同保留部分支持；没有旧对应的新端口称为**新显**，没有新对应的旧端口称为**撤露**。

于是「化」可以表现为：

- 内部连接改变，但接口延续；
- 内部结构延续，但外部接口新增或撤回；
- 内外组织同时改变，保留部分由见证精确给出；
- 接口顺序改变，通过明确的身份迹记录重排。

**暂不允许**在一次「续」中直接把类型 $A$ 的接口宣称为类型 $B$ 的同一个端口。类型转换可以发生，但它应作为有语义的适配器、转换过程或新的接口身份表达。这样可以避免把不可逆的物理或制度变换悄悄藏进重命名。

## 四、合与界变何时相容？

设两份系统依次相接，旧界面 $J_0$ 和新界面 $J_1$ 分别可连接。

\[
A_0:I_0\to J_0,\quad B_0:J_0\to O_0;
\qquad A_1:I_1\to J_1,\quad B_1:J_1\to O_1.
\]

其中 $A_0\rightsquigarrow A_1$、$B_0\rightsquigarrow B_1$ 是带有接口迹的改变。要求**共同接缝 $J$ 的身份完全持续，且两侧对该持续的配对一致**；外侧 $I,O$ 则允许新增、撤除、重排。

在有限类型化超图、离散端口、单态共同见证、逐端口推积粘合的模型中，可以沿旧接缝构造改变前整体、沿新接缝构造改变后整体，并将两侧共同保留部分沿持续的接缝再粘合。可得到合法的整体改变：

\[
\operatorname{glue}(A_0,B_0)
\ \rightsquigarrow\
\operatorname{glue}(A_1,B_1).
\]

这是一个**受限相容命题**，不是一般可变界面的双范畴结构定理。第 19 份形式规格给出准确条件与有限证明思路。软件实现通过一组「外界改变、内界持续」和二维接续案例。

为什么只做到这里？如果两个参与者共同撤去或增加一条正在使用的接缝，原有共同见证未必还能在整体两端保持单态。它可能涉及拆分已识别节点、合并原本独立的身份、重分配资源或改变交互协议。此时需要**显式适配器或更一般的界面变换方格**，不能未经证明就套用旧交换律。

## 五、界变能够如何成为时序过程？

「化」本身没有时长。一次 span/rewrite 只说明一种组织如何对应另一种组织，不告诉我们多久发生、是否有概率、是不是由环境触发。

因此引入**语义解释**而不是把「时间」偷藏在重写箭头里：

\[
\mathcal{M}:\quad
s\mapsto \bigl(I(s),O(s)\bigr),\qquad
P(s',o\mid s,a).
\]

状态 $s$ 决定当前可接受的动作 $a$ 与可发出的输出类型 $O(s)$；本轮输出须符合当前接口，然后进入新状态 $s'$，下一轮才采用新接口。这是一个**有限的模式依赖交互模型**。

例：某传感器在健康状态具有温度与湿度两个输出；遭受损坏后，下一轮只有温度输出。若程序仍尝试读取湿度通道，必须拒绝该操作，而不能返回空值并声称接口未变。

这类有限模式过程与 Spivak（2026）关于交互改变自身界面、以 polynomial trees 建模的方向相契合，但我们的简单模式机**不是**该论文完整的 $\mathbf{PolyTr}$ 或 $\mathbb{O}\mathbf{rgTr}$ 的实现，也未证明与之等价。

## 六、概率与连续动力学：同一种组织语言，不同的语义

### 6.1 有限概率过程

一个有限马尔可夫核 $K:X\rightsquigarrow Y$ 为每个输入 $x$ 给出 $Y$ 上的概率分布，满足 $\sum_y K(y\mid x)=1$。顺序复合由边缘化给出：

\[
(L\circ K)(z\mid x)=\sum_y K(y\mid x)L(z\mid y).
\]

如果两个过程独立，平行张量可由乘积核给出。这里的独立是**显式语义假设**，不能仅因为结构上「并列」便自动成立。

原型使用 `Fraction` 精确有理数，检验归一化、类型相容、顺序复合和独立张量；它不是通用 Markov category 证明器。

### 6.2 连续物质流

对于两个相连的储量节点：

\[
\dot x_A=u-kx_A,\qquad \dot x_B=kx_A-cx_B.
\]

整体物质量的导数满足：

\[
\frac{d}{dt}(x_A+x_B)=u-cx_B.
\]

**内部流在求和时抵消**，因此系统整体的守恒/边界收支性质可以直接检验。代码以有理数计算瞬时导数及收支恒等式，不把一次导数检查冒称为数值积分收敛证明。

在物理建模中，还需要非负性、量纲、参数范围、边界条件，以及 ODE 解的存在唯一性等额外前提。

## 七、观守：抽象所保留的是哪一个问题的答案？

设 $\alpha:X\to\bar X$ 把细尺度状态归为宏观状态。真正有用的宏观模型不只是为每个微状态取一个标签。

**确定性更新**：若所有被 $\alpha$ 视为相同的微状态，经一次更新后依然被 $\alpha$ 视为相同，才存在良定义的宏观更新 $\bar F$ 使

\[
\alpha\circ F=\bar F\circ\alpha.
\]

**随机更新**：对于任意同块 $x,x'$ 和任意目标块 $C$，必须有

\[
\sum_{y\in C}P(x,y)=\sum_{y\in C}P(x',y).
\]

这保证所有初始分布下的强可聚合性（strong lumpability），而不是对某个初始状态拟合一个看似有效的宏观模型。原型对有限状态逐行检验，遇到冲突就给出反例证据。

**接口可观察性**：如果两个微状态被映射到同一个宏观状态，却具有不同的外部接口，那么一个只有单一接口描述的宏观状态无法同时忠实表示这两者。除非额外指定观测层如何忘掉或转换接口，否则应拒绝该抽象。

**因果保真**则更强：宏观干预和对应微观干预之间还必须有明确映射，并满足询问/干预结果的相容性。这里我们只提供形式检查义务，不宣称已在软件中实现一般因果抽象。这一区分与 Lorenz–Tull（2026）所研究的 compositional causal abstraction 同向。

## 八、最小性的新理解：隐藏成本也是成本

「文、合、化」在表达层保持稳定，而「界、续、观、则」作为类型化、见证和解释层展开。我们暂不把它们升级为四个额外的宇宙本原。

比较候选文法时，应同时计算：

- 原始语法符号数；
- 隐含类型/边界/概率/时间假设数；
- 构造一个典型系统需要的表达长度；
- 程序拒绝非法构造的清晰度；
- 证明组合相容与语义保真所需的负担；
- 跨领域解释时的歧义和误译成本。

若强行把「合」和「化」编码为一条万能重写指令，语法看似只有一个运算，却可能把接口匹配、重写条件、时间、概率全部偷偷移到复杂的元数据里。这不一定更小，也不一定更可理解。

因此本版采取**一体多向、分层保真**，而不追求形式上更少的字。

## 九、四个实例与一个不可忽略的社会界限

1. **软件**：热插拔服务接入新的 API，保留旧接口迹；变更与连接在稳定接缝上可做局部替换。
2. **机器人**：新增一个传感器通道；通道身份、采样频率与物理约束需要分别检查。旧控制器未必能解释新数据。
3. **生态**：组织之间的交换通路可形成或消失；若用物质流解释，局部连接必须与守恒和能量边界相容。
4. **机构**：组织可改变可参与的程序与沟通渠道；形式上的「连通」不能推出同意、正义或幸福。

**规范性不能由拓扑推导。** 如果讨论社会合作、公平、权利和公共利益，必须另附人类给出的价值目标、程序条件及经验后果检验；任何抽象文法都不应以「系统最优」的名义替参与者决定其价值。

## 十、关键结果与其证据边界

| 结论 | 证据地位 |
|:--|:--|
| 开放网络可用推积组合 | 已有范畴论成熟结果；见 Baez–Courser 2020 |
| 固定界面的网络重写可进入高阶统一结构 | 已有研究；见 Cicala 2026，及此前相关工作 |
| 某类接口可以随状态/交互改变 | 现有 polynomial trees 理论支持这一研究路线；本原型另作有限定义 |
| 固定共享接缝下，外界变化仍可水平相合 | 本项目有限 typed graph 片段的构造与证明思路；测试覆盖实例，非一般定理形式化证明 |
| 有理有限概率核可顺序及独立并行组合 | 标准概率论；代码实现及测试 |
| 内部物质流对总量的贡献相互抵消 | 在本版 `MassFlow` 符号定义下的简单代数恒等式 |
| 强可聚合性保证良定义宏观链 | 标准有限马尔可夫链结果；原型检验有限行 |
| 完整现实的唯一最优文法已证明 | **否** |
| 任意动态界面共享连接均已统一 | **否**；需要 adapters / 更高阶完整形式化 |
| 一般因果、几何、规范性语义已保真 | **否** |

## 十一、这一版的文言精稿

> **文因相辨，合因相接，化因相易。界随所用而立，通随所接而成。**  
> **有增有撤，有显有隐；其所续者，须有其据。**  
> **同不足以为等，合不足以为守；观各有取，证各有度。**  
> **势由所可而见，常于变中可寻；生生相续，未尝有终局之形。**

注意：「因」在这里主要表达关系和条件，不必然表示严格的因果推断；「观」是模型解释，不等于主观意识；「守」是明确性质被保持，不等同于道德上的守善。精确语义最终由形式规格决定。

**结语：** 从 v2.0 的「合化一体」到 v3.0 的「界变、时流、观守」，我们没有增加宇宙的本原，却增加了对真实系统不可忽略之差异的尊重。最小的文法，不是把区别抹平，而是在每一个区别必须出现时都能以同一生成体系清楚地表达出来。
