# 反例、审查结论与最小性的未解之处

## 1. 不可从美感推出正确性

“文、合、化”相对于诸如“物、运动、联系”可能更适合某些思想习惯，但文言的精炼、音韵和哲学共鸣不是数学上的完备性或优越性证明。若整个理论只能在积极例子中解释现象，而遇到边界、非因果关系、资源约束、矛盾或不可计算时不能给出可证伪的限制，便仍是隐喻而非研究成果。

## 3. 三条必须保留的哲学限制

**不把文实体化。** 形式模型可以从图开始，却不能从而断言现实由最小节点和边组成。图是暂定语法，而不是微观世界的发现。

**不把合善化。** 有更多连接、较强互依或更高协调效率的系统，不一定更好；压迫结构也可能高度组织化。任何社会评价必须引入权利、能力、互惠、外部性、生态延续等明确准则。

**不把化目的化。** 变化不自动代表进步。适应、分岔、解体和崩溃都可以是一种变化；必须通过环境与目标评价。

## 4. 研究的强弱结论

| 主张 | 当前判断 |
|---|---|
| 用一种类型化开放图句法描述多类连接模式 | 已实现有限原型 |
| 用局部重写表示结构自身变化 | 已实现有限原型 |
| 严格的离散界面粘合可有泛性质 | 成熟数学，有定义与证明要点 |
| 在规定的保留界面条件下，局部重写与上下文合成可相容 | 限定命题 + 一例同构检验 |
| 「文、合、化」绝对最简且唯一 | 无证据，保持开放 |
| 任意物理系统可精确用有限图完全表示 | 不成立或至少无根据 |
| 社会善恶能从图结构自然推导 | 不能如此推出 |
| 文言的语义对数学创新提供构思价值 | 研究性判断，可通过写作与表达实验比较 |

## 5. 对“全做完”的明确解释

这一版把**一期研究交付**做到可读、可定义、可复现、可反驳。它不会冒称已经完成所有无法在一次研究中解决的开放数学和科学问题。若无此区分，表面上的完成度反而会伤害可信度。

## 6. 下一次独立审查应当怎样进行

请至少由图重写/范畴论、程序语言/形式验证、复杂系统/因果模型、古典文献训诂四类专家审查。独立评审应尝试构造失败实例，并复核 P1/P2 条件、相关工作归属、术语历史证据、软件安全边界。本轮没有实际启动独立子代理；不能把本文自审当作外部同行评议。
