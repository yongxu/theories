# 逆向审查：保真、等价与「同」的隐藏前提

**目标：寻找足以推翻本阶段过强结论的最小反例，而不是为漂亮的语汇辩护。**

## 一、必须拒绝的九种偷换

| 看似自然的结论 | 反例与失败模式 | 正确处理 |
|---|---|---|
| 比较 $\chi$ 存在，故两个系统等价 | $U=\varnothing,V=\{e\}$，比较非满射 | 只能承认一条方向性的比较；空源甚至无正规概率提升 |
| $\delta_q=0$ 故结构无损 | 观察把所有全局历史映成同一标签 | 说明该观察不区分；结构本身仍可异 |
| 精观、粗观均保真，故细节无关紧要 | 粗观可以把关键异常并入正常标签 | 由工程目的和风险决定需要哪些查询 |
| 每项查询各自都能保真，故可共同保真 | 对角线模型两个边缘目标不同 | 必须寻找同一 $\nu$ 或计算共同凸可行性 |
| 多个边缘查询共同保真，故联合分布保真 | 对角线模型匹配两个 $1/2$ 边缘，却缺非对角相关事件 | 需要联合查询或更丰富查询族 |
| 源分布存在提升，故提升自然且唯一 | 非单射 $\chi$ 可产生多个不同提升 | 构造可依赖任意代表元；不是一个天然逆函子 |
| 串联误差上界适用一切动态系统 | 状态相关反馈可改变输入分布、模型结构或核类型 | 必须使用声明的固定接口 Markov 核模型及其假设 |
| 独立张量误差上界适用于所有并行系统 | 两侧随机性相关而未指定耦合 | 不能从两边缘决定联合语义 |
| 形式上不可区分，故因果上等价或社会上正当 | 同观测分布的反向 SCM 干预结果不同；制度伤害被粗统计掩盖 | 因果干预与规范评判必须分别明示 |

## 二、对本阶段数学的逐条压力测试

### G.1 最小总变差

- **假设过窄？** 有限离散情形且 $U$ 非空；这是刻意限定，不能扩称所有测度空间。无穷维下的支撑、可测选择与可达分布集合可能需要额外条件。
- **提法是否误导？** `inf` 在本有限模型中实际由构造达到；实现中给出的某个 $\nu$ 是达到下界的一例，但未必自然、唯一或符合其他领域约束。
- **最关键的误用：** 「无观测误差」可能是由于选择了不具识别力的查询。

### G.2 单调性

- **真的没有反例？** 在 $q_2=h\circ q_1$ 且 $h$ 是总映射的受理域中，由事件集合包含关系严格成立。
- **不能拓展为：** 「更粗的模型永远更可信」。可信性还取决于目的、测量噪声、稳健性与解释力。

### G.3 共同凸可行性

- **算法规模是否诚实？** 当前采用小规模精确支撑枚举，指数级最坏复杂度，不是通用的工业级 LP。
- **边缘与联合区别是否显式？** 是：`joint_observation` 的联合查询有自己的目标像集合，不从单边缘成功推定通过。
- **可能的暗藏前提：** 一份局部 $\nu$ 可以任意赋权；若其权重受动力学、守恒、初始条件或经验估计约束，则可行域更小，需增加限制。

### G.4 近似组合

- **误差类型固定否？** 采用每输入行的最大 TV，适用于有相同明示接口的有限随机核。
- **是否可用于相关并行？** 不能；张量证书只对独立产品构造。
- **误差是否已校准？** 此处示例是精确构造的数值，不能当作对任何机器人、模型或社会系统的真实性能评估。

### G.5 高阶相干性

- **何种等同？** 见证在重关联后满足相同映射，不是原始字符串相等。
- **完整吗？** 不。四阶段与有限单共享接缝仍不足以覆盖横向多重粘合、任意变界、单位胞、三维自然性、非单态 DPO 等一般情况。
- **可逆性？** 四阶段富集模型有 50 条局部无法覆盖的整体见证；程序通过的是非可逆的相容切片。

## 三、文法及古汉语的独立问题

「文」可能代表纹理、组织、信息表达，也可能代表制度秩序或文辞；「势」可能指系统的可达发展，也可能让人联想到政治权势。不能因为字形、语感或历史惯用而断言对应某个唯一数学对象。

因此，研究文本中每个概念须标明：**经典语义线索／现代工作定义／形式类型／运算或命题／误用反例**。本轮新增词条均标为现代工作定义或沿古义的重新界定，不能被误当作古人的原始完整理论。

## 四、与已发表研究的归属关系

- Grandis、Paré 的 **Intercategories** 早已研究非可逆交换比较胞与相关 coherence；不能把「非可逆但相干」称为本项目原创的一般发现。
- Baez、Courser、Cicala、Patterson 等关于开放系统的余跨度、跨度、DPO 与双范畴已有独立成就。
- 总变差的收缩性、随机核组合和凸包可行性是标准数学知识。本项目把它们应用于 v5 的特定比较见证并形成贯通中文规格；若写成论文，原创贡献必须精准界定。
- Lorenz、Tull 的组合因果抽象及 Englberger、Dhami 的模型连接工作是重要的当代参考；这里未复现其全部定理，更不能把单纯的观察推前当作因果证明。

## 五、一个更有价值的负结论

**存在结构比较映射，不保证出现自然的概率逆；存在概率提升，不保证存在同一提升满足所有查询；存在共同边缘提升，不保证联合或因果结构得到保持。**

这三层的连续否定，不是理论失败，而是形式语言能够识别其自身边界的必要条件。

## 六、外部审查清单

1. **高阶范畴**：精确指定本项目的受理域，检验与现有 intercategory / equipment 的嵌入以及全部比较胞的自然性。
2. **概率与形式方法**：审查 G.1–G.4 的证明与边界，必要时用 Lean/Rocq 形式化。
3. **因果推断**：为干预翻译和抽象映射提供独立的查询定理，并验证干预而非被动观察。
4. **工程语义**：用一个现实的开放网络完成类型、资源、时间、概率、证书的端到端实例。
5. **语言与思想史**：区分古汉语词义、儒道思想史、现代数学新义，避免历史归属偷换。

**结论等级：** 数学命题 G.1–G.4 有书面证明，有限实例另有自动测试；G.5 仅为局部相干性测试；一般双范畴与现实普适性仍未证。此级别的清晰区分比增加术语或测试数量更重要。
