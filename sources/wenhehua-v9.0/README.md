# 文·合·化｜严格高阶生成框架 v9.0

**本轮完成：从有类型的生成元、组合与变化见证，建立一个具有自由性质、低维保守性和明确语义接口的高阶生成框架。**

核心结论分三部分：自由严格双范畴组织二维构造；相对高维生成保留变化而不压平低维区别；动态共界历史由余极限诱导的正规余松跨度函子解释。时间路径语法、全部有限分组、连续块宏展开、并排组合与观察误差的连接均有定义和纸面证明。完整范围见 `review/63_v9_证明状态与交叉审查.md`。

## 数学结果

| 层次 | 本版给出的内容 | 限定 |
|---|---|---|
| 生成 | 有完整四边界的自由严格双范畴、结构证书可靠性 | 严格目标；不把同边界等同为相等 |
| 高阶 | 相对三维生成、低维保守性、每个有限阶的归纳扩张 | 新增方向的低维面退化；不是任意弱无穷结构 |
| 语义 | `Span(colim)` 的比较、自然性、单位与全部有限时间相干 | 比较通常不可逆；装配是函子作用 |
| 接口 | 自由历史路径的两种求值及连续块宏展开相干 | 已指定原子赋值的时间子语言 |
| 并排 | 对称幺半并排与时间复合的兼容 | 不交并保留标签；数学模块，尚无专门公共 API |
| 保真 | 当前像方图的拉回/BC 判据、观察 TV 误差 | 观察误差定理要求来源非空；不等于历史忠实 |

上述数学证明不是证明助手的编译结果。Python 检查器验证证书和有限实例，不替代全称证明。也没有声称这套词法是现实唯一完备或词数绝对最少的描述。

## 实现与复现

建议使用本次实测的 Python 3.12 环境，从本目录进入 `software`：

```bash
cd software
python3 -m pip install networkx==3.7
python3 -m unittest discover -s tests -v
python3 demo_v9_kernel.py
python3 demo_v9_semantics.py
```

2026-11-24 实测 **313/313 测试通过**，Python 3.12.14、NetworkX 3.7。构成为继承的 245 项，加二维内核 26 项、三维项 11 项、有限图式 29 项、旧模块完整性回归 2 项。语义演示另有 **6 个模型 × 5 种四步括号 = 30 个相干实例检查**，未计入 313。

新生成内核、三维项与有限图式模块使用 Python 标准库；完整历史回归套件需要 NetworkX。实际日志、命令和环境见 `evidence/tests_v9.0.txt`、`evidence/v9_test_results.json`、`evidence/v9_reproduction.md`。
