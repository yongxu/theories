## 严格学术边界

- 程序测试不构成一般数学定理的形式证明。
- 本版的有限 `Evolution` 并非 `PolyTr`/`OrgTr` 完整实现，也尚未验证完整 varying-interface double category 的 coherence。
- v3.0 的水平相容仅在完整持续且同侧匹配的共享接缝上成立。
- `ModeMachine` 以类型标签检查输出，不检查物理单位或传感器校准。
- `MassFlow` 验证即时收支恒等式，不是 ODE 求解器或真实物理正确性证明。
- 跨尺度因果保真与规范价值判断尚无通用可执行检查。
