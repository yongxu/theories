# 具体构造：运行结果、反例与复核指南

## 1. 环境与命令

执行所用环境：Python 3.11+，`unittest`，一个使用 NetworkX 图同构检查的测试；运行算法本身仅依赖标准库。以下说明不依赖网络服务，不使用外部 AI 模型。

```bash
cd software
PYTHONPATH=. python demo.py
PYTHONPATH=. python -m unittest discover -s tests -v
```

`demo.py` 与 `tests/` 为可复现的初级研究证据；如果想拓展它们，建议先固定签名与需要验证的不变量，然后再引入新的物理/工程语义。

## 2. E1：沿界合成（合）

定义节点类型 `Signal` 和关系类型 `wire : Signal → Signal`。

配置 A：`a --wire--> b`，开放端口 `in=a, out=b`。

配置 B：`c --wire--> d`，开放端口 `in=c, out=d`。

选择 A 的 `out` 与 B 的 `in` 相合。因为端点类型一致且界面顶点单射，可得一个 3 顶点、2 边的图：

```text
L::a ───► L::b (= R::c) ───► R::d
 ↑                                 ↑
L.in                              R.out
```

注意：匹配端口在对外视图中被隐藏，但内部共用节点仍存在。若把右边的接入端口改为 `Energy` 类型，程序拒绝合成。

## 3. E2：局部插入模块（化）

规则：

```text
L:  a ─► b
K:  a     b   (只保留两端节点)
R:  a ─► c ─► b
```

把 A 的唯一边替换为长度为2的路径。`keep_nodes` 指定 `a→a, b→b`，原来的边不在 K 中，因此被删除；新节点 c 和两条新边被创建。类型检查通过、宿主对外端口仍是 a/b。

此例展示「内部可化而外部可续」。但它只能证明结构端口保留，不能证明新流程的时延、吞吐或输出语义完全等价。

## 4. E3：悬挂边——不能随意化

宿主包含 `a→b` 和 `c→b`，若规则只匹配并删除 `a→b` 中的 `b`，却没有处理 `c→b`，就会留下没有目标顶点的外部边。这种修改被拒绝。

同样，若宿主暴露外部端口 `external=b`，不允许删除 b 而不声明接口迁移。

反例说明：**局部看起来合法的修改，在整体中可能非法。** 合化相容必须附加条件。

## 5. E4：化与合在保留界面时相容

原始局部图 `a→b`，上下文图 `u→v`，将 `b` 与 `u` 合并。

路径一：先把 `a→b` 改写为 `a→c→b`，再将其与 `u→v` 相接。

路径二：先将 `a→b` 与 `u→v` 相接成 `a→b→v`，再在左半部分改写为 `a→c→b→v`。

由于连接处的 `b` 在规则中被保留，也没有新增外部悬挂关系，两条路径产生保类型、端口和边方向的同构图。测试使用 NetworkX 的 incidence graph 同构验证这一实例。它是受限条件下的**可执行见证**，而不是无条件的普适定理。

## 6. E5：微观到宏观的失败例（观）

微观状态循环 `0→1→2→0`，映射 `α(0)=α(2)=A`，`α(1)=B`。

如果宏观变化 `G` 存在，状态 A 的下一步既应为 B（因为 0→1），又应为 A（因为 2→0），产生矛盾。

程序返回：

```text
(False, {'A': 'B', 'B': 'A'}, ('2', 'A', 'B', 'A'))
```

这明确表明：一套粗观的变量不一定能够给出封闭的确定性宏观动力学。它可能需要增加历史、扩充状态或采用非确定性/概率语义。

## 7. E6：守恒需要资源语义（则）

一个离散 Petri 模型设 `H` 的质量权重为1，`H2` 的质量权重为2；反应 `2H → H2`。

初态 `H=4,H2=0`，加权总量 `4`。执行一次反应后得到 `H=2,H2=1`，加权总量仍为4；再执行一次为 `H=0,H2=2`；第三次尝试因 H 资源不足而被拒绝。

对于非守恒的 `H→H2`，同样的检查明确返回 `False`。

这个示例故意非常小，只说明**资源计量必须是额外语义**。把有向边画成化学反应，绝不会自动给出守恒规律。

## 8. E7：局部稳定不保证合后稳定

两个独立映射 `x' = 0.5x`、`y'=0.5y` 分别收敛。但引入互相耦合：

```text
[x']   [0.5  0.8] [x]
[y'] = [0.8  0.5] [y]
```

其特征值为 `1.3` 与 `-0.3`，故存在增长模式，整体不渐近稳定。这一计算可直接手工校验，不需要外部模拟。

## 9. E8：社会制度的语义界线

可以用同一配置语法表达：不同参与者的互动渠道、共享资源、决策规程、退出规则、异常追责。但一个合规图式并不能证明正义、充分同意、真正的自由或公平。必须明确规范目标、现实限制与参与者经验，并允许异议与修正。

本例不是「软件工程可替代政治哲学」；恰恰相反，它显示一个通用形式文法必须在哪些地方**主动停止推论**。
