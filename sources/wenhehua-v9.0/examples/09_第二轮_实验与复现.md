# 两轮修订实验：从反例到可检查的构造

**环境**：Python 3.13、networkx 3.6.1（仅用于图同构测试）；主引擎无第三方运行依赖。测得结果为 2026-11-24 在当前运行环境的一次复现，不是形式证明或性能基准。

## 运行方法

```bash
cd software
PYTHONPATH=. python -m unittest discover -s tests -v
PYTHONPATH=. python demo.py
```

测试集包含 15 项原基准测试、25 项两轮修订测试，共 **40 项，通过 40 项**。其中受控随机测试循环 30 个固定种子；它只提供多样化实例检验，并不是穷尽验证。

## 实验 E1：相同连接，不同分组

输入三个端口分别为 `in`、`out` 的开放有向链：`A→B→C`。

直接使用旧低层 `glue` 时，外部端口的名称随括号不同而不同：

- `(A⊕B)⊕C`：`L.L.in`、`R.out`；
- `A⊕(B⊕C)`：`L.in`、`R.R.out`。

若要求保留**字面端口名**，这两个表达不等价。若指定合适的外界重命名，它们的内部图同构。

v1.2 新增 `compose_pair`，将每次串接后外部端口规范化为 `in/out`； `compose_series` 对若干串接模块作有序折叠。测试验证不同括号分组的结果满足保节点类型、超边端点角色以及外界端口标签的同构。

**结论**：「数学上至同构」和「某份实现中逐字相等」不能混称。接口标签属于外部合同的一部分。

## 实验 E2：自动重写应寻找合法匹配

宿主图有两个同类型节点 `a,b`，外界端口指向 `a`。规则要求删除一个同类型、没有关联边的节点。最先匹配到 `a` 时，删除会破坏开放端口，应拒绝该匹配；但匹配到 `b` 则合法。

v1.0 可能在第一个匹配处停止并报错；v1.2 继续寻找满足端口保护与悬挂条件的匹配，最终保留 `a`、删除 `b`。显式指定 `a` 的非法匹配仍被拒绝。

**结论**：「有匹配」与「有可应用的匹配」是两个命题。

## 实验 E3：确定性粗粒化

`X={0,1,2}`，`F:0→1→2→0`，`α(0)=α(2)=A`、`α(1)=B`。

同一宏观态 `A` 的两个微观代表，在下一步分别进入 `B` 与 `A`，所以不存在决定性的宏观更新 `G` 满足 `αF=Gα`。返回的冲突见证具体指出 `2`、`A`、预期 `B`、实际 `A`。若转移离开声明的状态空间，v1.2 会明确报错，不再假装结论覆盖未知状态。

## 实验 E4：概率粗粒化

考虑微观状态 `a1,a2,b1,b2`；`α` 将以字母 a 开头的合为宏观 `a`，以 b 开头的合为宏观 `b`。指定：

- `a1` 以 1/2 到 `a2`，以 1/2 到 `b1`；
- `a2` 以 1/2 到 `a1`，以 1/2 到 `b2`；
- `b1` 以 1/4 到 `b2`，以 3/4 到 `a1`；
- `b2` 以 1/4 到 `b1`，以 3/4 到 `a2`。

虽然微观的具体下一状态不同，按块汇总后的概率完全相同：

| 来源 | 到 a | 到 b |
|---|---:|---:|
| a | 1/2 | 1/2 |
| b | 3/4 | 1/4 |

因此形成自洽的宏观马尔可夫核。另一个反例让 `a1` 有 1/2 概率去 b 而 `a2` 有 0 概率去 b，此时聚合被拒绝并给出见证。

**结论**：确定性闭合只是一个特殊情况，概率系统有自身的条件；可聚合性不意味着因果干预语义保真。

## 实验 E5：资源不是类型相同便能免费复制

从 v1.0 保留 Petri 风格示例：两个 H 单元合为一个 H2 单元，赋权 `w(H)=1`、`w(H2)=2`，检查加权总量不变。一个把单个 H 直接转成 H2 的规则则不能通过同一守恒判据。v1.2 进一步拒绝将布尔值 `True` 误当作整数资源计量。

**结论**：连接图和规则的合法性，与守恒物理量，是不同层级的性质。

## E6：给未来实现保留的失败验证

- 若隐藏端口仍有其他别名可访问，不能称已达到信息隔离。
- 并发规则争夺同一边时，需要临界对／冲突检查，本版不能保证合流。
- 图形具有合法粘合，不保证连通系统动力学稳定。
- 程序的重写语义本身未实现速率、随机调度或时间守卫。
- 规范性评价不由软件自动验证。
