# 「合—化」高阶统一：可复现实验记录

**运行环境**：Python 3.11+；标准库即可运行核心与测试。既有 v1.2 的 `networkx` 等包不是 v2.0 新接口的必需依赖。

## 运行方式

```bash
cd software
PYTHONPATH=. python -m unittest discover -s tests -v
PYTHONPATH=. python demo_higher.py
```

若因执行位置导致路径不同，请切换到项目目录中的 `software/` 再运行。该项目不要求连接互联网。

## 运行中的定理与程序的边界

- `horizontal()` 把输入/输出的相容顶点识别为共同的顶点，边的 ID 保持彼此独立。它尚不是任意结构化余跨度的泛化实现。
- `vertical_change()` 计算有限单态子对象的交：由两个保留子图映入相同中间图，提取同时出现的部分。它不保存时间长度、概率或决策理由。
- `isomorphic_witness()` 对固定前后网络的节点/边对应进行精确比较，避免单看计数或仅比较最终输出结构。
- `open_graph_isomorphic()` 是小规模穷举搜索，不适合数十万节点的大型工程网络。
- 同名节点在不同阶段可能不具有同一身份。若删除再重建，保留见证应反映真正持续的部分。

## 反例：一种局部约束不经自动组合保留

`A` 只有边 `a_in→a_out`；`B` 有边 `b_in→b_out`，另有内部节点 `helper→b_in`。分别看 `A`、`B`，每个节点入边数量不超过 1。然而沿 `a_out=b_in` 组合后，被识别的共享节点收到两条入边。于是性质 `∀v indegree(v)≤1` 在这次水平组合下破坏。

**解释**：数学上的组合正确，只保证生成合法的结构，不保证所有原先在局部成立的性质在合成后继续成立。要获得这样的保证，必须给接口额外合同，或把该性质做成真正的组合不变量并给出证明。

## 反例：二胞存在不蕴含行为保持

保留输入和输出端口节点，但移除它们间唯一一条有向边：

```text
before:  in ●──────▶● out   Reach = True
             │      │
common:  in ●      ● out   (two preserved vertices)
             │      │
after:   in ●      ● out   Reach = False
```

`Change` 是边界保持、节点映射单射、关联映射有效的合法跨度见证，但行为不等价。只有 `preserves_reachability()` 进一步检查后才能报告行为是否保留。

## 正例：可达性语义为什么合守？

单共享顶点的串联有向图，其左端到右端的路径当且仅当两侧都有通往/离开共享顶点的有向路径。核心算法为 DFS/BFS 计算输入到输出可达性。此语义没有涵盖超边的复杂资源语义、概率干预或多口网络的反馈路径。
