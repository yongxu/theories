# v9 可复现示例：拼合如何改变历史的可接续性

配套程序：`software/demo_v9_semantics.py`。所有实例直接使用公共有限图式与跨度构造器创建，没有导入测试文件中的 fixture。

## 1. 运行与输出

在 `software` 目录运行：

```bash
python demo_v9_semantics.py
```

程序向标准输出写确定性的 UTF-8 JSON。也可以指定文件：

```bash
python demo_v9_semantics.py --output examples_v9_semantics.json
```

顶层输出含六个实例、30 次四阶段括号检查，以及每个实例的下列字段：

- `two_stage_chi`：源、靶、像的大小，单射／满射／双射性质，未被覆盖的目标个数，以及逐目标的实际逆像列表。
- `beck_chevalley_singleton_family`：对第一步记录的每个商类放一个元素，计算每个第二步商类上的真正 BC 函数及其性质。
- `four_stage`：把可循环的两步历史重复一次，计算四步比较，并检查全部五种二叉括号。
- `meaning_zh` 与 `conditional_application_zh`：数学意义和有条件的领域解释。

`local_0`、`global_0` 等是有限见证的显示索引，没有物理个体身份含义。JSON 中 `all_instance_checks_passed` 只陈述本程序的有限实例检查通过。

## 2. 统一比较方向

令 \(W,V\) 是前后两步历史的见证图式，\(D\) 是相接的中间状态图式，\(Q\) 是对固定形状取余极限。每个实例计算同一方向：

\[
\chi:Q(W\times_DV)\longrightarrow QW\times_{QD}QV.
\]

左端先按各局部部件的原有中间状态匹配，再拼合完整历史；右端先拼合每步记录及中间状态，再匹配这些聚合记录。\(\chi\) 把每条局部完整历史送到它对应的全局配对。

这一比较是跨度上的正规余松函子结构的一部分。任意函子在有拉回范畴之间诱导此结构，是既有定理；这里的程序计算其有限图式实例。原始出处：Shulman 2008 现行修订版 Example 6.3，以及 Dawson–Paré–Pronk 2010 §2.1。[S1][S2]

## 3. 六例的实际运行结果

下表来自本轮实际运行。四步为两步序列重复一次；每行均检查了所有五种括号。

| 实例 | 两步 \(\chi\) | 单射 | 满射 | 单点族 BC 同构 | 四步 \(\chi\) |
|---|---:|:---:|:---:|:---:|---:|
| 完整共同见证 | \(1\to1\) | 是 | 是 | 是 | \(1\to1\) |
| 只有跨侧接续 | \(0\to1\) | 是 | 否 | 否 | \(0\to1\) |
| 两侧事件、无共同接缝见证 | \(2\to4\) | 是 | 否 | 否 | \(2\to16\) |
| 局部历史被合并 | \(2\to1\) | 否 | 是 | 否 | \(4\to1\) |
| \(C_2\) 群作用与相对关系 | \(2\to1\) | 否 | 是 | 否 | \(8\to1\) |
| 三部件、两接缝 | \(3\to9\) | 是 | 否 | 否 | \(3\to81\) |

空函数 \(\varnothing\to\{p\}\) 为单射，是单射定义的空域情形；它并未保留目标中的那条历史。必须同时报告单射与满射，不能只用一个数值表示“保真”。

### 3.1 完整共同见证：\(1\to1\)

中间状态为 \(L\leftarrow S\to R\)，三个分量均单点。每步也记录一个左事件、一个右事件及将二者连接的共同接缝事件。局部连续历史拼合后为一个类；分别拼合后的前后两记录也只有一个可接配对。比较是双射。

这个例子表示一个**确切符合强保留条件的实例**，不能推广成所有合法拼合必定精确。它适合展示软件模块或机器人部件的接口见证何时可以使两种求值顺序一致，前提是已经选择并验证了这样的有限记录模型。

### 3.2 跨侧接续：\(0\to1\)

状态仍把左点和右点识别为同一个全局点。第一步只有左事件，第二步只有右事件，两步都没有共同接缝历史。逐部件匹配时，没有部件同时拥有这两步见证，故源空。先把状态与每步记录拼合之后，中间点相同，出现一个全局可接配对。

这是“聚合后可接”而“局部没有持续来源见证”的精确区别。对模块重构或服务路由，是否允许这个跨侧接续，必须由额外的身份、资源或调度条件指定；数学例子本身没有赋予其物理合法性。

### 3.3 两侧事件：\(2\to4\)

每步均有左、右两事件，但共同接缝历史为空。局部两步历史只有一直在左侧和一直在右侧这两种。分别拼合后，每个阶段保留两个事件类，聚合中间点允许四个配对：左左、左右、右左、右右。比较的像只包含同侧两条。

四步时局部仍只有两个全程同侧历史，全局有 \(2^4=16\) 条配对序列。即便所有括号给出的比较严格相容，也不会使缺失的 14 条全局历史凭空获得局部见证。相干与可逆是不同性质。

### 3.4 合并局部历史：\(2\to1\)

中间接缝有 \(s_1,s_2\) 两个标识，两者均映到相同左点及相同右点。第一步的接缝见证分别连接两个左事件与同一个右事件；第二步的接缝见证分别连接同一个左事件与两个右事件。

按中间接缝标识逐分量匹配，得到两组互不连通的局部历史；但每步单独拼合时所有事件已连为一个商类，故全局配对只有一个。比较合并两条不同局部历史。

在软件或装配记录中，两个接缝标识可能用于区分不同来源、不同连接操作或不同替换轨迹。是否允许忘记这些区别取决于所选观察任务。一般的 \(\chi\) 不能被叫作“把局部历史包含进全局历史”，因为本例不是单射。

### 3.5 \(C_2\) 对称与相对关系：\(2\to1\)，四步 \(8\to1\)

取一对象、两箭头的有限范畴 \(BC_2\)，箭头满足 \(s^2=1\)。它的集合图式就是带 \(C_2\) 作用的集合，取余极限等于取轨道。

两份见证都是 \(\{0,1\}\)，\(s\) 交换两个元素。中间状态为平凡作用的单点。先形成联合历史再取轨道得到：

\[
\{00,11\},\qquad \{01,10\}.
\]

这两类分别保留“同向”和“反向”的相对关系。若先分别取轨道，每份二点集合已成为一个点，联合历史也只剩一个点。

四步共有 16 个二值序列；共同翻转把每个序列和逐位互补的序列配成一轨道，没有不动点，因此有 8 个轨道。逐步取轨道后则只有一个序列。

若把标签读作模块的抽象朝向，模型展示的是共同对称与逐模块独立忽略标签的区别。它没有包括空间几何、刚度、运动学或控制，所以不能直接据此判断真实机器人是否可装配。

### 3.6 三部件与两接缝：\(3\to9\)

图式形状为

\[
A\leftarrow S_1\to B\leftarrow S_2\to C.
\]

状态图式中每个分量单点，所以两个接缝把三个部件状态聚成一个全局点。每步保留三个部件事件，但不保留接缝事件。两步局部历史必须留在同一部件，共三个；全局配对可从任一部件到任一部件，共九个。四步相应为 \(3\to3^4=81\)。

这是一般有限图式的多接缝例子，说明计算已超出单一左右接缝。模型仍然是记录、匹配与识别的模型，不自行提供领域约束。

## 4. 全部四阶段括号实际检查

程序对每个实例检查以下全部五种有序二叉括号：

1. \(h_1;(h_2;(h_3;h_4))\)
2. \(h_1;((h_2;h_3);h_4)\)
3. \((h_1;h_2);(h_3;h_4)\)
4. \((h_1;(h_2;h_3));h_4\)
5. \(((h_1;h_2);h_3);h_4\)

每种括号都实际逐个合成二元比较；另一路独立构造平坦四重拉回比较。检查器明确建立源、靶两侧的重括号双射，并比较所得函数，而不是只比较基数。六个实例共 30 次检查全部通过。

这没有把四步实验当作任意阶段的证明。任意有限阶段的结论来自主文 S2：所有分组路径接各个最终投影后都等于原投影的函子像，因此由极限的唯一性为同一态射。

## 5. BC 实际纤维函数

把一个元素放在 \(QW\) 的每个商类上。对每个 \(v\in QV\)，程序构造实际函数

\[
\coprod_{u:\,Fq(u)=v}\{*\}
\longrightarrow
\coprod_{w:\,Fr(w)=Fs(v)}\{*\},
\quad (u,*)\mapsto(Fp(u),*).
\]

这里 \(F=Q\)，\(p,q\) 是局部拉回的两个投影，\(r,s\) 是两步指向中间状态的腿。运行结果如下：

| 实例 | \(QV\) 中的类数 | 每个 BC 纤维的实际基数 | 失效方式 |
|---|---:|---:|---|
| 完整共同见证 | 1 | \(1\to1\) | 无 |
| 跨侧接续 | 1 | \(0\to1\) | 不满射 |
| 两侧事件 | 2 | 每个 \(1\to2\) | 不满射 |
| 合并局部历史 | 1 | \(2\to1\) | 不单射 |
| \(C_2\) 相对关系 | 1 | \(2\to1\) | 不单射 |
| 三部件 | 3 | 每个 \(1\to3\) | 不满射 |

之所以这个单点 family 足以检测本有限比较的双射性，是因为它的各纤维直接重现 \(\chi\) 的各纤维。主文 S4 再证明：\(\chi\) 双射当且仅当**所有** family 上的 BC 映射都可逆。程序没有通过枚举所有 family 来声称这项全称结果。
