# 形式核心：定义、推演、命题与失效边界

**状态：有范围的严格定义 + 有限实例的可执行证据；不是全领域统一定理。**

## 0. 元语言与对象语言的区分

元语言中可声明 `Type`、`Signature`、`Graph`、`Port`、`Rule`、`Match`、`Semantics`、`Property`；这些是实现语法所需的分类，不是宇宙的实体种类。对象语言则描述被构造的图式及其规则。严谨讨论不可把两层混写。

给定签名 `Σ = (T_V,T_E,srcT,tgtT)`，其中 `T_V` 为节点类型集，`T_E` 为超边类型集，`srcT(e)` 和 `tgtT(e)` 为节点类型的有序有限列。

定义**有类型有向多重超图** `G=(V,E,src,tgt,τ_V,τ_E)`：

- `V,E` 是有限集合，边的身份不同，即使端点和类型相同仍可保留平行边。
- `τ_V:V→T_V`、`τ_E:E→T_E`。
- 每个 `e∈E` 的 `src(e),tgt(e)` 是有序顶点列，长度与类型由 `Σ` 决定。
- 图态射由顶点映射、边映射构成，并保类型、端点与顺序。

该模式可以看作某个多类预层（presheaf）式图范畴的有限对象。若只考虑有限图与需要的极限/余极限，应逐一核实其闭合条件；本软件没有试图实现全部泛性质。

一个**开放配置**在原型中为 `(G,P,p)`，其中 `P` 是有限端口名集，`p:P→V` 把各开放端口指向对应顶点。端口可同时是内部顶点，且端口名不是具有世界唯一性的地址。原型仅支持**以顶点作为界面**，不对超边本身沿界粘合。对形式推广，可用结构化余跨度 `L(I)→G←L(O)`，其中 `L` 将离散界面嵌入图。

## 1. 文、合、化三种语法层级

### 1.1 文

`Config_Σ`：有限且通过签名检查的开放配置。`Graph.check` 保证所有顶点类型属于签名、超边各端点和类型合法、端口确实指向内部顶点。

### 1.2 合

对两个配置 `A`、`B`，以及指定端口对照 `k:P_A'≅P_B'`，要求：端口存在；每侧界面顶点不重复；各配对顶点类型相同。

在限定的**离散顶点界面**上，`glue(A,B,k)` 计算左右图不交并后，把所配对的顶点识别为一个；原有边不被识别，分别保留其身份。若 `hide=True`，被用于连接的端口名称从外部接口列表中移除；节点和物理端点仍在图内。

若把被连接端口的顶点集看作离散图 `K`，其对应的顶点嵌入 `i:K→A`、`j:K→B`，则形成推积图 `A ⨿_K B`。在这里，`K` 中没有边，且 `i,j` 均单射，因此可以通过不交并及最小等价关系的商来构造。

**注意**：若一个资源接口要求线性使用、流守恒、权限或输入/输出方向，这些都必须通过更细签名和语义约束来说明。顶点类型相同只是最弱的连接条件。

### 1.3 化

重写规则 `ρ = (L ← K → R)`，其中 `L,R,K` 是同一签名下的图，两个从 `K` 出发的态射为单射；本原型通过 `keep_nodes:L→R` 和 `keep_edges:L→R` 的部分一一映射记录被保留的顶点和边。保留边的所有端点也须保留，并且左右端点结构与类型一致。

给定宿主 `D` 的单射匹配 `m:L→D`，应用规则的条件包括：

1. 所有匹配节点、边的类型和端点一致，且匹配单射。
2. 没有待删除节点仍被宿主中**未删除**的边关联（dangling condition）。
3. 待删除节点不是宿主开放端口所指向的对象。
4. 保留的节点、边在 `R` 中结构不变，且所有新增顶点和边保持类型。

产生 `D'` 的具体算法：去除 `m(L\K)` 中的边和顶点；保留环境及 `m(K)`；为 `R\K` 中的新节点和边分配新标识并连接至保留部分；保留宿主端口。此方法对当前所选有限图子类给出一个简单 DPO 风格重写器。一般 DPO 需要显式构造 pushout complement 与两个 pushout；其存在性在不同范畴中需要特定假设，不可凭本软件声称全部通用。

## 2. 最小公理与可推导定律

首先在更抽象的层次，结合 `glue`、不交并以及固定接口，可以构建对称幺半式结构；在适当的结构化余跨度范畴中，对象为接口、箭头为开放网络，复合由推积给出，并置由余积给出。

在该层次，组合与单位满足适当的结合和单位同构；对称交换满足相应相容律。原型代码的标识前缀使得组合结果的字面字符串可能不同，所以**等价应是保类型、边角色及外露端口的图同构**，而不是 Python 字典的逐字相等。

仅凭以上基础，不会得到唯一的时间、全局状态、复制算子、丢弃算子、固定点算子或因果方向；它们必须由选定的语义明确提供。

## 3. 命题 P1：离散边界粘合的结构性质

**命题 P1（在有限类型化图的顶点界面粘合下）**：若 `K` 是一个离散顶点界面，`i:K→A`、`j:K→B` 是保类型单射，则先对 `A`、`B` 做不交并再依 `i(k)~j(k)` 作顶点商，同时保留每条边的来源身份和端点序列，所得图满足 `A←K→B` 的图推积泛性质。

**证明要点**：任意 `f:A→Q`、`g:B→Q` 若满足 `f∘i=g∘j`，则其不交并上的映射常值于上述等价类，因此唯一下降为商顶点映射；由于 K 不含边，边映射直接由 A 与 B 的边映射拼接得到。兼容端点与类型由原态射的相容性保证；唯一性由商映射的满射性和并图的泛性质得出。这里顶点界面单射并非对推积一般存在性的必要假设，但与实现的安全限制一致。

**软件验证范围**：`test_glue_nodes_are_identified_and_connections_preserved` 检查一个2+2节点、2条边的实例。这个单元测试不能替代上述一般命题的数学证明。

## 4. 命题 P2：保留边界的局部重写与上下文组合可交换（受限）

令 `C` 是沿离散界面 `K_0` 粘合的外部上下文。假定 `ρ:L←K→R` 在 `D` 上有一个合法单射 DPO 匹配，并且：

- `K_0` 的像完全落在本次重写保留的顶点中，且这些顶点在 R 中对应保留。
- 所有待删除节点与外部上下文之间无非预期的关联边；由于沿 `K_0` 的界面只粘顶点且皆被保留，该条件在本模型中可直接检查。
- 外部上下文不识别两个原先不同、会影响匹配单射性的节点；连接只沿指定单射界面。
- 类型、规则匹配与端口一致性得到保持。

在此限制下：

`glue(rewrite(D,ρ),C) ≅ rewrite(glue(D,C),ρ)`。

**证明思路**：左右构造都保留 `D` 的环境、`C` 的所有顶点与边、规则共同部分 `K`；都移除相同的 `L\K`，加入同构的新 `R\K`；由于 `K_0` 完全保留、没有外部边触及删除部分，商关系与替换操作互不冲突，左右结果在重新命名新增节点与边后同构。这是有限离散界面模型中的集合构造证明；一般图重写的组合/并发定理需要更广泛的 adhesive 范畴假设及临界对分析。

**可复现实例**：`test_rewrite_disjoint_context_interchange` 在两条有向链的连接上分别执行上述顺序，并使用 `networkx` 的有向 incidence graph 同构检查验证两种结果相同（到同构）。

**不成立的情形**：若连接上下文新增一条边指向将被删除的节点，先连接后的匹配将违反悬挂条件；若粘合直接使两个匹配节点合一，匹配单射可能失效。绝不能丢掉条件只留下口号「局部变化总能融入整体」。

## 5. 反例 CE1—CE6

**CE1 悬挂边。** `a→b` 的规则试图删除 `b`，但宿主额外存在 `c→b`，这条边不在被删边中。合法 DPO 重写不应发生。测试 `test_dangling_host_edge_rejected`。

**CE2 类型不符。** 把 `Signal` 端口与 `Energy` 端口按同名连接，顶点类型不同，必须拒绝。测试 `test_glue_mismatch_fails`。

**CE3 复制资源。** 纯图的复制连接可能表示信号扇出；但它不能免费代表物理电池能量、独占锁或未知量子态的复制。线性资源需要额外代数约束，不能从 `glue` 自行推导。

**CE4 局部稳定、整体失稳。** 两个孤立离散系统 `x_{t+1}=0.5x_t` 和 `y_{t+1}=0.5y_t` 都稳定；耦合后 `z_{t+1}= [[0.5,0.8],[0.8,0.5]]z_t`，矩阵特征值为 `1.3` 和 `-0.3`，故整体并不渐近稳定。连接图合法不代表动力学稳定。

**CE5 粗粒化不闭合。** 取微观状态集 `{0,1,2}`，令 `F(0)=1,F(1)=2,F(2)=0`，粗观 `α(0)=A,α(1)=B,α(2)=A`。若存在确定性 `G` 使 `αF=Gα`，因 `α(0)=α(2)=A`，必须同时有 `G(A)=B` 与 `G(A)=A`，矛盾。因此不存在该宏观更新。`test_abstraction_failure` 输出明确冲突见证。

**CE6 相同网络不等于相同因果或规范意义。** 同一个 `a→b` 可能表示信息流、资源占用、影响力、授权甚至纯统计相关。图同构不意味着不同语义的机制等价，更不构成伦理正当性证明。

更多反例见 `review/04_反例与审查结论.md`。

## 6. 三类明确附加的语义

### 6.1 离散时间有状态过程

`F:S×I→S×O`，给定输入与状态，输出新状态与输出值。若想用图的连接表示反馈，需显式延迟、反馈不动点或 trace 等支持，不能只画圆圈就宣称合法。结构改变时，状态类型也可能改变，可用依赖和 `Z=Σ_{D∈Diag} X_D` 表示新构型中可能的状态，重构规则必须附带迁移映射。

### 6.2 概率过程

在合适的概率核范畴中，将确定性更新替换成随机核，进一步讨论条件独立、观测、贝叶斯更新等。相同的图结构不能独立确定概率核的值。

### 6.3 连续与物理过程

开放动力系统可以用微分方程、混合系统、守恒方程、约束流形等表示，数学上须指定足以定义解的正则性及边界条件。不同的可解性、稳定性、资源限制与因果约束应由特定后端验证。

## 7. 接口变化与高阶化

更高层配置可把下一轮可用端口集合、当前规则版本以及合法迁移映射列入状态：`Z=Σ_{D∈Diag} X_D`。更新 `U:Z×E→Z` 若改变 D，就应同时返回新 `D'` 与属于 `X_{D'}` 的合法状态。此为抽象设计模式，而不是上述图重写软件已经支持依赖类型及安全热重构的声明。

David Spivak（2026）讨论相互作用怎样使接口本身发生改变，提供了值得比较的更高阶框架。

## 8. 最小性实验设计

定义三种对照语言 L1（通用单操作）、L2（合/化双操作）、L3（具有双范畴表述的高阶统一）。对同一批12个算例记录：

- `AST` 结点数、类型注解数量、显式假设数量；
- 失败表达是否会被拒绝，错误能否定位；
- 自然语言解释长度及由盲测读者对规则的理解正确率；
- 组合后保留的性质与需额外证明的性质；
- 运行时间、状态空间和实现复杂度。

没有预先固定的权重就无法宣布某一种「结构最优」。若一操作法借助更繁复的编码才达到同样效果，不能只比较操作名的数量。
