# 第二轮：从「文、合、化」到可检验的语义层

**v1.2 · 形式定稿增补**

> 文不自固，界由所接；同非一同，常各有所守。合化相资，观则明其分际。

本稿专门解决第一轮暴露的三个缺口：**接口与等价**、**抽象与保真**、**最小性与高阶统一**。我们不宣称以三个字构成一种涵盖全部自然与社会的完备理论。给出的是一个可清晰实现与继续扩展的「文法—语义—验证」三层规格。

## 一、正式定义的层次

### 1. 元层：给定签名与可用数学背景

输入是签名 `Σ`，其中节点型集 `T_V`、有向多端点关联型集 `T_E`，每个边型指定有序源型列与靶型列。再给出接口规范、重写规则集 `R` 及预期语义 `M`。这些输入**不是**凭「文」自行生成的宇宙事实。

### 2. 文：有类型的开放配置

将 `文` 表示为 `D=(G,P,p)`，`G` 是有限 `Σ` 型定向超图，`P` 是外部端口身份集合，`p:P→V(G)` 指向端口所在顶点。端口身份与内部顶点身份是不同维度；多个端口可以引用同一个顶点，但用于一次特定粘合的边界映射要求单射。

一份文可以有不同外部视图；在某些应用中也可有多个观测映射，因此同一内部图不必只有一种界或一种观。

### 3. 合：通过给定边界的开放粘合

给定离散有类型界面 `K`，两个保类型的单射 `i:K→A`、`j:K→B`，定义：

`A ⊕_K B := A ⨿_K B`。

这一式子在这里是**底层类型化图的推积**；若把输入输出界面及外界标识作为结构的一部分来处理，更一般的正当形式是结构化余跨度的水平复合。后者才是讨论严格语义接口与组合结合性的首选框架。

本软件的 `glue` 实现了此运算的有限离散顶点边界情形。`compose_pair` 对 `in/out` 两端口添加了显式外界规范化；它不试图解决任意多端口网络的统一命名、配线与协议验证问题。

### 4. 化：保持共同部分的合法重写

规则 `ρ=(L←K→R)` 及其单射宿主匹配 `m:L→D`，在 DPO 悬挂等条件下生成 `D'`，写作 `D ⇒_ρ D'`。实现以左右节点／边身份、匹配、保留映射表示这种关系。

**重要区别**：规则定义的「重写」不是必然的现实时间变化；只有选定时间、激发条件、调度或速率语义，才可将规则应用解释为物理或程序历程。

### 5. 则与观：不同层级的准则与解释

「则」不是第五种自然实体，而是已声明的合法性、等价、约束、定律及证明义务；「观」是可声明的观测与语义映射，包括抽象。这使「文、合、化」不至于自我封闭为无法证伪的哲学话语。

## 二、五种「同」的形式说明

给出模型时，可为一个候选等价关系加上范围标签：

1. `≅_str`：**结构同构**，保持节点／关联类型、端点角色，以及外部端口在指定重命名下的对应关系。
2. `≈_int`：**接口可替换**，在已声明接口合同下，任何被准许的使用环境仍可连接；这不自动涉及内部状态与安全。
3. `≈_tr^E`：**观察迹等价**，在环境族 `E` 和可观察事件投影下得到相同的迹（或适当的弱等价）。
4. `≈_causal^J`：**干预等价**，在指定干预集合 `J` 和查询集合下给出等价的效应或允许误差界。
5. `≈_norm^N`：**规范认可/可接受性**，需独立确立的规范判据 `N`、参与者权利、经验后果和程序正当性。

这五种关系不构成普遍的全序。一种结构同构不推出行为相同，因为节点所运行的动力学可能不同；有限观察相同也不推得所有干预相同。应避免将这些关系统称「完全一样」。

## 三、有限可证明命题：两种抽象闭合

### 命题 A：确定性宏观闭合的充要条件

令 `X` 为**有限、非空、对更新封闭**的状态集合，`F:X→X` 为确定性更新；`α:X→Y` 为满射（若不是满射，取 `Y=α(X)`）。存在唯一函数 `G:Y→Y` 使

`α∘F = G∘α`

**当且仅当**对于所有 `x,x'∈X`，若 `α(x)=α(x')`，便有 `α(F(x))=α(F(x'))`。

**证明**：必要性由式子两侧对同一宏观值计算相同而得。充分性：定义 `G(α(x)):=α(F(x))`；假设保证选取任意同一纤维内代表元都得到相同结果，故良定义；满射保证定义覆盖全部 `Y`，也保证唯一性。

**代码**：`compatible_abstraction()` 检查该条件，并在不成立时返回一组冲突见证。测试现会拒绝未对更新封闭的 `X`。这并非一个一般的因果抽象定理。

**反例**：`X={0,1,2}`，`F(0)=1, F(1)=2, F(2)=0`，`α(0)=α(2)=A, α(1)=B`。来自同一粗状态 A 的 0 和 2，在下一步分别到 B 与 A，因此没有闭合的确定性宏观更新。

### 命题 B：有限马尔可夫链的强可聚合性

令 `X` 是有限状态集，转移核 `P(x,x')` 非负，且每一行求和为 1；`α:X→Y` 诱导一个划分。若对任意 `α(x)=α(z)` 及任意宏观状态 `y'` 均满足

`Σ_{α(x')=y'} P(x,x') = Σ_{α(x')=y'} P(z,x')`，

则可定义唯一的宏观转移核

`Q(y,y') := Σ_{α(x')=y'}P(x,x')`，其中 `α(x)=y`。

这是标准有限链的**强可聚合性（strong lumpability）**判准；在要求对同一宏观状态下任意微观初态都成立的意义下，该条件也是必要的。注意这不同于只对某个特定初始分布成立的弱聚合性，也不涉及一般随机过程的完全抽象。

**证明思路**：块间质量对纤维中的微观代表元无关，故宏观核良定义；非负性和行和为1从微观核继承。反之，若对同一粗状态所有微观起点的宏观一步转移一致，则相应块间总质量必相同。

**代码**：`strong_lumpability` 以 `fractions.Fraction` 做有限有理概率的精确检验，返回宏观核或冲突见证，并拒绝概率和不为一、未知微观状态等输入。参考 Kemeny–Snell 判准的综述：https://people.nmsu.edu/jtian/publications/2006-3.pdf

### 命题 C：资源守恒作为外加语义

考虑 Petri 风格的反应网络，物质计量向量为 `m`，反应化学计量矩阵为 `N`，可发生反应后的变化为 `m'=m+N·u`。若存在权重 `w` 使得 `wᵀN=0`，则 `wᵀm'=wᵀm`，即相应加权总量保持。这来自**额外指定的计量语义**，而不是合成图的抽象形状。

`PetriModel` 用有限非负整数标记与反应消费／产出计数验证一类简单守恒检查；它不能取代真实化学反应条件、空间分布与物理动力学。

## 四、合与化在更高层的关系

一条合理的形式升级路径是：

- **第一层：有类型开放图。** 提供图式、端口、合法连接、单次结构重写。
- **第二层：结构化余跨度。** 将边界看作数学对象；连接由推积构成，适当条件下得到对称幺半范畴／双范畴。
- **第三层：带有重写的高阶结构。** 将「开放系统」视为可组合的一类变换，将「系统改写」视为关于它的另一类变换；在合适条件下讨论这些变换如何相容、如何产生二维交换图式。
- **第四层：多语义函子／算子。** 从同一构造句法出发，分别给予确定性、随机、连续、资源、逻辑与控制等解释，并明确哪些图式在这些解释下仍可交换。

这个层级是设计建议而非已实现的一套普适双范畴。Cicala（2026）已为 structured cospans 中的重写给出严谨理论，不能把这类已有工作重新归功于本项目。https://doi.org/10.1017/S0960129526100668

## 五、为什么「一操作」不能单凭数量胜出

设两个候选语言：

- `L₁`：只有一个通用构造器 `Make(tag,payload)`，其中 `tag∈{glue,rewrite,observe,...}`。
- `L₂`：具有显式 `glue` 与 `rewrite`、带类型检查和可记录的失败条件。

在表面操作符数量上 `L₁` 更少。但「何时粘合，何时改写」「哪一种参数结构合法」已被藏到 `tag` 与 `payload` 的解释器中。**计数原语之前，必须固定允许哪些编码、哪些语义原语可被免费使用、何谓复杂度。**

因此我们应比较：

`C_total = C_syntax + C_types + C_semantics + C_proofs + C_execution + C_explanation`。

这不是一条物理定律，而是可操作的评价框架。各项不能简单等权求和；需在研究开始前预先确定任务与权重，否则优化结论会随着评估方式改变。

建议固定同一批跨领域题目，记录 AST 规模、接口标记数量、附加公理、证明义务、非法表达拒绝率、重写复杂度与人类读者的正确理解率。当前尚未完成这种系统比较，故称 `L₂` **工程基线**，不是唯一最小解。

## 六、语义构造的三项边界

**1. 从网络图到时间必须再作选择。** `D⇒D'` 描述合法的配置改写，不意味着该变化一定发生，也不规定速度与先后。可以添加离散事件、事件偏序、连续时间、随机速率或控制策略；如果涉及反馈，还要明确状态、延迟或适当的反馈解释。

**2. 从连接关系到因果关系必须再作选择。** 一条边可以是关联、协议、信息通道或机制作用。观察上的相关和干预下的效应是不同语义。强可聚合性也不是因果保真性。

**3. 从可行变化到善的制度必须再作选择。** 技术上可连接、可重写、甚至形式安全的制度，不一定有合法性、公平性或尊重退出自由。规范意义来自独立的评价规则及经验事实，而不是图的组合律。

## 七、十六条写作及建模规约

1. 不从字面精练性推出数学完备性。
2. 不把模型中的节点认作现实的终极实体。
3. 不以结构同构冒充行为等价。
4. 不以行为等价冒充因果等价。
5. 不以可连接性冒充语义兼容。
6. 不以隐藏端口标签冒充安全隔离。
7. 不以合法重写冒充必然发生。
8. 不以可达性冒充概率或价值。
9. 不以局部稳定冒充整体稳定。
10. 不以同一图式冒充同一物理规律。
11. 不以有限观察推断全局确定性。
12. 不以「能自描述」推断「能自证全部」。
13. 不以所有权关系冒充有资源守恒。
14. 不以组合式解释自动推出独立于条件的涌现。
15. 不以古典语义启发冒充古义证明。
16. 不以当前测试数代替公理证明与跨领域经验验证。

## 八、这一轮真正完成的是什么

从版本 v1.0 到 v1.2，增加了：外界标签的显式规范化、可接受的自动匹配搜索、闭合状态域校验、精确有限马尔可夫粗粒化检验、至少三条可证明的小命题的完整条件，以及以「同」为中心的多层等价框架。

没有完成：任意开放超图的统一端口语义、一般 DPO / adhesive 双范畴引擎、连续物理语义、可执行的因果干预验证器、算法正确性的形式化证明、所有古汉语词条的训诂学核对或对全部现实的本体论描述。

这使 `文·合·化` 比先前更完整，也更能够说明自己**在何种条件下成立、在何种条件下不成立**。
