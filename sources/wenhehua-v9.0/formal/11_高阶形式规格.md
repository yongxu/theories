# 「合—化」高阶统一：形式规格与公理边界

**编号：WHH-FORMAL-2.0｜状态：有限实现 + 基于已知定理的数学构造**

## 0. 术语固定

这里的 **bicategory** 译作「弱二范畴/双范畴」，不是具有水平箭头、垂直箭头和方格的 **double category（双重范畴）**。两者有关联但并非同义。选取 `MonicSp(Csp(T))` 的 bicategory 结构最为直接；若日后让外界接口自身变动，再进一步研究适当的 double category 或 fibrational/typed constructions。

「一体二向」是为帮助理解而引入的中文名称；已知数学定理归属原作者。

## 1. 数学公理背景

1. 给定小的有向超图关联模式 `S` 与类型数据 `Σ`。理想化背景 `T` 取相应预层范畴或合适的类型化图拓扑斯。只需使用其有限极限、推积、拉回及单态的良好性质。
2. `T` 中对象可为图、超图及其类型化版本；**代码实现**仅考虑有限、有固定元数的节点/关联集合。
3. 默认构造不携带物理长度、概率、能量、时间或社会价值。任何这些量都应通过单独语义签名引入。
4. 只在必要时施加边界腿单态限制。单个输入或输出接口中的两个不同端口不能指向同一顶点；输入与输出两侧之间可以指向同一顶点。

## 2. 对象（0-胞）：类型化界面

一个 0-胞 `X` 是类型化离散顶点接口，例如有序列：

\[
X=(\tau_1,\ldots,\tau_n).
\]

图范畴中可以将其视为无内部关联的离散类型化图。空界面对应零元素。端口编号是软件中的约定，不是范畴论本体上的绝对身份。

## 3. 一胞（「文」）：开放余跨度

\[
A=(X\xrightarrow{i_A}N_A\xleftarrow{o_A}Y).
\]

`N_A` 是内部配置，`i_A, o_A` 给出如何对接外部界面。对于当前软件，单侧边界嵌入为单射类型保持图映射。结构化余跨度的更一般形式为 `L(X)→N←L(Y)`，其中 `L` 把界面构造成具有内部类型的对象。本实现采取 `L` 为离散界面嵌入的有限实例。

约定：`A:X⇒Y` 表示水平一胞，勿与作为纵向改变的二胞 `α:A⇒A'` 混淆。完整文档中首次出现时必须明确层级。

## 4. 横向组合（「合」）

\[
A:X\to N\leftarrow Y,\ B:Y\to M\leftarrow Z,
\qquad
B\circ_h A := X\to (N\amalg_Y M)\leftarrow Z.
\]

`N ⨿_Y M` 按共通接口的映射构成推积。恒等一胞为 `X→X←X`。推积的泛性质保证组合在典范同构意义下结合；因此形成弱结合的高阶组合结构，而非依赖具体生成的顶点 ID 的字符串等号。

## 5. 二胞（「化」）：单态跨度的等价类

在固定接口 `X,Y` 上，给定一胞 `A=(X→N←Y)` 与 `A'=(X→N'←Y)`。一个二胞由图式：

\[
\begin{array}{ccccc}
&&K&&\\
&\swarrow^m &&\searrow^{m'}&\\
N&&&&N'
\end{array}
\]

给出，其中 `m,m'` 是单态，且存在 `X→K←Y` 使两个外界映射都通过 `K` 因子化：

\[
i_A = m\circ i_K,\quad i_{A'}=m'\circ i_K,
\qquad
o_A=m\circ o_K,\quad o_{A'}=m'\circ o_K.
\]

严格 bicategory 的 2-胞取**此类跨度在顶点 `K` 的同构之下的等价类**。此处统一的不是「变成另一个结构」与「相互连接」的字面同一，而是它们被同一高阶范畴组织起来。

## 6. 二胞纵向复合（「化之相续」）

\[
\alpha=(N_0\leftarrow K_{01}\to N_1),\quad
\beta=(N_1\leftarrow K_{12}\to N_2).
\]

取拉回：

\[
K_{02}:=K_{01}\times_{N_1}K_{12},
\]

由其两端投影得到 `N₀←K₀₂→N₂`。单态在拉回下稳定，故所得两腿仍是单态。其纵向单位为 `N←N→N`，结合律由拉回的泛性质在同构意义下得到。

程序为简化只允许中间网络 **完全同一份节点/边 ID 表示**；数学上只需它们等同或通过明确同构运输。这是实现限制，非理论必须。

## 7. 二胞横向复合（「相合之化」）

若 `α:A₀⇒A₁` 和 `β:B₀⇒B₁` 在一个公共界面上相容，且两者均保护共享接口，分别对其源一胞、靶一胞及保留部分执行推积，并引入自然诱导的单态跨度，得到：

\[
\alpha\odot\beta:(A_0\circ_h B_0)\Longrightarrow
(A_1\circ_h B_1).
\]

对于某些任意选定的局部修改，若改写破坏公共边界、类型或规则匹配条件，则它**不构成**这一固定外界片段的合法二胞，不能声称可以横向合成。这里不把任何重写规则强行视为有效的二胞。

## 8. 交换相容律（本研究的核心）

对四个可拼接的二胞 `α,β,γ,δ`，成立：

\[
(\gamma\cdot\alpha)\odot(\delta\cdot\beta)
\cong
(\gamma\odot\delta)\cdot(\alpha\odot\beta).
\]

如果在同构类上进行严格的 2-胞计算，这表达了高阶复合必须满足的 interchange law；具体代表元由不同推积、拉回次序生成时可能仅**典范同构**。在拓扑斯及单态条件下，其数学结构由 Cicala（2018）、Cicala 与 Courser（2018）研究并证明。

**反限制：**若跨度腿允许非单态，不能毫无附加假设地保留这一定理。若接口改变而没有显式 transport，也不能把方格当作原来那种端点固定的二胞。

## 9. 由 DPO 规则到二胞的桥

给定类型化图重写规则 `L←K→R` 以及单态匹配 `m:L→N`。当满足适当的悬挂条件、推积补存在及指定的外界面保持条件时，DPO 图式构造出 `N⇒N'`。可取前后网络共享的上下文作为保存部分，形成 `N←D→N'` 的单态跨度见证。

其中：

- **规则** 是一套可操作的局部改写许可；
- **推导** 是按规则在某宿主上应用的实例；
- **二胞** 是按前后网络与保留部分抽象后的高阶改变见证。

映射不是无条件双射：一个二胞可以不记录局部规则名、先后次序、时长；不同推导可能对应相同的二胞。语义层必须决定哪些信息需要保留。

## 10. 形式句法（面向编译器）

```text
Types   ::= finite declared type signature Σ
Iface   ::= [] | [Type, ...]
Graph   ::= finite typed nodes + typed incidence relations
Open    ::= iface X -> Graph N <- iface Y
Change  ::= (Open A <- preserved K -> Open B) with monic legs

horizontal(Open(X,N,Y), Open(Y,M,Z))
    = Open(X, pushout(N <- Y -> M), Z)

horizontal_change(Change(A0,K,A1), Change(B0,L,B1))
    = Change(A0∘hB0, pushout(K <- Y -> L), A1∘hB1)

vertical_change(Change(A0,K01,A1), Change(A1,K12,A2))
    = Change(A0, pullback(K01 -> A1 <- K12), A2)

check_interchange(α,β,γ,δ)
    = isomorphic_witness(horizontal_change(vertical_change(α,γ),
                                                vertical_change(β,δ)),
                         vertical_change(horizontal_change(α,β),
                                         horizontal_change(γ,δ)))
```

`Change` 的第二个参数是 **保留部分而非任意新系统**，两侧还必须附有单态映射；伪代码省略了这些映射以利阅读。注意伪代码中的左右顺序和上面的数学记号约定，在工程调用中需以明确的端口位置/类型规范消除歧义。

## 11. 哪些性质从形式构造自动得到？

| 性质 | 是否可由当前高阶形式结构得到 | 理由 |
|---|---|---|
| 复合类型正确 | 是，前提是输入均满足类型约束 | 对象、边界及箭头类型必须相容 |
| 网络水平复合的弱结合律 | 是 | 余跨度复合及推积的泛性质 |
| 变化纵向复合的弱结合律 | 是 | 拉回的泛性质 |
| 二胞水平/纵向的交换相容律 | 是，在拓扑斯与单态等条件下 | 已发表的高阶结构定理 |
| 每次改变都保持所有行为 | 否 | 同一个边界合法变化可删除关键路径 |
| 任意系统的资源守恒 | 否 | 需领域计量与守恒约束 |
| 任意过程的概率及因果意义 | 否 | 需概率核、干预与时序语义 |
| 外界接口任意自我改变 | 当前受限片段不支持 | 需显式接口变更/运输的高阶扩展 |
| 唯一最小的一切系统本体论 | 否 | 没有完成此类证明，亦未有固定合适的优化准则 |
