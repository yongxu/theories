# 形式规格 F：文法解释、跨语义桥与保真义务

**v6.0 · 可复核的数学规格**

## F0. 形式地位与记号

本稿以 v5 的有限类型集合谱系与弱交换比较为结构基础，但**并未构造横跨所有解释的单一大范畴**。我们在不同语义的受限子语言上定义若干确切桥梁和证明义务；其间有些箭头有严格组合保持定理，有些只是忘却映射，有些是要检查是否成立的查询相容性条件。

设 \(\Sigma\) 是一组有类型的生成元 \(g:A_g\to B_g\)。令 \(\mathcal G_\Sigma\) 表示其可合法组合的自由语法（完整开放图语言使用 v1–v5 的型化超图和余跨度，而此处的软件例子仅对线性生成元链实现解释）。对语义类别 \(\mathcal C_d\)，一个语义解释应是其定义域 \(\mathcal G_d\subseteq\mathcal G_\Sigma\) 上的结构保持映射

\[
S_d:\mathcal G_d\longrightarrow\mathcal C_d,
\quad S_d(g\circ f)=S_d(g)\circ S_d(f),
\quad S_d(1_A)=1_{S_d(A)}.
\]

有并行组合时，还须证明 \(S_d(f\otimes g)\) 与 \(S_d(f)\otimes S_d(g)\) 之间相应的严格或相干同构关系。**代码不以“名字相同”作为这些等式的证明。** 对尚未实现的组合不默认存在解释。

## F1. 确定行为到有限随机核（定理）

令 \(\mathsf{FinSet}\) 为有限集合与函数的范畴，\(\mathsf{FinStoch}\) 为有限集合与列／行惯例一致的随机核（本稿用行概率 \(K(y\mid x)\)）。定义

\[
D(f)(y\mid x):=[y=f(x)]
\]

其中括号为 0–1 指示函数。对 \(f:X\to Y, g:Y\to Z\)，

\[
\sum_{y\in Y}[y=f(x)]\,[z=g(y)]=[z=g(f(x))].
\]

故 \(D(g\circ f)=D(g)\circ D(f)\)，单位也保持；独立乘积下张量同样保持。这是一个严格的有限语义桥。**反向没有天然确定性解释**，因为一般核的单行可能有多个正概率结果。

代码：`semantic_bridges.py: FiniteFunction.as_kernel, interpret_kernels`。测试包括单位、结合律、显式缺失语义拒绝、错型拒绝以及 Dirac 组合等式。

## F2. 反应结构到动力学与守恒（定理）

给定有限物种集 \(P\)、反应集 \(R\)，化学计量矩阵 \(S\in\mathbb Z^{P\times R}\)，速率函数 \(v:\mathbb R_{\ge0}^{P}\to\mathbb R_{\ge0}^{R}\)。假定存在使 ODE 有意义的解并且其域足以支持求导，定义

\[
\dot x=S v(x).
\]

对每个 \(w\in\mathbb R^{P}\) 满足 \(w^\top S=0\)，沿上述解有

\[
\tfrac{d}{dt}(w^\top x)=w^\top\dot x=w^\top S v(x)=0.
\]

所以 \(w^\top x\) 在解的存在区间恒定。若开放系统含外界通量 \(Bu(t)\)，则导数应为 \(w^\top B u(t)\)；若界面被误认成“内部”，则得出的守恒结论错误。

代码实现的是已声明反应速率的**状态处导数求值**，并非导出通用开放 Petri 到 ODE 的双函子。我们给出 \(H_2,O_2,H_2O\) 的两种原子权重守恒证书，及线性 \(A\to B\to C\) 的数值导数测试。相关的开放反应网与黑箱化函子由 Baez–Pollard 等已有研究建立（参考文献列出）。

## F3. 有限 Markov 强可聚合（定理与检查）

给定概率核 \(K:X\rightsquigarrow X\) 和满射 \(\alpha:X\twoheadrightarrow\bar X\)。若对 \(x,x'\) 同属一纤维有

\[
\forall\bar y:\quad \sum_{y\in\alpha^{-1}(\bar y)}K(y\mid x)
= \sum_{y\in\alpha^{-1}(\bar y)}K(y\mid x'),
\]

则定义 \(\bar K(\bar y\mid\bar x)\) 为上式在任意代表 \(x\in\alpha^{-1}(\bar x)\) 的值，与代表无关，且自然归一化。

因此对任意微观分布 \(\pi\) 有

\[
\alpha_*\bigl(K_*\pi\bigr)=\bar K_*\bigl(\alpha_*\pi\bigr).
\]

反之若存在此类宏观核对每个微观点分布均满足上述等式，选取同一纤维中任意两点分布便可推出强可聚合条件。因此在**对所有初始分布有效**这一语义下，条件既充分又必要。

注意接口意义是另一项证明义务：如同一宏观类内端口类型／数量不同，就不能仅因 Markov 聚合成功而声称“接口也保真”。`quotient_markov` 在提供 `shapes` 时执行独立检查。

## F4. 因果忘却的不忠实（构造反例）

两个无混杂二元确定性 SCM：\(M_{X\to Y}\) 与 \(M_{Y\to X}\)，各有一枚独立 Bernoulli(1/2) 外生根变量，子变量直接复制根变量。观测联合分布相同。但在干预 \(\mathrm{do}(X=1)\) 下：

\[
P_{M_{X\to Y}}(Y=1\mid do(X=1))=1,
\qquad P_{M_{Y\to X}}(Y=1\mid do(X=1))=\tfrac12.
\]

因此将模型映到观测联合分布会丢失可区分的因果信息。**这不是一个“因果从概率不可恢复”的无条件绝对定理**：给定图、干预实验、识别假设或额外数据时可有不同推断结果；这里严格展示的是单独观测联合分布不足以区分这两个模型。

若要进行因果抽象，需指定可接受干预查询族 \(\mathcal Q\)，并检验每个查询的交换条件，不能由强可聚合自动推出。

## F5. 带权最短路径（受限组合命题）

令 \(G_1,G_2\) 为非负长度有向图，各有唯一入口与出口，除把 \(G_1\) 出口识别为 \(G_2\) 入口外，其余节点不识别，也没有跨图边。记 \(d_i\) 为对应入口到出口的最短路径长度（不可达记无穷）。那么

\[
d(G_2\circ G_1)=d(G_1)+d(G_2),
\]

因为任何由整体入口到整体出口的有向行走均经过唯一接缝，可以取接缝前后的子行走；反过来两侧最短路径拼接提供达到上界的行走。非负性允许消去不改善长度的回路。本命题**不**覆盖多个共界点、额外跨界边、几何碰撞或自动长度单位换算。

软件对非负有理边权求最短路，并拒绝不兼容单位。

## F6. 弱交换映射到带权谱系：覆盖阻碍（定理）

取 v5 比较映射 \(\chi:U\to V\)。有限见证权重 \(\nu:U\to\mathbb R_{\ge0}\) 沿 \(\chi\) 推前得到

\[
(\chi_*\nu)(v)=\sum_{u:\chi(u)=v}\nu(u).
\]

由此对 \(v\notin\mathrm{im}(\chi)\)，上式必为零。因此若某个全局权重 \(\mu:V\to\mathbb R_{\ge0}\) 满足 \(\mu(v)>0\) 且 \(v\notin\mathrm{im}(\chi)\)，则不存在 \(\nu\) 使 \(\chi_*\nu=\mu\)。反过来，只要 \(\mu\) 支持在 \(\mathrm{im}(\chi)\) 上，**存在**至少一种非负权重提升：为每个有正权重的 \(v\) 任取一个原像，赋予其全部权重，其余置零；但提升一般不唯一、不自然。

这完全精确地说明：**弱交换的缺失像可能阻碍一种给定权重语义的无损传递**。它不说明整体的新增形式路径必然携带自然界里的概率或物质。`trace_coverage` 会输出覆盖与未覆盖的形式权重，且拒绝负权重及漏项。

## F7. 多阶段弱比较的典范拼接（受限有限定理）

v5 的 χ 定义在两段变界见证上。现在对同一条时间链上任意有限个相容 `SeamStep` \(E_{01},\ldots,E_{n-1,n}\) 定义

\[
W_{\mathrm{loc}}^{(n)}=
\bigl(W_A^{01}\times_{A_1}\cdots\times_{A_{n-1}}W_A^{n-1,n}\bigr)
\amalg_{\left(W_J^{01}\times_{J_1}\cdots\times_{J_{n-1}}W_J^{n-1,n}\right)}
\bigl(W_B^{01}\times_{B_1}\cdots\times_{B_{n-1}}W_B^{n-1,n}\bigr)
\]

和

\[
W_{\mathrm{glob}}^{(n)}=
(W_A^{01}\amalg_{W_J^{01}}W_B^{01})
\times_{Q_1}\cdots\times_{Q_{n-1}}
(W_A^{n-1,n}\amalg_{W_J^{n-1,n}}W_B^{n-1,n}).
\]

各局部见证序列经每一步的水平推积映射进入全局见证序列，并因为同一时间链的中间状态一致而良定义；左右在接缝见证上相等，由推积的泛性质得到**典范映射**

\[\chi_n:W_{\mathrm{loc}}^{(n)}\longrightarrow W_{\mathrm{glob}}^{(n)}.\]

**有限时间链拼接唯一性命题：** 对于这个明确的有限单接缝、双侧模型，在选取拉回与推积的标准结合子同构后，任意将相邻二步的典范比较依次拼接而成的映射，只要起终点都是上述同一对整体对象，都与 \(\chi_n\) 相同。

**证明思路：** 每条局部见证（左侧或右侧）都被逐步送到对应时刻的水平推积见证，得到一个全局见证序列。任意二步比较是这些分量映射的组合。因此无论先比较哪一对相邻阶段，最后在全部生成局部见证上的结果相同。由 \(W_{\mathrm{loc}}^{(n)}\) 的推积泛性质，两个整体映射一致（更换括号时需通过拉回的典范结合同构）。□

代码 `n_interchanger` 在具体有限类型集合上实现此典范映射，三阶段测试核对了分步和直接比较的相同结果。**它不是对所有空间组合方向、水平复合形状和任意高阶胞的完整双范畴相干律证明**。

## F8. 跨层语义的共同合约

对每个声明的桥梁 \(b:d\to e\)，最少需要写出七项内容：

| 证书字段 | 检查内容 |
|---|---|
| `Domain` | 接受哪些有类型的图、过程、值域、时间结构 |
| `Interface` | 何种边界映射或重命名得到认可 |
| `Compose` | 语义组合的定义、单位与相容条件 |
| `Query` | 期望保留的观察、行为、流量或干预族 |
| `Law` | 需要证明的交换图、等式或误差界 |
| `Witness` | 证明证书、有限检测结果或经验依据 |
| `Failure` | 不满足时的反例、错误消息或剩余信息损失 |

不具备这七项的“从结构推出一切意义”的箭头，只可视作比喻或研究假设。

## F9. 高阶相干性与我们尚未证明的部分

v5 的有限 \(\chi\) 由通用构造给出，而非任意赋值；这支持继续寻找 lax double category 或相关 equipment 的数学形式。**本稿没有证明**下列内容：

1. 所有 `SeamState`、`SeamStep` 与比较胞满足**超出 F7 单时间链范围的**完整双范畴结合、单位、自然性和 coherence 公理；
2. 所有解释领域都有定义在同一结构上的保水平、保垂直的双函子；
3. 这些双函子都把 \(\chi\) 送入目标范畴的可逆比较胞；
4. 连续反应动力学、随机动态接口、规范许可及因果干预可以无条件用同一套图重写语义表达；
5. 该文法具有普适最小性或是现实唯一正确的本体论。

研究上更稳健的路线是：选择一个成熟的结构语义（例如开放反应网络的 rate equation 解释），首先证明组合保持，再在有穷适用域上研究变化见证及比较胞如何映射，而不是从所有领域同时猜测一个大定理。
