# 文·合·化 v8.0｜合化同源：双向生成图与高维粘合

**主要结论：** 「合」与「化」不必被设成两种绝对独立的宇宙本原，也不能无条件压成同一个无类型的运算。更合适的统一是：**一套具有维度、方向、边界和相干规则的高维拼接机制**。合表现为某些一维过程的连接，化表现为网络间的二维改变与接续；二者的相容或失配本身可继续由更高维的见证表达。

**特别重要的新文献：** Fairbanks–Shulman (2026-05-04) *Doubly Weak Double Categories*，从 double computad 出发，在可表性条件下取得两个方向的一维弱复合。与 Cicala 的 open-network rewriting、Grandis–Paré 的 intercategory 及 polygraphic coherence 形成互补。

**两条可复现的失效证据：**

- 中间时刻共享接口产生跨侧历史：局部接续再合得 2 条，先整体合再接续得 4 条；比较映射不满射。
- Beck–Chevalley 基变换：拉回方格成立；仅要求方格可交换却不为拉回时，相关纤维可以出现 3 对 2 的差异。

**数学上的关键纠错：** 标准 structured-cospan double category 中，纵向 1-胞通常表示接口映射，重写不是自动一个纵向 1-胞；网络变化通常由二维胞/重写见证表达。`MonicSp(Csp(T))` 又是另一种密切相关的高阶构造，不能随意等同。

**工程结果：** 新增 13 项精确有限模型测试，加上 v7 的 232 项回归，**245/245 项通过**。测试验证的只是构造片段，尚未证明 v7 的具体模型满足完整 doubly weak double category 或 intercategory 公理。
