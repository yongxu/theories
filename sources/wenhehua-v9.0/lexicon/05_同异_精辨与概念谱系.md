# 同异精辨：使词林真正成为可构造的文法

**第二轮词义复审 · 2026-11-24**

与其再增加数百个美丽词语，不如保证关键概念彼此不偷换。以下是 **34 组必须分辨的词**，每组标记正式差异和使用限制；相关工作定义沿用本项目，不代表先秦字义。

| 对照 | 不可混同之处 | 最小形式要求 |
|---|---|---|
| 文 / 物 | 文是某观下的关系配置；物可指保持可识别性的相对单位 | 组织模型、身份准则 |
| 文 / 象 | 文是被建模配置；象是某种观察或表征（不必唯一） | 观察映射 |
| 别 / 分 | 别是判别差异；分是把组织拆作部分 | 等价判据、分解操作 |
| 同 / 等 | 同可以指任一给定等价；等需要明示等价关系或量值 | 等价关系或数值比较 |
| 等 / 似 | 等有精确定义的等价条件；似有相似度或容差 | 同构证据或度量阈值 |
| 界 / 域 | 界是相对于连接或观察的接口；域是模型适用的空间或集合 | 接口图、定义域 |
| 界 / 隔 | 暴露接口与物理、信息隔离不同 | 威胁模型／可达性 |
| 端 / 径 | 端是连接口；径是由若干关联组成的路 | 顶点接口、路径语义 |
| 通 / 达 | 通偏于存在连接；达偏于沿方向可达 | 有向可达定义 |
| 合 / 并 | 合可能沿公共界识别；并可沿空界无识别 | K 是否为空 |
| 合 / 融 | 结构合成不一定使功能或身份融合 | 整体行为与身份模型 |
| 连 / 耦 | 连接图存在边，不等于动态耦合一定非零 | 交互函数／系数 |
| 顺 / 因 | 时间先后不是因果作用 | 干预模型 |
| 化 / 迁 | 化可改组织；迁通常只改位置或映射 | 重写对象范围 |
| 化 / 生 | 合法变化不必产生新的可辨组织 | 新组织识别判据 |
| 化 / 进 | 变化不是价值意义上的进步 | 规范评价 |
| 事 / 程 | 事可指单次事件；程是可追溯历程 | 事件、路径/序列 |
| 序 / 时 | 偏序依赖不等同于单一绝对时钟 | 事件偏序／时间域 |
| 复 / 循 | 结构重复嵌套不等于状态循环返回 | 递归/循环判据 |
| 返 / 逆 | 回到同一状态不意味每步可逆 | 可逆态射与路径 |
| 量 / 质 | 量值不等于类型与语义性质 | 测度、签名 |
| 稳 / 衡 | 稳定可描述扰动响应；平衡是特定动态条件 | Lyapunov或平衡定义 |
| 守 / 常 | 守表示指定不变量；常可能指统计稳定或组织持续 | 不变量/时间模型 |
| 势 / 能 | 可达可能性不等于物理能量 | 规则可达集/能量函数 |
| 势 / 概率 | 可达不等于可能性大小 | 随机核/概率分布 |
| 观 / 知 | 观察提供信息，不确保真实知识 | 噪声/可辨识性/验证 |
| 观 / 因 | 观测相关不等于干预因果 | 干预和识别前提 |
| 抽 / 简 | 结构简化不保证保留目标性质 | 需保留的查询/性质 |
| 粗 / 宏 | 粗化描述不一定具有闭合自主动力学 | 聚合性/闭合检查 |
| 义 / 法 | 合法规则不自动具备伦理正当性 | 外部规范与程序 |
| 共 / 合 | 共享或协作不等于任意组合 | 参与和资源约束 |
| 善 / 效 | 达到某个技术指标不等于社会善 | 规范目标及外部性 |
| 续 / 恒 | 延续需要条件，不能许诺永恒不变 | 时域与持续性阈值 |
| 元化 / 自证 | 自修改可能，自证全部安全并不随之成立 | 元层/可信核 |

## 词库的四级地位

- **G：文法级**。构成形式语法或其直接操作：文（有类型配置）、合（界面组合）、化（合法重写）、界面、签名、匹配、端口。
- **D：严格派生级**。一旦固定签名与相应定义便可准确推出：连通、图同构、重写路径、可达集合、有限拓扑性质等。
- **S：语义扩展级**。需要独立模型：时间、概率、力学、控制、因果、资源、信息、观察、稳定性。
- **N：规范与实践级**。需要社会与伦理事实、价值和程序：权利、善、公平、正当性、自由、社会福祉。

古典证据评级是**另一条独立轴**：历史的 K1/K2/K3 与研究使用的 P1/P2，不应与这里的 G/D/S/N 混为一维。一个词可以历史上很早出现、却在本项目中作为现代新定义使用；也可以数学非常精确、但根本不出现在古典文本里。

## 「文」派生词应当怎样写

- **文界**：一个给定组织在指定互动中的外部端口，以及它与内部组织的映射（G）。不是天生的绝对内外。
- **文路**：在选定有向连接语义中由一系列关联构成的路径（D）。不等于物理可达。
- **文势**：给定规则、环境和时域条件下的可达未来集，若带概率需追加概率后端（D/S）。
- **文序**：变化步骤构成的序列或偏序，需明确并发模型（S）。
- **文常**：在给定重写族或动力学下被保留的属性（D/S）。
- **文同**：相对于明示的等价层次，两个文可互换或一致（D/S/N 需区分）。
- **文观**：观测与解释所给出的表征及其保留性质（S）。
- **文生**：出现满足既定辨认标准的新组织（D/S）。
- **文谱**：具有来源与转变注记的配置谱系（D）。
- **元文**：文法构造本身的数据表达（S），须分对象层和元层。

## 术语设计准则

**词短，定义不可短。** 一个字可以做总括标记，数学规格必须明确；不要为了古雅而将不同类型的「同」「势」「界」混成一个不可区分的概念。**意简，证明不可省。** 只有给出适用条件及反例，才可在复杂系统里可靠组合。**文贵通达，但通达不等于无差别。** 最好的文法应当允许不同语义并存，并明确它们能够相互比较的界限。
