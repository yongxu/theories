# 高阶统一概念增注：从古汉语线索到数学的两向构造

**词源说明：**以下大多是现代研究中对单字或字组的工作定义，不能视为未经考据的古汉语原义。数学专名沿用现代通行译名；研究性新造用语以“研究性术语”注明。原389词在 `完整词库389_增注.csv` 原样保留。

本增注表共 **79** 项。它们是对核心概念的严格用法与风险提示，不追加统计成“全部词条都经古籍考证”。
