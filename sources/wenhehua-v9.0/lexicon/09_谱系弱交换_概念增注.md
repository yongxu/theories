# 谱系与弱交换：工作概念精注

**本轮新增 60 条精注，分 7 个语义族。**

这是一套供研究、建模和编程使用的工作定义，不是未经考据的古汉语义项。相同词形可能在更早版本出现，不能把版本条数简单相加为独立词汇数。

## 迹与谱系

| 词 | 工作义与形式参照 | 易混之处 | 最小例 |
|---|---|---|---|
| 迹元 | 一次明确记录的前后关联，不等同于持久个体；w∈W | 单个token可非同一物 | 旧端a经w相关于新端b |
| 续迹 | 两段关联见证可经共同中点相续；W01×_B W12 | 中点对应不一定是物理因果 | u在b与v相续 |
| 断迹 | 当前见证中缺乏某段对应；W=∅ | 不可由无迹断言现实无事 | 未给端口续迹 |
| 分迹 | 一个旧端点对应多个后续见证；p:W→A非单射 | 非自动物理复制 | 一旧端点对应w1,w2 |
| 合迹 | 多个来源见证指向同一新端点；q:W→B非单射 | 非自动个体融合 | u,v同至终点b |
| 旁迹 | 首末相同而经不同中点的历程；(u1,v1)≠(u2,v2) | 不能压成一条即称无损 | a经b1或b2到c |
| 迹重 | 首末相同但见证不止一条的重数；\|{w:p(w)=a,q(w)=b}\| | 不等于概率大小 | 同端点二条路径 |
| 迹径 | 由可接续见证构成的一条有限路径；(w01,w12,…) | 不是几何长度或时间参数 | 三阶段历程 |
| 迹谱 | 多个见证的类型与连接结构之全貌；Span及路径重数 | 不是经过实验认证的因果谱 | 两条分支再汇合 |
| 源迹 | 附有来源端点的见证；p:W→X0 | 不能仅凭来源确定责任 | 记录来自哪一模块 |

## 界与相接

| 词 | 工作义与形式参照 | 易混之处 | 最小例 |
|---|---|---|---|
| 共界 | 两侧模型指定为可连接的中介接口；J→A,J→B | 不是宇宙中客观固定隔墙 | 两机器共享端口集合 |
| 沿界 | 通过指定接口识别完成的合成；A⊔_J B | 不是无条件相加 | 把两个网络的端口粘接 |
| 界商 | 连接引起的等价类识别；(A⊔B)/∼ | 商节点非物理同一证明 | 左右端口落于同一商类 |
| 变界 | 接口随阶段而改变；J0,J1 | 不以同名代表续同 | 新增传感器输入 |
| 界迹 | 旧新接口之间给出的关联跨度；J0←WJ→J1 | 不默认单射 | 两旧端口指向一新端口 |
| 界续 | 共界关联跨越相邻阶段；WJ01×_J1 WJ12 | 不能强制每个端口都持续 | 旧连接经历两次改线 |
| 共迹 | 两侧历史通过共界见证相容；WJ→WA,WB | 须验证交换方格 | 同一协议事件映射到两侧 |
| 借界 | 在整体商空间利用共享中点连接历程；W01×_Q1 W12 | 不自动表示真实跨系统传递 | 左见证后接右见证 |
| 接力 | 一个形式历程从一侧转到另一侧；交叉匹配的见证对 | 必须说明是否有因果作用 | 左模块后接右模块 |
| 入界 | 暴露一侧端口供组合使用；J→A | 不是输入信号方向 | 声明共界到左状态映射 |

## 同异与强度

| 词 | 工作义与形式参照 | 易混之处 | 最小例 |
|---|---|---|---|
| 同名 | 标识字符串相同；name(x)=name(y) | 不代表节点持续身份 | 两阶段端口都叫out |
| 同型 | 类型标签相同；τ(x)=τ(y) | 不保证可以直接连接 | 同为Temperature |
| 同端 | 两见证首末映射相同；(p(w),q(w))相同 | 仍可拥有不同来路 | 两条路径起止相同 |
| 同迹 | 见证可在保端映射下相互对应；W≅W′ over endpoints | 不自动行为等价 | 两种重命名的历史 |
| 同构 | 具有可逆的结构保持映射；f可逆 | 依赖选择的模型范畴 | 两个接口图结构同构 |
| 可比 | 存在明确的结构比较映射；χ:X→Y | 不要求可逆 | 零见证映入一个见证 |
| 可同 | 比较在指定语义下为同构；χ为双射/同构 | 不适用于所有性质 | 两种组合路径相等强度 |
| 弱同 | 存在某种弱于同构的比较关系；lax comparison | 不得冒充等价 | 有方向但不可逆的比较 |
| 强同 | 存在可逆的保结构比较；χ iso | 不等于所有现实语义相同 | 交换比较是双射 |
| 异历 | 相同首末但见证历程不同；w1≠w2 | 不能仅以状态比较抹除 | a经不同中点到c |

## 合化互换

| 词 | 工作义与形式参照 | 易混之处 | 最小例 |
|---|---|---|---|
| 比较胞 | 联系两种高阶合成方式的映射；χ:WVH→WHV | 不是自然可逆 | 不同顺序之间的箭头 |
| 弱交换 | 有方向比较而无普适逆；lax interchange | 不意味着计算错误 | 先续后合注入先合后续 |
| 强交换 | 比较为同构的相容情形；χ≅ | 须说明前提 | 完整稳定共界样例 |
| 先续后合 | 局部见证拉回后沿界推积；WVH | 与先合后续不一定同构 | 局部完成两步再拼整体 |
| 先合后续 | 阶段推积后按中间整体拉回；WHV | 可能产生额外跨边界路径 | 先构造整体再接时序 |
| 拉续 | 拉回实现的谱系时间接续；×_B | 不是一般时间流体方程 | 两段见证有共同中点 |
| 推合 | 推积实现的沿界空间连接；⊔_J | 不是所有连接都能保真 | 把端口同一化 |
| 交换准 | 两种构造顺序可否等价的判据；χ bijective | 有限判据不自动一般化 | 测试 χ 是否双射 |
| 单向比较 | 保持一端点的定向映射；χ:W1→W2 | 另一方向不一定存在 | 空集到非空集映射 |
| 不逆 | 不存在保结构的反向恢复；χ非同构 | 不等于两边不可比较 | 0→1的反例 |

## 观与信息

| 词 | 工作义与形式参照 | 易混之处 | 最小例 |
|---|---|---|---|
| 观迹 | 观察函数能区分哪些谱系见证；obs:W→Y | 观察未必完整 | 记录中点名称 |
| 忘迹 | 将见证压缩为存在性关系；W→R⊆A×B | 非无损化简 | 两条路径映为一个真值 |
| 迹守 | 变换保留特定谱系不变量；I(W)=I(W′) | 必须指定不变量 | 路径重数相同 |
| 迹失 | 变换抹去某些来源区分；obs非单射 | 不应从信息丢失推出不存在 | 两源事件合并为一标签 |
| 路径闭合 | 粗尺度接续仍能定义自洽更新；αF=Fbarα | 不等于因果保持 | 宏观行为可封闭描述 |
| 观准 | 观察之间判断等价的规则；选择语义函子与谓词 | 无指定观察不能谈绝对同 | 接口等价而资源不同 |
| 语义保真 | 解释映射保持声明的结构与性质；F(χ)相关条件 | 不等于对现实完整保真 | 概率模型满足指定保真 |
| 观察余量 | 形式路径中未被解释核验的部分；在整体时间接续的见证中，未被比较映射命中的部分 | 不能把形式余量直接读作因果 | 跨界接力产生额外token |

## 资源与规范

| 词 | 工作义与形式参照 | 易混之处 | 最小例 |
|---|---|---|---|
| 守恒 | 某计量在允许变化下不变；m(X)=m(Y) | 不能从图同构直接得出 | 质量平衡规则 |
| 可复制 | 某类型允许显式复制操作；Δ:X→X⊗X | 非所有资源皆可复制 | 普通数据与独占锁不同 |
| 独占 | 类型/权限不得同时被多处占用；线性或仿射类型约束 | 不是由共享节点名称决定 | 文件写锁 |
| 因证 | 使某形式路径可解释为因果传递的证据；干预/时间/机制条件 | 路径本身不是因果证明 | 物料确曾经接口转移 |
| 许可 | 接口使用是否得到规则授权；policy(actor,port) | 数学可合不保证有授权 | 权限范围校验 |
| 合善之别 | 构造合法性与规范正当性的区别；形式定理 vs 伦理评价 | 不可从形式可达推出应当 | 制度协调需合法性与同意 |

## 验证与研究

| 词 | 工作义与形式参照 | 易混之处 | 最小例 |
|---|---|---|---|
| 有限判据 | 在确定的有限模型中可判定的性质；测试 χ 双射 | 不能自动推广无限结构 | 遍历所有有限token |
| 反例证书 | 具体给出何种假设失败的数据；失败实例＋输出 | 不等于整理论否定 | 混合接力 0→1 |
| 前提账 | 记录每个定理需要的数学条件；assumption registry | 不能省略关键限制 | topos、monicity 等 |
| 归属 | 区别已有数学与本研究的新整合；source attribution | 不得把前人定理宣称原创 | 标注文献与软件贡献 |
| 证据层级 | 区分证明、测试、模型、类比；proof/test/model/analogy | 数百项测试仍非一般证明 | 给每项结论标注强度 |
| 待证 | 尚未建立、不得当成结果的主张；open obligation | 不宜用确定性语言暗示完成 | 一般lax coherence |
