# 高维粘合与合化同源：二十条精注

**说明**：以下词条是现代数学研究的中文工作命名，不构成对古典文献原义的断言。

| 词 | 工作定义 | 严格要求 / 防误读 |
|---|---|---|
| 文胞 | 可辨的有类型生成单元 | 指定维度和全部边界 |
| 文界 | 生成胞用于相接的有向接口 | 不等于固定物理边缘 |
| 通界 | 两胞匹配的共同边界 | 相同名称不一定相同身份 |
| 合形 | 规定多个胞如何拼接的形状 | 必须携带方位与类型 |
| 拼接 | 沿有证书的共界生成复合 | 并非无条件取并集 |
| 横合 | 沿水平 1-胞方向复合 | 切勿偷换成所有并行操作 |
| 纵续 | 沿纵向连续复合二维胞 | 不等于“化是纵向 1-胞” |
| 化胞 | 两个开放过程之间的变化见证 | 通常处于二维，不只是箭头 |
| 共化 | 作用于多个相接组织的协调变化 | 必须检查重写冲突 |
| 方格 | 四界兼容的二维胞 | 不是任意矩形图片 |
| 双文 | 同时保留横、纵界的生成描述 | 以 double computad 为候选 |
| 弱合 | 复合仅在相干同构意义下成立 | 不代表可以随意不确定 |
| 可表 | 一条路径由单个胞代表至同构 | 不是机器学习 representation |
| 相干 | 多种合法拼接序列兼容的性质 | 不等于所有路径字面相同 |
| 强通 | 比较胞可逆 | 需要对应定理前提 |
| 弱通 | 存在非可逆比较胞 | 不保证信息无损 |
| 换基 | 沿映射改变描述所依赖的基 | 属于特定函子语义 |
| 移求 | 依赖求和与替换的相容 | Beck–Chevalley 的一类体现 |
| 临歧 | 两条重写在局部发生重叠分叉 | 是否需合流由目标语义决定 |
| 合化同源 | 两类构造由带界、高维粘合统一组织 | 不声称是相同的无类型二元运算 |
