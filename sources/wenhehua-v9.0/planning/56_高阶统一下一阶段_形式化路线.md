# 下一阶段路线：从双向生成图到可审查的高阶文法

**优先级 A — 选择精确的目标数学对象。** 写出 v7 动态接缝模型的 0-胞、两类 1-胞、2-胞、候选比较 3-胞。首先尝试映射到已有的 spans-of-cospans / intercategory 构造；只有失败才考虑新定义。验收为**类型完整的定义和四个基本交换图**，而不是新造名词。

**优先级 B — 生成-语义两端的实际函子。** 使用 double computad 的 free/representable 机制建立纯生成侧；目标为有类型开放网络的成熟双范畴或适当更高结构。验收为边界、单位、组合及至少一组非平凡二维胞可解释，且解释遵守相应组合关系。

**优先级 C — 强、弱交换的判定与反例。** 尝试给出一类充分条件使 $\chi$ 可逆；给出一个违反该条件仍可逆的例子以表明仅为充分非必要；保留 2→4 不可逆反例。验收为清楚的命题与非平凡反例，而非只统计是否通过。

**优先级 D — 三维相干与临界分叉。** 识别三次重写与两次横向粘合的关键图式，验证单位、结合、自然性、两种交换先后次序和比较胞的复合。可利用 polygraphic critical pairs 组织证明。验收为完整的填充图及数学证明，最好附 Lean/Rocq 无占位源代码。

**优先级 E — Beck–Chevalley 与语义。** 选择一种具体领域（建议 Petri-net rate semantics 或 finite stochastic systems），证明一个真正有用的 base-change/composition 交换同构或单向比较。必须明确它与旧 $\chi$ 的关系，不可因为图形相似直接等同。验收为语义函子、自然性命题、最小失败模型。

**优先级 F — 最小性与可理解性。** 比较三套候选语言：① 双范畴直接公理，② double computad + 可表性，③ 一种更高维的泛化 pasting。评价表达长度、隐藏前提、类型检查复杂度、证明成本、工程可调试性。不要把符号数最少当作“最优”的唯一指标。

**长期终点**：一份可执行中间表示（IR）、一套数学证明证书、一组多领域解释器及一套可检验的跨尺度保真合约。目标是领域内可用的通用生成文法；普适现实本体论另当别论。
