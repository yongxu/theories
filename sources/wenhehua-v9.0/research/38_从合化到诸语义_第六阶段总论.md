# 从合化到诸语义：文法、解释、保真之统一

**文·合·化 v6.0 · 第六阶段总论 · 2026-11-24**

> 相因成文，沿界而合，随势而化。文可同形而异用，化可同迹而异因。故有合，须问其所成；有化，须问其所守；有观，须明其所取。理不离其境，证不越其域。

## 〇、问题与结论

v5.0 已能在有限类型化集合的**关联谱系**中构造余跨度（沿界之合）、跨度（前后之续）与方向性比较映射 χ。v6.0 不再试图把所有物理、概率与因果关系“编码成 χ”便声称完整，而是为每一种解释建立明确的**受理域、组合律、保真查询、失败见证**。

**本阶段答案：六类解释可以逐一接入一套共享的类型化组合语言；但它们不是在不附加条件下互相等价的六套表达。** 我们实现并测试了若干严格的局部桥梁：确定性函数的 Dirac 随机化，随机核的顺序组合，化学计量到连续时间向量场，有限 Markov 强可聚合，观测等价但因果干预不等价，以及结构谱系的权重覆盖阻碍。它们构成一个**可核验的语义网络原型**，还不是跨所有语义的高阶双函子定理。

## 一、最小性的新标准：不添本原，明确解释

「文」「合」「化」仍是研究的组织核心：文是有类型、可辨的配置与相接可能；合是在相容界面上的组合；化是配置、关系或关联历史的变化。「则」和「观」**不是需要与文并列的宇宙实体**：则表现为约束、等价与证明义务；观表现为对某一模型的解释、观察映射与查询。

然而，同一连线的意义可能完全不同：信号可以复制，电荷需要满足守恒，物理位置要求长度和单位，概率核要求归一化，因果机制要求干预结构，法律许可需要由制度来源建立。若全部解释都压入一种无类型的“关系”，理论就不再忠实。

因此更简洁的架构不是削减语义，而是**把重复的组合骨架留在共同层；把不可互推的物理、概率、因果与规范义务清楚地放在解释层。**

## 二、七个逐次建立的连接

### 连接甲：类型化文法 → 确定性行为

对一条类型匹配的过程链 \(f:A\to B\)、\(g:B\to C\)，用有限函数解释。要求 \(\llbracket g\circ f\rrbracket = \llbracket g\rrbracket\circ\llbracket f\rrbracket\)。这是函数组合的严格语义，能表达有限状态的软件过程。v6 代码强制生成元签名一致，不允许以字符串相似代替类型匹配。该实现暂只处理单输入、单输出链，不代表任意开放超图。

### 连接乙：确定性行为 → 概率过程

每个有限函数 \(f:A\to B\) 可变成 Dirac 随机核 \(\delta_f(b\mid a)=1\) 当且仅当 \(b=f(a)\)。于是有严格等式

\[
\delta_{g\circ f}=\delta_g\circ\delta_f,
\qquad (L\circ K)(c\mid a)=\sum_b K(b\mid a)L(c\mid b).
\]

这是一条真实的结构保持桥。一般随机核不能直接“逆译”为确定性函数；如果需要确定化，通常要引入额外噪声变量以及相应假设。概率系统的并行张量还需说明是否假设独立；不能把任意共享噪声过程误当成独立张量。

v6 用精确有理数计算 `flip` 后接 `noise`：输入 0 最终得到 1 的概率为 \(3/4\)。这只是有限离散核的可执行例子，不自动是因果或连续时间语义。

### 连接丙：资源流 → 连续动力学

给定物种向量 \(x\) 与化学计量矩阵 \(S\)，每个反应是一个有符号向量 \(S_{\cdot r}\)。若对某种物质不变量 \(w\) 有 \(w^\top S=0\)，任意速率向量 \(v(x)\) 诱导的封闭系统

\[
\dot x=S\,v(x)
\]

都满足 \(\frac{d}{dt}(w^\top x)=w^\top Sv(x)=0\)。这是一条**结构性守恒推论**，不依赖选用特定的非负速率函数；但若有外部输入输出，须加入 \(B u\) 并计算 \(w^\top Bu\)，不能谎称总量不变。

我们的具体例子：\(2H_2+O_2\to2H_2O\)，氢原子与氧原子分别守恒；另一例是 \(A\to B\to C\)，两反应速率 \(r_1=x_A/4\)、\(r_2=x_B/3\)，在 \((A,B,C)=(8,6,1)\) 时导数为 \((-2,0,2)\)，总导数为零。这里只实现向量场求值，没有声称完成 ODE 数值积分或所有物理单位检查。

### 连接丁：拓扑连接 → 空间与度量

无权连接只说明**可达**。把非负长度与统一单位赋给边后，才能建立 \((\min,+)\) 路径语义。对两张仅沿一个中间端点顺向连接的有向图，在没有其它跨界捷径的严格设定下，最短距离为 \(d_{A\circ B}=d_A+d_B\)（只要两边都可达）。v6 的单接口图例为 3 米 + 4 米 = 7 米。

这种距离语义不能替代几何嵌入、曲率、碰撞检测或物理可行性；网络可以结构合法但违反空间安全要求。接口上若一侧单位为米、一侧为千米，程序拒绝隐式拼接。

### 连接戊：概率观察 → 因果机制

**这条桥并非可逆。** 我们构造两个二元结构因果模型：

- \(X\sim\mathrm{Bernoulli}(1/2)\)，\(Y:=X\)；
- \(Y\sim\mathrm{Bernoulli}(1/2)\)，\(X:=Y\)。

两者对 \((X,Y)\) 的观测联合分布完全一致：只在 (0,0) 和 (1,1) 上各占 1/2。但是

\[
P(Y=1\mid \mathrm{do}(X=1))
=1\quad\text{与}\quad\tfrac12
\]

分别成立。因果方向、外生机制和干预语义并不由结构连线或观测分布唯一决定。

这也说明：把 v5 的一条谱系见证命名为“因”，不会让它自动成为真实因果。只有声明机制和干预规则，并通过识别假设或实验验证，才有相应因果主张。

### 连接己：微观动力学 → 宏观观守

对有限马尔可夫链 \(K\) 和划分映射 \(\alpha:X\to\bar X\)，若同一宏观类内任意两微观状态到所有宏观类的总概率相同，即

\[
\forall x,x':\alpha(x)=\alpha(x'),\quad
\forall\bar y,\quad
\sum_{y:\alpha(y)=\bar y}K(y\mid x)
=\sum_{y:\alpha(y)=\bar y}K(y\mid x'),
\]

便可定义宏观核 \(\bar K\)，并得到严格的动力学兼容 \(\alpha_*\circ K=\bar K\circ\alpha_*\)（等式在由点分布延拓到分布的意义下成立）。这是**强可聚合性**。

v6 提供成功例和失败例，另加界面形状检查：即使转移概率可聚合，温度通道与湿度通道若被粗粒化成同一宏观端口，其接口意义也不能不经说明就声称保留。更高要求的**因果抽象**还必须检查允许的干预查询是否交换，而不只是观测动力学闭合。

### 连接庚：合化弱交换 → 带权历史的语义障碍

v5 的比较 \(\chi:W_{\mathrm{loc}}\to W_{\mathrm{glob}}\) 不必是双射。为全局见证集合定义非负权重 \(\mu\)。若 \(\chi\) 不是满射，则可能有一个未被局部见证覆盖的 \(w\in W_{\mathrm{glob}}\)。对它赋正权重时，任何局部权重沿 \(\chi\) 的推前都不可能恢复这部分全局权重。

严格地说，对任何 \(W_{\mathrm{loc}}\to W_{\mathrm{glob}}\) 的映射，推前测度仅能支持在 \(\mathrm{im}(\chi)\) 上。因此：

\[
\mu\bigl(W_{\mathrm{glob}}\setminus\mathrm{im}(\chi)\bigr)>0
\quad\Longrightarrow\quad
\nexists\nu\ \text{使}\ \chi_*\nu=\mu.
\]

这给出一条**结构层到概率／权重层的真实障碍**，但权重本身只是形式权重；若要称为物理流量、真实出现概率或因果贡献，必须另外证明其语义来源。v6 的反例中，全局有一条局部不可表达的历史，赋权 1 时“未覆盖权重”确为 1。

### 进一步：从二步比较到任意有限时间链

本轮还把 v5 的二阶段比较 \(\chi\) 延伸为单条共享接缝下任意有限阶段的 \(\chi_n\)。每条局部的完整见证序列分别映入每个时刻的水平组合，再由推积唯一性得到整体比较。此构造在标准结合同构下与二步比较的逐次拼接一致；三阶段的软件检查已经通过。它为高阶相干性提供一个可证明的**时间向切片**，但不覆盖一般横向多重接缝、并发重写与所有双范畴自然性公理。

## 三、连接不是把不同语义同一化

| 层次 | 可以检查 | 不能自动推出 |
|---|---|---|
| 结构 | 端口类型、推积、拉回、比较 χ | 能量守恒、时间演化或真实身份 |
| 确定行为 | 有限函数与顺序组合 | 概率、意图、因果 |
| 概率 | 核正规化、组合、可聚合性 | 观测到干预的可识别性 |
| 资源 | 化学计量、线性不变量 | 反应速率、可达性、效用 |
| 连续流 | 向量场与守恒导数 | 解存在唯一、稳定性、离散无误差 |
| 空间度量 | 图上最短路径与单位 | 真实几何、碰撞安全 |
| 因果 | 结构机制、do 分布 | 由观察单独推断的真实因果方向 |
| 抽象 | 指定查询的交换或近似 | 无条件保留一切信息 |
| 规范 | 明确规则下的允许与禁止 | 善、正当性、普遍价值共识 |

## 四、最重要的理论转折

**完整性不是让所有解释变成同一个概念，而是让每一条解释关系都有可陈述的条件、可检验的结果与可观察的失败。**

这样「文」可以不等同于任何具体物质；「合」不等同于物理粘合；「化」不等同于单一时间函数；「观」也不是无损真理映射。这套语言仍然简洁，却允许不同领域的事实与规律有其应有的位置。

### 研究结论强度

1. **数学上严格且有一般证明思路**：有限函数的 Dirac 嵌入保持组合；\(w^\top S=0\) 推出封闭反应 ODE 的线性守恒；有限强可聚合条件刻画宏观核的良定义；非满射比较可产生无法沿其推前恢复的见证质量。这些都依赖所列条件。
2. **软件有限实例证据**：本轮新增的 50 项自动测试与 v5 的 137 项回归共 187 项通过。它们是实现层回归测试，而不是一般定理的机械化形式证明。
3. **仍为研究提案**：存在一个覆盖这些语义的统一变界双范畴、全体语义解释的双函子结构，以及自动选取合适的宏观查询和实证语义。此稿没有把它们写成已完成定理。
