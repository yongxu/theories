# 严格审查：v3.0 的真正进展与危险边界

**审查原则：先寻找能破坏美观概念的最小反例，再讨论其是否普适。**

## 审查 1：是否又把「文」变成了物？

目前的有限程序仍以节点、超边和端口为数据结构。它是**一种表达模型**，不是宇宙终极构成的证明。若把程序节点直接当作物理原子，则重新陷入实体预设。修正：把节点看作该模型中可辨的单位，并允许它在细尺度由更复杂的图式展开。

## 审查 2：新增「续」是不是第四种宇宙本原？

不是。`InterfaceTrace` 是对特定改变的见证数据，它告诉我们哪些外露身份被保留。没有这份数据，无法判定新旧端口是否确为同一个身份。语法基础仍可保持「文、合、化」，但**隐藏证据不能凭文字省掉**。

## 审查 3：将「界变」称为高阶统一是否过度？

若声称 v3.0 已实现任意界面变化的完整 double category，便是过度。当前有一个限制很强却确实有效的结果：**外侧端口可变，共用接缝须整体持续，并有同一配对见证**。对改变共用接缝的情形暂时拒绝，留待显式适配器、垂直边界态射及其相容方格。

相关研究已有 Cicala 的开放网络重写与 Spivak 的动态接口理论；本项目目前是将其启发转成一个有限可运行的中间架构，**不是上述成熟理论的等价实现**。

## 审查 4：接口和状态的区分是否严格？

`EvolvingChange` 是拓扑/接口的有限结构见证，不含真实时间；`ModeMachine` 是状态依赖的有限概率时序语义，不含空间几何。若说两者直接组成一个统一的数学范畴，目前没有给出对应完整的函子或自然变换，不能宣称已经证明。

下一步要给 mode 状态到 graph/interface 的赋值，以及状态转移与网络重写之间的自然性条件；必要时使用依赖和（dependent sum）或索引化范畴。

## 审查 5：同型接口是否意味着语义可替换？

不意味着。两个端口可都叫 `N`，但一个是电压输入、一个是物质量输入；如果签名未把量纲、方向、采样率和权限编码为类型，就可以通过错误连接。**类型签名本身有表达责任。** 只检查有限的字符串类型，不能取代物理或协议合约。

**最小反例**：两个端口都标记 `Signal`，一边以摄氏度解释，另一边以开尔文解释。类型相容但数值语义不保真。应引入单位类型或明示适配过程。

## 审查 6：结构改变见证能证明行为保持吗？

不能。移除一个连接的 monic span 可能完全合法，但改变了网络的可达路径。v2.0 已展示该反例。v3.0 继续坚持两级语义：先证明变化合法，若声称保留可达性、概率、资源或因果，必须为对应解释另给命题与见证。

## 审查 7：粗粒化的最大危险是什么？

把**观测不到**误认为**不重要**。一个隐藏的接口差异可能导致宏观状态无法决定未来可行动作；一个隐藏的微状态差异可能导致不同的宏观迁移概率。v3.0 分别检查这两类失败。

**最小反例 A**：两个微状态有不同端口，但被映射到同一宏观状态；严格接口解释失败。  
**最小反例 B**：两个微状态端口相同，但一个通向吸收态、另一个不会；强可聚合性失败。  
**最小反例 C**：宏观状态预测正确，但微观 `do()` 操作没有合法的宏观映射；不能宣称因果保真。

## 审查 8：连续守恒是不是普适定理？

不是。代码中内部弧的速率在两端以符号相反方式计入，故求和抵消，这是**具体形式语义**的代数恒等式。若存在化学反应净生产、能量交换、跨单位量纲、未建模的损失，需加源项或重新指定守恒量。现实实验不能由式子取代。

## 审查 9：概率张量是否总意味着独立？

否。代码里的 `tensor` 实现独立核的乘积；相关噪声、共享环境或共同原因不属于这一解释。把并排画在图上的两件事默认独立，会丢失因果与统计信息。

## 审查 10：追求「一操作」是否真的最简？

即便把合、化都编码成某一种高维重写，若要恢复可读的边界配对、持续身份、时间模型和统计查询，隐含结构可能比双操作还复杂。**极小词面不等于极小理论复杂度。** 必须基于典型任务的表示长度、证明开销、拒绝错误的能力及人类理解成本对比。

## 审查 11：程序测试及论文声明的边界

本次新增 finite Python 片段与旧版合计 94 项测试通过。含一项两层改变的水平/垂直接续等价实例、一个重排接缝、一个撤露—新显身份不连续案例。但尚无完整 Lean/Rocq 数学证明、没有独立代码审计、没有第三方同行评审。对一般高阶结构的相关定理必须归属其原作者。

## 审查 12：对社会系统的最后一道防线

「相合」「相通」「常守」描述关系与可保持的条件，不是伦理上对服从、统一或协调的指令。只有把人类的自由、不同生活方式、退出权、损害边界、合法性和福利明确纳入规范层，社会类推才负责任。合不等于善，稳定不等于正当；这不是文法缺陷，而是防止越界推论的必要区分。

## 结论：最该留下的反例

这一版最有解释价值的反例是：**两个微观状态可以拥有完全相同的宏观标签和宏观转移统计，却因暴露不同接口而不能在严格接口意义下合并。** 它将「观察」从一句哲学口号，变成了一项有明确失败条件的数学检验。
