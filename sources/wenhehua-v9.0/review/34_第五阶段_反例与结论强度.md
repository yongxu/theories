# 审查 G：我们解决了什么，哪些说法仍然不成立

## G1. 核心进展的正确强度

| 主张 | v5.0 证据 | 不能推出什么 |
|---|---|---|
| 关联见证可表示一对多、多对一 | `TMap` 允许非单射；构造支持 | 物理复制、个人同一或因果合并 |
| 见证可以按时间接续 | 有限拉回构造；跨度结合律的三元组证明 | 任意现实的时间理论 |
| 局部与整体间有方向性比较 | E.3 构造与 `interchanger` | 无条件同构 / 强交换 |
| 强交换有可检验的有限判据 | 比较映射是否双射 | 一般高阶 coherence 定理 |
| 存在不可逆反例 | 空见证到单见证的完整反例 | 任意结构不可交换 |
| 多条历史不能被布尔关系完整表达 | 两路径同端点、关系压缩例 | 每条形式路径都是实际原因 |

## G2. 七个必须保留的反例

1. **无迹非无事**：没有 witness 不代表现实里没有连接，仅意味着当前模型没有声明相应见证。
2. **同端不同历**：两条路径即使连接相同端点，仍可携带不同来源；压缩为集合关系会丢失重数。
3. **相合非同一**：余跨度使两个节点在商空间被识别，不证明有单一持久实体。
4. **关联非因果**：$\chi$ 中出现跨域拼接路径，不证明存在实际能量、物质或信息传递。
5. **弱交换非强交换**：$\chi$ 存在不代表可逆；反例为 $0\to1$ 的非满射。
6. **谱系非守恒**：保留更多见证 token 不代表能量、资金或权限不增减，仍需资源语义。
7. **局部合法非全局正当**：数学上可构造的连接，不自动说明社会规范或技术安全。

## G3. 与 v4 的实质差别

v4：因双态的单态要求可能发生冲突，采取拒绝或 `forget_conflicts` 的信息弱化路径；临时融合分裂的反例表明这一策略无法任意交换。

v5：不再试图把非单态的**关联见证**伪装成单态的**持续身份**；可以保留不同来源路径，并显式给出非可逆比较。当需要真正身份持续时，应再加上 monicity、稳定追踪或领域身份公理。

这并没有推翻 v4；v4 是一种更强的「身份持续证明」子语言，v5 则新增更弱的「关联谱系」语义。两者并列而有明确边界。

## G4. 对已有数学的归属

我们不宣称首创 span、cospan、lax interchange、DPO/SqPO、structured cospans、polynomial trees 或双范畴相关定理。这些概念和结果已有完整研究历史。

本项目的贡献是：以中文「文、合、化」组织其概念联系，提出变界关联见证的受限形式规格，给出可运行的比较映射与精确反例，并把「可成—可比—可同」作为文法的显式判断层次。

**不是**受过独立同行审稿的统一理论，**不是** Lean/Rocq 形式化证明，也**不是**通用实时软件的实现。

## G5. 最关键的尚未完成部分

最重要的开放问题不再是「所有变界过程有没有硬性同构」。更正确的问题是：

- 对选定的动态接口语义，是否能构造一致的 **lax double category**，并证明单位、结合、交换比较间的 coherence？
- 何种约束可把有方向的比较提升为可逆同构？这些约束能否模块化验证？
- 什么语义函子将这种形式谱系解释为过程、资源、时间、概率或因果，同时恰当地保存比较？
- 若外部端口的角色、类型或权限变化，应使用什么显式的适配过程，使每个语义承诺都可审计？

以上至少是 v6.0 要求的独立证明义务。
