# 第六阶段严格审查：语义桥不得越界

**审查立场：尽力寻找理论中的隐含偷换，而非为任何版本辩护。**

## 1. 逐项失效压力测试

| 可疑跳跃 | 最小反例／拒绝条件 | 本阶段采取的处理 |
|---|---|---|
| 共同接口等于行为兼容 | 两个生成元看似都叫 `Bit`，却并未提供函数解释 | 需要每个生成元的显式解释；缺失则拒绝 |
| 任意随机过程可以当函数 | 单个输入有两项正概率输出 | Dirac 嵌入只单向有效 |

| 无权连线可以推出长度 | 两条可达路径拥有不同边长 | 必须给出长度与单位，采用单独度量语义 |
| 连接可无代价复制任何资源 | 一份物质量被接到两个消耗口 | 消耗、复制和守恒需要单独生成元／证书 |
| 内部反应守恒意味着开放系统守恒 | 存在外界输入 `source→A` | `wᵀB u` 必须计入边界平衡 |

## 2. 三种「连接」不可合并

**语法连接**要求端口类型、方向与关联合法；**语义连接**要求解释映射在其受理域中保持相关组合操作；**经验连接**要求模型假设与测量现实相符。三者可以分别成立或失败。

例如，`source` 反应在语法上合法，但对封闭质量守恒公式给出非零残差。一个随机核可以合法且归一化，但没有经过数据校准。因果模型可以正确计算内部干预概率，却并不说明真实人群遵循该结构方程。

## 3. 「同异」与「观守」必须被索引化

称两个描述「同」，至少需要指定：

- 关注哪些端口，哪些结构身份与上下文；
- 考虑哪些可观察查询，如路径、质量、概率、资源流、干预或规范许可；
- 是否要求严格相等、同构、近似有误差界、还是只有单向模拟；
- 哪些外部环境和初始条件被量化。

不存在脱离这些条件的一般「意义相同」测试。我们应当研究**依查询而定的同异，而非取消同异**。

## 4. 对数学归属的明确限制

开系统双范畴、structured/decorated cospans、span-of-cospans、DPO、Markov categories、开放反应网和因果抽象都已经由前人深入研究。这个项目目前的独特工作是构造一个连贯的中文概念与工程规格，把有限例子、证明义务与反例整合起来。我们尚未提出一个有同行评审的全新普适高阶范畴定理。

## 5. 下一阶段真正需要的外部评审

1. 专门的高阶范畴数学家检查 v5 的 χ 自然性、所有 pasting diagrams 与可能形成的双范畴结构。
2. 动力系统研究者检查变量合并、边界流量与正则性假设。
3. 因果推断研究者检查干预映射和跨尺度查询族。
4. 程序语言／形式方法研究者检查类型系统 soundness 和可执行解释的完整性。
5. 古典汉语专家检查「文」「化」「势」「则」的语义来源与新造义区分。

在这些任务完成之前，**将本阶段称为可复现的研究性语义连接体系，而非普适现实理论的最终证明**。
