# 高阶统一专项批判审查

## 最重要的纠错

**误写 1：「化就是纵向 1-胞」。** 在结构化余跨度双范畴中，纵向 1-胞常是接口映射，变化应明确表示为二维方格或重写见证；连续两次变化沿纵向合成。这不是同一件事。

**误写 2：「既然两者都能粘合，所以合化只有一种数学运算」。** 推积与拉回具有不同的泛性质。可以在更高层次用一个“有类型的粘合方案”统一语法，不可以直接认定二者相等。

**误写 3：「双范畴能证明一切变界变化满足强交换」。** 强交换的定理依赖具体 topos/单态/相容条件。扩大到非单态、见证损失或整体共界切换，典范比较可能不可逆。

**误写 4：「polygraph 直接就是双范畴」。** 普通 polygraph 提供 globular 维度的生成呈示；double computad 保留两类一维方向与四侧边界，需要明确转换或专门构造。

**误写 5：「double computad 已经给出真正唯一最小的宇宙文法」。** Fairbanks–Shulman 的成果给出一类高阶范畴结构的等价表达，不涉及物理现实的完整本体论或信息论最小性。

**误写 6：「BC 同构就是我们以前的 χ」。** 两者都描述某种先后次序的可比较性，但涉及不同函子与相容方格，需要逐项建立联系。

## 应当优先寻找的三种反例

1. **接口重复识别**：同一个外部名字对应两个实际上不同的资源或身份。在粘合过程中错误归并可以凭空产生历史。
2. **局部稳定而整体增能**：各子系统状态变化不产生新的局部路径，但短暂共界使全局历史增加。当前 2→4 例已说明此点。
3. **结构交换而语义不守**：选择一个严格相容的二维拼接，却在物理语义下违反资源或概率限制。结构相容不自动包含这些法律。

## 需外部数学审查的真正问题

- 对指定 v7 核心定义，准确是 pseudo double category、doubly weak double category、intercategory、bicategory 还是它们之间的某个函子？
- 何种生成子与相干子能使 v7 的有限比较 $\chi$ 有普适构造？是否有一个自然性失败的最小反例？
- double-computad 的自由构造与实际 `MonicSp(Csp(T))` 之间是否存在足够忠实的解释？在何种域存在？
- 当我们沿边界主动改变规则、身份和因果机制时，是否还存在适当的可表性？
- 能否在 proof assistant 中形式化 BC、2×2 interchange、Eckmann–Hilton 与指定小模型的 $\chi$？

## 正式结论强度

**外部已证明**：structured cospan 相关双范畴、若干 spans-of-cospans 可逆交换结果、double computad 与 doubly weak double category 的数学基础、Beck–Chevalley 的相应基变换定理、polygraphic coherence 理论。

**本稿推导**：双向生成签名的候选、与「文·合·化」的概念对齐；有限 Set 中的 BC 元素证明与 2→4 历史比较构造。

**程序实证**：13 项新的有限检查，及与 v7 旧测试的回归结果（最终数字以日志为准）。

**未完成**：一般 double-computad 到 v5–v7 跨语义重写体系的函子性、三维比较胞完整自然性、所有相干公理与普适最小性的证明。
