# 文理生生 · 关系网络与系统演化

独立静态网站。可阅读、检索和展开冻结研究中的字、义项、构式、卦象、原文、规则与系统实例。本地运行不需要账号、后端或构建依赖；托管网站保留所有者私有访问，需要以所有者身份登录。

首页从整个研究的概念地图进入。先选择结构、变化、环境、调节等部分，查看它与其他部分的联系，再展开具体字义、八字关系或系统实例。八字是整体中的一条主线。分合模型保留为独立实例，首页不再默认播放模型；旧版带情境与步骤的首页分享链接会定位到原实例。

首页的整体/局部层级、选中概念或关系可以分享，并在返回时恢复。图中的观察、规范与表征入口分别解释其角色；不把所有连线当作世界中的因果作用。

v2.0 重做默认阅读方式：十二组核心表达各有语义图，图中的连线直接写出关系动词；含义、条件和就近原文共同解释这幅图。相生的两种原典语境分别呈现，不混用概念互定与五官支持。字、具体义项、卦象和原典各按阅读需要展开，完整资料网络作为进一步探索的入口。研究内容仍以冻结 v0.4 为依据，界面升级没有扩大理论证明的范围。

v1.2 的索引筛选、繁简搜索、模型手动分支、实际轨迹回溯与分享状态恢复继续保留。v2.0 浏览器复核见 `test/redesign-review-v2.0.json`；历史记录见 `test/round-review-v1.2.json`。已检查窄屏关系图、原文往返、完整网络返回、繁简原文搜索，以及分享后阅读路径与模型步骤恢复。

v2.1 新增“字与字的关系”图：从首页四域的25字出发，按已有义项规则、组合成分、具体表达和跨表达接口展开。可逐字加邻接，也可进入全部144个已登记字。首页“行”尚无独立字义登记，另作明确标注。连线索引共同参与的依据，不把多元规则变成字形之间的两两因果；同来源、同类型、同卦归类不用于造线。无他字邻接的条目仍可访问。

本轮也修复义项页缺少已登记关系入口、部分繁简原文召回、无记忆水箱误用双阈值介绍和图示、搜索结果点击及范围切换丢失选中字的问题。最新实际浏览器复核见 `test/word-network-review-v2.1.json`；分享链接保留所选字、关系依据、展开字和缩放比例。

v2.2 再次复核：全部字模式增加“聚焦当前关联”，可在手机同屏阅读局部关系，较多邻字分组显示。选中多字记录时，以完整构式框或共同参与节点呈现；共享字保留一个位置，原来的两两投影不再加亮为完整图。侧栏、键盘搜索、返回地图和画布滚动位置恢复已修复。八卦程序切换后显示对应公式与已声明时长；单向作用反例与双向反馈分别说明。实际浏览器记录见 `test/round-review-v2.2.json`。

## 本地预览

在此目录运行：

```sh
python3 -m http.server 8000 --directory dist
```

浏览器打开 `http://localhost:8000`。请通过本地服务器打开；浏览器直接打开 `index.html` 会阻止资料读取。部署时上传 `dist/` 的全部内容。

## 编辑与重新编译

- `dist/index.html`、`dist/styles.css`：界面与样式。
- `dist/app.js`：统一导航、阅读窗、搜索、索引、分享与位置恢复。
- `dist/home.js`：整体概念地图、八字主线及同页关系阅读。
- `dist/reading.js`、`dist/reading.css`：以含义、语义关系和原文组织的阅读页。
- `dist/editorial.js`：从冻结构式卡整理的十二组表达、十三个语境读法；原资料不被覆盖。
- `dist/atlas-v2.css`：整体地图与导航的新版布局。
- `dist/word-network.js`、`dist/word-network.css`：可扩展的字际关系图与按依据阅读。
- `dist/word-network-layout.js`：聚焦邻接和整组记录的显示几何；不生成语义关系。
- `dist/data/word-network.json`：由现有研究登记派生的字、义项和关联依据；包含覆盖边界与未登记项。
- `tools/build_word_network.py`：重建字际关系数据，保持同一份来源。
- `dist/graph.js`：关系、条件规则、过程与水箱图。
- `dist/dynamics.js`：有限转移表与双单元方程。
- `dist/foundations.js`：原有结构图、定性身份案例与解析数学展示。
- `dist/research/`：完整冻结研究副本；原始语境与字段保留。
- `tools/build_data.py`：由冻结资料生成目录、关系、完整范围、搜索与详情。
- `tools/site_foundations.json`：从研究 Markdown 明确登记的原图与数学案例。

在原工作区执行 `python3 tools/build_data.py`，默认读取外部冻结研究包。独立下载包不需要原机器目录：编译器会自动回退使用 `dist/research/`。也可明确指定：

```sh
python3 tools/build_data.py --source dist/research
python3 tools/build_word_network.py
```

原资料与生成目录分开；修改冻结副本之前应另存新版本。不要手动修改生成的 `dist/data/`，否则下一次编译会覆盖。

## 验证与范围

```sh
python3 tools/validate_site.py
```

需要 Python 3 和 Node.js，均不需要第三方包。自动检查完整登记守恒、原始字段保真、所有关系端点与方向、每个子网的必要边界、所有有限转移、失败情境、双单元方程和解析边界。结果保存为 `test/validation-report.json`。真实浏览器任务检查与人类首用测试是不同的验证，自动测试不冒充它们。

最新覆盖数与限制读取 `dist/data/integrity.json`。本版有144字、245义项、32组表达登记及1组补充、12重点构式与13微型模型、55连续语料单元。49个模型/图示记录包括37个可推进实例、3个解析展示与9个静态模型或结构示意；这些是多来源的记录及反例，不代表49套独立理论。

关系节点保留全部参与项、前提、角色、结论与依据。来源或角色关联的箭头不自动等于因果推论。大图的分组只改变显示，全部记录可以展开及以文字列表进入；自选范围、搜索范围与已登记子网均保留必要的外部条件。繁简转换只用于检索召回，不合并语义身份。

分享按钮会记录当前对象/范围、图分组与位置、模型情境/步骤、展开状态与阅读位置。输入搜索文字不会逐字增加浏览器历史。浏览器返回保留此前探索位置。
