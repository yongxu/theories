# 最小文法的相对结果

**v0.4｜2026年10月21日｜相对于 G1 的表达充分性、限定必要性与成本**

本轮得到两个实质结果。第一，G1 的 22 种命题／过程构式可归约到一个含 **13 种构式的候选核心 G0**，并在相同领域解释上保持所有命题真假和所有过程关系。第二，在明确限定的局部、前向、无闭包片段中，任何固定有限表达式都不能统一完成所有有限规模上的可达性判断；这给出一项具体的能力下界。

**这不是“13 个不可再减的原语”证明。**我们没有证明 G0 的每个构式都独立，也没有证明它是所有编码方案中成本最低的语言。所得进展是：从一个候选文法，推进到可审查的消去定理和一项有明确假设的必要性结果。这里的数字数的是语法构式，不是汉字、词义或古典概念的数目。

本报告的语义基准是 07《完整组合文法》及 10 的 `wenli.py`；研究边界回应 18《核心研究主张与完成边界审计》第七节。古文词义与现代核心的绑定仍是独立工作，本证明不以删除中文标签代替删元证明。

## 1. 固定比较对象

比较范围是 G1 的 `Formula` 与 `Program`：状态集有限且非空；多类对象域有限，允许某类为空；谓词解释和原子过程关系完整给出；定义闭合且依赖无环。对象类型、常量解释、相等标准、原子谓词真元组、原子过程边、模型上下文均固定。

我们允许改写表达式，**不允许靠增加一个已经含有答案的领域原子来缩小文法**。归约前后不改变原子词汇和解释表。规范判断、文本解释记录、候选模型等外围接口没有被转成真假命题，也没有因本次核心缩减而取消。

G0 的产生式如下；所有写在同一行的二元构式都恰有两个子式：

```text
项       t ::= 常量 | 变量

命题     φ ::= ⊤ | p(t₁,…,tₙ) | t₁=t₂ | ¬φ
             | (φ∧ψ) | ∃x:τ.φ | 〈π〉φ

过程     π ::= a | ?φ | (π;ρ) | (π∪ρ) | sync(π,ρ) | π*
```

其中 7 种命题构式、6 种过程构式，合计 13。另有 2 种项形式，不能悄悄并入或漏报。`p`、`a`、对象类和常量是可变的领域签名，可能有很多个；“一个原子应用构式”不表示“一个领域事实”。G1 的对应计数是 13 种命题构式、9 种过程构式，合计 22，包含 `fref/pref` 两类命名引用。

G0 沿用 G1 的含义：公式在状态和对象赋值下取真假，程序是同一状态集上的二元关系；`sync` 是同一前后态对上的关系交集，`star` 是包含零步的任意有限可达闭包。

## 2. 可审查的消去表

用 `N` 表示归约，表中子式均先按相同规则归约。新变量必须新鲜，不能捕获既有绑定。

| G1 构式 | G0 展开 | 成立依据／边界 |
|---|---|---|
| `false` | `¬⊤` | 不依赖任何对象类非空 |
| `φ∨ψ` | `¬(¬Nφ∧¬Nψ)` | 德摩根律 |
| `φ⇒ψ` | `¬(Nφ∧¬Nψ)` | 同状态材料条件，不是因果过程 |
| `∀x:τ.φ` | `¬∃x′:τ.¬N(φ[x′/x])` | 空域也正确：不存在反例即为真 |
| `[π]φ` | `¬〈Nπ〉¬Nφ` | 没有允许后继时仍为空真 |
| `skip` | `?⊤` | 二者都是全状态恒等关系 |
| `repeat(0,π)` | `?⊤` | 零次，不要求原过程可执行；原输入仍须合法 |
| `repeat(n,π)`，`n>0` | `Nπ` 的 n 次顺接 | 保持恰好 n 次；不是“至多 n 次” |
| 空 `and` | `⊤` | 保留 G1 约定 |
| 空 `or` | `¬⊤` | 保留 G1 约定 |
| 空 `seq` | `?⊤` | 恒等关系 |
| 空 `choice` | `?¬⊤` | 空关系 |
| 单项 `and/or/seq/choice` | 对应子式的归约，或其等值布尔展开 | 没有额外事件发生 |
| 多项 `and/seq/choice/sync` | 用对应二元构式括号化 | 合取、关系复合、并、交均结合；顺接次序不变 |
| `fref(F)`、`pref(P)` | 内联其闭合定义，然后归约 | 按依赖 DAG 展开；每次内联均独立改名 |

`sync([])` 与单项 `sync` 在 G1 本来不合法，不能给它们偷偷补一个新含义。归约器先调用原检查器，保留其拒绝结果。类型错配、变量重绑定、未绑定变量、循环定义、额外字段、非法重复次数，也不能因处于“不会执行的分支”就被忽略。例如 `repeat(0, missing_program)` 依旧报错。

保留 `true` 有明确作用：即使所有对象类为空、没有常量和谓词，也能表达空合取及恒等测试。这里没有用“必有某对象可与自身相等”来代替真，从而避免引入原模型没有的非空性假设。

## 3. 作用域与闭合引用

G1 的闭合定义在自己的变量环境中解释，不捕获使用处的变量。假设：

```text
AllLive := ∀x:Item. Live(x)
查询    := ∃x:Item. (Live(x) ∧ AllLive)
```

定义里的 `x` 与外部 `x` 各自绑定。朴素字符串粘贴会制造重绑定，甚至在别的实现中误把独立量词改成同一对象条件。正确归约是：

```text
∃u:Item. (Live(u) ∧ ¬∃v:Item.¬Live(v))
```

实现对**每一个量词**分配全局新鲜的名字，包括重复内联的定义；普通子式继承当前改名环境，进入 `fref/pref` 的定义体则重新从空词法环境开始。输入变量即使本来叫 `__g0v0` 也会被一致改名，不会和生成名相撞。常量与变量是不同项形式，不能靠同名合并。

量词可绑定内部过程测试中的对象，且过程执行不改变这个逻辑赋值：

```text
∃x:Item.〈?Live(x); a〉Live(x)
```

归约保留的是同一个 `x` 在前后态都满足条件，不是“前态有一个活着对象，后态另有一个”。这项对应进入下述相互归纳的赋值条件。

## 4. 相对表达充分性定理与证明

**定理。**给定上述任一合法 G1 有限模型 M 及合法闭合表达式 e，存在一个有限 G0 表达式 `N(e)`。移除已被内联的定义表，得到原子解释完全相同的 M₀，则：

```text
对每个状态 s： M,s ⊨ φ  当且仅当  M₀,s ⊨ N(φ)
对每个程序 π： ⟦π⟧M = ⟦N(π)⟧M₀
```

归约还保持类型与闭合性。因此 G0 足以表达 G1 的全部命题和过程。反方向立即成立，因为 G0 的每个产生式都是 G1 允许的产生式；故二者在这个固定解释合同上具有相同表达力。

**第一步：消除命名依赖。**定义依赖是有限 DAG，先按拓扑次序处理被引用定义，再处理引用者。定义体有限，依赖无环，所以反复内联终止。每个定义闭合；独立改名后，它的量词仍只绑定原来绑定的出现位置。G1 引用求值本来使用空变量环境，因此在使用处内联一个已改名的闭合体，保持该处的真假或关系。这个归纳同时涵盖“命题引用过程、过程测试命题”的跨类型依赖。

**第二步：项与改名。**令 r 将原绑定变量映到新鲜变量，并令新旧赋值在这些对应变量上指向同一类的同一个对象。常量解释不变，变量查表的对象也不变，所以对应项取值相同、类型相同。相同参数元组对原子谓词的成员资格和同型相等判断随之保持。

**第三步：对公式与程序作相互结构归纳。**归纳命题同时包含任意相容对象赋值下的公式等值，以及程序关系相等；这比只证明闭合根式更强，能处理量词内部的过程测试。

1. **真、原子、等同。**由定义和第二步成立。`false` 展开为真之否定，不需要对象存在。
2. **布尔构式。**假定子式等值，否定和二元合取保持真值。析取和条件采用表中的逐真值等式。多元合取／析取的空表和单项情形分别按 G1 的单位元处理。
3. **存在量化。**两式遍历完全相同的域；对每个对象 d，把新旧对应变量赋成 d，归纳假设保证主体等值，所以存在见证相同。全称由“没有反例”等值消去；空域时存在为假，外层否定为真。
4. **原子过程与测试。**原子关系未改。测试只可能保留 `(s,s)`；由公式归纳假设，保留与否完全相同。因此 `?⊤` 是恒等关系，`?¬⊤` 是空关系。
5. **顺接、选择和交集。**若子关系逐对相同，则存在相同中间态的复合关系、边集并集、边集交集分别相同。关系复合的结合律允许重新括号化：两边都要求按原次序存在相同的中间态序列，不能交换过程顺序。多元情形以结合律归于二元情形。
6. **有限重复。**对 n 再作归纳。零次为恒等关系；n+1 次为一步关系与 n 次关系的复合。故归约恰好 n 次关系相等，即便没有该长度路径或过程含自环仍成立。
7. **闭包。**子过程关系相同，所以其每个非负整数次幂相同，这些次幂的并集也相同。这里保留 `star`，没有偷用一个固定重复次数代替任意有限次数。
8. **模态。**由程序归纳假设，两式从当前态得到同一终点集合；由公式归纳假设，每个终点上后件真假相同，故存在见证相同。方括号等于不存在满足反例后件的终点，包含没有终点的空真情形。

所有相互调用都进入严格子语法树；定义依赖已在第一步单独处理，所以不存在循环论证。输出只含 G0 构式，绑定改名保持闭合性；原子签名、量词域、关系所在状态集均未变，因此类型也保持。有限状态语义保证旧求值器仍能计算该输出。

这是一项普遍的数学归纳证明。后面的有限模型比较检查的是实现是否遵守这份翻译，不用测试次数替代定理。

## 5. 一项限定的表达力下界

为了得到清楚的必要性结果，冻结一个比 G0 更窄的片段：原子词汇只有当前态零元谓词 `Goal` 和向前一步程序 `a`；允许布尔构式、测试、顺接、选择、交集、固定次数重复以及前向模态；**不允许 `star`、递归定义、全局状态访问或新增答案原子**。无环命名可以预先展开。每个重复次数是公式中的固定整数，不随模型大小改变。

需要判断的任务是 `〈a*〉Goal`：存在某个有限步数能够到达目标。注意这不是无限执行任务。

### 5.1 不能只数程序走了多少步

程序 `?〈a;a;a〉Goal` 自己位移为零，但测试看到了三步之外。因此对程序同时记最大位移上界 L 和观察半径上界 R，对公式记观察半径 R：

| 构式 | 有限上界 |
|---|---|
| `Goal, ⊤, ⊥` | `R=0` |
| 布尔组合 | 子式 R 的最大值；空表为 0 |
| `a` | `L=1, R=1` |
| `skip` | `L=0, R=0` |
| `?φ` | `L=0, R=R(φ)` |
| `π;ρ` | `L=Lπ+Lρ; R=max(Rπ,Lπ+Rρ)` |
| `choice` 或 `sync` | 分别取各分支 L 与 R 的最大值 |
| `repeat(0,π)` | `L=R=0` |
| `repeat(n,π), n>0` | `L=nLπ; R=(n−1)Lπ+Rπ` |
| `〈π〉φ` 或 `[π]φ` | `R=max(Rπ,Lπ+Rφ)` |

空 `seq` 视为 `skip`；空 `choice` 的 L、R 均为零。`sync` 用最大值是保守上界，不能把某分支的远端测试因另一分支较短就丢弃。每条固定表达式的 R 都是有限数，且由归纳有程序 `R≥L`。

### 5.2 双链不可区分论证

取两份状态、一步边完全相同的链 `s₀→s₁→…→s_N`，仅让它们的 Goal 标签可能不同。

**局部不变引理：**若两链在位置 i 起至 i+R 的范围内 Goal 标签一致，则公式在 `s_i` 的真假一致；相应程序从 `s_i` 出发的每个终点成员资格也一致。超过 `i+L` 的终点本来不属于该程序关系。

证明对公式／程序相互归纳。原子与布尔情形直接成立；测试调用公式假设。顺接的中间态最多位于 `i+Lπ`，检查第二段最多看到 `i+Lπ+Rρ`，所以表中的最大值足够。并与交保留每一对端点的成员资格。固定重复展开为有限顺接。模态后件最多从终点再看 Rφ 步，因此观察界是 `max(Rπ,Lπ+Rφ)`。空关系与方括号空真不破坏该论证。

现在假设某固定无 `star` 公式 χ 在所有有限链上表达可达性。令 `h=R(χ)`，取 `N=h+1`：正链仅在末端 `s_N` 标 Goal，负链处处不标 Goal。两起点半径 h 内完全相同，故 χ 同真同假；但 `〈a*〉Goal` 在正链为真、负链为假，矛盾。

**结论：**在该固定局部词汇和组合片段内，任意固定有限观察不能统一代替不受固定步数限制的可达性能力。这是一项能力的相对必要性，不是 `star` 这个记号在任何语言中都不可替代。递归、不动点或一个另行计算的闭包关系都可以提供替代能力，但必须计入输入合同与成本。

本证明没有声称所有一阶逻辑、所有关系代数或完整 G1 删除 `star` 后都已得到不可表达性定理。特别是，若另外把状态作为可量化对象、提供全局关系或预计算答案原子，就需重新检验假设。

### 5.3 两个有用的成本边界

若事先限定 `|S|≤B`，任意可达终点有长度至多 B−1 的简单路径，因此可用 `⋁ₖ₌₀ᴮ⁻¹〈aᵏ〉Goal` 代替本任务中的闭包。这是随模型类上界增长的展开，不是所有有限规模共用一条固定展开。

若 `repeat` 和引用已展开，表达式以**无共享语法树**保存，则可按同一归纳证明 `R(e)` 不超过树中 a 的出现次数。因此，若一条树公式要覆盖所有至多 N+1 个状态的链，至少需要 N 次 a 出现，否则长度 N 的末端标签反例仍不可区分。这个线性下界不适用于带二进制次数或共享 DAG 的紧凑文本字节数。

完整的独立下界核对见 [lower_bound_review.md](lower_bound_review.md)；脚本中的十组双链是对构造与半径计算的核验，不能代替对任意候选公式的上述证明。

## 6. 更少构式不一定意味着更低总成本

本轮没有把所有成本强行相加成一个分数。至少要分开登记以下项目：

| 成本层 | 本轮如何处理 |
|---|---|
| 构式种类 | 从 22 归约为 13；2 种项形式另列 |
| 查询树 | 记录构造节点、项出现、绑定槽；归约可能增大树 |
| 命名与共享 | 引用可以缩短表面表达；定义体本身必须计费，内联会复制共享内容 |
| 领域签名与对象 | 状态、对象类、类型化域元素、常量、谓词与过程名均保留 |
| 原子解释 | 谓词逐态表、真元组、过程边及规范表保留；没有免费答案表 |
| 编码 | 给出规范 JSON 字节数样例；构造节点数不包括整数编码成本 |
| 词义桥梁及经验取得 | 本轮没有测量，不能当作零成本 |

例如 `repeat(128,a)` 的原树有 2 个构造节点，展开后有 255 个；本实现规范 JSON 从 61 字节增至 6,249 字节。去掉 `repeat` 减少了构式种类，却失去了这里的压缩能力。定义 DAG 的展开也可能呈指数增长；本轮的充分性定理只保证存在有限展开，不保证多项式体积。

基准模型本身另有 5 个状态、3 个对象类、3 个类型化域元素、3 个常量、4 个谓词、20 张谓词逐态表、22 个真元组、3 个原子过程与 8 条边；另有 24 个定义构造节点、3 个定义项出现、4 个定义绑定槽，以及 5 个显式规范判断。去掉 G1 表层构式并没有删除这些输入知识。各计数有交叠，是成本向量，不应直接相加。

若新增 `ReachGoal` 原子并预先把可达性写进解释表，查询可以缩成一个原子；但闭包计算或数据提供的成本被移到原子层，不能据此宣布“理解只需要一个原语”。本轮归约严格不采用这种做法。

## 7. 可运行核验与实现边界

`normalizer.py` 仅用 Python 标准库，复用旧 `wenli.py` 的合法性检查与求值器；归约后的模型删除定义表，确保表达式不再暗中依赖命名定义。发布目录优先使用同版本的 `../core/wenli.py`；工作目录回退到旧 10 号解释器。旧解释器文件没有被修改。

在本目录运行：

```text
python3 normalizer.py
python3 normalizer.py --check
```

第一条重算并写 `results.json`；第二条重算，要求与保存结果完全相同，不修改结果文件。文件还保存实际依赖解释器的 SHA-256，避免静默换用另一份语义实现。

| 核验 | 结果 |
|---|---:|
| 非平凡有限模型 | 25 份，每份 5 状态；含分支、回环、死端及空对象域 |
| 原公式／归约公式 | 2,750 对，逐态共 13,750 次真假比较 |
| 原过程／归约过程 | 1,900 对，比较完整前后态关系 |
| 检出的真／假结果 | 7,433 真、6,317 假，避免全真样例掩盖错误 |
| 非空且非恒等的过程关系 | 708 项 |
| 命名边界与拒绝／资源检查 | 51 项 |
| 下界双链见证 | 10 组，候选同值而可达性一真一假 |
| 构式覆盖 | 全部 22 种源构式、全部 13 种目标构式 |

比较包括：空域全称与存在、空合取／析取／顺接／选择、单项与多项组合、无效 `sync` 拒绝、零次重复先验证输入、共同终点交集、跨类型定义 DAG、定义和外层同名绑定、变量在过程测试中的持续、已有生成名形式的输入变量、不同类型同名对象的拒绝等。除手写边界外，生成式检查使用固定随机种子，可复现；这不是对全部模型或全部表达式的穷举。

独立审阅曾发现左结合展开使合法 `repeat(600,a)`、`repeat(1000,a)` 在 Python 中出现过深调用栈。本版已改成**保序平衡二元树**，两项的完整关系核验通过。默认构造预算为 100,000 节点；极深输入、定义或输出仍受 Python 栈限制，两类限制都明确返回 `NormalizationLimit`，不伪装成语法不合法或不可表达。数学定理不受这些实现资源限制影响。

## 8. 本轮能与不能宣布什么

可以宣布：

- 在 G1 已固定的有限、多类对象、关系语义范围内，13 构式 G0 是与 G1 表达等价的较小候选核心，且有逐构式翻译、相互结构归纳和可复算实现。
- 对限定的局部前向片段，所有有限规模共用的可达性任务需要超出固定有限观察半径的能力；闭包不能被固定展开免费代替。
- 减少构式种类与压低表达、领域解释或理解成本是不同问题，具体展开会增加体积。

仍不能宣布：G0 是最小不可约基；其余每个构式分别不可删除；五元或113字已被证明不可替代；所有系统都可无损进入这个有限核心；中文标签或词义体系已因此证明具有认知、预测或迁移增益。

下一步若继续研究“最小”，应在同样固定的模型类、原子合同与任务集上，选择一个具体能力或成本比较并证明其边界。换名、删字，或把答案搬入新的领域表，都不是该证明的替代品。
