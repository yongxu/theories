# 文理生生 逐字动态映射与古文出处

**版本 v0.2　2026年10月21日　全面复核修订**

本表逐项覆盖两份原材料中明确作为概念提出的 **113 个单字**，再补入机制与句法需要的相关字。这里的「每一个文字」指这套模型的概念词表，既不指全部汉字，也不把原文件中的每个普通叙述用字都当作原语。

113 是按原稿概念表与明确提出的核心关键词固定的工作词表数量，不是古汉语的全部概念，也不是已经证明的最小基元数。按字覆盖不等于按全部义项覆盖；表内合写的多个义项，在建立证据图时仍须拆成独立义例。

本表**以字为索引，行内可并列多个已注明语境的义例**。表中选取足以支持本轮模型的主要义例，不宣称给出了全部词义史。引文编号链接到原典网页；完整短引、语境、版本与定位见[原典证据索引](05_原典证据索引与校勘说明_v0.2.md)。

**所有「动态对应」均为本项目的现代重构。**出处支持的是前一栏的原句或语境义，不直接证明相邻的公式、普遍规律或跨域应用。「项目定义」表示技术用法出自这次建模；没有据此声称该字古代不存在。

类型按作用分为：**结构**（对象与配置）、**过程**（状态转移）、**关系**（项间联系）、**条件**（可行性与限度）、**认识**（识别与检验）、**规范**（价值和行动标准）、**句法**（参与者与命题组合）、**统摄**（文本总体解释）。非过程字也可以影响 dynamics，但不应硬译成一种运动或力。

`S→S′` 表示前后态转换；`x` 是需另行定义的状态量；`K` 是允许持续的状态域；`I` 判断同一实例，`L` 另记可分支的谱系承接。它们都是现代记号。模式类型与具体实例、时窗内不可恢复与模型内不可逆的区别，以主稿第五节为准。

| 词、句、章、篇 | 现代分析中区分的表达层级 | 词义须落到句法，句子须落到篇章；机制通常由整段表达 | 原计划六级回溯框架；不为这组方法标签追认古代统一理论 |
| 意、义 | 所要表达或理解的意思；义另有伦理义 | 读者更新的是解释模型，不能仅凭字面相同认定义同 | [D1][D1]；意不作为物理动态单元 |

原对话引用《老子》二章中的「难易、长短、高下、音声、前后」，是五组不同领域的对待例项。解释整句时应分别处理难易的条件依赖、长短高下的比较参照、音声的配合、前后的次序。它们不能因为排列形式相同就被判为同一种因果动力。二章的「易」在难易中是容易，与「生生之谓易」的易须分义；「长」在长短中读 cháng，与增长之长也不同。[王弼本二章][L01]。

## 十五 复合概念的回查表

这里将原材料的组合词与整句按同一机制族归并，保留不同历史状态。复合词不能只靠单字相加取得出处。

| 组合或句族 | 组合后的作用 | 出处与性质 |
|---|---|---|
| 文理生生、求文、求理 | 连接可辨样态、机制解释与生成延续 | 项目名称和分析用语，不标作古代现成理论 |
| 生生、生生之谓易 | 生成的接续与易之关系 | [Y03][Y03]；生命个体可死而生成接续 |
| 生生不息 | 现代稿用来表达生成未停止 | 生生见 Y03；不息见 JC6b；本次不以两句拼接证明整语源流 |
| 相生、有无、有无相生 | 对待生成或依存，具体读法须论证 | [L01][L01]；不能直接转成互因网络 |
| 相克、相生相克 | 生环与胜环两种有向关系；具体字义须区分 | [F01][F01] [F02][F02] [F03][F03]；已核《春秋繁露》的相生相胜，相克作现代通称，不主张已找到该固定术语最早出处 |
| 共生、自生 | 共同生成生活、或自发生成的现代组合候选 | 共与自的义例分别 M3、L07；本次未核定这两个复合词的最早用例及技术史 |
| 养生 | 维持生活、顺结构行动、保存能力 | [Z03][Z03]；原篇实践意义保留 |
| 本末、终始 | 根本与末端、开端与完成的排序 | [C07][C07]；价值排序与因果排序分开 |
| 体用 | 构成与功能的候选区分 | 本轮分别核体的部分义与用的功能义，未证明先秦已有成熟统一体用论 |
| 阴阳、刚柔、动静、柔弱 | 对举性质、状态与作用倾向 | [Y03][Y03] [Y06][Y06] [L05][L05]；不赋统一现代物理量 |
| 虚实 | 资源或防备配置的对比 | [S4][S4]；不是有无的简单同义词 |
| 消长、兴衰 | 量、作用或活动的增减与阶段变化 | [Y07][Y07] [H1][H1]；不默认守恒或固定周期 |
| 分界、度量 | 分配边界与尺度 | [C02][C02]；不是已经完成定量建模 |
| 感应 | 作用与响应 | [JY1][JY1] [S4][S4]；机制和中介需补证 |
| 制衡 | 约束与反向调节的现代组合标签 | 相关单字有义例，复合机制仍需方向、强度、延迟与标准 |
| 和同、和而不同、和实生物同则不继 | 差异配合与同声附和之辨 | [C05][C05] [C08][C08]；不能推出同必亡、异必善 |
| 中和、时中 | 情感表达、适节与合时判断 | [C06][C06]；保留规范层 |
| 名实、同异、约定俗成 | 对象识别与命名、约定与所指 | [C01][C01]；不由名称推出自然本质 |
| 穷变、变通、穷变通久及其完整格言 | 受限后改组并寻找可持续路径 | [Y04][Y04]；现代重构保留失败支路 |
| 聚散、聚则为生散则为死 | 气聚散与生死的原典解释 | [Z01][Z01]；现代只抽取组织与解组区别 |
| 往复、反复 | 来往、回归或反转的历程 | [Y09][Y09] [JY8][JY8]；周期和身份须另定 |
| 天文、人文、道之文 | 自然样态、人事之文、文学本源论 | [Y01][Y01] [W02][W02]；不同文本的文分层 |
| 自然、道法自然、无为 | 自己如此、非外命与无为治理 | [L04][L04] [L07][L07]；不能径译为自然环境或完全不行动 |
| 齐物、方生方死 | 对待、是非与成毁视角的论说 | [Z02][Z02]；齐物不是把所有对象判成相同 |
| 天人之分、天行有常 | 自然运行与人事职分区别 | [C03][C03]；反对自动道德报应式映射 |
| 仁义礼、性 | 行动规范、制度实践、禀赋与教化之争 | [C02][C02] [C08][C08] [C09][C09] [C10][C10]；不消去各家分歧 |
| 三表 | 言论的历史、耳目与施政效果依据 | [M4][M4]；不是现代实验法的完整等价物 |
| 状变而实无别、有化而无别、存中之变 | 状态改变与对象同一可分 | 古文部分 [C01][C01]；存中之变是现代总结 |
| 生存变亡、身份延续、失稳、续存 | 在尺度、身份与持续域下判别历程 | 主稿中的现代定义，古文提供问题资源 |
| 物相杂故曰文、文者物象之本 | 爻位错杂之文与文字发生之文 | [Y02][Y02] [W01][W01]；不能跨语境无缝合成公理 |
| 反者道之动 | 道之动与反的关系 | [L05][L05]；不是直接的反馈方程 |
| 读书百遍其义自见 | 反复阅读可见义的历史说法 | [D1][D1] [D2][D2]；通行转述与原句字形有别，认知因果另验 |

## 十六 怎么使用这份表

先找字，再回到该行的原句与篇章。确认此处词义和句法之后，才选用动态对应。把对应变成模型时，至少补出参与者、变量、时间、边界、转移规则与可能失败的条件。

如果一个新例必须不断改换某字的定义才能套入，应该拆分义项或撤销映射，而不是以「一切皆相通」掩盖差异。「互、层、限、证、坏」等技术标签暂以现代定义登记，便于模型使用；它们的古代词义史仍是另一项研究。
