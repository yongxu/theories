# 文理生生 完整组合文法

**文法 G1｜版本 v0.3｜2026年10月21日**

这套文法使概念能够组成明确的判断与过程：什么存在，什么与什么有关，哪些条件允许变化，变化之后可以或必须满足什么，以及何时仍算同一个实例。它由**类型、产生式、组合语义、派生规则、推理规则和有限模型求值**共同构成。

核心区别是：**命题说明一个状态下什么成立；过程说明哪些前态能够转到哪些后态。**两者可以相互组合，但不能互相冒充。“有联系”不是一个变化过程，“可能改变”也不是已经改变。

本版的“完整”有明确范围：下文列出的每一种核心构式都有类型和语义，在声明完整的有限模型中都能计算。任意古文的自动理解、所有现实系统的普遍理论，以及一套公理对所有模型的逻辑完备性，不属于这一项完整性。古文进入核心之前，必须明确选义、作用域和所补的领域条件。

## 一 从原句到可推演的组合

一个汉字不是一个不变的函数。真正进入组合的是一个已经选定语境的义项，例如“分”的认识划分、实际拆分、资源分配，分别需要不同类型的输入与输出。

```mermaid
flowchart LR
    A[原句与出处] --> B[选择义项与句法作用域]
    B --> C[补明对象 条件 尺度与身份]
    C --> D[展开为有类型的表达式]
    D --> E{类型与声明检查}
    E -->|合法| F[命题与过程递归求值]
    E -->|不合法| G[指出错用或缺少的绑定]
    F --> H[模型内结论与反例]
    H --> I[与实际观察比较]
```

每个解释保留三项依据：原句允许怎样理解；现代模型另外假定了什么；由这些假设实际推出什么。来源编号不进入真值运算，引用某句古文不会自动把一个现代谓词置为真。

例如“和而不同”选定协调与同质的义项后，可以展开为 `协调(a,b) ∧ ¬同质(a,b)`。合取规则允许推出“两项同时成立”，却没有允许推出“差异造成协调”的规则。若要提出因果解释，需要另外给出机制和识别依据。

## 二 类型和统一的解释范围

### 模型上下文

每份模型固定一个上下文 `c`：问题、尺度、观察范围、对象分类、实例身份、一步的含义，以及边界与环境的处理方式。同一核心表达式始终在这个上下文内求值。

状态集记为有限非空集合 `S`。一个状态可以同时记录系统、环境、资源、关系及与未来有关的历史。对象域可以包括当前尚未出现或已经终止的实例标识；对象是否存在由状态中的存在谓词表达，而非由它是否在总词表里决定。

不同尺度、不同身份准则的模型不能凭同名变量混合。每份机器模型须给出`context_id`，候选模型汇总会拒绝不同标识；使用者须在模型说明中记录这个标识对应的问题、尺度、身份、步长与边界。相同标识是语义相容的声明，不是程序自动理解了现实语境。跨模型比较必须另给对象、状态和谓词的对应，并检验这种对应保留了哪些性质。单纯改名不会建立这项保证。

### 核心类型

| 类型 | 含义 | 合法用途 |
|---|---|---|
| `Term[τ]` | 某个有限对象类τ中的对象，如实体、模式、角色、位置 | 代入签名相符的谓词；同类对象比较与量化 |
| `Formula` | 在状态与变量赋值下取真或假的命题 | 否定、合取、条件、量化，以及对过程后果作判断 |
| `Program` | 同一状态集上的前后态关系 | 条件测试、顺接、择一、重复及共同转移约束 |

对象类由模型声明。例如 `Entity`、`Kind`、`Role`、`Place`可以分别有有限域，但不是必须恰有这四类。即使两类对象都写作同一个字符串，它们也不自动同型。

谓词声明写作 `p : τ₁ × … × τₙ → Formula`。例如 `E : Kind × Entity → Formula`、`part_of : Entity × Entity → Formula`。状态是求值时的隐含参数。原子过程声明为 `a : Program`，其解释是 `S × S`的一个子集。

`Formula`与`Program`之外还有三个接口：文本解释记录、观测及候选模型集、规范判断。它们有各自的使用规则，不能直接塞入逻辑合取或过程顺接。接口与核心的连接在第九节说明。

### 五元怎样进入文法

| 五元 | 在核心中的具体承担 |
|---|---|
| 辨 | 声明对象类、对象标识、谓词签名、等同标准和量化范围 |
| 系 | 应用有名称、有参数类型的关系谓词；区分它与状态转移关系 |
| 序 | 用顺接记录先后，用重复记录轮次；结构次序另用关系谓词 |
| 化 | 声明原子转移，再组合为较复杂过程 |
| 限 | 用测试筛选前后态，用持续条件约束每一步，用模态检验可能与保证 |

五元是组织这些操作的接口，不是五个万能函数。尤其，`part_of(a,b)`与一个过程的前后态边即使都称“关系”，也不能直接互换。

## 三 封闭的核心产生式

以下用数学记号书写；机器形式使用JSON语法树，字段对照见第十一节。括号决定作用域，不依赖汉字相邻关系猜测。

```text
项 t ::= 常量 k | 变量 x

命题 φ ::= ⊤ | ⊥ | p(t₁,…,tₙ) | t₁ = t₂
         | ¬φ | (φ ∧ ψ) | (φ ∨ ψ) | (φ ⇒ ψ)
         | ∀x:τ.φ | ∃x:τ.φ
         | 〈π〉φ | [π]φ | 已声明的闭合命题名

过程 π ::= 原子过程 a | skip | ?φ
         | (π ; ρ) | (π ∪ ρ) | sync(π,ρ)
         | πⁿ | π* | 已声明的闭合过程名
```

`n`是非负整数。`〈π〉φ`读作“存在一次π的允许执行，使终态满足φ”；`[π]φ`读作“π的所有允许终态都满足φ”。它们都不是“π已经发生”。

多项合取、析取、顺接和选择是相应构式的有限展开。空合取为真，空析取为假，空顺接为`skip`，空选择为空关系。`sync`至少有两个过程，表示它们的关系交集。

命名定义只允许无环依赖。定义本身必须闭合，不能偷偷捕获使用处的变量。带参数的词典宏先在文档层实例化，再将明确的结果写成核心表达式；参考实现不把任意自然语言或参数化宏直接当作程序运行。

### 变量与绑定

变量必须由外层量词绑定；每个变量的类型固定。量词只遍历所声明的有限对象域，不隐含遍历全部世界。空域中的全称命题为真、存在命题为假；不能从空域全称命题推出有实例。

参考实现拒绝量词在同一作用域内重用已经绑定的变量名，要求显式改名。量词可约束内部过程测试中的对象，例如：

`∀x:Entity. [ ?E(火,x) ; tick ] E(火,x)`

这里`x`在前后态是同一个已绑定标识。过程改变的是状态，不会把逻辑变量重新分配给另一个对象。若`tick`无后继，方括号仍可空真；要求实际能够继续时，须使用下文的非空条件。

## 四 合法组合的类型规则

用`Γ ⊢ e : T`表示“依据声明Γ，表达式e具有类型T”。Γ含模型上下文、对象类、常量、当前变量以及谓词和过程的签名。

| 规则 | 成立条件与结果 |
|---|---|
| 常量与变量 | 名称已声明且类型为τ，则可得到`Term[τ]`；未声明名称拒绝。 |
| 谓词应用 | `p:τ₁×…×τₙ→Formula`，每个参数逐位匹配且数量相同，才能形成`p(t₁,…,tₙ)`。 |
| 等同 | 两项必须同型，结果为Formula；跨类型“相等”须另建明确关系。 |
| 逻辑组合 | 非、且、或、条件的输入都必须为Formula，结果仍为Formula。 |
| 量化 | 对象类已声明，变量在主体内绑定，主体为Formula，结果为Formula。 |
| 条件测试 | `φ:Formula`才能形成`?φ:Program`。测试只筛选当前状态。 |
| 过程组合 | 顺接、选择、重复、交集的输入必须为Program，结果为Program。 |
| 模态组合 | `π:Program`和`φ:Formula`组成`〈π〉φ`或`[π]φ`，结果为Formula。 |
| 命名定义 | 定义类型与引用位置相符，闭合且依赖无环，才可展开。 |

因此，`similar(a,b) ; grow`会被拒绝：前项是命题，不是过程。合法的`?similar(a,b) ; grow`含义是“仅在相似判断成立时允许进入grow”，它并没有说明相似导致生长。

`¬grow`也会被拒绝。若问“grow不能执行”，应写`¬〈grow〉⊤`；若问“grow之后不满足P”，则需要指定`〈grow〉¬P`或`[grow]¬P`。这三者不能互换。

类型通过只保证组合有定义。把虚假的作用关系登记成一个原子过程，仍会产生有定义却不符合现实的模型；类型检查不会替使用者证明输入假设。

## 五 每个构式的精确语义

一个有限模型为：

`M = (c, S, {Dτ}, constants, V, A, definitions, norms)`。

`Dτ`是每类对象的有限域；`V(p,s)`给出谓词p在状态s的全部真元组；`A(a)`给出原子过程a的全部允许状态对。`η`给已绑定变量赋值。定义展开后，命题解释为状态集合，过程解释为状态对集合。

### 命题语义

| 构式 | 在`M,s,η`中的意义 |
|---|---|
| `⊤`、`⊥` | 分别恒真、恒假。 |
| `p(t₁,…,tₙ)` | 各项求出的对象元组属于`V(p,s)`。 |
| `t₁=t₂` | 同型两项指向同一个域元素。 |
| `¬φ` | φ为假。 |
| `φ∧ψ`、`φ∨ψ` | 分别是两项都真、至少一项真。 |
| `φ⇒ψ` | φ为假或ψ为真；是同状态的材料条件。 |
| `∀x:τ.φ` | 对`Dτ`中的每个对象d，φ在`η[x↦d]`下都真。 |
| `∃x:τ.φ` | 至少一个这样的d使φ真。 |
| `〈π〉φ` | 存在t，使`(s,t)∈⟦π⟧η`且φ在t为真。 |
| `[π]φ` | 每个满足`(s,t)∈⟦π⟧η`的t都使φ为真。 |

### 过程语义

```text
⟦a⟧η       = A(a)
⟦skip⟧η    = {(s,s) : s∈S}
⟦?φ⟧η      = {(s,s) : M,s,η满足φ}
⟦π;ρ⟧η     = {(s,u) : 存在t，(s,t)∈⟦π⟧η 且 (t,u)∈⟦ρ⟧η}
⟦π∪ρ⟧η     = ⟦π⟧η ∪ ⟦ρ⟧η
⟦sync(π,ρ)⟧η = ⟦π⟧η ∩ ⟦ρ⟧η
⟦π⁰⟧η      = ⟦skip⟧η
⟦πⁿ⁺¹⟧η    = ⟦π;πⁿ⟧η
⟦π*⟧η      = ⋃{⟦πⁿ⟧η : n≥0}
```

顺接需要实际存在相容的中间态t；把两个标签放在一起不足以满足它。选择表示允许两者之一，不表示两个过程都发生。`sync`要求同一个前态和同一个后态同时属于两种过程关系，不代表一般的物理并发。描述真实并发时，应先构造联合状态及联合转移，并处理共享资源或冲突。

`π*`包含零次和任意有限次重复，不是一条无限执行本身。测试与`skip`不推进时间，原子过程是否推进一个真实时间步必须由模型声明。把这些区别保留，才能避免由“什么都没做”的自环推出永久存续。

### 为什么能够算完

表达式是一棵有限语法树，命名依赖无环。对象量化只遍历有限域；关系顺接只搜索有限中间态；闭包最多增加`|S|²`个不同状态对，因此计算会停止。

对语法结构作归纳：原子有完整解释；每个复合构式只使用已经有定义的子式与上述有限运算，所以合法闭合命题在每个状态都有唯一真假，合法过程有唯一关系。实现因此能够决定**给定有限模型中**的命题，而不是由一次求值证明某命题在所有可能世界中成立。

## 六 可以安全使用的推理规则

下表既是手工推导规则，也是检查器递归求值的依据。其中`⇔`表示两式在同一模型、状态及变量赋值下等值。

| 规则 | 可推出的结论 |
|---|---|
| 合取拆分与合成 | 从φ∧ψ可得各项；两项分别成立可合成φ∧ψ。 |
| 条件应用 | 从φ与φ⇒ψ可得ψ；不能由ψ倒推φ。 |
| 全称实例化 | 从∀x:τ.φ可对域内同型对象实例化；不能代入域外或异型对象。 |
| 存在引入 | 一个域内对象确实满足φ，可得∃x:τ.φ；不能由全称空真引入。 |
| 模态对偶 | `[π]φ ⇔ ¬〈π〉¬φ`。 |
| 顺接展开 | `〈π;ρ〉φ ⇔ 〈π〉〈ρ〉φ`。 |
| 选择展开 | `〈π∪ρ〉φ ⇔ 〈π〉φ ∨ 〈ρ〉φ`；方括号对应合取。 |
| 测试展开 | `〈?φ〉ψ ⇔ φ∧ψ`；`[?φ]ψ ⇔ φ⇒ψ`。 |
| 重复展开 | `〈π⁰〉φ ⇔ φ`；`〈πⁿ⁺¹〉φ ⇔ 〈π〉〈πⁿ〉φ`。 |
| 有限闭包展开 | `〈π*〉φ ⇔ φ ∨ 〈π〉〈π*〉φ`，取有限可达闭包。 |
| 不变式 | 若每个可达状态中`K⇒[π]K`成立，且起点满足K，则所有π的有限重复终态满足K。 |

不变式规则有“每个可达状态”的前提，不能只检查起点的一步。上表列出可靠的常用规则，不宣称它是对所有模型有效性的完整公理化；本版的决定程序是对指定有限模型进行语义求值。

以下推论均不成立：

- `φ⇒ψ`不能推出φ导致ψ，也不能生成一个从φ到ψ的过程。
- `〈π〉φ`不能推出`[π]φ`；存在成功路径不表示所有选择都成功。
- `〈π〉φ ∧ 〈π〉ψ`不能推出`〈π〉(φ∧ψ)`，两个见证后态可能不同。
- `〈π〉φ ∧ 〈ρ〉φ`不能推出`〈sync(π,ρ)〉φ`，两关系可能没有共同的后态。
- `[π]K`不能推出π可执行；没有后继时它也为真。
- 从古文引用、相似关系、观察不到或某规范要求，均没有直接推出世界事实的规则。

## 七 生存变亡与调节的派生文法

### 非空可行与受限过程

```text
Enabled(π)       := 〈π〉⊤
Must(π,φ)        := 〈π〉⊤ ∧ [π]φ
Guard(P,π,Q)     := ?P ; π ; ?Q
Safe(π,K)        := ?K ; π ; ?K
If(P,π,ρ)        := (?P ; π) ∪ (?¬P ; ρ)
Plus(π)          := π ; π*
```

这些是可以完全展开的宏，没有增加新的无定义原语。`Guard`与`Safe`只保留满足条件的边；筛掉危险边不代表现实中的危险已经被控制。若π含环境的不确定结果，不能先过滤坏结果，再声称所有实际结果都安全。

### 实例与模式

在固定身份准则下，为每个实例分配稳定标识i，`E(P,i)`说明它当前是否满足模式P。前后用同一个标识，表示已经依据所选准则完成身份对应；词法上同名不能替代这项判断。分裂后的B、C使用不同标识，谱系`L(A,B)`、`L(A,C)`另存为关系，不把B与C当作同一实例。

本版优先用稳定实例ID与同型`eq`表达严格同一。自定义描述谓词即使取名I，也不会自动获得身份性质。若另输入跨截面的匹配表，须检验端点存在、每对前后截面中的匹配为部分一对一，以及沿可行历程复合后的身份一致性；未验证时只称身份匹配候选，不用于严格同一的生灭推断，也不自动改判为谱系L。

以相邻事件的真实转移`a`为基：

```text
KindExists(P)       := ∃i:Entity. E(P,i)
AppearKind(P,a)     := ?¬KindExists(P) ; a ; ?KindExists(P)
EndKind(P,a)        := ?KindExists(P) ; a ; ?¬KindExists(P)
BornAs(P,i,a)       := ?¬E(P,i) ; a ; ?E(P,i)
ContinueAs(P,i,a)   := ?E(P,i) ; a ; ?E(P,i)
EndAs(P,i,a)        := ?E(P,i) ; a ; ?¬E(P,i)
```

这些输出都是Program：它们筛选某种生、存、亡事件，而不是保证该事件实际发生。要问能否发生，用`Enabled`；要问是否实际发生，须与观测记录中的前后态对照。

`BornAs`表示实例进入模式P，未必是这个对象第一次存在。学生转为教师，可以是进入教师模式而非人的出生。若要定义首次生起，须把先前是否出现的历史放进状态，另声明并验证`Seen(i)`或`SeenKind(P)`的更新；不以当前看不见代替从未存在。

`ContinueAs`只保证所选相邻截面的条件。若a是合并了许多中间步骤的粗粒度转移，它不能排除内部中断。连续性要在实际采用的步长和历史假设下判断。

### 久不是一个无限的形容词

设`tick`为明确推进一个固定正时间步的原子过程，K为持续条件，T为非负整数。若一步仅指一轮，则首先得到无限轮数的判断；要解释成无限物理时长，还须保证每轮时长有统一的正下界。

```text
MayLast(T)  := K ∧ 〈Safe(tick,K)ᵀ〉⊤
MustLast(0) := K
MustLast(T+1) := K ∧ 〈tick〉⊤ ∧ [tick]MustLast(T)
```

第一式要求起点安全，并找出至少一条T步安全路径；第二式要求所有允许的后继都能继续，并逐步排除无后继。两式在T=0时均只要求起点满足K，不声称已经经历一个时间步。

必须约束每一步，不能只写`〈tickᵀ〉K`：后者允许中途离开K后又回来。

给定同一份完整有限模型，令N为状态总数，则：

`MayLastForever := MayLast(N)`。

理由是N条安全边包含N+1个状态位置，必有重复状态，因而存在可以重复的安全有向环。反向也成立：无限安全路径必有N步前缀。这里需要状态已经包含相关历史、资源与环境，规则保持不变，tick每步推进固定正时长；遗漏耗竭变量的假循环不能证明现实中可永续。

所有允许路径都安全并能不断继续，可写为：

`AllLastForever := [tick*](K ∧ 〈tick〉⊤)`。

零步让起点也受检查，所有可达态的非空条件排除中途停机。它比存在一条无限安全路径强。若有可选择的行动与不可控制的扰动，二者都不能直接等同“存在可实施的稳健策略”。策略须在每次观测后选择行动，并对所有允许扰动负责；本版检查已给定的过程关系，不自动合成这种策略。

活动的无限延续也不等于无限多个新实例的生成。固定有限实体域可以检查有限代的生生；若重用实例槽位表示代际活动，须明确这是抽象，不能据此证明无限多个彼此不同的新个体出生。

### 穷 通 复 与不可逆

```text
穷(old,K)          := ¬〈old〉K
通(new,K)          := 〈new〉K
可经改组续存(T)    := 〈reform〉MayLast_new(T)
可经有限步恢复(π,P) := 〈π*〉P
T步内可恢复(π,P)   := ⋁{〈πⁿ〉P : 0≤n≤T}
模型内不可恢复(π,P) := ¬〈π*〉P
```

这里的穷选用“旧方式下没有安全下一步”的具体义项，不穷尽古文的至尽、困厄等义。`MayLast_new`必须用改组后的实际过程关系定义。“可经有限步恢复”不预设统一期限，T步内恢复才给出具体上界；物理时窗还要根据每步时长换算。恢复式中的π应包含研究所允许的全部后续行动与环境转移；少列一条边只能证明所列模型中无路，不能证明世界中绝无办法。

若问题是“在正次数后复现”，用`Plus(π)`替代`π*`；否则起点已经满足P会提供零步见证。同一实例复续与同类模式重现分别使用`E(P,i)`和`KindExists(P)`。

### 消长 分合 感应与制衡

消长不是对任意对象都适用的无参操作。必须选择量、单位、观察方式和前后态比较，将符合增减条件的边登记为过程。例如域内某量从前态值变为更大值的边构成长过程；参考实现接收已经计算好的有限关系，不自动计算无限实数或微分方程。

实际分合要改写成员、关系或边界，并说明实例身份和谱系；认识上的分则改变分类描述，两者分别绑定过程或谓词。感应要声明输入、响应和时滞；制衡要声明调节过程及目标，之后检验`MustLast`或其他目标式。不存在“有制就稳定”“有感就因果”的通用规则。

## 八 虚词和复合词的组合规则

| 形式 | 选定义项后的展开 | 不可省略的决定 |
|---|---|---|
| 不P | `¬P`，P须为Formula | 否定的作用域；不发生、不可能、未观察到分开 |
| 无P | 例如`¬∃x:τ.P(x)`；或某种有用空处的另行谓词 | 是不存在、缺少某物，还是留空功能；不能统一为null |
| 未P | 在指定过去区间内没有P的发生或满足 | 历史区间、事件判据及记录是否完整；不能只否定现在P |
| P则Q | 若选逻辑条件义，`P⇒Q` | 若选过程义，须另给`?P;π`或条件行动式；则字本身不产生π |
| P而Q | 同状态并列可为`P∧Q` | 顺承时是`π;ρ`，转折的语用关系还需保留；不可混型 |
| 相R | 把参与者分别放进已选关系的角色位 | 双向、单向、相待须由语境确定；不存在默认对称化 |
| 互R | 选双向义时，`R(a,b)∧R(b,a)` | 两方向分别需要解释；不要求强度相同 |
| 自R | 将某义项的相应参与者绑定为自身 | 不能删除外部资源、环境及历史条件 |
| 共R | 若选每个参与者都满足，使用有限全称；集体行为可另给群体谓词 | 逐个成立和整体成立不同，共同不自动互利 |
| 以X | 在所选义项中绑定手段、根据或目的角色 | 先定角色及类型；依据、因果、目的不是同一关系 |
| 于X | 绑定位置、时间、对象或范围 | 位置项不能放入时间位，伦理内外不能当作空间内外 |

这些是有选义前提的编译规则，不宣称每个虚词在所有古文中只有表内功能。省略的参与者可以由语境补出，但必须写入解释记录；若多个补法改变推论，保留多个候选，不静默选一个。

时窗可以直接落入核心：声明`Time`、`Interval`、`Event`三个有限对象类，以及`InWindow:Time×Interval→Formula`、`Occurs:Event×Time→Formula`，则某事件e在窗口w内“未发生”展开为`¬∃t:Time.(InWindow(t,w)∧Occurs(e,t))`。改变窗口不改变t的类型，也不把一个Formula当成谓词的对象参数。这个历史表仍须与当前状态一起完整解释。

完整复合表达式的检验顺序为：选义 → 绑定角色 → 实例化宏 → 类型检查 → 求值。把“生生”“无为”“自然”直接按单字拆分，并不会自动得到正确的词义或合法程序。

## 九 文本 观察与规范怎样接入

### 出处与模型前提

一条解释记录至少包含：原句和来源ID、所选义项、形式表达式、额外桥梁假设、适用范围。这个记录说明为何选择某表达式，不负责给它赋真值。

例如原典支持“有无相待”这一解释选项，与某领域确有两种物质相互生成，是两个不同命题。即使核心接收一个名为`生成`的关系表，该表仍是模型输入；它的真实性与因果资格需要独立证据。

### 模型内否定与证据不足

参考实现要求`closed_world:true`：每个谓词都提供每个状态的完整真元组，原子过程提供完整边集。在这个明确约定下，没有列入的元组为假。缺少整项解释、状态条目或声明会报错，不默认为假。

这只适用于已经指定的模型。实际观察不完整时，可以提供非空的候选模型集`ℳ`，其对象签名、查询状态和查询含义必须兼容，再计算：

```text
全部候选满足φ       → true，表示相对于候选集得到支持
全部候选不满足φ     → false
候选之间真假不同   → unknown
候选集为空         → 错误，不以全称空真宣布已知
```

`unknown`是候选模型间分歧，不是核心逻辑中新增的真值。应先在每个候选中求完整公式，再汇总；不能先将各原子变成unknown，再任意套三值真值表。例如P未知时，`P∨¬P`在每个候选中仍为真。候选集若遗漏真实可能性，结论仍可能失当；观测到模型的筛选规则要另行交代。

### 规范判断与行动

规范以显式命名的判断表给出，对每个所列状态和行动返回`required`、`permitted`、`forbidden`或`undetermined`，分别表示要求、许可、禁止、未定。表的伦理依据必须公开；参考实现能检查表完整，却不会替使用者证明它正当。

规范判断不属于Formula，因此不能由`稳定`或`可达`直接推得“应当”。给定规范N，以及某行动的过程绑定π，可以分别询问：N如何评价该行动，π当前是否可行。仅当规范要求或许可且过程可行时，才得到“在该规范下准入”的结论；这不等于总体最优或必须立即执行。

参考实现提供`judge(N,s,action)`和`decision(N,s,action,π)`。后者同时返回规范判断、过程是否有后继及准入结果：许可或要求且可行时为true；禁止或不可行时为false；规范未定且可行时为null。行动名称与π的对应由调用者显式给出，不能把另一个行动的过程借来充当可行性证据。

不同规范可以对同一行动有不同判断。缺少选用哪套规范的理由时，保留冲突，不通过把存续最大化偷偷设为默认价值解决它。规范中的“要求”也不会生成实际转移边。

## 十 一条完整推导

取“穷则变，变则通，通则久”作为问题资源，出处是[《系辞下》制器尚象一段](https://zh.wikisource.org/wiki/易傳/繫辭下)，对应Y04。下面的有限资源模型是现代桥梁假设，不是对原句的逐字翻译。

设五个状态`a,b,c,d,e`。a是储备充足、旧制难以继续；b是改组完成；c是稳定维持；d是过晚、改组费用已不可承担；e是不满足持续条件。令K在a、b、c、d为真，在e为假。

```text
old    = {(a,e),(d,e)}
reform = {(a,b)}
new    = {(b,c),(c,c)}
```

这里没有把“旧制难以继续”与“已经死亡”混为一谈：a与d当前仍在K内，只是old没有安全下一步。所有未列边均按本例完整关系的约定不存在。

1. 从a经old只能到e，e不满足K，所以`穷(old,K)`在a成立。
2. reform有a→b，b满足K，故改组在a可行。
3. 从b经`Safe(new,K)`到c，c可继续到c，因此`MayLast_new(2)`在b成立。
4. 顺接与模态规则给出：在a，`〈reform〉MayLast_new(2)`成立。
5. 同样的穷在d也成立，但reform没有d的后继，因此相同的改组可续存结论在d为假。

这说明文法能保留一条有条件的机制链，并给出原句不能单独保证的失败条件。若删除c→c并改为c→e，则改组虽可行，长期续存结论仍会失败。

检查器可以验证每一步在本例中的真假；要把结论用于真实组织，还须证明这些状态分类、费用限制和转移边符合该组织的实际情况。更多语义不同的完整案例见[推导与反例](09_组合文法完整推导与反例_v0.3.md)。

## 十一 机器表达与参考实现

核心使用严格JSON语法树，没有隐式运算顺序。例如“通过改组，可能到达安全状态”写为：

```json
{
  "op": "diamond",
  "program": {"op": "atomic", "name": "reform"},
  "body": {"op": "atom", "name": "Safe", "args": []}
}
```

| 数学形式 | JSON操作名及主要字段 |
|---|---|
| 常量、变量 | `{"const":"a"}`、`{"var":"x"}` |
| 真、假、谓词 | `true`、`false`；`atom`含`name,args` |
| 同型等同 | `eq`含`left,right` |
| 非、且、或、条件 | `not`含`arg`；`and,or`含`args`；`implies`含`left,right` |
| 全称、存在 | `forall,exists`含`var,sort,body` |
| 可能、全称后果 | `diamond,box`含`program,body` |
| 原子过程、空动作、测试 | `atomic`含`name`；`skip`；`test`含`condition` |
| 顺接、选择、共同转移约束 | `seq,choice,sync`含`args` |
| 任意有限重复、恰好n次 | `star`含`body`；`repeat`含`count,body` |
| 闭合命名定义 | `fref,pref`含`name`，分别引用命题和过程定义 |

未知操作、额外字段、缺字段、异型参数、未绑定变量、循环定义、错误边端点及缺失解释都属于错误，不会用一个`false`掩盖不合法输入。参考实现中的范例包含实际通过案例、合法但为假的反例，以及应被拒绝的输入。

完整模型格式与运行方式见[参考实现说明](10_组合文法参考实现_v0.3/README.md)。逐字JSON词典保存义项的类型合同；它与核心解释器之间仍需按具体案例进行绑定，不能仅输入任意汉字串就自动得到可靠结论。

## 十二 完成条件与后续扩展规则

本版核心提供了封闭产生式、逐构式类型与语义、变量作用域、无环定义展开、模型内决定算法、生命周期与持续性宏，以及文本、观测和规范的连接方式。113字按词典中的义项进入这个核心，构成可追溯的组合接口。

增加新概念不必增加原语。优先给出可完全展开的宏；若必须增加原语，须同时交付输入输出类型、全部边界情形、递归语义、实现和至少一个有效例与拒绝例。只增加名称、隐含“通常如此”或用空字段容纳任何解释，不算扩展文法。

本版采用有限离散状态与有限对象域。连续动力学、概率、无限对象生成、一般并发、部分观测策略合成，均需要明确扩展；当前可以对它们建立有限抽象，但抽象是否保持结论必须另外论证。没有把有限抽象的可执行性当作世界只有有限状态的主张。

最小性与经验增益仍是另一项研究。G1解决的是“如何组合且能判错”，下一项检验是这些组合能否从原文中提出有约束的新模型，并在未见案例上比竞争表述更有效。

## 十三 形式方法与古文出处的分工

命题与过程分型、顺接、选择、测试、有限迭代以及模态判断，采用现代动态逻辑和关系语义的基本方法。可参见Fischer与Ladner的[原始论文](https://www.cs.man.ac.uk/~ezolin/dl/bib/Propositional_Dynamic_Logic_of_regular_programs_%28JCSS_1979%29.pdf)，以及Kozen与Tiuryn的[Logics of Programs](https://www.cs.cornell.edu/kozen/Papers/Handbook.pdf)。本版有限多类对象、严格声明、词义绑定、身份宏、观测和规范接口，是为本项目组合起来的具体设计；不是把古文认定为已有这套符号系统。

古文出处支持字词在具体篇章中的意义与论证资源；形式方法支持组合的清晰定义；领域证据支持现实机制。三者各有任务，任何一方都不能替其余两方完成论证。
