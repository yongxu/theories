# 文理生生 组合文法逐字类型词典

**版本 v0.3　2026年10月21日**

这份词典规定每个概念字怎样进入组合文法：先选义项，再确定它产生事实判断、过程、规范判断，还是解释与证据记录。核心113字保持原顺序；多义字拆开，不能在推理中随意换义。出处沿用[原典证据索引](05_原典证据索引与校勘说明_v0.2.md)。

核心113字在本版分成 **211 个义项接口**；另有12个句法接口和20个补充字的22个义项。数量表示本项目当前选义粒度，不代表穷尽历史词义，也不表示这些字都是独立运算原语。

## 怎样读这份词典

| 产物 | 怎样组合 |
|---|---|
| 事实判断 Formula | 在同一有限模型中与否定、合取、条件、量词及可达/全部后继查询组合。 |
| 过程 Program | 与顺序、选择、测试、重复及关系交集组合；没有后继也是明确的模型结果。 |
| 模型声明 | 为实例、种类、关系、量、动作补给有限域和解释；声明规则不表示现实已遵守。 |
| 规范判断 NormJudgement | 给行动提供评价和理由；若用于选择动作，另给明确的选择规则。 |
| 解释、文本、证据、因果记录 | 保存所指、出处、解释桥梁或证成依据；不能自动变成事实公式。 |

**“绑定”**表示必须由领域模型给出谓词或过程的具体解释。**“宏”**表示补齐参数后，可展开为核心构造。参数化接口不是执行器表达式：需完成消歧、类型检查和闭合实例化；本词典JSON尚未自动连接执行器。

Entity、Kind、Agent、Time等只代表所需的领域类型，并非文法已内置的世界分类。数量、单位、阈值与身份准则都须补出；当前有限核心中的数量比较须登记为有限域上的谓词，不假设存在任意实数计算器。完整类型签名、所需参数和禁止转换见[机器可读词典](08_组合文法逐字类型词典_v0.3.json)。

签名是**绑定函数或宏的元层合同**：Criterion、Rule、State等是解释与建模时所需材料，不能直接塞入atom当对象参数。实际参与谓词的对象须先声明有限类型与常量；前后态比较可用07的事件Program宏，或明确声明Event、StateLabel域及历史记录，再应用相应事实谓词。状态求值不会偷偷给任一谓词访问前一帧的能力。

严格身份优先使用经领域判据确认的稳定实例ID和同型eq。另行声明的I谓词不会因名称而自动满足身份性质；跨截面匹配表须验证端点、部分一对一及沿历程的复合一致性，才可用于严格身份的生灭判断。未验证的I只是匹配候选，也不能自动当作谱系L。详见[完整文法的实例与模式规则](07_文理生生_完整组合文法_v0.3.md)。

## 组合前必须通过的检查

1. **义项确定。** “息”的滋长与停止、“义”的文义与正当性、“实”的实例与容量等，必须选择明确义项。
2. **类型匹配。** 事实与规范、对象与种类、相似与同一、模型修订与世界变化不能隐式转换。
3. **参数完整。** 对象域、时间、边界、单位、量、阈值和身份准则须按词条要求补足；未绑定的词项不能求值。
4. **作用域固定。** 实例化使用同一context_id，对应的问题、尺度、身份、步长与边界须说明；跨域推论需要明示桥梁。
5. **宏能展开。** 宏实例化后只用已声明的核心构造，命名定义的依赖须无环；同名不是递归定义的许可。
6. **证据层次保留。** 古文确有某说、解释者提出某映射、有限模型某公式为真、现实机制得到支持，是四项不同判断。
7. **事件与命题分型。** BornAs、ContinueAs、EndAs输出Program；询问能否发生用Enabled。要求同一前后态同时满足两种事件约束，用sync，再用Enabled，不能把两个Program直接合取。
8. **真实时间与新实例分开。** 久的tick必须推进固定正时长；skip和test不代替时间。固定有限实体域可检有限代生成，不能证明无限多个彼此不同的新个体出生。

例如，“和而不同”可以在某一明确场景中解释为`and(harmonious,not(homogeneous))`。和与同的谓词须分别绑定；该句不生成“差异必然导致和谐”的因果规则。“因其固然”则须先解析“其”的对象，再把固有结构的条件放入测试或允许转移中，不能把“因”当成证明一切原因的算子。

一个字能够进入词典，只说明其接口已说明；一个完整表达式能够计算，还须它的所有参数、领域谓词和程序都已落实。模型检查得到的真，也仍然相对于那一个已声明模型。
