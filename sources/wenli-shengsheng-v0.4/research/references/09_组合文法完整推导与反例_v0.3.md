# 组合文法 完整推导与反例

**版本 v0.3　2026年10月21日**

组合文法的作用，是让解释者必须说明每一步用了什么含义、什么条件和什么规则，并使错误推论能够被明确拒绝。本篇以七组案例展示从原句、选义、现代模型到结论的完整链。每组同时给出不能推出的结论，避免只为成功的解释寻找例子。

所用形式系统是在有限模型上定义的项目文法。古文出处支持原句及其语境；状态、参数、关系和动作表是现代增补。形式上可表达、在模型中为真、符合原文、符合现实，是四种不同判断。

配套[可执行案例集](10_组合文法参考实现_v0.3/casebook/README.md)包含本篇七组案例、反模型及07的五状态教学例，共12个独立模型文件。公式、过程关系、规范查询和边界拒绝的120项检查已实际执行通过；[详细结果](10_组合文法参考实现_v0.3/casebook/validation_results.json)保留每项输入名称、预期与实际结果。

## 一 阅读推导所需的记号

`s`表示状态，`p、q`表示该状态上的命题，`α、β`表示状态间的动作关系。

| 写法 | 意思 |
|---|---|
| `¬p`、`p∧q`、`p⇒q` | 否定、合取、条件蕴含；条件蕴含本身不表示因果。 |
| `∃x:A. p(x)`、`∀x:A. p(x)` | 对指定有限域A量化；改变域就可能改变结论。 |
| `?p` | 检查p；p真时保持原状态，p假时没有后继。检查不推进物理时间。 |
| `α;β` | 先完成α，再完成β；中间状态必须相接。 |
| `α∪β` | 在两种关系中任选一种；这不是已经作出选择的事实。 |
| `α*` | α执行任意有限次的关系闭包，包含零次。 |
| `α^T` | 恰好执行T次α。 |
| `⟨α⟩p` | 至少存在一个α后继满足p。 |
| `[α]p` | 每个α后继都满足p；若没有后继，这个式子形式上也为真。 |
| `tick` | 本篇离散模型中推进一个固定正时间步的实际转移。`skip`和`?p`不能充当tick。 |

因此“可持续”必须同时排除无后继和零时间重复。有限T步安全路径统一用`K∧⟨(?K;tick;?K)^T⟩⊤`表示，T为0时也检查起点K。所有允许的tick路径都可永续且安全，在此有限模型内可写为`[tick*](K∧⟨tick⟩⊤)`；它要求每个可达状态都安全，并有真实下一步。

用`TextClaim`登记原句主张；用`Bridge`登记现代解释的增补；用`ModelClaim`登记模型结论；规范评价另属`Judgement`。这几种记录之间没有自动提升的推理规则。

## 二 不 未 无怎样组合

### 原句与选义

《中庸》有“不息则久”，其中息为停止，见JC6b；《孙子·军争》有“无粮食则亡”，见S5。前者否定停止，后者否定供给项目的存在，不能因为都有否定意味，就使用一个不带作用域的“无”节点。[《礼记·中庸》](https://zh.wikisource.org/zh-hans/禮記/中庸)、[《孙子·军争》](https://zh.wikisource.org/wiki/孫子兵法#軍爭第七)。

“未”在下面选择“指定既往时窗中尚未发生”的操作义；这是文法定义，不声称所有古文中的未都只有这一义项。

### 类型与展开

- `不(p) := ¬p`，要求p已经是完整命题；`不(刀)`没有补足谓词，属于类型错误。
- `无[A:P] := ¬∃x:A. P(x)`，要求指定对象域A与谓词P。
- `未[event_id;window_id] := ¬∃t:Time. (InWindow(t,window_id)∧Occurs(event_id,t))`。其中event_id属于Event，window_id属于Interval，不把一个Formula塞入Term位置。
- “未观测到”展开为`¬Observed(event_id,window_id)`。Observed的签名为`Event×Interval`，命名的事件与窗口如何绑定观测资料须另说明。没有完整检测条件，不能把它变成上一条的“未发生”。

### 完整有限例

固定时点域`Time={t0,t1,t2,t3}`，I与J是Interval中的两个窗口标识。InWindow把I解释为t0、t1、t2，把J解释为t0、t1、t2、t3。事件标识为ignite，Occurs只在`(ignite,t3)`为真。机器文件使用字符串标识t0等，不把数值文字当作未声明的数值类型。

1. 枚举属于I的三个时点，没有一个使Occurs(ignite,t)为真。
2. 故`¬∃t:Time. (InWindow(t,I)∧Occurs(ignite,t))`为真，即相对于I的“未点燃”。
3. 保持同一Time域，改查窗口J；t3是见证，故相对于J的“未点燃”为假。
4. 因此`未[ignite;I]`不蕴含`未[ignite;J]`，更不蕴含“永不点燃”。这里改变的是明示窗口参数，没有静默改变模型的对象域。

若只知`Observed(ignite,I)=假`，真实事件表没有确定，则可以提供两个签名兼容的候选模型：一个在I内无点燃，一个在t1点燃；二者都未观测到。候选模型合评给出“未观测到”为true、“未发生”为unknown。缺失整张解释表的单一模型则直接报错，不能把缺数据补成假。

### 不息与持续的反例

有限模型只有一个安全状态s，K(s)为真，但tick没有任何边。`[tick]K`形式上为真，`⟨tick⟩⊤`却为假，故不能判可继续。另有`?K`自环，但它仅检查，不推进时间：`[(?K)*]K`也不能证明一刻的存续。

要得到本模型的“久”，需另证明真实tick后继存在，并在所声称时域内保持K。古文的“不息则久”启发这个问题，但它没有给出检测完备性、时域或这里的关系语义。

## 三 穷 变 通 久怎样成为有条件的机制

### 原句与解释层

Y04的原句是“易穷则变，变则通，通则久”，位于神农、黄帝尧舜及制度器用变革的叙述中。它给出受限、改变、通达、延续的论说链。[《系辞下》第二章](https://zh.wikisource.org/wiki/易傳/繫辭下)。

先登记`TextClaim(Y04, 穷⇒变；变⇒通；通⇒久)`。这一登记不把每条⇒直接加入现实公理。现代模型要补出的，是可行改革、转换成本、动作选择及后续供给条件。

### 一个完整有限模型

状态集为`S={o3,o2,o1,o0,n1,n0,dead}`。o表示旧方案，n表示新方案，数字为储备。dead表示储备低于持续下限；它是显式失败状态，不是程序没有定义。

持续条件`K=S\{dead}`。下列未列出的动作边均不存在，关系表在本模型内是完整的。

| 动作 | 全部关系边 | 解释 |
|---|---|---|
| `old_tick` | `o3→o2，o2→o1，o1→o0，o0→dead，dead→dead` | 旧方案每个真实时间步净消耗1。 |
| `reform` | `o3→n1，o2→n0` | 改革支付2单位；储备不足时无此动作。 |
| `new_tick` | `n1→n1，n0→n0，dead→dead` | 固定供给条件下，新方案每个真实时间步收支相抵。 |

这三张动作表和K是Bridge，不是古文的直接事实。“穷”在本例具体化为：只采用旧方案时，没有未来4步的安全路径。“通”具体化为改革后存在可持续路径。“久”具体化为在新方案与固定供给下，每个后续真实时间步都能安全继续。

### 逐步推导

初态为o3。

1. 旧路径唯一，依次是`o3→o2→o1→o0→dead`。第4步在K外。
2. 所以`¬⟨(?K;old_tick;?K)^4⟩⊤`成立。这是相对旧方案和4步时域的“穷”，不是一切行动都不可能。
3. 关系表含`o3→n1`的reform边，且K(n1)为真，故`⟨reform⟩K`成立。
4. 从n1经`new_tick*`可达的状态只有n1；n1在K内，且有真实new_tick后继n1。
5. 因而在n1，`[new_tick*](K∧⟨new_tick⟩⊤)`成立。
6. 结合第3、5步，在o3得到：

`⟨reform⟩[new_tick*](K∧⟨new_tick⟩⊤)`。

这证明存在一次可行改革，使后续按所给新规则运行时可永续安全。它不证明改革已经发生。实际发生需要行动选择与执行记录；现实成立需要验证模型的供给、成本、组织和身份条件。

### 失败支路

在o1，reform无后继，故`¬⟨reform⟩⊤`成立。旧方案受限不产生支付改革的资源。这里能看见时机的机制内容：迟延会删去原本可行的动作。

再建立独立的反模型M′，把新方案改为`n1→n0→dead`，表示供给下降；其余条件不动。现在改革仍可发生，却不能得到原来的久结论。不得悄悄改变new_tick后仍沿用旧证明。

### 拒绝的推论

- “穷，所以改革必定发生”：把行动可能性当实际选择。
- “变化，所以通”：未排除破坏性改组。
- “单步通，所以无限久”：越过持续条件。
- “存在某条安全路径，所以行动者有在线可行策略”：未说明行动者能获得的信息、可控动作与扰动顺序。
- “`?K`可以无限检查，所以可久”：检查不推进真实时间。

## 四 有无相生怎样避免变成无条件互因

### 原句与选择的读法

L01“有无相生”处于美恶、善不善以及多组相待论述中。本例选择“对待概念的确定相互关联”的解释；生成论等其他读法须另立解释记录，不与此读法共用证明。[《老子》王弼本二章](https://zh.wikisource.org/wiki/道德經_(王弼本)#二章)。

### 类型化表达

“有”“无”作为本例被讨论的概念标签，类型为Concept。声明：

`CoDefine : Concept×Concept → Formula`。

选择“相”的互向分配义，展开为：

`CoDefine(有,无) ∧ CoDefine(无,有)`。

这是概念解释之间的关系。“因果影响”需要另一个关系声明及其对象类型；它不由CoDefine转换而来。关系的语义也必须声明，单给它取名并不算证明。

给定非空分类域d，可进一步定义公式宏：`Has_d:=∃x:d.P(x)`；`Lacks_d:=¬Has_d`。状态由求值环境给出，不再作为一个未声明的普通谓词参数。这是本例对有无的互补操作化，不是说两标签本身是物质。

### 推导与反例

1. 选择同一d和P后，Has与Lacks使用同一分类判据。
2. 由互补定义，在同一状态求值时`Has_d∧Lacks_d`为假。
3. 令d中每个位置都被占据，则Has为真，Lacks为假；有与无的概念区分依然可以被理解。
4. 因此概念上的相待不要求当前现实中两种状态都得到实例化，更不要求它们彼此制造。

“概念相依，所以物理互因”没有合法推导。若把Concept直接填入要求Entity的因果谓词，是类型错误；即便因果谓词接受了同型参数，也仍缺连接CoDefine与Cause的实质前提。**类型正确只保证表达合格，不保证关系为真。**

### 相并不总指定互向

F01—F03的五行相生模型给出木→火→土→金→水→木。这个有向环并不包含火→木的生边。字面“相生”不能让检查器自动补上每条反向边。[《春秋繁露》四库本卷十一](https://zh.wikisource.org/wiki/春秋繁露_(四庫全書本)/卷11)、[卷十三](https://zh.wikisource.org/wiki/春秋繁露_(四庫全書本)/卷13)。

所以“相”的组合步骤须选择参与者集合与关系分配方式。五行生边、概念相待与实际互因是不同关系，不共享一个无条件的“相”算子。

## 五 和而不同怎样保留合取与规范

### 原句与选义

C08“君子和而不同”保留君子、小人的规范对举。此处“同”不直接等于任意数学特征相等。下面选择“在议题上没有同一意见”的有限操作化，用来展示组合；它不能穷尽原句中附和等含义。[《论语》子路13.23](https://zh.wikisource.org/zh-hans/論語/全覽#子路第十三)。

对群体g，声明两个状态谓词：`H(g)`表示按约定判据能协调合作；`U(g)`表示本次议题上全体意见一致。

选择“而”的合取义、“不”的命题否定义，得到：

`and(H(g),not(U(g)))`，即`H(g)∧¬U(g)`。

“而”的转折意味可以保留在解释记录中，但不额外生成因果边。

### 完整有限模型

实体域包含群体g与成员甲、乙。甲支持A方案，乙支持B方案。状态s中，两人遵守共同程序，并完成合作任务；模型事实表规定`H(g)=真，U(g)=假`。这些程序与任务事实是现代Bridge。

1. 从事实表得到H(g)与¬U(g)。
2. 由合取引入得到`H(g)∧¬U(g)`。
3. 由合取消去可以分别取回H(g)、¬U(g)。
4. 这构成“协调与意见不一致可共存”的一个见证。

### 拒绝与反模型

新状态s′中，两人仍意见不同，却互相阻碍、无法合作。于是`¬U(g)=真，H(g)=假`，反驳`¬U⇒H`。另一状态s″中，两人一致支持A并合作，反驳`H⇒¬U`作为所有群体的普遍规律。

因此本例不推出“差异越多越和谐”，也不推出“协调者必善”。若要保留原句的君子评价，须在相应规范解释中登记Judgement，不能把它删去以后宣称古文原本只在说中性协作效率。

## 六 分合与方生方死怎样处理实例身份

### 原句与解释限度

Z02《齐物论》彼是段有“方生方死，方死方生”，同篇又有“其分也，成也；其成也，毁也”。这些句子提出生死、成毁与观照的关系，但不能仅凭字面认定同一对象在同一判据、同一截面既存在又不存在。[《庄子·齐物论》](https://zh.wikisource.org/wiki/莊子/齊物論)。

文法先要求补出省略的索引：模式P、实例i、前后状态、比较尺度与身份准则。下面是成毁的一种现代重构，不宣布解决“方生方死”的所有训诂与哲学解释。

### 完整有限模型

有两个状态s0、s1，一个真实分裂转移`split:s0→s1`。实体域为`{A,B,C}`，三者彼此不同；P为旧整体组织，Q为分裂后的后续组织。

| 谓词 | s0 | s1 |
|---|---|---|
| `E(P,A)` | 真 | 假 |
| `E(Q,B)` | 假 | 真 |
| `E(Q,C)` | 假 | 真 |
| `L(A,B)`、`L(A,C)` | 假 | 真 |

本例身份判断I不把A与B、C等同。E与L是完整登记的模型事实；不是看到外形相似后自行推定。

### 推导

1. 用07的过程宏定义`EndA := ?E(P,A);split;?¬E(P,A)`；其关系恰为`{(s0,s1)}`。
2. 同样定义`BornB := ?¬E(Q,B);split;?E(Q,B)`、`BornC := ?¬E(Q,C);split;?E(Q,C)`，两者关系都恰为`{(s0,s1)}`。
3. 生、亡宏输出Program，因此以关系交集组合：`Combined := sync(EndA,BornB,BornC)`。Combined仍包含同一条边`(s0,s1)`，故在s0，`⟨Combined⟩⊤`为真。
4. 这证明同一转移兼具旧整体终止与B、C生起三个条件，而不是三个可能由不同后继分别见证的命题。L记录承接；由`L(A,B)∧L(A,C)`不能推出`I(A,B)∧I(A,C)`。

这允许“一个层次上的终止与另一组实例的生成同时发生”。它没有抹去对象、层次及身份的区别。

### 拒绝的合并

对同一P、A及split，`BornAs(P,A,split)`要求前态¬E、后态E；`EndAs(P,A,split)`要求前态E、后态¬E。两种Program的交集为空，故`⟨sync(BornAs(P,A,split),EndAs(P,A,split))⟩⊤`为假。把两个Program直接用命题合取连接属于类型错误；用sync可以合法表达所要求的共同转移，但其条件在这里不相容。

也不能从这个例子推出物质守恒，因为模型没有提供物质量与守恒式。若解释者无法确定原句省略的索引，正确输出是解释待定及候选读法，而非伪精确的方程。

### 生生的有限域边界

一个始终在K内的tick自环证明活动可继续，并不证明每一步都有新实例诞生。固定有限实体域也不能容纳无限多个彼此不同的新个体。要谈生生，须额外登记每代的生成事件、后继实例与L；有限T代可以在足够大的有限模型中检查。把实例槽位重复使用，是一种抽象，不能直接证明现实中有无限新个体。

## 七 因其固然怎样约束动作与角色

### 原句与选义

Z03庖丁段“因其固然”与依循结构和间隙行动相连；后面还描写遇复杂部位时警惕并减慢动作。因此这里选择依循对象已有结构的义例，不直接把“因”当作逻辑蕴含或充分原因。[《庄子·养生主》](https://zh.wikisource.org/wiki/莊子/養生主)。

### 类型化角色

声明切割动作需要四种角色：

`切割(agent:Agent,patient:Body,instrument:Tool,route:Path)`。

“以刀”在手段义下把刀绑定到instrument；“于某部位”把部位绑定到已声明的处所角色。古文中的以、于还有其他用法，必须逐句选择，不由本例统一。

“因其固然”在本模型中要求：所选route属于对象结构与工具条件共同允许的路径集合。这个约束删去不合条件的动作，没有自动创造一条完成路径。

### 完整有限模型与推导

状态集为入口A、中间B、出口C；两条允许动作`cut_AB:A→B`、`cut_BC:B→C`。直接A→C穿越不允许区域，不在动作表中。工具尺寸适合通道，两条允许动作的模型损伤成本均为0。

1. `⟨cut_AB⟩atB`在A成立，B是其见证。
2. `⟨cut_BC⟩atC`在B成立，C是其见证。
3. 由关系复合，`⟨cut_AB;cut_BC⟩atC`在A成立。
4. 如果另给成本相加规则，这条具体两步路径总成本为0；数值结论依赖该成本规则与边成本。

### 反例与拒绝

在反模型里移除B→C边，其余不变。A→B仍合法，但A到C不再有这条复合路径。“顺应结构”因而不保证目标可达。

“以刀”不能推出刀是行动者；工具角色与施事角色不同。“以养生为目的”也不能直接推出成功养生：目的绑定与结果命题是不同表达。一次具体路径的低损伤，不能扩成任何工具、任何对象下的永久无损。

## 八 从可持续到应该选择还需要什么

### 原句与规范内容

Y10《节·彖》将制度节制与不伤财、不害民相连；C09《孟子·告子上》第十章把义置于某些生命选择之上。这些来源使规范标准不能被直接替换为“越持久越好”。[《周易·节》](https://zh.wikisource.org/wiki/周易/節)、[《孟子·告子上》](https://zh.wikisource.org/zh-hans/孟子/告子上)。

下面采用一项有限的示范标准V：在该决策任务中，只接受所有允许后果都不伤害指定人的可行行动。V是显式规范前提，不声称涵盖原典全部伦理学，也不声称任何现实情形都只有这一价值。

### 完整有限模型

状态为s、h、n。s有两种行动：`a:s→h`、`b:s→n`；h与n各有真实tick自环，都满足持续条件K。Harm(h)为真，Harm(n)为假。动作关系、伤害判据与K分别登记。

因两后态都可持续，所以在s：

`⟨a⟩[tick*](K∧⟨tick⟩⊤)`与`⟨b⟩[tick*](K∧⟨tick⟩⊤)`都为真。

另定义模型后果检查：

`SafeForPeople(x) := ⟨x⟩⊤ ∧ [x]¬Harm`。

前一项排除无可执行后继的空真情况。这个检查仍是事实层，不直接等于伦理评价。

### 带规范前提的推导

1. a有后继h，但Harm(h)为真，故`SafeForPeople(a)`为假。
2. b有后继n且¬Harm(n)，故`SafeForPeople(b)`为真。
3. 显式加入V的规则：本任务中可行且所有后果不伤害指定人的行动，判为可接受；违反该要求的行动判为不可接受。
4. 在V下得到`Judgement_V(a)=不可接受`、`Judgement_V(b)=可接受`。
5. 若还要推出“选择b”，须再给行动选项集与决策规则，例如“只在可接受行动中选择；本次只有b符合”。如果多个行动均可接受，现有规则不产生唯一选择。

### 拒绝与边界

- 不得从持续条件K推出可接受：h可持续而违反V。
- 不得把事实层的`SafeForPeople(b)`直接当成所有伦理体系都赞成b。
- 不得从“应当做b”推出b已经发生，也不得从b实际发生推出它正当。
- 不得以未测得伤害代替¬Harm：伤害检测与事实充分性仍须交代。

这个案例把状态后果、规范前提和决策规则三者接在一起，同时使每个增补都能被质疑。

## 九 组合规则的最小拒绝清单

| 试图进行的组合或推论 | 文法应给的结果 |
|---|---|
| 对对象直接使用命题否定 | 类型错误；须补足谓词。 |
| 把“未观测到”换成“不存在” | 缺检测完备性桥梁。 |
| 把有限时窗的未发生推广成永不发生 | 时域越界，存在反模型。 |
| 从相似、概念相待推出因果 | 不同关系之间缺推理前提；有时还发生参数类型错误。 |
| 见相字就补所有反向边 | 关系分配未经解释，五行环即可构成反例。 |
| 从动作可行推出动作实际发生 | 可能性与实际性混淆。 |
| 从单步安全或测试自环推出久 | 缺真实时间步、后继存在或持续不变条件。 |
| 从谱系L推出严格同一I | 关系种类不同，分裂模型反驳该推论。 |
| 使同一实例在同一判据下同时满足互斥生灭过程 | 生灭Program的sync合法但无边；用命题合取直接连接Program则是类型错误。 |
| 从模型可持续推出应当延续 | 缺规范前提。 |
| 从原文明言推出现实机制成立 | 证据层级不匹配。 |

这些拒绝不是附在图旁边的一串提醒：每一项都对应类型、作用域、关系语义、前提或具体反模型。核心文法的完整性应体现在对这些表达给出确定处理，而不是保证任意古文都有唯一自动翻译。
