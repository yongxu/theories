# 八卦原典与参照项目证据 v0.1

核读日期：2026-10-21。配套11的结构模型、12的逐字映射及14的计算验证。

八卦的名称、卦画、取象、性质、时序和后世变换方法，分别有不同的文献依据。将它们连接为现代动力模型，需要另行写出桥梁假设。本册说明每一条连接究竟由哪一层文本支持，以及文本没有承诺什么。

## 一、证据层级与使用办法

| 层级 | 本册如何标记 | 可以据此说什么 |
|---|---|---|
| 经 | 卦辞、爻辞 | 传世《周易》该卦该爻确有此辞；不把《彖》《象》混入卦辞 |
| 传 | 《彖》《象》《文言》《系辞》《说卦》《序卦》《杂卦》 | 易传相应段落如何解释卦、爻与变化；不由网页传统署名断定成书作者与年代 |
| 后世解释 | 具名注家、著作、卷篇 | 该注家采用了某种解释或算法；不反写成早期经传已有的定义 |
| 参照项目 | 规范记录ID、来源ID、冻结引文 | 既有研究如何保存和限定这些材料；阅读记录不等于本轮重新全文核读 |
| 本项目现代构造 | 11—14中定义的编码、关系、模型与判断 | 在明示定义和输入下可得到哪些结论；不由古文的权威代替现实检验 |

本轮实际核读下列公开原典转录。引文保留关键原字，正文说明用简体；“说”在兑的释义中按悦读，“烜”不擅改为别字。章次采用所链接网页分章，尤其《系辞下》的九章分法不能冒充跨版本统一章次。网页可定位与引文匹配不等于已完成异本校勘。

文献声明在G1中首先属于 `TextClaim`。只有在给出选义、论域、类型、测量与桥梁后，才能写成现实模型的 `Formula` 或 `Program`；一句古文不直接产生状态边。

## 二、《说卦》给出的七组基础证据

以下B编号是本轮稳定引用入口，不替换05中已有Y、JY编号。

| ID | 原典定位与短引 | 支持的内容 | 适用边界 |
|---|---|---|---|
| B01 | [《说卦》第一、二章](https://zh.wikisource.org/wiki/易傳/說卦#第一章)：“观变于阴阳而立卦”；“兼三才而两之，故易六画而成卦” | 阴阳、刚柔、卦爻及六画六位的结构解释 | 不是现代二进制计算或卦画发明史的证明；第二章讨论六画层 |
| B02 | [《说卦》第三章](https://zh.wikisource.org/wiki/易傳/說卦#第三章)：“天地定位，山泽通气，雷风相薄，水火不相射。八卦相错” | 四组对举，以及各组不同的关系词 | 不能把定位、通气、相薄、不相射全改成同一种因果关系；此段未列八方坐标 |
| B03 | [《说卦》第四章](https://zh.wikisource.org/wiki/易傳/說卦#第四章)：“雷以动之，风以散之，雨以润之，日以烜之”；继以艮止、兑说、乾君、坤藏 | 不同作用词构成一组功能描述 | 前四项原字是雷、风、雨、日；连至震巽坎离须结合自然取象，不能篡改为该句原有卦名 |
| B04 | [《说卦》第五章](https://zh.wikisource.org/wiki/易傳/說卦#第五章)：“帝出乎震，齐乎巽，相见乎离，致役乎坤，说言乎兑，战乎乾，劳乎坎，成言乎艮” | 震→巽→离→坤→兑→乾→坎→艮的叙述次序，以及万物阶段、方位和时令解释 | 次序不是已经识别的因果链；未给物理时长、转移概率、必要条件或反馈增益 |
| B05 | [《说卦》第六章](https://zh.wikisource.org/wiki/易傳/說卦#第六章)：“终万物、始万物者，莫盛乎艮”；“水火相逮，雷风不相悖，山泽通气” | 雷动、风桡、火燥、泽说、水润、艮终始；相互作用与变化的论述 | 与第三章词义有联系但不是逐字同句；终始叙述本身不证明现实周期轨道 |
| B06 | [《说卦》第七章](https://zh.wikisource.org/wiki/易傳/說卦#第七章)：“乾，健也。坤，顺也。震，动也。巽，入也。坎，陷也。离，丽也。艮，止也。兑，说也。” | 八卦的八项性质释义 | 这些是传文，不是八条卦辞；性质释义还不是唯一、确定的动力函数 |
| B07 | [《说卦》第八至十一章](https://zh.wikisource.org/wiki/易傳/說卦#第八章)：动物、身体、家族、自然及其他取象 | 一卦有多组取象，取象按类别和语境组织 | 类比关系不自动具有传递性；卦对应某物，不等于该物拥有同列所有属性 |

B02四组不可省略原来的关系词。若将天地、山泽、雷风、水火画成四对，可以把“配对”作为结构信息；若再以相错定义全位取反，便已经增加了变换定义。第三章本身没有逐位取反的伪代码。

B04第五章明确写震东方、巽东南、离南方、乾西北、坎正北、艮东北；坤在该段说地与致养，兑说正秋与万物所说。**坤西南、兑西方不是这一段逐字说出的方位**。若绘完整后天八方图，须标明采用后世图式，不把补足的两项伪装成逐字引文。

全表依据B04、B06、B07。家族、动物与身体是文本取象，不是现代遗传关系、性别本质或解剖因果。八卦符号为三画；下一节同名乾坤等卦是上下同卦相重的六画卦，层次必须分开。

动力模型可从这些属性选择观察方向，但必须说明增补了什么：

| 卦 | 有文本依据的动力线索 | 可提出的现代桥梁 | 不能直接声称原典已经给出 |
|---|---|---|---|
| 乾 | 健、君；乾知大始；既有静也有动 | 以主动更新、持续施作为一种候选机制 | 能量源、永动、全能控制者；乾永远动而没有静 |
| 坤 | 顺、藏、致养；坤作成物；动辟静翕 | 承接、保持、资源条件或承载机制 | 完全惰性、没有自身动态的环境；顺必然服从任何控制信号 |
| 震 | 动、万物出；雷动 | 扰动、启动、显著变化的事件类型 | 固定幅值脉冲、唯一启动因、任意相变都属于震 |
| 巽 | 入；风散；木风；进退 | 渗入、传播、条件性的扩散过程 | 普适扩散方程、单向传输、熵必增 |
| 坎 | 陷、水；水润；重险而水流 | 约束、风险、流动中的通道或困难条件 | 必败、永不退出的陷阱、负价值固定标签 |
| 离 | 丽；火日；明与相见；日月草木有所丽 | 依存、附着、可见性或显现机制 | 丽即现成的 `attach` 指令；离在此必为分离；火即信息 |
| 艮 | 止；终始；时止则止、时行则行 | 门限停止、边界、条件切换 | 永久吸收态、天然稳定吸引子、所有动态终止 |
| 兑 | 说〔悦〕；泽；口；朋友讲习 | 在限定领域中的交流、响应、协调候选 | 所有交换必互利；悦必然正反馈；口即通信协议 |

“有文本依据”与“现代桥梁”分列，正是为了保留可推演性。桥梁不是禁用的猜想，而是可以被修改、比较与反驳的明确假设。

第十一章的“坤为文”、第五章的“离也者，明也”确实提供同字联系。但12中原有“文”的关系结构义、“明”的辨识义，仍须核对各自选义；相同字形不能完成全部语义等同。

## 四、《系辞》对组合、变化与时间的支持

### B08：《系辞上》

[《系辞上》原文](https://zh.wikisource.org/wiki/易傳/繫辭上)中，下列段落各有职责：

| 网页章次 | 短引 | 可支持的区分 |
|---|---|---|
| 第一章 | “刚柔相摩，八卦相荡” | 关系与相互作用的表述；没有给八卦之间唯一转移图 |
| 第二、三章 | “刚柔相推而生变化”；“爻者，言乎变者也” | 爻、辞与变化的联系；不等于每一爻都是已发生的现实事件 |
| 第五章 | “一阴一阳之谓道”；“生生之谓易” | 合举阴阳及持续生成的语义入口；不直接推出任何系统必可持续 |
| 第六章 | “乾，其静也专，其动也直”；“坤，其静也翕，其动也辟” | 乾与坤都存在动静方面；反对机械地把乾=动、坤=静当穷尽定义 |
| 第十章 | “参伍以变，错综其数” | 对数与变化的操作性论述；本句不是今日错卦、综卦两函数的完整定义 |
| 第十一章 | “一阖一辟谓之变，往来不穷谓之通” | 阖辟、往来与变通的联系；须另给对象、条件和时间才能建模 |
| 第十一章 | “易有太极，是生两仪，两仪生四象，四象生八卦” | 文本有此生成序列；逐层加画的具体解释须再标注家层 |

### B09：《系辞下》

[《系辞下》原文](https://zh.wikisource.org/wiki/易傳/繫辭下)第一章说“八卦成列，象在其中矣；因而重之，爻在其中矣”。这是三画与六画层级、象与爻的关键线索。第二章“易穷则变，变则通，通则久”已在05的Y04、09案例中展开；它不取消该处原有的制器尚象与制度叙述背景。

第七章既说“变动不居，周流六虚”，也说“六爻相杂，唯其时物也”。这支持关注时、位、对象及变化语境；不能只抽出“变”而删除具体条件。该章的“非其中爻不备”，没有在句内列出取第二三四爻和第三四五爻的互卦算法。

第八章“道有变动，故曰爻；爻有等，故曰物；物相杂，故曰文”，适合保留“爻—物—文”的中介层。直接把单爻变动等同整个文，会丢失组合层级。

以上文本可启发状态、过程、语境与组合的分工。G1的类型检查、关系复合、交集、闭包以及正时间步 `tick`，仍是本项目的形式化设计。

## 五、八纯卦与四个组合卦的校正证据

本节中的“经”专指卦爻辞；彖、象、文言均属“传”。上下卦按下在前、上在后列出。

| ID与来源 | 卦体与短引 | 可支持的选义与关键限制 |
|---|---|---|
| B10 [乾](https://zh.wikisource.org/wiki/周易/乾) | 乾下乾上。《彖》“万物资始”；《象》“天行健”；上九经“亢龙有悔”，《象》“盈不可久也” | 发始、健行有据；过亢及盈不可久限制无限强化的读法。《文言》“先天而天弗违，后天而奉天时”中的先后天，不是后世两幅图的题名 |
| B11 [坤](https://zh.wikisource.org/wiki/周易/坤) | 坤下坤上。《彖》“万物资生，乃顺承天”；《文言》“坤至柔而动也刚” | 顺承与生成有据；坤不能被穷尽为无动态的被动背景 |
| B12 [震](https://zh.wikisource.org/wiki/周易/震) | 震下震上。经“震来虩虩，笑言哑哑”；《象》“君子以恐惧修省” | 震动连着惊惧、修省、祭祀的语境；不只是一个无语义的开关脉冲 |
| B13 [巽](https://zh.wikisource.org/wiki/周易/巽) | 巽下巽上。《彖》“重巽以申命”；《象》“随风，巽；君子以申命行事” | 风、命令重申与行事可作为传递机制的类比入口；未给传播速度或扩散方程 |
| B14 [坎](https://zh.wikisource.org/wiki/周易/坎) | 坎下坎上。《彖》“习坎，重险也”；“水流而不盈，行险而不失其信” | 危险与在险中行并存；“陷”不等于必然失败或永无出路 |
| B15 [离](https://zh.wikisource.org/wiki/周易/離) | 离下离上。《彖》“离，丽也；日月丽乎天，百谷草木丽乎土” | 日月、草木有所附丽的例子，为“丽”的依附方向提供文本支撑；现代依存关系仍须具体定义 |
| B16 [艮](https://zh.wikisource.org/wiki/周易/艮) | 艮下艮上。《彖》“时止则止，时行则行，动静不失其时” | 止必须受时宜约束；艮不能由文本直接定为不再离开的状态 |
| B17 [兑](https://zh.wikisource.org/wiki/周易/兌) | 兑下兑上。《彖》“兑，说也”；《象》“君子以朋友讲习”；六三经“来兑，凶” | 悦与讲习有据；文本并不承诺任何悦或交往都吉 |
| B18 [泰](https://zh.wikisource.org/wiki/周易/泰) | 乾下坤上。《彖》“天地交而万物通也，上下交而其志同也” | 交与通的关系明确；属于该卦解释，不能推出一切耦合都改善系统 |
| B19 [否](https://zh.wikisource.org/wiki/周易/否) | 坤下乾上。《彖》“天地不交而万物不通也”；上九《象》“否终则倾，何可长也” | 同两经卦不同上下位置形成不同解释；否也没有被定为永久终局 |
| B20 [既济](https://zh.wikisource.org/wiki/周易/既濟) | 离下坎上。经“初吉终乱”；《彖》“终止则乱，其道穷也”；《象》“思患而豫防之” | 已成仍有终乱与预防问题；既济不能直接等同永久稳定均衡 |
| B21 [未济](https://zh.wikisource.org/wiki/周易/未濟) | 坎下离上。《彖》“虽不当位，刚柔应也”；《象》“慎辨物居方” | 未成并不等于完全无结构、无关系或必败 |

泰—否、既济—未济可用于展示“组成相同而位置不同，整体解释不同”。将上下互换实施为一个符号变换很清楚；要证明现实水火或天地会按该变换变化，还须物理对象、边界条件和机制。

## 六、三种次序与三类转换不能混同

### 1. 阶段次序、先天图和传世六十四卦序

B04的阶段次序是震、巽、离、坤、兑、乾、坎、艮。将艮的终始联系到下一轮震，可以构造循环叙述图；将图上的每一步视为等时状态转移，则是新增模型假设。

**B22** [《序卦》](https://zh.wikisource.org/wiki/易傳/序卦)解释传世六十四卦的排列。《序卦》有“物不可以终动，止之，故受之以艮”，紧接着又说“物不可以终止，故受之以渐”；末尾以“物不可穷也，故受之以未济；终焉”收束。它可支持次序解释与终始不封闭的阅读，但不是八状态的后天方位环。本文称“传世六十四卦序”；使用习称“文王卦序”不等于在此证明其个人编定史。

**B23** [《杂卦》](https://zh.wikisource.org/wiki/易傳/雜卦)有“震起也，艮止也”“兑见而巽伏也”“离上而坎下也”“否、泰，反其类也”，以及“既济，定也”。这是另一组语义对举。既济“定”须与B20初吉终乱共同阅读，不能独摘一字证明永稳；对举的语义关系也不等于现代倒序或取反函数的定义。

**B25** [《朱子语类》卷六十五，“伏羲卦画先天图”](https://zh.wikisource.org/wiki/朱子語類_(四庫全書本)/卷065)详论“乾一、兑二、离三、震四、巽五、坎六、艮七、坤八”及乾南坤北、离东坎西等先天图式。这是宋代易学解释层的直接材料。它还记录先天图与“文王卦序亦不相应”的讨论，足见不同图序不应拼成一条统一历史链。

**B29** [胡渭《易图明辨》题辞](https://zh.wikisource.org/wiki/易圗明辨_(四庫全書本))对将后出图式增入经文提出异议；**B31** [黄宗羲《易学象数论·八卦方位》](https://zh.wikisource.org/wiki/易學象數論/八卦方位)也批评“文王改先天图”的解释。此处援引它们证明后世存在明确争论，不以其中任何一家代替完整的图学史考证。稳妥结论是：图式可以作为研究传统使用，其伏羲亲作、文王改作的归属不能仅凭后世命名当作已证史实。

### 2. 爻变、错、综、互卦的历史层级

|---|---|---|---|

B28重点句和B30重点注段同时核对了参照项目的冻结正文；B30转录中“画”有“畵”异体。本册没有依赖缺失的图像字。

若采用现代编码，明确从下到上令阳为1、阴为0。三爻 `b=(b1,b2,b3)` 的指定爻翻转、全位取反和倒序分别为：

```text
flip_i(b)：仅把第 i 位的 0/1 互换
complement(b)：(1-b1,1-b2,1-b3)
reverse(b)：(b3,b2,b1)
```

六爻 `h=(b1,b2,b3,b4,b5,b6)` 的互卦编码可写为：

```text
nuclear(h)=(b2,b3,b4,b3,b4,b5)
```

以上函数式是本项目对明确选定操作的现代精确表达。它们操作的是卦画；将这些操作赋予实际持续时间、概率、驱动变量与状态更新规律，是另外一层工作。尤其综卦是上下倒序，不应默等于“仅交换上下两个三爻块”：两种运算对一般六爻卦不同。

## 七、与113字、G1及动力学名词如何相接

| 连接 | 文本能提供什么 | 现代模型必须补什么 |
|---|---|---|
| 八卦—113字 | 某些字有直接同字依据，如动、明、文；另有意义相关的取象、功能与时序 | 逐项指定原词表义项、对应类型、是否一对多；不把113字硬分成8个互斥类别 |
| 八卦—G1 | 卦画组合、性质释义、上下位置、变化及关系的材料 | 卦画或卦名的类型、状态判据、程序关系、参数域；区分“描述某状态”与“从某状态走向另一状态” |

## 九、本轮核查结论

可以直接立于原典的，是八卦多层取象、性质释义、不同相互关系、阶段次序、重卦与位置差异，以及对变化、时宜和成终成始的论述。可以明确归于后世解释的，是本册已具名定位的图式、加画解释、错综及互卦方法。可以由本项目精确定义和验证的，是这些结构在指定编码、状态、规则和时间下产生的数学性质。

“八卦具有可用于构造动力模型的结构资源”有上述证据支持；“古代八卦已是一套与现代动力系统完全相同、能无需增补地计算现实的理论”，没有由本轮证据建立。
