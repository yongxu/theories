# 文的组合规则与系统推演

八卦、语词与系统能够组成可推演的表达，关键在于保存三个相互连接的层次：**当前各部分怎样组织，什么条件允许变化，变化之后能得到什么。**“文”提供理解配置的入口；过程规则赋予配置以动态；完整的辞将对象、条件、过程和判断说清楚。

本册将15号文档的映射落实为组合规则，并以两个公开定义的现代模型检验。原典依据、解释选择及模型结论分别列出。规则沿用G1的类型和语义，不新增可以跳过定义的万能算子。

## 一 一句完整表达必须保存什么

可以采用下面的现代受控表达模板：

> 在情境c中，a居于p，b居于q，二者以R相接；当条件P成立，过程π可以执行，并保证终态满足Q。若另有评价，则注明谁依何标准，对哪个结果或行动作出何种判断。

这里的各部分有不同职责：

| 要素 | 回答的问题 | 在现有文法中的位置 |
|---|---|---|
| 所指与义项 | 说的是哪个对象，取哪个意思？ | 有类型的对象项与解释记录 |
| 位与关系 | 谁处在何处，以什么方向或方式相接？ | 描述命题 Formula |
| 时与条件 | 何种阶段、状态或历史使行动适用？ | 模型上下文及明确的条件命题 |
| 变化过程 | 哪个前态可以进入哪个后态？ | 过程 Program |
| 后果 | 有可能达到，还是所有允许结果都达到？ | 存在或全称模态命题 |
| 判断 | 文本如何断言，目标如何评价，行为是否应当？ | 文本、结果评价、规范分别记录 |

《系辞下》“六爻相杂，唯其时物也”把组合与时物相连；“二与四同功而异位，其善不同”说明位置参与解释。由这些材料建立上述字段，是现代文法的明确设计。[《系辞下》第七、八章](https://zh.wikisource.org/wiki/易傳/繫辭下#第七章)

“时”有时指时机或阶段，在数值模型中又可以指经过的时间；“位”可以是爻位、空间位置或职分。模型必须选定本次含义。例如水位的数值不因为也有一个“位”字，就自动等于六爻位置。

## 二 八条可以检查的组合规则

下列八条为本项目的设计规则。原典栏标明解释入口，不声称古文已经给出现代形式系统。

| 规则 | 必须做到什么 | 原典入口与解释范围 |
|---|---|---|
| 选义 | 字词连到一个已说明语境、参数和用途的义项 | “当名辨物”；具体称名需要辨清所指 |
| 定位 | 保存组成者的角色、上下、内外及其他有关位置 | “同功而异位”；相同性质不抹去位置差别 |
| 联结 | 给关系命名，并保留方向、对象类型与条件 | “物相杂，故曰文”；具体配置需要具体关系 |
| 成式 | 将相容的描述组成完整状态条件 | “设卦”“系辞”提供整体解释的入口；逻辑合取是现代规则 |
| 定时 | 将可执行条件、阶段或所需历史写进模型 | “变通者，趣时者也”；适时不等于任意时刻均可执行 |
| 明变 | 明确过程、步长、变化对象及保留条件 | “刚柔相推”“效天下之动”；数值更新另行定义 |
| 转合 | 前段结果满足后段条件，而且后段有允许的执行 | “变而通之”提供问题方向；非空顺接由G1精确定义 |
| 断辞 | 保留可能、保证、已发生、预测与规范之间的区别 | “爻彖以情言”“正言断辞”；判断要有对象和适用范围 |

主要出处：[《系辞下》第一、三、五、七至九章](https://zh.wikisource.org/wiki/易傳/繫辭下)、[《系辞上》第十二章](https://zh.wikisource.org/wiki/易傳/繫辭上#第十二章)。八条规则与G1“辨、系、序、化、限”的关系是进一步落实，不替换原有核心产生式。

## 三 通必须区分结构 行动与结果

假设A与B之间有通路，B与C之间也有通路。可以据此谈对象图中的连接链。若要得到“消息从A到达C”，还必须有发送、接收和转发过程，并满足它们的条件。

| 表达 | 实际承诺什么 |
|---|---|
| A与C在对象图中可达 | 存在符合所定义边关系的对象链 |
| 发送过程可执行 | 当前状态存在一个允许的后继 |
| 发送后可能到达C | 至少一条允许执行具有所需结果 |
| 发送后保证到达C | 所有允许执行都有所需结果，且确实存在执行 |
| 已经到达C | 某次实际运行或观察确认到达 |

对象图的节点是A、B、C，过程图的节点是整个系统的状态。这两张图之间可以建立对应，但对象间的一条边不能直接代替系统的一次状态转移。

配置本身也有一条明确的接合规则。若两个关系模板分别描述A连到中介m、m连到C，它们可以通过同一个m组成更大的配置：

```text
配置接合(A,C) := ∃m:Entity. (Link(A,m) ∧ Link(m,C))
```

这里使用G1已有的合取和存在量化；A、C须先实例化或由外层量化绑定，m须采用不与外层冲突的变量名。两个接口必须属于相容类型，并指向同一个实例。若只有A→B和D→C，且B与D不同，就不能把两段拼成A到C的链。B、D同属一个卦象类别，也不能代替实例相同。

这给组合提供了两种不同的接点：**配置通过共同对象接合，过程通过前后条件接合。**前者建立更大的关系表达，后者建立更长的允许历程。

泰《彖》“天地交而万物通”可以作为研究相交与通达关系的文本入口。具体模型需要说明采用上述哪一种“交”和“通”，以及二者之间的机制。[《泰·彖》](https://zh.wikisource.org/wiki/周易/泰)

## 四 转合怎样形成真正的组合规律

在G1中，P和Q是状态命题，π是过程。定义一个可以完全展开的现代表达：

```text
C(P, π, Q) := P ⇒ (〈π〉真 ∧ [π]Q)
```

意思是：P成立时，π至少有一次允许执行，而且所有允许终态都满足Q。要求非空，是为了避免把“没有任何后继，所以没有反例”误当成过程成功。

若同一模型的所有状态都满足：

```text
C(P, π, Q)
C(Q, ρ, R)
```

就能得到：

```text
C(P, π ; ρ, R)
```

理由是：从任一满足P的状态，π有后继；每个后继都满足Q，因而ρ在这些状态也能执行；所有ρ的后继都满足R。实际使用时仍要检查起点满足P。

**这给“转合”一个可检查的含义：前段形成后段的条件，后段接续前段的结果。**配置在过程之间作为可共享的条件，过程依此顺接。两个过程名写在一起，并不足以成立这条规律。

其他组合仍沿用G1：同一状态下合并描述用合取；允许多种过程用选择；需要同一个前后态同时获准时用关系交集；重复过程用有限重复或闭包。不同组合回答不同问题，不能都叫作笼统的“合”。

## 五 泰否入口下的双单元反馈模型

本例借泰否的“交／不交”提出关于联结的问题，使用现代信号模型作回答。它只选取一个关系侧面，不把现实状态直接判为完整泰卦、否卦或吉凶。

两个单元A、B的无量纲信号记为x、y，每一步为1秒。定义：

```text
x(t+1) = p · y(t)
y(t+1) = q · x(t)
```

p表示B作用于A的强度，q表示A作用于B的强度。在本例中p、q均非负，初态为(1,0)。当两者均非零时，两单元互相作用，并在两步后回到原单元：

```text
x(t+2) = p q · x(t)
y(t+2) = p q · y(t)
```

因此，固定关系图之后，长期行为仍取决于作用强度：

| 参数 | 两步总作用pq | 对所有初态的数学性质 |
|---|---:|---|
| p=q=0.5 | 0.25 | 信号收敛到零，原点具有全局吸引性 |
| p=q=1 | 1 | 两步回到原态；已有振幅保持，邻近轨迹不因此趋向同一条轨道 |
| p=2，q=1 | 2 | 每个非零初态的范数在两步采样下倍增，原点不稳定 |
| p=0，q=1 | 0 | 只有A到B的单向作用；任意初态至多两步归零 |

前三行的双向关系图相同，长期结果不同。第四行还说明：收敛可以在没有双向闭环的情况下发生。因此，**联结形式、反馈存在和稳定性，是三个需要分别判定的性质。**反馈的现代定义可参见[MIT反馈课程](https://openlearninglibrary.mit.edu/courses/course-v1%3AOCW%2B18.031%2B2019_Spring/courseware/week6/lec10/)，上表结论直接由本例方程推导。

本例在pq=1处改变稳定性性质。若要进一步讨论某个物理系统的相变，还须指定物理对象、序参量和相变判据；表中的信号增长本身只给出这个离散模型的动力结论。

## 六 艮止时行入口下的条件控制模型

艮《彖》“时止则止，时行则行”将止行与时宜一起解释。本例据此提出一个现代问题：怎样在明确条件下停止，并在条件改变后重新运行？[《艮·彖》](https://zh.wikisource.org/wiki/周易/艮)

设水箱水量h取整数0至6单位；泵运行时每秒流入2单位，持续流出1单位；停泵时只保留流出。每一步为1秒。低阈值为2，高阈值为4：水量不高于2时开泵，不低于4时停泵，在中间区间保留原模式。

系统状态是“水量、当前泵模式”这两个量。每一步先按当前模式更新水量，再根据新水量决定下一步模式。允许状态共八个：0开、1开、2开、3开、3停、4停、5停、6停。

从4停出发，完整一轮为：

```text
4停 → 3停 → 2开 → 3开 → 4停
```

这里有三个不同层次的结论。

第一，**泵止，水仍在变。**4停经两秒到2开，停止模式并非整个系统永远停留的终点。谈“止”必须交代哪个对象、哪一种活动停止。

第二，**同样的水量可以需要不同的下一步。**3开下一步为4停，3停下一步为2开。两个阈值之间保留原模式，形成滞回：当前动作还取决于之前进入的模式。因此，“时”在模型中不仅可以是钟表时间，也可以由状态中保存的历史条件来落实；这是本次建模选择。

第三，四态循环在本例完整的八状态域中吸引所有轨迹，循环外的四个状态至多两步进入循环。具有吸引性的是由完整规则形成的循环集合；单个“停”标签并不承担这个性质。这个结论限于所声明的流入、流出与阈值。

第四节的转合也可以直接落在此例：以P表示4停，Q表示2开，π和ρ都取两次真实时间步。先检查P经π可行且保证Q，再检查Q经ρ可行且保证P，就能得到从P出发四步回到P。完整验证同时检查每一中间状态及时间推进。

## 七 取象需要保留哪些差异

在双单元模型中，如果只保存“双向相通”这一标签，就失去决定消退、保持或增长的参数。关系图适合回答有没有回路；要回答稳定性，还需保留作用强度。

在水箱模型中，如果只保存水量而删去泵模式，3开和3停都会被映为3，却分别走向4和2。因此，单靠水量无法给出唯一的下一步规则。可以保留泵模式，也可以改用允许多个后继的抽象；后一种做法还应检查它是否增加了现实中不存在的路径。

这说明取象的尺度要由所问的问题决定：**为分类够用的表示，未必为预测够用；为一步推演够用的表示，也未必保留所有长期性质。**已有14号验证包保存了粗化产生假循环及共同终点丢失的反例。

对应到八卦与中文字：卦名、字形或单个性质，可以成为查询入口；时、位、关系、作用条件及必要历史，则需要留在完整表达中。把这些信息组织起来，才形成可继续组合的“文”。

## 八 判断怎样接回文辞

“稳定”“安全”“适宜”和“吉”不是同一个判据。信号归零对消除噪声可能有益，对维持信息则可能不利；水箱模型在2至4之间循环，是否合适取决于用水目标和允许范围。

原文中的吉凶先作为有篇章与情境的占断或判断保存。现代模型若要评价结果，应另外说明涉及的主体、对象、期限、目标与损益判据；若要表达应当、允许或禁止，再依相应规范接入G1的规范接口。这样既能保留文辞的判断功能，也能避免将预测、目标达成和行为义务压成一个真假标签。
