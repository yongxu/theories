# 文卦系统映射验证

这两组现代示范检验16号文档的组合规则：同样的双向关系能否决定长期行为，停止怎样随条件重新转为运行，以及两段过程怎样通过前后条件接合。原典提供解释入口，状态、参数、时间和更新规则由本项目公开定义。

全部163项断言通过，其中调用现有G1解释器作124次命题求值。计算结果证明的是给定模型的性质，不代表完成了实际设备或历史解释的经验验证。

## 两组模型的结论

| 模型 | 定义 | 验证结果 |
|---|---|---|
| 双单元信号 | 每秒更新x'=p·y，y'=q·x；初值为(1,0) | 相同双向作用图，在不同强度下分别消退、保持或增长；两步更新等于原信号乘pq |
| 条件止行水箱 | 低阈值2、高阈值4；开泵每秒入2单位，持续出1单位；中间区间保持原模式 | 八个完整状态最终进入四态循环，至多两秒入环；停泵后仍可重新开泵 |

水箱循环为：

```text
2开 → 3开 → 4停 → 3停 → 2开
```

3开与3停具有相同水量，却分别走向4停与2开。因此，保留水量但删去泵模式，会丢失决定下一步的信息。循环具有本有限模型中的吸引性，单个“停”标签没有这种保证。

双单元模型的无限时间结论由恒等式M²=pqI推出，0至12秒的数值轨迹用于展示与核对。信号是无量纲幅度，不是守恒物质、能量或信息量。G1对A模型仅查询另行定义的有限作用路径，其状态表示作用所在位置；这不构成数值信号动力系统的完整有限抽象。B模型则直接以八个完整状态进入G1。

## 已核验的接合与反例

令P表示4停、Q表示2开，π与ρ各为两秒更新。验证了：

- P成立时，π可执行且所有结果满足Q。
- Q成立时，ρ可执行且所有结果满足P。
- 两者顺接，从P出发四秒回到P；两个前提集合均非空。
- 三秒更新不能得到同一回返结论，步长不可随意删去。
- 空过程没有后继，虽然“所有后继满足Q”形式上为真，但可行性为假，因此不满足非空保证。
- 删除一个反馈方向之后，信号仍可在两步归零；双向闭环不是本例收敛的必要条件。

另有不保留中间模式的单阈值对照。该对照的周期为两秒，长期每秒切换一次；双阈值模型的周期为四秒，长期每秒切换半次。此比较限于整数水量、固定一秒采样及指定流量，不推断连续系统的无限频率抖振。

## 文件与复核

| 文件 | 内容 |

| [results.json](results.json) | 全部结论、逐态查询、轨迹、循环及反例 |

使用Python 3.9或更新版本，标准库即可。从本目录执行：

```sh
python3 verify_models.py --check
```

脚本向上寻找现有10号目录中的G1解释器，不修改该引擎。若将本目录单独移动，可以显式指定引擎路径：

```sh
python3 verify_models.py --check --engine /absolute/path/to/wenli.py
```

默认不加`--check`时，脚本重新生成本目录三个JSON文件；加上该选项只核对，不改写。模型与预期结果不一致时以错误退出。
