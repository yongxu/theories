**文之立名。** 立名之法，是看理论中有没有一个结构，恰好是这个字所说的。名表的其他名也是这样定的。文理生生的词典给文三义：可读之纹（文¹）、书写之文（文²）、所读之构（文³）。在核心中，有一个对象，篇九的知来之线每一环都陈述在它上面，而它在名表中原无其名：一历之状经一象逐步之值（`Becoming.Parting.course`、`Becoming.Learnable.course`）。本章以「文」名之：

> 文，一历之状经一象逐步之值也。

理由有四（讀，AI，D63）：

- **出处。** 系辞上「通其变，遂成天下之文」〔DS02〕相合：文沿一变之行而成。系辞下「物相杂，故曰文」〔DS03〕定域：文的诸状只由逐步之值之异分开；原句之杂是一卦六爻同时之杂，那是一状，不是文。
- **文之状与法自文读出。** 自二步起逐步之值皆同，这二步即是一状（`Becoming.SameAhead`）；二步为一状，其次步亦为一状（`Becoming.SameAhead.next`）。所以文不须先给状，也不须文外的立法者。法之一行，读出的状恰是同（`Becoming.IdentificationRuns.sameAhead_iff_alike`）。
- **三义归于一文一理。** 一时之纹是一状经一象之值，即像；沿步而读，就是文（文¹）。一部书是以名为值的文，名经码配义项（文²）。所读之构不是文，而是理：变随之而同的类（文³，七·二）。法经一象示之时，守象之值之理所并之二状皆文同（`Becoming.Law.sameFuture_of_law`）；守值、为理而又并凡文同之状者为正名（`Becoming.Law.identifiesAlike_of_law`）。所以「文理」二字，在本表中是一个关系：守值之理中最粗者，所并恰是文同之状（`Becoming.Law.coarsest_iff`，一条定理）；理自文读出，只在此义。
- **认识论在它上面。** 往是文之前段，知来、符、阙、终而复始、不测、可知、衢都陈述在文上，「读书百遍，其义自见」的三条律也陈述在文上（本章第一部分）。

不取的名：「历程」（与历相混：历给状与动，文只给值）；「序」（名表已名所给之序）；「迹」（名表中的足迹是一状所履之物，见所履、分；「所以迹」不采为名，见中华本附录二）；「像」（文于一步之值即像）。二状于一法经一象逐步之值皆同，谓之文同（`Becoming.Law.SameFuture`）。

### 一、文：一历之状经一象逐步之值

中华本已有以下一组名：

- 状、动、步（一·三）：状是大化于一步之所是，动是步间之所移，步是诸物共计之自然数序。
- 象与读（一·三）：象予所施之每一者一值，读是以一象予状以值。一者经象之值，叫像（七·一）。
- 历（名表：「沿步之状与动之任一序列，不问它是否为某变所许」）。为某变所许之历是行（一·四）；凡历皆其自然之法之行（一·七）。
- 同（一·二十二）、往（五·六、九·十八）。

篇九的知来之线，即知来与符（九·二十九）、往不定来与不测（九·三十）、过则改（九·三十一）、终而复始（九·三十二）、有界则往定其行（九·三十三）、可知（九·三十五）、衢（九·三十六），都陈述在同一个对象上：逐步之值，Lean 中的 `o : Nat → O`。`Becoming.Learning` 的模块说明这样界定它："A course is a sequence of values, such as a determined law's orbit read through a map"。中华本的经原称它为「历程」，名表无其名。称它为历程，会误示其状与动已给；而它的要点，恰在于状由它读出。所以中华本今以「文」名之（一·二十一，名表第七次之改）。

**所名（讀，AI，D63）。** 「文，一历之状经一象逐步之值也。」

中华本一·二十一之经：

> 文，一历之状经一象逐步之值也。凡逐步之值皆文：以每步至其次步为法、以此值为象，二步同，恰当自二步起逐步之值皆同；二步同，则其次步亦同：文之状与其法皆自文读出，不须给状。法之一行，其经一象之文二步同，恰当法经此象示之，此二步之状同。二状于一法经一象，其文逐步皆同，谓之文同。

经中「二步同」，即二步为一状（`Becoming.SameAhead`，见律 1）；「法经一象示之，二状同恰当文同」在其说中（`Becoming.Law.alike_iff_sameFuture`）。

- 一变之一行 r 经象 reg 之文：`Becoming.Parting.course reg r n = reg (r.state n)`。法下自一状 s 起者：`Becoming.Learnable.course next reg s n = reg (Law.orbit next s n)`。
- 凡逐步之值皆文。每一 `o : Nat → O`，都是自由分支之变（每状之后可接每状）的一行经恒等之象之文（`Becoming.Parting.freeRun_course : course id (freeRun o) = o`，按定义）。
- 文只给值，不给状与动。文于一步之值，就是那一步之状的像。
- 文理生生之文与此名（讀，AI，D63）：文理生生给文的工作定义是「有差异的成分，在一定关系与时序中呈现出的可辨样态」，并说这一定义已借用差异、关系与时序，所以「以文为基」是「研究入口与组织原则」，不从文推出五元（[基础全图 §一](../../../sources/wenli-shengsheng-v0.4/research/references/03_文理生生_基础全图与动态文法_v0.2.md)）。其逐字映射说文「描述差异成分如何形成可辨配置，跟踪配置随时间改变」（[逐字映射](../../../sources/wenli-shengsheng-v0.4/research/references/04_逐字动态映射与古文出处_v0.2.md)文行）；其模型骨架把观察记为 `y_t = H_c(S_t, 观测条件)`，含漏检、分辨率与误差（基础全图 §五）。沿一轨迹逐步之 y_t 与此处之文部分同构：H_c 当象，但另含观测条件与误差，核心之象是一函数。此处之文也有所借：共同之步标，与以相等比较之值（名表文之注「所依之拟」）；其名是一项约定（「未决与限度」）。

**文同（讀，AI，D63）。** 「二状于一法经一象，其文逐步皆同，谓之文同。」Lean 中即 `Becoming.Law.SameFuture next o s s'`，定义为 `∀ n, o (Law.orbit next s n) = o (Law.orbit next s' n)`：二状的 `Learnable.course` 逐步相等。n = 0 也在其中，所以文同含当步之值。

**律。**

1. **文的状与法读自文，不须给状。**
   - 文的二步为一状（`Becoming.SameAhead o t t'`，定义）：自此二步起，逐步之值皆同。
   - 以每步至其次步为法、以此文为象，二步同（一·二十二），恰当二步为一状（`Becoming.alike_moments_iff`）。这条律近于定义：它把一·二十二的同用在步之相继这一法上（经 `Becoming.Law.alike_iff_sameFuture`）。
   - 二步为一状，则其次步也为一状（`Becoming.SameAhead.next`）。诸状依自身而行，所以状之法也读自文。
   - 每步之值皆新，则每步自为一状（`Becoming.SameAhead.new_each`）。
   - 沿一法之轨，文的二步为一状，恰当这二步之状文同（`Becoming.sameAhead_orbit_iff`）。
   - 讀（AI，D63）：除了拟所共用的步标，文不须先给一法。状与法都读自文，文外没有立法者。这与历的情形同构：凡历皆其自然之法之行（`Becoming.Shown.run`，§二）。历给出状与动，读出的是法；文只给值，读出的是状与法。
2. **法之一行：文的状就是同。** 这一条是实质之律。
   - `Becoming.IdentificationRuns.sameAhead_iff_alike`：r 是一法之行（`Run (Law.process next)`）时，它经 reg 之文的二步为一状，恰当这二步之状在法经 reg 所示之系辞中同。
   - `Becoming.Law.alike_iff_sameFuture`：法经一象示之，二状同，恰当文同。
   - 所以在法之下，从文读出的状恰是同的诸类，不须先立商。
3. **文的状有穷，恰在它终而复始。**
   - `Becoming.finitely_many_states_iff`：有某个 L，使文的每一步都与 L 步之前的某一步为一状（`StatesBelow o L`），恰当有二异步为一状，也就是其值自某步起重复。证明用的是一关系上的鸽笼之律（`Becoming.shared_below`），不判定任何东西。
   - `Becoming.finitely_many_states_iff_lasso`：这也恰当文终而复始（`Becoming.Learning.Lasso`）。
   - 一状若复，则经每一象，自它起之文都有二异步为一状（`Becoming.Law.Returns.states`），所以依前一条，状有穷。
4. **有界：有穷之往定文。**
   - `Becoming.Identification.sameAhead_iff_below`：文的状不过 N 种（`StatesBelow o N`）时，二步为一状，恰当自这二步起 N＋N－1 步之值皆同。
   - `Becoming.Identification.sameAhead_iff_within`：同样的条件下，N－1 步已足，且不须判定值之同异。这是一文之内的 Moore 之界。
   - `Becoming.Identification.bounded_agree`：二文的状分别不过 N 种、N′ 种，于 N＋N′－1 步之前皆同，则处处皆同（九·三十三）。
   - `Becoming.Identification.bounded_agree_exact`：有二异值时，对每一对 M、M′，都有二文，状分别不过 M＋1 种与 M′＋1 种，于 M＋M′ 步之前之往相同，而在这一步异。所以对二文而言，N＋N′－1 这一长对每一对界都确切。
   - `Becoming.Law.sameFuture_iff_within`：法之下，一族之状闭于此法时，族中二状文同，恰当其文于族之员数减一步之前皆同；不须判定值之同异。

**篇九的知来之线皆在文上。** 这条线的每一环都陈述在文上，每一环有一条已检之律：

| 环 | 在文上所名 | 律 |

| 衢 | 二行之文于某步之前皆同，于此步异（`Becoming.Parting.PartAt`） | 于衢，没有一个知来于此步于二行皆得（`Becoming.Parting.not_right_on_both`） |

讀（AI，D63）：所以这条线是 文 → 往 → 知来、符、得、阙 → 过则改 → 终而复始 → 有界则往定其行 → 可知 → 衢 → 不测。类、理、推类都不是文（§四）；理自文读出只在一义：法经一象示之，守象之值之最粗之理所并者恰为文同之状（一·二十一，`Becoming.Law.coarsest_iff`）。识是一个待者经其感读它自身之所历，也在展开之中：感读作值时，它所择者恰依它自身之文之往（§六）。

- 「参伍以变，错综其数，通其变，遂成天下之文，极其数，遂定天下之象」〔DS02〕

  - 「通其变，遂成天下之文」相合（讀，AI，D63）。以名表之名读：通是行之可续（「推而行之谓之通」〔DS02〕），变是过程（「化而裁之谓之变」〔DS02〕）。文定义在行上：`Parting.course` 以一变之一行为参，`Learnable.course` 是法自一状之轨。所以文只沿行而成。在有穷多状之中，自一状起有一行，恰当自此状起有一程，其长等于诸状之族的员数（`Becoming.Onward.run_iff_continues`，若：一族尽其状；八·八）。

### 二、律读自展开：内在生成的解释

**古书。**

- 「天行有常，不为尧存，不为桀亡。」〔RU2-S-XZ17〕
  - 相合，与 [RO 一章 p-ru-xunzi-tian-xing-you-chang](CHINESE-SOURCES-AND-BECOMING.md#p-ru-xunzi-tian-xing-you-chang) 和[脉络一章 §四·四](CIVILIZATION-THOUGHT-AND-BECOMING.md)相同：有一法许一段历，恰当此历不忒（`Becoming.exists_law_iff`）。
  - 天不立为名（中华本附录二），只用「天行」作展开之行。同段「应之以治则吉，应之以乱则凶」中的吉凶不带。
- 「圣人有以见天下之动，而观其会通，以行其典礼」〔DS02〕
  - 定域：从所见之动读出其会通，即有一法许之，恰在所见之历不忒之处成立（`Becoming.exists_law_iff`）。
  - 圣人这一中心、「以行其典礼」，以及其后的「系辞焉以断其吉凶」，都不带。
- 「神以知来，知以藏往」〔DS02〕
  - 「神以知来」相分：这是不经感的前知（中华本九·十八，脉络一章 §四·三）。
  - 「知以藏往」相合：已采之动，往定其果（`Becoming.Run.fixes_of_takes`）。

**律。**

- **历之层。**
  - `Becoming.Shown.run g m : Run (Shown g m)`：每一历都是它的自然之法的一行（一·七），无设。`Shown g m` 只许此历所经之移。
  - `Becoming.shown_le_iff`：自然之法是以此历为行的最小之变。一变含自然之法的每一移，恰当它许此历的每一步。
  - `Becoming.shown_determined_iff`：自然之法为法，恰当此历不忒（`Consistent g m`：两次在同一状以同一动，果都相同；一·八）。
  - `Becoming.exists_law_iff`：有一法许此历的每一步，也恰当此历不忒。
  - `Becoming.Shown.agrees`：凡许此历之法，在此历所显的每一移上，所给之果都与自然之法相同。
  - `Becoming.Run.not_fixes_of_untaken`：若变为法、此行在第 t 步之前未在状 s 采动 b、状有两个不同者，则往不定 b 在 s 的果。
- **经一象读一行。**
  - `Becoming.Run.law_through_iff`：有一法许此行第 t 步之前经象所读的各步，恰当这些步不忒：像相同、动相同的两步，所至之像也相同（`r.ConsistentThrough π t`）。
  - `Becoming.Run.not_fixesThrough_of_untaken`：若有一法许此前经象所读的各步，第 t 步之前此行未在像为 k 的状上采此动，且像有两个不同的值，则往经此象不定它的果。
- **文之层。** 文的状与法读自文，除步之相继外不须先给一法（`Becoming.alike_moments_iff`、`Becoming.SameAhead.next`，§一 律 1）；法之一行，读出的状就是同（`Becoming.IdentificationRuns.sameAhead_iff_alike`，§一 律 2）。

**域。**

- **成立。** 每一历都有它的自然之法，无设。自然之法为法，恰在此历不忒之处；经一象读时，恰在经象所读的各步不忒之处。每一文都读出它的状与法，无设。
- **不及。** 律不及于未采之动。先于历而给出的法，与自然之法之异只在此历未经之移（`Becoming.Shown.agrees`），而这些移的果，往不能定（一·七、一·九；规范章 §1.1）。讀（AI，D63）：所以一个外在的立法者（一个意志），既不会被任何往否定，也不为任何往所需要；它在自然之法以外所加的，正落在往所不及之处。
- **忒时。** 一行经某一象读出时若忒，这个象之上就没有法许它所读的步（`Becoming.Run.law_through_iff`）。讀（AI，D63）：那么，或者需要更细的象（所并的东西之中有关系没有读进来），或者展开在此处本来就有分支。

讀（AI，D63）：

- 内在生成的解释，是从展开读出的法。它有两层：历之层，自然之法读自历；文之层，状与法读自文。两层都不须历外或文外的立法者。外止的解释，止于一处不再由关系说明者。[脉络一章 §四·三](CIVILIZATION-THOUGHT-AND-BECOMING.md)所列四种非关系之层中，先在的根据、先定的性或价值、意志或单一中心都是这样的止处；第四种，争胜与等级，是另一种非关系之层。四层在那里各有其律。外止的解释在认识上的一面，见 §三 的失效 (a)。
- 这不是中西之分。在已对应的判断中，相分占 19%；在法、墨、三教互动中，超过四分之一（脉络一章 §四·四）。对话中的 AI 当时也已改述：障碍不在信神或形上二元本身，而在解释终止于内在关系被重建之前。

### 三、读书百遍，其义自见

**古书。** 「讀書百徧而義自見」，见《三国志》卷十三王朗传附王肃，裴松之注引《魏略》董遇之事（文理生生[原典证据索引](../../../sources/wenli-shengsheng-v0.4/research/references/05_原典证据索引与校勘说明_v0.2.md) D1）；《太平御览》卷六一六引作「當先讀百遍，而義自見」（D2）。此句不在冻结语料之中，本节依该索引转引，未能对冻结原文逐字核对。总计划 §八 作「读书百遍而义自见」、记在王肃传，索引之校正第八条改正其位置，并说「读书百遍，其义自见」是通行之转述。索引又说，此事「不能证明百遍这一数量必然有效，也不能证明中文独有迁移效果」。对话中 Ren 记作「疑读百遍，其意自现」。

总计划的五环，各有一个定义或一条律与之相配（这种配合是 讀，AI，D63）：

| 环 | 律 |
|---|---|
| 例句积累 | 往：文至某步之前之值（`Becoming.Learning.prefixOf`） |
| 提取不变量 | 文之状：自二步起逐步之值皆同则为一状（`Becoming.SameAhead`）；法之下即同（`Becoming.IdentificationRuns.sameAhead_iff_alike`）。又：变跨之而同的类（`Becoming.Learning.goAlike_iff_lumped`，见 §四） |
| 建构关系模型 | 状之法读自文（`Becoming.SameAhead.next`）；以类代状之变为法，恰当其类为理（`Becoming.image_determined_iff`，七·二，见 §四） |
| 解释未见例子 | 推类（`Becoming.Learning.determines_lumped_iff`）；在相若之下，一次所采之动代表其全类（`Becoming.Run.generalizes`，九·二十一） |
| 遇反例修正模型 | 过则改（`Becoming.Learning.byElimination`）。若有一个候选与文相符，过则改就不越过它，也不屡不符（`Becoming.Learning.index_le_of_accords`、`Becoming.Learning.misses_not_recurring`；若：值之同异定然否） |

「读书百遍，其义自见」可以分成三条律。

**(1) 百遍：在有界之处，有穷之往定其文。**

- 知来是往的函数（定义），所以重读同一往，所出之值不变。过则改也是这样：同一往，同一当前候选，同一所出之值（`Becoming.Learning.byElimination_through_prefix`）。讀（AI，D63）：百遍所增的，不在重读同一往，而在往变长。
- `Becoming.Identification.bounded_agree`：
  - 若：两文分别满足 `StatesBelow o N` 与 `StatesBelow o' N'`，即状不过 N 种（N′ 种）：每一步都与第 N 步（第 N′ 步）之前的某一步为一状；两者在 N＋N′－1 步之前处处相同。
  - 则：两者处处相同（九·三十三）。
  - 此长确切（`Becoming.Identification.bounded_agree_exact`，§一 律 4）。
- `Becoming.Identification.leastBound_exact`：
  - 若：值之同异定然否；`StatesBelow o N`。
  - 则：不给界、只用最小界的知来，自第 N＋N－1 步起每步皆得。
  - 与之相配的是 `Becoming.Identification.rest_earliest`（若：有两个不同的值）。对每一个 M，没有一个知来，能在每一个状不过 M＋2 种的文上，于第 M＋M＋2 步都得。所以对 N 不小于 2，N＋N－1 是能于每一个状不过 N 种之文上皆得的最早之步。
- `Becoming.Learnable.ahead_fixes`：
  - 若：像之同异定然否（`DecidableEq R`）；法自 s 之轨都在一族 l 之中。
  - 则：自第 l.length＋(l.length＋l.length－1)·tri l.length 步起，在终而复始的候选上做过则改，再以它自己所出的值向前展开，所出的就是此文自此步起每一步之值。它没有被给予诸状、诸状的数目，也没有被给予法。
- **域。**
  - 在文的状有界之处成立，或在法之轨在一族之中之处成立。不给界，则没有一个往定其次值（`Becoming.Learning.no_prefix_fixes_next`）。
  - 讀（AI，D63）：「百遍」可以读作，所读的步数须达到一个界，这个界由文的状数而定；过了这个界，再读也不增加所知。
  - 给出界，并不使知来更早每步皆得（`rest_earliest`）。界所换来的只是阙：给界之知来（`withBound`）按定义于 N＋N－1 步之前阙，于每一个状不过 N 种之文上无一步不符（`Becoming.Identification.withBound_accords`，若：值之同异定然否）；有两个不同的值时，没有一个知来，既于每一个状不过一种之文上第 1 步皆得，又于每一个状不过两种之文上皆无不符（`Becoming.Identification.rest_without_bound_missed`）。

**(2) 其义：状值须自某步起是自所在之状起之文的一种读。**

讀（AI，D63）：「其义」读作一个状值，即给每一状一值者。

- `Becoming.Learnable.learnable_iff`：
  - 若：像之同异定然否（`DecidableEq R`）；`world : ∀ s, s ∈ l`，即一族尽其状。
  - 则：有一个知来，从经象之往出值，在每一状的轨上都自某步起每步皆得其状值；这恰当凡经象文同的两状（`Law.SameFuture next reg s s'`），沿二者之轨，状值自某步起逐步相同（九·三十五）。
- `Becoming.Learnable.learnable_iff_reading`（若同上，且状值之值域中有一值 v₀）：上述条件也恰当有一种读 G（对每步同值的两个输入给出同值），使在每一状的轨上，自某步起，所在之状的状值，就是 G 对自此状起之文的读出。
- **域。** 在一族尽其状的宇中，状值能从文中读出，恰在状值自某步起是自所在之状起之文的一种读之处。讀（AI，D63）：这就是「内在生成」的确切形式。

**(3) 自见：只须给出状值所对应的读，不须给其余。**

- `Becoming.Learnable.reading_predicts`：
  - 若：像之同异定然否；法自 s 之轨在 l 中；G 对每步同值的两个输入给出同值；`ReadOff next reg val G`，即每一状的状值恰好是 G 对自此状起之文的读出。
  - 则：只被给予 G 的知来（`reading G`），自 (1) 中的界起，在 s 的轨上每步皆得此状值。它没有被给予诸状、诸状的数目、法，也没有被给予状值的任何值。
- `Becoming.Learnable.given_nothing_not_every`（构造之例：一个状，经象只有一个值）：
  - 状值恒真与状值恒伪，各有一个被给予其读的知来，自某步起每步皆得之；但没有一个知来于两者皆然。
  - 所以，没有一个不被给予任何东西的知来，于每一种可知的状值都自某步起每步皆得（九·三十五）。
  - 讀（AI，D63）：自见之前，须先问「其义」是对文的哪一种读。
- **自见而不自证。**
  - 法自一状之轨在一族之中时，过则改于终而复始的候选上自某步起每步皆得，这是不可非的（`Becoming.Learning.held_rest_unrefuted`，双重否定之形；若：经象之值的同异定然否）。正面之形，连同其界，见 (b) 中的 `held_byElimination_rests`。
  - 但往不能显示它已经每步皆得。有两个不同的值时，从一往所出的任何值，「在两段同此往、都终而复始的文上都不不符」是不成立的（`Becoming.Learning.no_prefix_fixes_next_finite`）。值之同异定然否时，它在其中一段上不符（`Becoming.Learning.claim_missed_on_one`）。何时每步皆得，是界给的，不是往给的（九·三十二）。
  - 讀（AI，D63）：义会自己显出，但它的往不显示它已经显出。

**失效。**

- **(a) 义止于文外。**
  - 律：经象文同的两状，每一步之往都相同（`Becoming.Learnable.prefixes_same`）。若沿二者之轨，它们的状值屡异，则没有一个知来能在两者的轨上都自某步起每步皆得（`Becoming.Learnable.not_predicts_on_both`；不须一族尽其状）。
  - 讀（AI，D63）：若一部书之义由读所不及者（一个意志）来定，同一个文可以有两种义，而且两者之异屡见，读多少遍都不能定下。这可以读作原话所说「dualist books」的确切形式。总计划 §八 所设的 B 组（「权威宣告密集型」），是同一区分在实验中的形式。
  - 这条律说的是义能否从文中读出，不说那个义本身的真伪。
- **(b) 不测之文。**
  - 有一个移动每一个值的象时，对每一个知来，都有一个文，使它所出的每一个值都不符（`Becoming.Learning.diagonal_misses`）。在这个文上，没有一步之后每步皆得（`Becoming.Learning.diagonal_unrested`）。这个文是一法之轨经一象所读（读其最近之值），此法之状藏其全往，没有一族尽此法之轨上之状（`Becoming.Learning.diagonal_open`）。
  - 反过来，法自 s 之轨在一族之中、经象之值的同异定然否时，过则改自 (1) 中的界起每步皆得（`Becoming.Identification.held_byElimination_rests`）。所以过则改不止息之文，都不是轨上之状有一族尽之的文。义之不见，在有一族尽其状之处也可以发生，即 (a)。
- **(c) 无类。** 在全体函数之中，所见的值不定任何未见之入的值（`Becoming.Learning.every_determines_nothing`；若：入之同异定然否、x 未见、有两个不同的值）。「學而不思則罔」〔RU1-S-LY〕与此相合（中华本九·三十四）。

**名之义项：贯与通意。** 读书百遍也定下一名之义项。讀（AI，D63）：一部书是以名为值之文，其名经码配义项（§一）；一名之义项，从凡遇此名之录读出。

- `Becoming.CrossSituational.stands_iff`：一个义项贯于一名，恰当凡遇此名之录都予之（中华本十·五）。
- `Becoming.CrossSituational.candidates_eq_iff`（若：义项之同异定然否；义项之族其员各异）：此名于族中犹贯者恰为 [e]，恰当三条都成立：e 在族中；凡遇此名之录都予 e；族中其他每个义项，都有某一遇此名之录不予之（通意，十·六）。
- `Becoming.CrossSituational.narrows`：后来的录只会减少犹贯者，已去掉的不会回来。
- `Becoming.CrossSituational.resolved_is_target`：所指在族中、且凡遇此名之录都予之，则唯一犹贯者就是所指。
- `Becoming.CrossSituational.Omitted.wrong_unique`（构造之例）：只要一录漏了所指，就可能留下一个错的唯一犹贯者。

讀（AI，D63）：文理生生的词典（245 个义项中 236 个附出处号）和中华本的名表（449 个名中 248 个附所引之句），都以出处为录，可以读作这条律的应用（脉络一章 §五·一）。词典自己也说，出处号「不能直接证明现代类型、公式、机制或最早词义」。

**举一反三。**

- 「擧一隅，不以三隅反，則不復也。」〔RU1-S-LY〕——相合（lunyu-ju-yi-yu）：原句以四隅为一类而推，不立全称；推之为对的条件是这一读之前提，见下（讀，AI，D63）。
  - `Becoming.Run.fixesThrough_of_takes`：一行若已在像为 k 的状上采过一个动，则经象所读的果为往所定。
  - `Becoming.Run.generalizes`：若变经 π 相若于一法 Q，往经 π 定 a 在像 k 上的果为 κ，π s = k，且 s 经 a 至 u，则 π u = κ，无论此行是否经过 s。这就是九·二十一说的：在相若之下，一次代其类。
  - `Becoming.Run.not_fixesThrough_of_untaken`：这一类中没有一个状采过此动，往就不能定它。若：有一法许此前经象所读的各步，像有两个不同的值。
  - `Becoming.Learning.transfer_right_iff`（若：变为法；在 s₀ 见到 a 至 u₀）：把这个果经 π 移到 s 上为对，恰当 s₀ 与 s 以 a 所至之状经 π 同像（`GoAlikeAt P π s₀ s a`）。
  - 所以三隅能反，在四隅同属一类、且变经此类相若于一法之处成立。就一个动而言，恰在所见之隅与所反之隅以此动所至之状同像之处成立。「则不复也」是教者的做法，不在律中。
- 「引而伸之，触类而长之，天下之能事毕矣。」〔DS02〕——定域：在类中推，恰在世界跨此类同值之处为对（`Becoming.Learning.lumped_right_iff`）。「天下之能事毕矣」这一全称，只及于与所见者同类的事（`Becoming.Learning.determines_lumped_iff`）。同段的筮数之用不带。
- 「欲知億萬則審一二」「以近知遠，以一知萬，以微知明」〔RU2-S-XZ05〕——定域，与中华本九·三十四所引同篇「類不悖，雖久同理」相同：以一知万，恰在万者与一同类、且展开跨此类而同之处成立。同段以後王、君子为所审，不带。
- 「推類之難，說在之大小。」〔MI1-S-JX〕——相合（中华本七·三）。

### 四、理与相若：压缩与推广由同一个类给出

对话中的 AI 曾经猜测，读到共同的结构时，压缩与推广「may be deeply connected」。在脊柱上，两者由同一个类给出，并且有确切的界。理与文的关系也在这里：七·二说「以其类代状之变为法」，九·二十一说相若，用的是同一个变，即以类代状之变。它不是文，中华本也不另立名，下面的律 4 陈述它。

**古书。**

- 「其称名也小，其取类也大，其旨远，其辞文」〔DS03〕
  - 定域：名小而所及之类大，所及也就远；所并的就是所推的（`Becoming.Learning.determines_lumped_iff`）。
  - 所推之处要为对，须世界跨此类同值（`Becoming.Learning.lumped_right_iff`），原句没有说这一条件。
  - 「其辞文」的文是文采，不在名内。
- 「仰则观象于天，俯则观法于地，观鸟兽之文，与地之宜，近取诸身，远取诸物；于是始作八卦，以通神明之德，以类万物之情。」〔DS03〕
  - 定域：用八类去并万物之情，推出的结论恰在万物跨此并而同之处为对。
  - 讀（AI，D63）：「鸟兽之文」是一时之纹样，即一状经一象之值（像），不是名中的文；文饰在名之所不带中。
  - 「以通神明之德」和包牺氏王天下的叙事，都不带。
  - 易传一章不把说卦的取象当作律（[易传一章 §8](YI-ZHUAN-AND-BECOMING.md#8-未做之事)）。文理生生的试点也说，《说卦》的单项卦训等「不应仅因能写成对照表就算作动力模型」（[README](../../../sources/wenli-shengsheng-v0.4/research/README.md)）。
- 「賜也，女以予為多學而識之者與？」「非也，予一以貫之。」〔RU1-S-LY〕
  - 定域，见下面律 3。
  - 这里的「識」是记取。名表把这一义归入「往」。
  - 「貫」在名表中名跨情境成立（中华本十·五，所引为里仁「吾道一以貫之」）。这里只作对照，不给贯另立一义。
  - 里仁的「一以貫之」，曾子释为「夫子之道，忠恕而已矣！」〔RU1-S-LY〕。这一单一原则中心不带。
- 「易简，而天下之理得矣。」〔DS02〕——定域（[易传一章 p-yijian](YI-ZHUAN-AND-BECOMING.md#p-yijian)，xici-yi-jian-li-de）：原句之易简，上文自释为「干以易知，坤以简能」〔DS02〕（冻结本作干，即乾），是乾之易知、坤之简能，不是归并之粗。讀（AI，D63）：以简为一个粗的读法是类比；依此类比，一种简化是理，恰当它是律所同行的归并。
- 「所見无非牛者。三年之後，未嘗見全牛也」〔ZH1-S03〕……「依乎天理，批大郤，導大窾，因其固然」〔ZH1-S03〕
  - 「依乎天理……因其固然」相合（中华本七·二）。
  - 省略号所省之中有「臣以神遇而不以目視，官知止而神欲行」〔ZH1-S03〕，是不经感之知，不带。
  - 「三年之後」不立对应：读者怎样到达他的类，脊柱不导出，所以不给其成立之域。`Becoming.Learning` 明言不导出的，正是一个形成实际经过或能够到达哪些候选、类或归并。

**律。**

1. **一个类，三种用途：结构的模型、变化的模型、推广的所及。**
   - `Becoming.Learning.goAlike_iff_lumped {next : S → S} {π : S → K} : GoAlike (Law.process next) π ↔ Lumped π (fun s => π (next s))`：对一法（每状恰有一个次状），此类为理，恰当次状之像随此类而同。此外不须别的若。
   - `Becoming.Learning.determines_lumped_iff`（若：类之同异定然否；有两个不同的值）：在随此类而同的诸函数中，所见的值定下 x 的值，恰当所见之中有与 x 同类者。
   - 讀（AI，D63）：所以压缩所并的，就是推广所及的。对法而言，结构的模型与变化的模型是同一个类（七·二）。
2. **对与不对。**
   - `Becoming.Learning.lumped_right_iff`：随此类而同的 g 在所见之处与 f 同值，则对与所见之 d 同类的 x，g x = f x 恰当 f d = f x。
   - 对为法之变：`Becoming.Learning.transfer_right_iff`（若：变为法；在 s₀ 见到 a 至 u₀）。此果经 π 移到 s 上为对，恰当 s₀ 与 s 以 a 所至之状经 π 同像。
3. **多学而识与一以贯之。**
   - `Becoming.keepHistory_fixes_nothing_else`（若：变为法；行在藏往之变上；b 不是此行第 n 步所采之动；藏往之状有两个不同者）：藏往之行，在它所经的每一状上，往只定它所采之动的果（九·十八）。
   - `Becoming.Run.generalizes`：变经一类相若于一法时，一次所采之动，就定下其全类的果。
   - 讀（AI，D63）：
     - 多学而识之，所定的不出于所记。一以贯之，所定的及于全类，但只在那个「一」是相若于一法的类时才如此；就一个动而言，恰在 `transfer_right_iff` 所说之处。
     - 能为理的「一」总是有的，但可能无用：达名于每一变都为理（`Becoming.goAlike_const`），却什么都不分开。所需要的「一」，要留下所要的异，又要是理。
4. **以类代状之变：理与相若。**
   - 定义：`Becoming.Image P π`。`(Image P π).step k a κ` 按定义就是 `∃ s u, π s = k ∧ P.step s a u ∧ π u = κ`：像 k 以动 a 至像 κ，恰当有一状像为 k，以 a 至一像为 κ 之状。
   - 每一变、每一类，变经此类相若于以类代状之变（`Becoming.factors_image`，无设）。若变经此类相若于某一变 Q（`FactorsThrough P π Q`），则 Q 许以类代状之变的每一步（`Becoming.Image.least`）。所以它是变经此类所相若的最小之变，一步也不多（九·二十一）。
   - 沿一行，经类所读的每一步都为以类代状之变所许（`Becoming.Run.stepsThrough_of_factors`，以 `Becoming.factors_image` 为若）。一行经 π 之文，按定义就是以类代状之变之一行的逐步之状（`Becoming.Courses.reducedRun`）。
   - **理。** 以类代状之变为法（每状每动至多一个果，`Determined`），恰当类同的两状以同一动所至之状仍类同，即此类为理（`Becoming.image_determined_iff : Determined (Image P π) ↔ GoAlike P π`）。有一法使变经此类相若于它，也恰当此类为理（`Becoming.carries_law_iff`），对每一变、每一类都成立。这就是七·二的「以其类代状之变为法，亦恰当此」。
   - **互不蕴含。** 一类为理与变为法互不蕴含。有变不为法，而变经其一类相若于一法（`Becoming.Coarse.carries`，构造之例）。也有变为法，而其一类不为理（`Becoming.Switching.determined`、`Becoming.Switching.not_goAlike`，构造之例）。
   - **类之类。** 用类 ρ 去读以 π 代状之变，ρ 于其上为理，恰当复合之类 ρ ∘ π 于原变为理（`Becoming.goAlike_image_iff : GoAlike (Image P π) ρ ↔ GoAlike P (ρ ∘ π)`）。
   - **达名。** 不分开任何者的类叫达名（十·四），它于每一变都为理（`Becoming.goAlike_const`）。讀（AI，D63）：达名载法，而不分开任何东西；一类所载者，在它所留之异。
   - **路。** 以类代状之变的每一步都以变的某一步为本，它的路却未必是某一状实际可走的路。对每一状 s，以类代状之变自 s 之像起的有穷之路，恰是变自 s 起之路经类所读，恰当以下条件：类同的两状，一状以一动所走的每一步，另一状都能以同一动走到与其终处类同之处（`Becoming.image_exact_iff`，即 `MatchesThrough P π`）。为理不保证这一条件：达名为理，却不能如实给出变的诸路（`Becoming.Stuck.goAlike_not_matches`，构造之例）。讀（AI，D63）：以类推路，须另有这一条件。
5. **不是每一种简化都是理**（构造之例，易之模型中的消息之律）：
   - 以一卦与其错为一类，消息之律跨之而同（`Becoming.Hexagram.pairs_goAlike`）。
   - 以刚爻之数为类，则不同（`Becoming.Hexagram.yang_not_goAlike`）：泰、否各有三刚爻，下一步一成四、一成二。
   - 以刚爻之数的奇偶为类，又同（`Becoming.Hexagram.yangOdd_goAlike`），而奇偶比数目更粗。
   - 对互卦之法，奇偶却不是理（`Becoming.Hexagram.nuclear_yangOdd_not_goAlike`）。
   - 所以一类是否为理，不随其粗细单调变化，也不在类本身，而在所行之法（七·二）。
   - 文理生生的止行水箱（[16 号 §六、§七](../../../sources/wenli-shengsheng-v0.4/research/references/16_文的组合规则与系统推演_v0.1.md)；[17 号](../../../sources/wenli-shengsheng-v0.4/research/references/17_文卦系统映射验证_v0.1/README.md)）是同一结构（讀，AI，D63；文理生生之构造之例）：状是水量与泵之模式，三开下一步至四停，三停下一步至二开。以水量为类，三开与三停并为一类，下一步却一至四、一至二，所以水量之类不是理，与刚爻之数同。16 号说「为分类够用的表示，未必为预测够用」；它的另一办法，改用允许多个后继的抽象并检查是否增加现实中不存在的路径，对应律 4 的以类代状之变与其路之条件（`Becoming.image_exact_iff`）。
   - 讀（AI，D63）：从水量之文也读得出被删去的模式。自四停起，水量之文是 4，3，2，3，4，3，2，3，…：第 1 步与第 3 步（自第 0 步起数）之值皆三，其次值一为二、一为四，所以这二步不为一状（`Becoming.SameAhead` 之定义）；此文终而复始，读出之状恰四种，正是循环中的四停、三停、二开、三开（§一 律 1、律 3）。
6. **最小的压缩与可知之界都落在文同上**（这一框架是 讀，AI，D63）。
   - `Becoming.Law.identifiesAlike_of_law`：
     - 若：π 相同者，o 值也相同；`GoAlike (Law.process next) π`；凡经 o 文同的两状，π 都把它们并在一起。
     - 则：π 为正名（`IdentifiesAlike (frameBy next o) π`），恰把同者并为一（一·二十三）。
   - `Becoming.Law.sameFuture_of_law`（只用前两条若）：凡守 o 之值而为理的类，所并的两状都经 o 文同，不失去 o 所分开的任何东西。
   - `Becoming.Law.coarsest_iff`（若：π 守 o 之值，且 `GoAlike (Law.process next) π`，即 `Becoming.Law.KeepsAndCarries`）：以下四者是一：凡守 o 之值而为法所守（`Becoming.Law.KeepsRelation`）之关系所连之二状，π 皆并之；凡经 o 文同之二状，π 皆并之；π 所并恰是经 o 文同之状；π 为正名。
   - `Becoming.Law.sameFuture_coarsest`（无设）：经 o 文同守 o 之值、为法所守，且含每一守 o 之值而为法所守之关系。所以守 o 之值之理中最粗者，所并恰是经 o 文同之状，且为正名；恰并经 o 文同之状之类，粗于每一守 o 之值而为理之类（`Becoming.Law.coarser_of_exact`）。
   - `Becoming.Law.coarsest_class`（若：一族尽其状）：以自每状起之文前 N＋N－1 步之往名此状（N 为族之员数），这些名守 o 之值、为理、所并恰是经 o 文同之状；守 o 之值而为理之类，粗于每一守值为理、其值与 o 之值同一 universe 之类，恰当它恰并经 o 文同之状。不给一族时，核心不立这样的类：以文同取商可以有，商并文同之状须 `Quot.sound`；最粗者作为关系仍在。
   - 另一面：经象文同的两状，每一步之往都相同（`Becoming.Learnable.prefixes_same`），任何知来都分不开它们。可知与否也落在文同上（`learnable_iff` 的条件，§三 (2)）。
   - 法使每状不改时（若：一族尽其状、像之同异定然否），经象可知的，恰是随此象之类而同的状值（`Becoming.Learnable.still_learnable_iff_lumped`）。

**域。**

- 推广所及恰是压缩所并，这对任何类都成立（`determines_lumped_iff`，若：类之同异定然否、有两个不同的值）。推广为对，恰在世界跨此类同值之处（`lumped_right_iff`）；就变化而言，就是此类为理之处（`goAlike_iff_lumped`）。讀（AI，D63）：压缩与推广是同一件事，恰在压缩是理之处。
- 以类代状之变对每一变、每一类都有；它为法，恰在其类为理之处；以它推路，还须律 4 中的那一条件。
- 讀（AI，D63）：总计划 §七 提议用最小描述长度（MDL）的思想来比较压缩，脊柱上没有关于这种度的律。脊柱上的压缩是并，以所并的东西来衡量，而不以长短来衡量。

### 五、最小的读，及其失效

**古书。**

- 「书不尽言，言不尽意。」〔DS02〕——定域，与中华本九·六所判相同（xici-shu-bu-jin-yan）。经一象所读之文，不能复原此象在同一步上所并的二行之异状：两行经一象之文在某步相同而状异，就没有一个从像到状的映射能在每一步都复原两行（`Becoming.Courses.runs_no_restore`）。所以「不尽」在象于某步并了二行之异状之处成立；象不如此并时能否尽，这条律不说。
- 「圣人立象以尽意」〔DS02〕——定域：在一族尽其状的宇中，状值能从文中读出，恰在状值自某步起是自所在之状起之文的一种读之处（§三 (2)）。讀（AI，D63）：一个状值若依于无尽的全体，而不依于它的任何一分（一个尾，见下），就没有一种有穷的读能尽它。圣人这一中心不带。读者读其自身的情形，见同章「设卦以尽情伪」〔DS02〕：中华本九·二十八判它为相分，所判限于卦辞所读含读者自身之处。

**律。**

- `Becoming.ExchangeLaw.ReadsFinitely.least_coupling`：
  - 若：所待之同异定然否；`fin : law.ReadsFinitely`，即读有穷：每一步、对每一待者、在每一历下，此法只读一族所待，这一族可随历而不同。
  - 则：对体外每一待者，此法缘其所察而读。此法所缘的每一感，连同此待者所待，都含有它所察的每一所待；这一点以不可非之形成立（`¬ ¬ W.CoupledInto obs h c`；中华本九·十一）。
  - 察于一所待（`Becoming.ExchangeLaw.Sensitive`），是说一待者之取与于某步，非独由他所待至此步之积而定（九·十一）。
- `Becoming.tailLaw_no_least_coupling`：
  - 若：所待以自然数编号；对诸所待之积，都能判定它们是否自某一所待起皆为零（`decides`；这一判定给出无穷可尽，`Becoming.lpo_of_vanish_decided`）；待者不待任何所待。
  - 则：尾法（只读第 0 步诸积是否自某一所待起皆为零）所缘之感没有最小者。尾法也不是读有穷的（`Becoming.tailLaw_not_readsFinitely`）。
- `Becoming.wlpo_of_not_through_sensitive`：若法唯读既立者、所待以自然数编号，且两段历在其所察者上至某步都相同，而此法在这一步所给的取与仍不同，则无穷可定其皆否（WLPO）成立。

**域。**

- 最小之感就是所察。这在法读有穷之处成立，所待的数目不限；所成立的是不可非之形，不是正面的包含。
- 所待以自然数编号时，最小之感的反例不能以构造的方式给出：给出一个，就给出了无穷可定其皆否。有了「是否消失」的判定，就有一个反例。
- 讀（AI，D37、D63，依 `Becoming.Sensitivity` 的读法）：依于全体而不依于它任何一分的东西，是尾，例如诸积是否终归为零、长程的均值。律中的尾，是一步之中无穷多所待的尾；沿步而读的察，脊柱没有导出。沿步之尾另有其律：屡是稠密的，凡有穷之段皆有一屡之行与之同至此段（`Becoming.Sequences.recurs_dense`），所以没有有穷之段驳之（`Becoming.Sequences.recurs_not_refutable`）；也没有有穷之段征之（`Becoming.Sequences.recurs_not_verifiable`）。

### 六、知在展开之中：识，与文理生生的「观／证」

文理生生以「观／证」为一面镜子。总计划 §3.2 说：“「观—证」是知识论层（meta-level），不是宇宙中必须存在的人类观察者”。观问所据为何、尺度何在、哪些现象不可见；证问凭什么判断真伪、什么发现会推翻此说。

中华本另有同字之名：观名视图（一·二十），证名经检查的证明（凡·十五）。文理生生的观，在下面对应感与识；它的证，对应验（九·十二）。在核心中，这面镜子不在展开之上，而在展开之中，它的名字是识（讀，AI，D45、D63）。

**古书。**

- 「然则何缘而以同异？曰：缘天官。」〔RU2-S-XZ22〕——相合（中华本九·二，xunzi-zhengming-yuan-tianguan）：同异经感而定。
- 同篇：「心有征知。征知，则缘耳而知声可也，缘目而知形可也。然而征知必将待天官之当簿其类，然后可也。」〔RU2-S-XZ22〕
  - 相合（讀，AI，D63）：心的征知，须等天官依其类有所簿记之后才成立；也就是说，同异先经感而定。
  - 这里的心只作又一种读。心不立为名（中华本附录二），解蔽「心者，形之君也」〔RU2-S-XZ21〕的中心义不带。
- 「觀我生，進退」〔YD-JG20〕——相合（中华本九·三）。
- 「吾生也有涯，而知也无涯。以有涯隨无涯，殆已。」〔ZH1-S03〕——相合（中华本九·二十八）。

**律。**

- **识**（中华本九·三；讀，AI，D45：一待者自身之后程，随其感所作之类而定）：
  - `Becoming.Web.SelectsThrough`（定义）：缘感而择，是说凡缘择者之感至 t 无异的两段历，择之皆同（九·二）。
  - `Becoming.Web.selects_alike_iff`：两段历被每一个缘 g 之感至 t 的择同样地择，恰当两段历缘 g 之感至 t 无异。这条律说出的是定义所筑入的东西（九·十三）。
  - `Becoming.Learning.Training.web_selectsThrough_iff`：缘感而择，就是经「缘感无异」这个类而择（`Iff.rfl`；九·三十四）。
  - 讀（AI，D45、D63）：所以知者之感作一个类：缘感无异（`Becoming.Web.AlikeThroughUpTo`：至 t 每步，两段历于此待者同容或同不容，以积感入之所待其积亦同）。它所择，只依其所历在这个类中之所在。缘感无异一般是一个关系，不是一个象：容是一辞，以积感入之所待可以无穷。下面的律说它在何处是一个象，那时它所读的就是它自身之所历经其感逐步所显者，即它的文；文的状与法读自文（§一）。
- **待者自身之文**（感读作值之处）：
  - `Becoming.Web.ValuesThrough`（定义）：value 给出感入 g 者之值，是说每一步，两组积之值相同，恰当二者同容或同不容 g、以积感入 g 之所待其积亦同。待者自身之文（`Becoming.Web.courseThrough`）是每步感入它者经 value 之值。
  - `Becoming.Web.listed_values`（若：g 之容已定然否，以积感入 g 之所待列尽）：容与否连同所列诸积，就给出这样的值。
  - `Becoming.Web.alikeThroughUpTo_iff_prefix`：两段历缘 g 之感至 t 无异，恰当 g 自身之文在二历下至 t 之往相同。
  - `Becoming.Web.selectsThrough_iff_prefix`：一择缘 g 之感至 t，恰当它依 g 自身之文至 t 之往而择（有一辞读往，此择恰依之）；`Becoming.Web.selects_alike_iff_prefix`：二历被每一缘 g 之感至 t 之择同样地择，恰当其往相同。所以缘感而择，就是读自身之文之往。
  - `Becoming.Web.alike_of_bounded`（若：g 自身之文在二历下各不过 N、N′ 状）：二历缘 g 之感在 N＋N′－1 步之前每步无异，则至每一步都无异；凡缘其感之择，于每一步都同样地择这二历（`Becoming.Web.selects_alike_of_bounded`）。这是有界则往定其行（九·三十三，`Becoming.Identification.bounded_agree`）用在待者自身之文上。二文合读不过 P 状时，P 步之前无异即足（`Becoming.Web.alike_of_joint_bounded`，`Becoming.IdentificationRuns.joint_agree`）。
  - `Becoming.Web.bounded_exact`（构造之例，一待者一所待，以积感入，以积读之）：对每一 M、M′，有二历，其文各不过 M＋1、M′＋1 状，于 M＋M′ 之前每步缘感无异，于 M＋M′ 步有异。所以界 N＋N′－1 确切。
  - `Becoming.Web.states_by_reading`（同一构造之例）：连步数之积也给出感入者之值；积恒为零之历，以积读之，其文一状，连步数读之，其文之状多于每一界。文之状比较异步之值，感只比较同一步之二历，所以文之状随读而定。
  - 讀（AI，D45、D63）：识所读的，是它自身之文之往。它自身之文之状有穷时，凡它所能分开的二历，于 N＋N′－1 步之内都已分开；二历缘其感于前 T 步无异、其后有异，则它在二历下的文之状数之和大于 T＋1。这条律只在一种读之下说话，读越粗，所说越多。
- **所据与不可见：**
  - `Becoming.Web.alike_of_threshold`（若：所待之同异定然否；其他感入此待者之所待，此步之积都相同；此所待不以积感入；此步若待之，两段历之积皆足其需或皆不足）：则两段历于此步缘此待者之感无异。唯以阈感入的所待，只传过需之足否（九·一、九·四）。

    - 若：其余的交换固定；闭包内诸待者所感入的所待皆衡；一体的每个员都在 f 之感的闭包之外。
    - 则：有此体与无此体，凡缘闭包内某一待者之感的择，都同样地择。
- **验：** 一辞要见去，须它在感入之处与所然之历有异（`Becoming.Web.Excludes.not_of_alike`：若有一段如此辞的历，与所然之历缘 g 之感至 t 无异，则此辞在此不见去；九·十二）。
- **无顶：**
  - 在诸类合并之上学习，仍然是过则改，只是所列举的更宽（`Becoming.Learning.merged_bound`）。有一个移动每一个值的象时，它在自己的对角之文上不会止息（`Becoming.Learning.merged_unrested`；若：值之同异定然否）。

**域与比较。**

- 文理生生那面镜子所问的东西，在核心中都是展开之中的关系：
  - 所据，是感（九·一）。
  - 尺度，是感所作的类（九·二）。
  - 不可见者，是阈下（九·四）、涯外、感之闭包以外的东西（规范章 §3.1 的三种不见）。
  - 证，即验：只经感入之处的异而见去（九·十二）。
- 那面镜子所护持的两种区分，核心不另立一层，也保住了：
  - 世界如何运行，与我们如何知道（总计划 §3.2）。知者之感以外的东西照样展开，照样有所失（`Becoming.Clearing.unselected`，构造之例）。在这个例子中，清除者之感唯以阈感入；它的每一种择，在每一步都同样地择被清除之宇与未被清除之宇；而栖居者在前一宇中终止，在后一宇中不终止。
  - 所是与所宜（总计划 §十）。所表示的动力学不定顾：在同一待网上，若有一事件是活的（其物于此步运，且不在剥中），则凡皆无顾时，活皆有顾不成立；凡皆有顾时，则成立（`Becoming.Web.significance_undetermined`）。这条律不表明延续之条件是必需的。
- 讀（AI，D63）：二者之异只在「在上」。文理生生自己说观／证「不是宇宙中必须存在的人类观察者」，这一点与核心相合。但若把观／证立为展开之上的一层，它就成了一个顶；而学习之上仍是学习，读者读自身必有所不尽（九·二十八）。所以在核心中，观／证只能是又一种读，在展开之中。
- 讀（AI，D26、D45）：识、理、明是同一个结构。识是待者之后程随其感之类而定；理是展开随之而同的类；明是一个择所经之感，及于容所不标出者（中华本篇九、篇十一）。

### 七、组合：字合为模

对话第一轮中，Ren 说："I feel a lot of the composition Chinese are either the composition of dynamics, which was described by the single character, or some, like, structural composition." AI 的回答进而说，汉语的概念组合起来，像一个个小的系统模型。文理生生的总说把组合分为配置组合、过程顺接、条件筛选与规范判断，并说「“合”不能在几个层次间无声明地换义」（[README](../../../sources/wenli-shengsheng-v0.4/research/README.md)）。在脊柱上，组合有以下几种，各有其律和界。

**古书。**

- 「以名舉實，以辭抒意，以說出故。」〔MI1-S-XQ〕——「以说出故」相合（[RO 一章 p-mobian-qi-ran-suo-yi-ran](CHINESE-SOURCES-AND-BECOMING.md#p-mobian-qi-ran-suo-yi-ran)，那里读「以说出故」须有返回与变动）；三句合看定域（mobian-ming-ju-shi）：听者之码分开诸义项时，「以辞抒意」恰在说者与听者之码于此义项一致之处成立（`Becoming.SharedCodes.reads_iff`）。讀（AI，D63）：名、辞、说又是组合的三层：名举一实，辞合名而成意，说合辞而出其故。
- 文理生生的每张完整构式卡，都列出原句、成分关系、整体义、不能逐字推出的内容、现代补充、有限模型和失败条件（README）。组合的界就记在这里。

**律。**

- **过程的接续：** `Generative.trace_append_iff`（基础层）。从 s 经 xs ++ ys 到达 t，恰当有某个 m，使从 s 经 xs 到达 m、从 m 经 ys 到达 t。两串动相接，须有同一个中间之状。这与文理生生所说「过程顺接要求实际中间状态相同」相合。
- **转合与两种接点**（[16 号 §二至§四](../../../sources/wenli-shengsheng-v0.4/research/references/16_文的组合规则与系统推演_v0.1.md)）：文理生生定 C(P, π, Q)：「P成立时，π至少有一次允许执行，而且所有允许终态都满足Q」；若同一模型之每一状皆满足 C(P, π, Q) 与 C(Q, ρ, R)，则得 C(P, π;ρ, R)，并要求非空，免于把「没有任何后继，所以没有反例」当作成功。它又分两种接点：配置经共同之对象相接，过程经前后条件相接。`Generative.trace_append_iff` 只给存在之一面。全称而非空之一面，基础层有部分同构之律（讀，AI，D63）：一串动自一状成其所求，是每一动于所至之处皆可行、所至之状皆续、终处皆合所求（`safe` 取恒真）；两串相接而成，恰当前串成「后串于此成其所求」（`Generative.InquirySufficiency.completes_append_iff`，与 `Generative.trace_append_iff` 同在基础层，公理报告空）。此即中华本之必至（十六·十七），它要求每一所至之处皆可行。凡变，必至则可行至一终状，每一终状皆合所求（`Becoming.Assurance.runs_of_completes`）；凡法（一动至多一果），无安之条件，反之亦然，必至恰是 C(P, π, Q) 后件之形（`Becoming.Assurance.completes_iff_runs`）；一动二果之变，一族动可行，每一终状皆合所求，犹不必至（`Becoming.Assurance.Branch.runs_not_completes`，构造之例）。所以一般而言必至比 C(P, π, Q) 之后件更强。16 号的八条组合规则（选义、定位、联结、成式、定时、明变、转合、断辞）是文理生生文法之设计，不是律，不对照。
- **读的接续：** `Becoming.goAlike_image_iff`（§四 律 4）。
- **码的组合**（一个所给的小语法：式由两个原子以接与倍组成，十·九）：
  - `Becoming.CodeAcquisition.acquired_every_expression`（若：两个原子的值不同）：从三个所问（两个原子、一个接）读出的码，对每一个式都与原码同值，深无所限。
  - `Becoming.CodeAcquisition.primitives_no_exact`：只读原子之值，没有一种读能确知接之次序；须有接之所问。
  - `Becoming.CodeAcquisition.nonuniform_agrees_on_probes`、`Becoming.CodeAcquisition.nonuniform_fails_transfer`（构造之例）：有一条律，在三个所问上与寻常之码同值，其余的值都相反。三个所问不能排除它，而它在一个未问之式上失败。
  - `Becoming.CodeAcquisition.equal_primitives_unresolved`（构造之例）：两个原子同值时，只差次序的两个码，三个所问读出的值完全相同；读出之码在那一个未问之式上的值，仍与原码相同。
- **读出一切词之串：** `Becoming.CrossSituational.reads_every_iff`。
  - 若：义项之同异定然否；义项之族其员各异；分组能在每一串编码之词中复原各词之名。
  - 则：逐组以通意读之，读出每一串各词的义项，恰当每一个词都满足三条：其义项在族中；凡遇其名之录都予之；族中其他每个义项，都有某一遇其名之录不予之。
  - 讀（AI，D63）：一部书是以名为值之文，其名经码配义项（§一）；这条律说一个读者何时能从这样的文读回每一名之义项。
- **名之文：**
  - `Becoming.SharedCodes.course_states_iff`：一码之下，凡义之文，其名之文二步同，恰当义之文二步同，恰当此码辨诸义（不二义同名，`Becoming.SharedCodes.TellsApart`）。二义同名，则先取其一、后皆取其二之义之文（`Becoming.Learning.holdFrom`），其名之文并了义之文所分之首二步。
  - `Becoming.SharedCodes.course_read`（若：同上条之三若；以通意读出每一串）：于每一词之文，通意逐步把名读为义，义之文就是名之文经此读所得；名之文二步同，则义之文二步同。
  - `Becoming.SharedCodes.code_read_every`（若：同上，词就是义，名由一码给出）：以通意读回每一串之码，必辨诸义，所以名之文与义之文同状。
  - 讀（AI，D63）：读回每一名之义项的读者，从名之文读出的状，并于义之文之状之中；码辨诸义时，二者恰同，文之律（§一）对名之文所说的状，就是对义之文所说的状。有异名同义者，名之文之状可多于义之文之状。
- **兼不在两两之中：**
  - `Becoming.separation_faithful_iff`：分述二体，能复原其兼，恰当兼是矩形的（一·二十四）。
  - `Becoming.whole_not_in_pairs`（构造之例）：三体中任两体都可以自由相配，而三者合起来有一个关系。
- **名是自由的：** `Becoming.SharedCodes.renamed_carries_iff`（若：改名是一一的）。一一改名之后的象载一法，恰当原来的象载之（脉络一章 §四·四）。

**域。**

- 在一个所给的组成之语法中，两个原子相异、又有接之所问时，每一式之值由原子之值与次序定下，深无所限。没有接之所问，次序就定不下来。这是一个所给的有穷律族之律，不是语言之律：`Becoming.CodeAcquisition` 自言它不定义认知或语言。
- 所问排除不了一条在所问处同值、在别处相反的律。读出之码在未问之式上为对，依于一个前提：所读者本来就是以接组成之码。讀（AI，D63）：文理生生构式卡上的「不能逐字推出的内容」，正是这一前提不成立的地方。兼之关系也可以不在任何两者之中。
- 字形本身不承载所载之义：一一改名不改变所载之法。文理生生的审计也说，它的推导「其来源是公开的关系语义与证明，不是字形本身」（18 号 §5.2）。
- 讀（AI，D63）：认识论在文与它所读出的状与法之中，不在字形之中；它在字所绑定的关系之中。
- 文理生生的审计对概念组合像小的系统模型、复合词是微型理论两说（审计所列之主张，原为英文）的裁定（[18 号 §一、§三](../../../sources/wenli-shengsheng-v0.4/research/references/18_核心研究主张与完成边界审计_v0.1.md)）：选定词义、句法、角色及领域条件之后，一些概念可作小型关系与过程模型的组合接口，这是条件化的现代重构；微型理论只在图式的宽义上可说；补入的内容「不能再被记作词面已经编码的信息」。这与上面码之律同向：所问排除不了在别处相反的律，读出之码在未问之式上为对，依于另给的前提。

### 本节未立者

1. **任一实际的书满足上述条件，即它是内在生成之文。** 这是一种对应，不是定理；相合不是印证。
2. **文理生生的 H2：理解这些组合可改善对未见实例的结构重建、解释与迁移。** 律只说明从文中学到状值在什么时候可能、经由什么程序可能。人类读者是否这样学、读者怎样到达他的类，都没有导出，须另做实验（实验设计见总计划 §八；文理生生 18 号审计记其「尚未进行」）。
3. **古汉语是核心的最佳媒介。** 未经检验。一一改名不改变所载之法（`Becoming.SharedCodes.renamed_carries_iff`）；认识论在文与其状、法之中，不在某一种书写之中。
4. **任意系统的最小概念语法（H3）。** 脊柱只有对某一条法、某一个类的最小之读（`Becoming.Image.least`、`Becoming.ExchangeLaw.ReadsFinitely.least_coupling`、`Becoming.Law.identifiesAlike_of_law`），没有一个普遍的最小语法。
5. **恰并文同之类，于任一法皆有。** 一族尽其状时有之（`Becoming.Law.coarsest_class`）；一般以文同取商，商并文同之状须 `Quot.sound`，核心不用，只立其关系（`Becoming.Law.sameFuture_coarsest`）。缘感无异之为象亦然：一般而言要以此关系取商，核心只在容已定、以积感入者列尽之处给出其值（`Becoming.Web.listed_values`）。原列于此的三项 Lean，已由看板项 WL2 证出，见 §四 律 6、§六、§七（[研究第 349 节](../../../_process/research/2026-10-05-generative-foundation-review/root-foundation/BECOMING-RENEWAL-READING.md#349-the-laws-of-文-as-theorems-the-coarsest-value-keeping-class-a-formations-own-course-the-course-of-forms-wl2)）。

## 两个项目的对照

**独立到什么程度。** 两个项目分开建成，形式也各自独立：文理生生用命题动态逻辑，判定在有穷的多类模型上；本理论用 Lean 的纯核心。但独立只是部分的：

- 两者读同一套经典，用的是维基文库同样的版本；
- 文理生生的八卦部分以《中华思想脉络》为只读参照，而中华本也从它取名；
- 两者都由 AI 写成，文理生生的发端对话也以生生不息论为背景。

所以两边的相合，可能出于原文对读法的约束，也可能出于共用的版本与参照、同由 AI 写成，二者分不开；它是同一线索的两次阅读，不是统计意义上的独立证实。

**十二构式与十三个微型模型**（讀，AI，D63）。文理生生统一登记原 32 组表达（另补分合一组），展开生生、感应、中和、变通、分合、名实、本末、虚实、阴阳、自然、无为、相生十二张构式卡；相生分概念相待与有向支持两读，所以有十三个微型模型（[构式与微型模型](../../../sources/wenli-shengsheng-v0.4/research/constructions/构式与微型模型.md)）。每卡以有穷之例拒一些推论。各卡与本书之关系如下；微型模型是文理生生之构造之例，不入脊柱。

**各自所缺。**

- **本表有而文理生生无。** 待、资、足与需、容、取与、衡、耗与端、恒与竭、广狭与益、顾。也就是理论关于依存、流、耗散、扩大与意义的全部之名。文理生生的模型是有穷闭世界，所以也无法陈述开放之律。
- **文理生生有而本表无。** 以下几样，本书应当学：
  - 一套「不强制转换」的类型纪律：辞、程、规范、证据、读法各为一类，不相混；
  - 逐义项的出处；
  - 一份冻结样本上的两份试标及其一致之数（项目自注：是两份 AI 独立试标，不是人类实验）；
  - 在 12 处异读中，字义更贴近原文（见下节）。

**结构。** 文理生生的推理在一个现代的形式层上进行，汉字是手工绑定的接口，没有一个义项直接接到它的执行器上。本理论的推理在 Lean 里，古典之名锚定在声明上。两边因此各自走到了同一个两层的结构：一层是形式的核，一层是古典的读法。

有一处本理论更彻底：文理生生把观与证放在模型之外，作为元层；本理论把知放在展开之内（识）。

文理生生的候选文法是「五元一镜」：辨、系、序、化、限五类操作并列使用，观／证为镜（[总计划 §三](../../../sources/wenli-shengsheng-v0.4/research/references/01_文理生生_以古文为基的最小概念文法_研究总计划_v0.1.md)，[基础全图 §二、§三](../../../sources/wenli-shengsheng-v0.4/research/references/03_文理生生_基础全图与动态文法_v0.2.md)）。镜见第一部分 §六。五元之字分见逐字之对照：辨、序、化同构，限部分同构，系同字异构（本表以系名系辞）。作为五个原语，文理生生自己说它们「尚未被定义并证明为五个不可替代的语义原子」（18 号 §七）；脊柱上的最小只对一条法、一个类而言，没有一个普遍的最小语法（第一部分「本节未立者」4）。

## 文理生生的形式部分与八卦

**形式部分。**

- 文理生生的语法 G1 是带测试与交集的命题动态逻辑，加多类一阶量化，判定在有穷闭世界上。
- 它的两个形式结果都是已知数学，而且有限度：
  - 22 种构式归约为 13 种（G0），是手证，用了古典逻辑；
  - 「无界有限可达性不能由固定有限观察半径的表达式统一替代」，限于固定的局部原子词汇、前向的关系与模态组合、无闭包的有限表达式（[basis/lower_bound_review.md](../../../sources/wenli-shengsheng-v0.4/research/basis/lower_bound_review.md)），是一阶逻辑之局部性一类的已知事实。
- 按本库的标准，它们记为与已知结果之关系，不进入脊柱。

后者与本理论的几条律同向：

- `Becoming.Learning.no_prefix_fixes_next`：没有一段有穷之往能定下一个值；
- `Becoming.Identification.bounded_agree_exact`：给出界，往的长度恰好够用。

文理生生的 G1 可以作为脊柱上「系辞」一层的查询语言。若要嵌入，须在定然否之下证明两边相等，这是一个可以认领的后续项目。

**八字有类型规则图。** 文理生生把生、变、势、理、分、合、中、和八字之图的十三条邻接逐条处置：九条有界之现代规则，四条规范接口；每条有所选义项、前提、结论、反例与可复跑之查询，依重组、约束可达、表达与评价三个公开的模型（[八字有类型规则图](../../../sources/wenli-shengsheng-v0.4/research/graph/八字有类型规则图.md)，[规则案例](../../../sources/wenli-shengsheng-v0.4/research/engine/README.md)）。图中八字所取之义多与本书之名不同（生取实例入类，势取可达画像，理取结构条理与可行路径之限），所以十三条规则不移作脊柱之律，只按结构对照（讀，AI，D63）：

- edge_03（势—理）：收紧允许之边，可达不扩大。同构：一变之步皆在另一变之中，则前者所能至者后者皆能至（`Becoming.Branching.SubProcess.reach`）。
- edge_04（分—合）：分而再合，部件重聚而原整体不复（新整体 D 不是 A），谱系不等于同一。与本书复只指构形再得、续另名跨步之同一、所出另名世系相合（见上「复」）。
- 四条规范接口（edge_05、06、09、13）：事实与规范分算。edge_05、09、13 中可行不推出合宜，合宜不保证可行；edge_06 中未发不推出其后之表达皆和，已发而合所列之全部标准方称和。与脊柱「所表示的动力学不定顾」（`Becoming.Web.significance_undetermined`）同向。
- 其余诸边依所选之义与模型而立，本章不对应。

文理生生的审计说，此图是一项研究取舍，不是八卦，也不是已经恢复的古典知识之总拓扑（18 号 §五）。

**八卦。** 两边用同一种编码（自下而上，阳为真），所以能逐卦比较。

- 同读：
  - 文理生生的「反相回路」就是本理论的消长环，是同一个函数、同一个环；
  - 它的「清零传递」就是 `wane`，两边都说坤之吸收属于所选之律，不属于坤；
  - 互卦有损，且不幂等；
  - 卦序不是一条律，只是一张表；
  - 说卦第三章的四对恰是错卦；
  - 取象的对应条件，就是本理论的 `Lumped`。
  - 粗化可造出不存在的环（[11 号 §十](../../../sources/wenli-shengsheng-v0.4/research/references/11_八卦系统与组合文法_动力结构与转化_v0.1.md)、[14 号](../../../sources/wenli-shengsheng-v0.4/research/references/14_八卦动力学验证_v0.1/README.md)之抽象反例）：具体只有 a→b、c→d 二边，a、d 记为乾，b、c 记为坤，聚合之卦间边成乾→坤→乾，可以无尽地循环，具体却没有一条二步之路。这就是以类代状之变之路多于变之路（第一部分 §四 律 4）。11 号所立之条件（每一具体之状，其后继经取象恰是抽象之后继），在取聚合之边时就是 `Becoming.MatchesThrough`；以类代状之变如实给出诸路，恰在此条件成立之处（`Becoming.image_exact_iff`）。同构（讀，AI，D63）。11 号与 14 号另有同步之共同终点之反例（每一原子过程各自可提升，二者之交仍可不保），本章不对应。
- 各有所长：本理论多证了互卦之迭代（一个二步的吸引子与 16、16、32 的势），并把卦序之律机器检查到原文；文理生生守住了说卦文本的界限，不把后起的方位图读进原文。

## 怎样检验「最合适的表达」

讨论之后，可以分开说的有两层。

- **已有理由支持的。** 讀（AI，D63）：古书与汉字中这一条线，是核心之语言与认识论的一种贴切的表达：以逐步之值为文，以动与构之合为字，以反复读中重建内在生成之理为知。理由是它的每一环在核心中都有已检之律相对，并写明其成立与不成立之处（见本章第一部分）；其中「物相杂」只是定域，字之组合只有所给之语法之律，读者怎样到达他的类也没有导出。
- **尚未检验的。** 它是否比其他表达更贴近，以及是否「最好」于一切可能的表达。

后一层只能部分地检验。下面两项设计只比较所运行的几种表达（阅读试验比古典之码与受控之英文码，忠实之测比中华本之经与英文本之句），古典之码输了可以推翻「更贴近」，赢了也不判定它「最好」于一切表达（DESIGN-H2 §1）。设计已经写好，都还没有运行：

- **一个阅读试验**（[DESIGN-H2](../../../experiments/wenli-reading-transfer/DESIGN-H2.md)）。这是文理生生 H2 的一种检验：同一个冻结的核心，以古典之码与受控之英文码、同样篇幅，交给不同的读者，比较他们对未见之例的结构重建与反例处理。
- **一个现在就能做的忠实之测**（[FIDELITY](../../../experiments/wenli-reading-transfer/FIDELITY.md)）。对中华本的每一條，以及英文本中同一律的陈述，计数措辞引入了几个 Lean 陈述所没有的关系项、施动者或实体。

两项都写明了什么结果会推翻什么主张。

## 未决与限度

- 「最好」未经检验，见上节。
- 文之立名是一项约定，属讀（AI，D63）。依名表的规则，它可以被更好的论证修订。
- 两个项目的相合不是统计意义上的独立证实（见对照一节）。
- 文理生生的形式结果没有 Lean 证明，记为与已知结果之关系。
- 文本都是电子转录，未与刻本对校。
