# 生成中的知识

> **中文版（2026-10-17）。** 正典文本是[英文版](KNOWLEDGE.md)；本版由重构时从双语原文拆出，只含原文中的中文段落（多为各节要点），完整论述见英文版。本版不与英文同步维护，两者有出入时以英文为准。

<a id="the-account"></a>
## 论述

**相连候选已完成：**后续研究解释可能性的纳入、参与地位与可纠正的结束；不宣告全部哲学或更强基础目标完成。

**命题知识是这样的真实判断：它的形成或当下维持，通过认知能力与使其正确的实际关系相连；面对相关的出错可能，其正确不是偶然碰中。** 它须能进入知者实际的认知活动；某处存有一句真话，不就等于某人已经知道。这个表述是本研究辩护的候选，不冒称已经解决一切知识分析争论。

知识可以使实际关系进入后续的理解与回应，但不要求每项知识都已经产生实际用途、道德收益或永久记忆。认识的形成也不创造它所声称的全部事实：知道一件过去的事，不会使那件事现在才发生。

<a id="how-knowing-differentiates-within-one-unfolding"></a>

<a id="how-content-becomes-cognitively-available"></a>
## 内容怎样进入认知

**知识的持有不等于信息存放。关键是某种有内容的区别，能够进入实际的判断、推论或熟练回应，并在其所论关系中得到根据。** 这不要求每个知者先证明自己的可靠性，也不把一切调节或反馈都命名为知识。短暂知觉、尚未使用的知识、社会支持及暂时受阻的能力各保留其范围。

<a id="how-content-can-form-and-remain-mistaken"></a>
## 内容怎样形成，又怎样保留所指而出错

**生成的内容可以保留所指而出错，正确的内容也可能被错误运用。** 内容的形成、内容的真假、判断的根据及运用的伦理意义，是同一过程中的不同关系；不能由一次成功或一个整体名称抹平。

## 理由与标准怎样取得

**理由的形成不等于理由的正当；对根据的辨认也不等于已经依此修订。** 共同认识能够生成新的接近与检验，也能够复制并强化同一错误。整体观点要求追踪这些实际关系，而非把共同接受当成真。

<a id="hard-cases-and-scope"></a>

<a id="knowledge-through-changed-concepts-and-methods"></a>
## 概念与方法改变之中的知识

**认识的接续要求说明前后所问、所指及根据怎样相连；新问题、新根据与旧答案的纠正不能混作一件事。** 新认识也可能确认某些旧区别已经失去，不能以当前方法自动补写过去。

<a id="objectivity-and-explanation-within-the-unfolding"></a>
## 展开之中的客观性与说明

**客观性的形成，不等于共同接受制造真；生成的说明，也不等于给一切现象加上“生成”之名。** 本理论须接受它对其他解释所提出的根据、范围和纠正要求。

<a id="warranted-extension-beyond-investigated-conditions"></a>
## 超出已调查条件的有根据推展

**有根据的推展须说明支撑关系怎样延续；同属一个生成整体，不保证局部规律永不改变。** 错误的后果可改变调查与依赖的要求，不能被当作偏爱结论的证据。

<a id="inquiry-sufficient-understanding-and-timely-response"></a>
## 探究、足够的理解与及时回应

**智慧不要求先知道一切；它要求有根据地辨认哪些区别会改变回应、哪些仍可保留未定，以及何时继续调查会错失真实的回应条件。** 这一方向保留求知本身的意义，也保留不同参与者的能力、责任和实际负担。

<a id="relevant-possibilities-and-standing-in-shared-inquiry"></a>
## 相关可能性与共同探究中的地位

**有理由查，不等于已有理由信；有相关认识、直接受影响与有权决定，也不是同一种地位。** 共同认识的范围须可说明、可挑战、可修正；有界结束保留未知和重开条件，并不要求事先穷尽一切可能。

<a id="g0-truth-and-wisdom"></a>
## G0、真与智慧

G0 作为明确的伦理起点保留：**整体中的生及其继续生成具有基本正面规范意义。**

**智慧比知识多一层：它要判断哪些真实关系在此刻重要、怎样回应、由谁承担、何时停止或改变方向。**

<a id="what-the-theory-explains-and-what-remains-to-establish"></a>
## 理论解释了什么，尚待确立什么

**生成可以解释认识怎样发生及进入生活；知识还要求所论内容真实，且其正确有实际的认识根据。G0 说明其中的正面方向，不单独判定真假。**

<a id="toward-the-broader-philosophical-account"></a>

<a id="frontier-when-acquired-relations-support-understanding"></a>
## 前沿：取得的关系何时支持理解

**前沿方向：检验已形成的关系怎样成为可辨明根据、可保留所指、可选择性修订的理解。** 已有机制不重开；四项统计量复核不冒称新实验。G0、进一步比较承诺与真实对应仍分别明示；意识、普遍语义充分性及整套理论必要性继续开放。

<a id="selective-revision-and-the-warrant-for-reliance"></a>
## 选择性修订与信赖的根据

**会按根据改变判断，还不等于已经有根据地判断了哪些来源可依赖；两份相同记录，也不自动构成两条独立认识路径。**

<a id="acquiring-grounds-for-reliance"></a>
## 取得信赖的根据

**有根据的信赖须追踪报告怎样形成、哪些错误会一同传递，以及检查在什么范围内有效。可修正性不是把真实取消，而是保持对同一实际关系继续负责。**

<a id="evidence-guided-model-revision-completed-connection"></a>
## 证据引导的模型修订：已完成的连接

**修订的根据来自新的可检验差异及其实际检查。它可以增加确信，也可以揭示原来没有承认的不确定；完成一次调查，是完成其有范围的回应，不是取得不可修正的全知。**
