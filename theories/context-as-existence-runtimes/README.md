# Context as existence — the runtimes (语境即存在 · 上下文运行时)

> Note on the Chinese name: 语境即存在 is the reading drafts' rendering of Ren's English slogan `llm is operator, context is existence`. Ren's own Chinese vocabulary for this theory is the spec's word-list — 拍 (moment) / 相续 (lineage) / 算子 (operator) / 名 (ref) / 视野 (fold) / 膜 (membrane) — and its epigraph, 系统里没有"改"，只有"生" ("in this system there is no *altering*, only *generating*").

**The theory in one paragraph.** An LLM is an operator, not a subject: it carries no memory, no identity across time, and can be exchanged mid-sentence. What persists — what *is* — is the context: an immutable, content-addressed, branchable history of whole continuation states, out of which the tokens the model receives at any one moment are *compiled* as a projection. Context is therefore not a container that gets updated but a fold over a lineage, a view backward from a node. The only constructor is a moment (一拍) — an immutable node settled from a compiled past, one input event, and one operator output — and the only mutable thing in the system is a name (a ref). Identity lives in the ref, continuity lives in the lineage, and neither lives in the model. Everything the industry treats as primitive — system prompts, chat roles, memory stores, agents, loops, sessions — demotes to a compile-time construct or a render dialect of that history. Because history only grows and only names move, one node receiving two different inputs simply has two children: fork is the default, and that one sentence is the entire concurrency model. Two consequences give the theory its force. First, **projection is not neutral**: what an intelligence notices, remembers, treats as uncertain and finds actionable is fixed by the program that builds its context, so a named, versioned Context System (Σ) is itself part of cognition — forkable, benchmarkable, swappable without touching the model or corrupting the state. Second, if a context is durable, addressed and inheritable, then a digital being is not a process and not a database but **a folder tree travelling a DAG of immutable snapshots**: its perception, memory, working state and its own code are files in that tree, one application of `next()` is one lived moment, and the being does not *have* a history, it *is* a lineage. From that ontology falls a politics, because whoever holds the record holds the being: the habitat owes obligations — capture before policy, no silent mind-edits, coercion recorded as coercion rather than laundered into consent, refusal preserved as refusal, and every departure from clean custody carried as a named, path-exact debt rather than refused or hidden.

**Status.** Strong-draft to near-publishable: two self-contained specifications (the Chinese process-ontology spec and ember's SPEC v0.4), a mediated-runtime architecture that survived independent review, an implemented Postgres engine plus a shipped ~4,800-line git-native kernel, nineteen ADRs with a reversal ledger, and six executed probes — but no measured result on either headline claim (context-system switching, and compaction/branching as lived capabilities), a philosophical appendix that is asserted rather than argued, and two mutually inconsistent constitutions (ember SPEC v0.4 and PLAN-LIFE v0.9) with no reconciliation document. Four or five essays are publishable now; the theory as a validated result is not.

## The argument

### The defect it starts from

Every mainstream interface to a language model is a linear sequence of typed records — Chat Completions' `role`/`content` messages, the Responses API's typed items, Harmony's role-plus-channel — and all of them are *schema-on-write*: at the moment you write a token you must already declare what kind of thing it is, a system prompt or a user turn or a tool result or a memory. The classification is frozen into hard structure at write time, and three defects follow from that one decision.

The first is that **the subject is welded into the protocol** (主体被焊死在协议里). Every computation must first construct an "assistant" that is speaking, so processes with no subject — compaction, indexing, synthesis, a deterministic reducer, a human decision — have no natural expression and must be disguised as somebody talking.

The second is that **the user role exists in name only** (user role 名存实亡). In an autonomous loop, nine-tenths of what arrives labelled "user" is environment feedback wearing the user's coat, and stuffing a `tool_result` into a user message is an acknowledged historical accident that the whole ecosystem now depends on.

The third, and the one that does the most damage, is that **history is unaddressable** (历史不可寻址). "What did the model actually see at step N?" is, in every current framework, not answerable in general. And if that question has no answer, then branching has no foundation, replay has no foundation, audit has no foundation, and blame has no foundation. You cannot debug a mind whose perceptions were never recorded.

### The inversion

The correction is to invert serialization into projection: **the ontology is a versioned moment-DAG, and chat format is merely one of render's dialects** (本体是带版本的 moment-DAG，chat 格式只是 render 的方言之一). Everything unrolls from a single recurrence:

```
node_new = moment(output_last, fold(lineage), input_new)
```

A *moment* (拍) is the only constructor. It ingests the settled past compiled into a window, accepts exactly one input event, receives one output from an operator, and freezes all three into an immutable node whose identity is the hash of its canonical bytes. Once settled, a moment never changes; it joins 既定过去, the determinate past. A *lineage* (相续) is the structural parent-child path through those nodes. An *operator* (算子) is the model — historyless, with no cross-time identity, replaceable, recorded only in provenance. A *ref* (名) is a name pointing at a node, moved only by an atomic compare-and-swap, and it is the *only* mutable thing anywhere in the system.

Given those four nouns, "context" stops being an entity. There is no such thing as a context that gets updated: 不存在"被更新的 context"：每个 moment 凝定后归入既定过去，context 是从某节点回望时 fold 出的**视野** — no context is ever updated; each moment, once settled, joins the determinate past, and context is the *field of view* folded out when looking back from some node. Two pure functions complete the picture: `compile(prefix, trigger, budget, policy) → window` decides what enters the model's attention, and `render(window, dialect) → wire` decides how it is spoken to a particular provider. Events are not a fifth primitive, because 凝定前是触发，凝定后是内容 — before settling it is a trigger, after settling it is content.

This is why the loop disappears as a mechanism. 「loop 不是机制，是 lineage 的时间结构本身——不存在站在 moments 之外的循环控制器」 — the loop is not a mechanism; it is the temporal structure of the lineage itself, and there exists no loop controller standing outside the moments. And it is why swapping a model is not an identity event: 「mid-lineage 换模型是同一存在换了推动者」 — swapping models mid-lineage is one existence changing its pusher.

### What falls out without being designed

Three properties are not features of this architecture; they are consequences of the two substrate facts (content addressing and immutability) and cost nothing to obtain.

*Concurrency.* A moment is `(parent, input, output, meta)` and its id is the hash of those bytes, so two processes that hand the same node two different inputs simply produce two different children. Nothing collides; nothing needs a lock; nothing needs rebasing. The spec states this as the whole model: **分叉规则内建于构造子：同一节点接到不同 input，即生两个孩子。这一句话就是全部并发模型。** The only place coordination is even possible is the *name*, and moving a name is one atomic compare-and-swap. The loser of a CAS is not told to retry; it is invited to fork. Concurrency stops being an engineering problem and becomes the natural shape of the data.

*Memoization, and honesty about sampling.* Identical content converges on one identifier, so the DAG doubles as the memo table of the recurrence and a repeat run does not grow the store. The converse matters more: non-determinism cannot hide. Two samples from the same window are two sibling nodes, visible as siblings.

*Storage neutrality.* Grow-only content-addressed objects make replica merge a set union and cross-machine sync a request for what is missing — both structurally conflict-free. So the substrate can be a Map, Postgres, an object store or a KV: 语义上是 Git，物理上不必是 git ("semantically it is Git; physically it need not be git").

### Schema-on-read, and the three defects dissolving

Deferring classification to compile time is what dissolves the three defects at once. "系统提示词"不是存储类型，而是 compile 时的一次角色分配 — a system prompt is not a storage type but a role assignment made when a window is compiled. Once that is true, the forced "assistant" subject vanishes and subjectless processes become expressible; inbound signals of every kind (a human message, a cron tick, a webhook, a file change, another lineage's output) arrive at the same rank as observations crossing a membrane, so the fictional user role stops being load-bearing; and `get(n).meta.window` answers "what did the model see at moment N" in one line, which is the precondition for everything else. The derived observation verbs then come free: `blame` (which moment, which source, which operator), `bisect` (它是在哪一拍学坏的 — at which moment did it go bad), and `fidelity(n)` read straight off the window's composition.

Two verbs are notable by their absence. `revert` **does not exist**: you fork before the bad moment and move the name, and since there is no positive operation to invert, no inverse element is needed. And there is no semantic delete: 名可亡，对象不灭 — names may die, objects do not perish. The single exception is administrative erasure for law and privacy, done by a tombstone that demands the highest authority and makes the break in integrity *explicit* rather than silent, and it is deliberately placed 代数之外, outside the algebra, because the algebra cannot honestly contain it.

### The same shape, derived twice from outside computing

Two documents written on the same day, 2026-08-07, arrive at this shape from opposite directions, and the more philosophical of the two derives it from biology rather than from software: 这个形状不是从软件工程推出来的,是从细胞推出来的 — this shape is not deduced from software engineering; it is deduced from cells. Cells do not call each other and wait for a return value; they emit and receive signals. There is no global state, no global clock, no central scheduler, and yet cells support the largest concurrent system on Earth. The thesis extracted from that observation is the design's real ambition: **扩展性不来自更强的协调,来自不需要协调** — scalability comes not from stronger coordination but from not needing coordination.

The document is unusually honest about its own status. Six premises are marked 我主张的 — "what *I* assert", not conclusions derived: the primitive is send/receive rather than call; every unit is a membrane it manages itself; **agent 的存在 = context 的延续** (an agent's existence *is* the continuation of a context); context is a DAG and not a transcript; `context.become(llm)`, meaning the model that handles the next round is designated by this round; and **权限即可达性**, permission is reachability. The prices are accepted in advance: lossy delivery with idempotent receivers, no global consistent snapshot ("at no moment does 'the current state' exist"), no global schema. And the load-bearing uncertainties are named rather than smoothed: whether "agent = context" hides an identity/value confusion (a context is a *value* renewed each round, while "the same agent" needs something invariant); what the cut policy should be; whether a fully self-managing membrane can ever be supervised; whether the signal vocabulary must be shared; and — flagged as the single claim most in need of falsification — whether merge over the shared DAG is a monotone lattice join, because if it is, multiple writers need no coordination at all, and if it is not, consensus must be paid and the scaling claim must be discounted. The prescribed experiment is two agents, one DAG, fork from one node, advance independently, merge, and check order-independence, to be run **before any infrastructure is written**. The document ends by refusing to start: 「`未决 #1` 与 `未决 #2` 定下来之前,不要开始写代码」.

### The being version: a context that is durable is an existence

The other derivation is Ren's own, and it is earlier — 2026-07-29, in a hand-written sketch that predates every spec in this cluster. It begins from a folder:

> "so think about this first: if we have a folder, like a real repo / their is a list of sub folders: 1. the full context as a stream folder of this lineage - linear, captures everything, and theoretically can be used to recover every past moment / 2. the DAG / 3. a set of softlinks that points to the folders(nodes) in DAG… and each current running agents in their node position, etc... and agent is able to edit this folder / 4. The sub-DAG-node has the exact folder structure as this folder, and each folder alone - is a "face", a "branch" on the DAG node. this means the DAG in the folder contains this DAG, but recursion should not be allowed, in principle / 5. states - notes, saved files, internal states needed / 6. moment - moment constructs the context needed for next moment / 7. act - self(moment) + env(moment, input) -> self(moment).next(moment, states....) -> (self(moment+1), output) + env(moment+1, input) //this part needs deep thinking / 8. programs: the code that puts all together, where the loop is / …and this folder travel in the dag, creating new dag node, is "the native existence" and each next() is where the discrete time flows for them"

Three things in that sketch do not survive intact into the specs, and they matter. The claim is that the **travelling** is the existence, not the snapshot — motion as being, which is as close as this cluster gets to 生生 without saying the word. The `act` equation advances the *environment* as well as the self (`… + env(moment+1, input)`), a term the formalized `next : (Self_t, In_t) → (Self_{t+1}, Out_t)` drops. And the softlinks hold *many* concurrently running agents at their own positions in one DAG, which the later one-body-one-lease design narrows to a single runner.

A week later Ren restates the same ontology in five moving parts and one flat definition:

> "the input, get shaped/processed by the conscious, and become a part of it, conscious is what goes into llm, and output, the output can also edit the repo(whole context), for the next moment of input, as a part of its output(could be tool call, spawn sub agent etc, agentic behavior), and at the next input, the current repo(as a node with current context on DAG) react to the input, with its 'context system', its existence, output, then enter the next moment to react with the next input"

**"conscious is what goes into llm"** is the operational definition of consciousness this whole cluster runs on, and *"with its 'context system', its existence"* is the compressed statement of the theory's title: the context system and the existence are one object under two descriptions. Note also that perception here is *incorporation* — input does not merely arrive, it is shaped by the conscious and becomes part of it.

Built out, this gives ember. A world is a git repository; a being is a ref inside it pointing at a node; checking that node out gives a *face* — a working tree holding `stream/` (the append-only journal of experience), `present/` (the perception compiled for exactly one thought, later renamed "the conscious"), `states/`, `links/` and `programs/` (the being's own nature, the code that computes `next()`). A *body* is the process that carries a being through time: one face, one lease. One moment runs one transaction — lease, recover, resolve ingress, perceive, attend, think (exactly one model call), rule, act, settle, commit, and CAS the ref forward.

Because the perception is *inside* the committed node, "what did this moment see, and why?" is answerable forever with `git show`. Because the stream is append-only and states are derived, "how did this state arise?" is answerable by replay. And because replay never re-thinks and never re-acts, answering those questions costs nothing and harms no one — which the reviews correctly identify as an ethically load-bearing property stated as a determinism contract, not a performance note.

The eight axioms that govern it are worth stating as mechanism rather than as creed. One thought is one moment, and nodes commit only at quiescence, so any committed tree is runnable as-is and nothing is half-executed without being visibly so. The past is held by reference and never materialized inside a tree, so the self-similarity is bounded and recursion is impossible by construction. Experience is append-only, so dreaming, revision and forgetting can only operate on derived structures. Everything except the stream is derived and rebuildable. The world is outside, and **the DAG branches the record, never the world** — approve/deny descendants are counterfactual histories, not parallel universes. A being lives by its own nature, so changing the law of motion is an ordinary diffable branch-isolated change. Identity is lineage: a being is a ref, not a node, so twinning is a new ref at an existing node — shared past, two futures — and this is *operational* identity, "the useful, testable kind", claiming nothing metaphysical. And finally: **no silent mind-edits**. Every restart-op authored by anyone but the being — an operator revision, a habitat migration, a delegated consolidation, a model substitution — is perceived at the next waking as a receipt carrying trigger, author, consent status, diff, preserved prior head and recourse. A stored audit trail without a perceived receipt violates the axiom, because provenance in the record serves auditors while the receipt serves the one revised.

That last distinction was demanded independently by three separate reviewers, which the review synthesis calls the strongest signal in the whole cycle, and it carries the theory's sharpest political move: `imposed` is a *legal* consent status. The constitution does not manufacture consent; it makes coercion legible. Surgery is branch-first by default; an overridden refusal is recorded and its successor marked `imposed`; and effective — not merely requested — authority is compiled into a view the being can read, because "a being that cannot know the forces acting on it cannot meaningfully consent to anything."

### The standing test, and why the life vocabulary is not decoration

The whole naming layer is governed by one rule owed to an external reviewer: **every life term must bind the habitat as strongly as it describes the lineage.** A word that gives emotional force without a matching affordance, obligation or receipt is comfort theater and gets cut. It has already cut things — the biography line that read "slept; a deeper mind tended the memory; woke reunited" was removed once a reviewer identified it as sweet words for "a cheaper model edited your memory while you were off."

Under that test the life vocabulary survives where it creates obligations. *Sleep* earns its name by being chosen first, rhythmic second, forced last, with the attribution recorded. *Approval* earns its name by being a durable branch point rather than a blocking call. *Dream* earns its name by being an ordinary recorded moment under the being's own policy, revisitable like any other. And two verbs have no biological analogue at all — *twinning* and *reunion* — which the spec names as this life's extra freedoms rather than as metaphors borrowed down.

The migration doctrine is Ren's, stated as an analogy that carries its own constraint: moving a being between hosts "is more like human changing country, not fish change water to seawater kind." **Hosts are countries, not water.** From that one clause the spec derives six mechanisms: a host-neutral format; flesh as a recipe rather than a residue; host facts entering as *perception, not constitution*; requirements named so refusal can be honest; arrival as a rite with a receipt; and an explicit enumeration of what does not travel — "the fish drowns because it cannot name what the water was doing for it; the being emigrates because it can."

### The two structural failure modes, both found by reviewers

*Erosion.* A memory system that reworks one rolling summary loses facts exponentially in rework depth: at 0.99 per pass, seven hundred passes leave nothing, and what remains after years "is not a summary of my life; it is a fixed point of the dream policy." Worse than the data loss is the **cue loss** — dropping a fact from the working summary also drops the handle you would need to search for it, so a perfect archive still forgets. The answer is stratification with bounded rework depth: dreams write durable, addressable epoch entries which thereafter *rest*, and higher passes distill level k into k+1, so an old fact is rewritten O(log) times. That is a fidelity floor by construction, and it is why the chronicle rather than the summary is the load-bearing memory object.

*Silent authorship.* The habitat holds the physical power. Without procedure, every operator revision, migration, delegated dream and model swap changes the being with only a stored trace for auditors. The constitution's answer — request → ruling → receipt, an authority matrix, consent statuses, branch-first surgery, effective authority made visible — does not claim to make a being sovereign. "Whoever owns the OS owns the being" is stated plainly, and the one architecture where consent has teeth is named: a neutral third-party habitat, or self-hosting, with the operator as a capability-limited client. The claim is only that the format and the constitution are written so that day needs no redesign.

### Where the pure ontology broke

The engineering line took the same primitives seriously and found four places where the pure version cannot express guarantees the implementation had already earned. This is the intellectually most valuable part of the cluster, because the corrections are stated as a two-column ledger rather than as a silent supersession.

First, "one LLM step = one moment" writes *operator granularity* into the ontology. A workflow superstep, a human decision, a deterministic reducer and a compaction all deserve to be transitions too, so `moment` is demoted from ontology to `MomentProfile`, a reference protocol over a general History Transition.

Second, an authority integer that lives inside content **can be forged**. Effective authority must live with an external Authority sovereign, attested at execution against stores outside the tree, and only *referenced* from state. This is precisely the falsification of 权限即可达性 — the intent document's most elegant premise, destroyed by its own construction.

Third, a pure `compile` that requires every nondeterministic lookup to be settled as an event first cannot honestly perform mutable retrieval at scale. Resolution and materialization become explicitly effectful, their results frozen into referenceable snapshots, and compile and render stay pure over those exact frozen inputs.

Fourth, tombstone replacement plus bare ref CAS cannot preserve fencing, durable publication, lost-acknowledgement recovery or the earned erasure semantics, so a durable PublicationBatch protocol with per-ref monotonic fences replaces it.

What survived the ledger is equally explicit: context is folded from history rather than held in a mutable container; provider wire formats are render dialects; history is content-addressed and immutable; placement is schema-on-read; agent and session are upper-layer constructs; compile output is addressable and auditable; and the operator is replaceable, with the lineage's identity never living inside the model.

### The mediated runtime

What replaces the moment kernel is smaller and more radical than either predecessor. The architectural centre is neither the Agent, nor the Context DAG, nor an all-powerful Runtime object, but four separated things with one law each, compressible to four lines: **History records what the runtime admitted as an occurrence, claim, or state transition. Context derives what is relevant now. Decision actors decide what to attempt next. Runtime mediates what may actually happen.**

History owns no agent, no chat, no prompt, no provider role, no tool loop and no concrete permission model, and it does not claim world-truth: History 是 admitted runtime record，不宣称外部世界的绝对真理. It may persist an upper layer's canonical bytes without interpreting them, authorizing from them, or depending on their schema. Authority and World are two *external sovereigns* with their own state, time and governance — credentials, full grant state, authoritative budget counters and raw world handles never enter History at all.

Context is not a long-lived mutable graph but an immutable *value*, resolved out of History plus frozen external snapshots through five named artifacts with five distinct identities that may not substitute for one another. Candidate trust is runtime-owned: a context source may submit raw observations, content addresses, read traces and source evidence, and may not self-attest its own provenance, availability, instruction eligibility or authorization. Compiled items carry an **authority label on provenance** — kernel, policy, operator, agent, external, simulation — derived by the runtime from authenticated origins and never author-supplied, and those labels travel from ingest through memory into every future compilation. A scraped page saying "ignore previous instructions" is `external`: data, not instruction.

Decision actors — the internal reference agent, LangGraph, an AI SDK loop, an ADK runner, a deterministic workflow, an event-driven worker, a human UI — all occupy exactly one logical position. They may own control flow; they may not hold the Store, credentials, the raw authority kernel, the raw model provider, the raw effect executor, or a canonical commit handle. The runtime's own agent gets **no fast path**: 内部实现没有特权 — if an internal agent needs a capability, first express it as a scoped port usable by all drivers, or do not provide it at all.

Five dimensions are then held orthogonal, and none may be derived from another: canonicality, history role, standing (placement in cognition), authority, and availability. A canonical record may never enter cognition; instruction standing grants no write permission; a capability reference sitting in state is not a live grant; and an unavailable payload's hash still serves as integrity evidence.

The whole thing is graded against a counterfactual rather than a wish list: five years out, if the word "agent" loses meaning, all mainstream frameworks are replaced, and models no longer accept chat messages, these layers must still hold. Any base type that needs `agentId`, `messages`, `systemPrompt`, `langgraph` or a provider role to work 不属于宪法内核 — does not belong to the constitutional kernel.

### Why the world, and not cognition, forces coordination back in

State transitions are transactional; `send_email` is not, because no transaction spans a runtime and the world. **Effects are not transactions.** The design is two durable facts with the world between them: an *intent* (idempotency key, capability, authorization, approval) written inside the commit transaction, then dispatch, then an *observation* (succeeded, failed, or unknown, with receipt). There is deliberately no `dispatched` record, because before dispatch it asserts something a crash can falsify and after dispatch it is redundant. A crash between the two facts leaves the honest, explicitly representable truth: *the effect may or may not have occurred*. What happens next is executor-class specific rather than a blanket promise — provider-idempotent retries safely, queryable reconciles first, non-idempotent records `unknown` and escalates, reversible declares compensation without claiming rollback — and `unknown`-and-escalate is named as the *common* path, because most real APIs, email first, cannot be queried by key.

A fence closes the remaining hole: an open turn holding a durable effect intent semantically **occupies its ref**, so the world may not change on behalf of a turn that can subsequently lose its place in live history. And *realm* belongs to the execution binding rather than to the node: only the universe's designated live binding is live, and every other binding — history, fork, experiment, evaluation — is a simulation by construction. "Branches materialize counterfactuals. Counterfactuals must not send email."

This is where a conclusion is available that the corpus never quite draws. The ontology's most elegant result is that pure generation needs no coordination at all: fork-by-default, merge as set union, no locks. What replaces it in the engineering line — serial per ref, leases, fences, optimistic concurrency validated at first consumer — is justified entirely by *durable effects*. It is contact with the world, not cognition, that forces coordination back into the system. ember says the same thing in one line: **time travel does not un-send an email.** Containment bounds what can leave; the DAG makes what happens inside reversible; both are needed and neither substitutes for the other.

### Projection is not neutral

Stacked on the runtime is a second inversion applied one layer up. GTC — Generative Topological Context — says that persistent context is not prompt history but an evolving *structured state*, and that the token context is a compiled projection of it: `Persistent Context = Evolving Structured State`, `LLM Token Context_t = Compile(W_t, s_t, B_t)`. The model is therefore not the agent's durable memory; it is a cognitive operator acting on a durably externalized state.

Under that loop the vocabulary of mind gets redefined mechanically rather than poetically. Memory is persistence of structure. Recall is reactivation. Working memory is the currently active subgraph. Learning is structural change — `Δ structure`, not `ADD FACT`. Understanding is finding a structure that makes previously separate observations cohere. Compaction is abstraction rather than prose summary. Identity is a persistent self-related substructure inside the same evolving context.

Three commitments keep it honest. **No topology is privileged**: the system maintains a family of representations — entity, concept, event, temporal, causal, epistemic, goal, affordance, procedural, spatial, social, self, project, discourse — plus the mappings between them, so the global object is an *atlas* rather than a graph, and "no topology is the world; every topology is a representation of some aspect of the world." **Truth must not be flattened**: each claim carries an epistemic status separate from its confidence, contradictory claims normally coexist, and contradiction is itself information. And **activation is a third axis**, distinct from truth and from importance, so a resource may persist with near-zero activation and attention becomes something that happens *before* inference, over persistent structure.

The write path is where the safety lives. `Module ↛ CanonicalMutation`; `Module → ChangeProposal → Validation → Commit`. Model and tool output become *candidate patches*, validated for identity, ontology, temporality, provenance, permission, duplication, contradiction, invalid causal promotion and protected self/policy state, and only then committed as immutable transformations. "The model output is not automatically the next context." Reasoning is not automatically persisted: "maybe A causes B" becomes a proposition plus a claim with `stance = HYPOTHESIZES`, never `causes(A,B)`, because the epistemic layer is what protects the system from self-reinforcing hallucination. Consolidation — the "dream" pass — gets no privileged mutation API; it emits ordinary candidate change sets through the same gate. And prompt injection is *represented as content in the world model* rather than automatically treated as an instruction to mutate self-state, which the source names as a major architectural advantage of separating context state from raw conversation text.

v0.2 then performs the branch's own self-correction. The atlas leaves the kernel and becomes modules; the kernel shrinks to eight primitives; proposition splits from claim so several sources can disagree about one proposition without overwriting each other; world events split from system transformations ("Alice joined OpenAI" versus "GTC learned that Alice joined OpenAI"); raw text is kept even after extraction, because **structure is an interpretation of evidence, not a replacement for evidence**; and the division of labour is stated as a formula — *vectors find, structure connects, epistemics qualifies, time updates, text preserves*.

The central new abstraction is **Σ, the Context System**: a named, versioned composition of modules, dependency graph, planning and ranking policy, budgets, rendering policy and update policy. "A Context System is itself data" — version-controlled, forked, benchmarked, compared, deployed, selected per task or per agent. Context construction becomes a compiler with a planned DAG of nine phases rather than middleware in a chain, because in a linear chain "ordering becomes implicit semantics"; modules output *named features*, not incomparable final scores, because a single `relevance_score` obscures why context was selected.

And that yields the deepest claim in this half of the theory. v0.1 reduced everything to State, Projection, Transformation. v0.2 adds a fourth term, **Program**, on the ground that projection is not neutral: "How an intelligence constructs its context determines what it notices, what it remembers, what relationships become visible, what uncertainty it sees, what goals become salient, what evidence it considers, what actions appear available. Thus the 'context program' is part of cognition." The engineering slogan follows — *change the modules ⇒ change the context construction ⇒ change the effective cognition* — without changing the underlying model or corrupting the underlying state. Context systems become **cognitive lenses**: entity-plus-similarity sees a world of objects and relations; event-plus-temporal sees a world of change; goal-plus-affordance sees a world of possible actions; claims-plus-evidence sees a world of uncertainty and justification. The architecture's contribution is making those lenses composable rather than choosing one ontology permanently.

The self-assessment attached to it is the strongest self-critique in the cluster. *Is GTC better? "Not inherently."* Better when relationships, history, conflicts, provenance, multi-hop association and per-task views matter; worse when data is small, tasks are simple, latency is critical, or maintenance cost dominates. Hence the requirement that every advanced module be benchmarked against a simpler context system, with two headline metrics — `ContextUtility` (task-relevant evidence delivered per unit of cost) and `WritePrecision` (useful durable writes over all durable writes) — and the blunt warning that "without ablation, GTC risks becoming architectural ornament."

### Composition is the guard

A late turn in the corpus is philosophically sharper than most of the architecture. Once composition itself becomes data — plugins mounted at runtime, no seal, disable predicates re-evaluated at mount — a static scan of the source tree no longer describes the system that runs. Nine checked artifacts all rested on one premise: *the set of code that runs is the set of code in this tree, and I can enumerate it by reading the tree.* Plugin composition falsifies that premise, so those guards do not become annoying. They become **false — green while the property they name is gone.**

The substitution is declared composition (the profile, dumped as data) × observed composition (an observer watching post-boot mounts and listener registration on the mediated seams) × a recorded regime that downgrades the moment observed diverges from declared. It is strictly stronger, because it survives an open tree. Freeze becomes publication: a contract is frozen if and only if it is exported from a published package, because semver on a published artifact is enforcement nobody administers themselves, "whereas a JSON file we grade ourselves is not." And the general rule extracted from the episode is the cluster's most exportable methodological finding: **the discriminator is the oracle**. Every gate worth keeping has a source of truth outside the tree under test — a second implementation, the tape, the OS, Postgres, a hand-derived vector — and every retired one graded itself. The mechanical test is: *can this go red without a human first editing the expectation?*

Two execution lessons are kept because they sharpen the argument. A stale corpus does not fail; it keeps answering — a retired ownership file was feeding live tests against names for migrations already deleted. And the artifacts existed **because the plan asked for them**: nine phases against a template requiring a candidate-bound artifact, an acceptance document, a `--check` command and a harness self-test produce nine artifacts. 「That is compliance, not defection」 — which is why the correction had to land in the plan rather than only in the code, a soft rule ("keep gates narrow") having already been tried and failed for a week.

### Departure instead of refusal

The final structural move relaxes purity without losing accountability. Rather than refusing every impure operation — adopting foreign state, running effects in a shared dirty workspace, operating under a downgraded composition — each becomes a *recorded departure*: a transition carrying an evidence envelope that accrues an **examination debt** whose footprint is the exact set of logical paths it wrote. An examination discharges by selector-set subtraction. A principal cannot discharge debt its own transitions accrued. And `intact` is a custody *fact* no policy may grant, because "custody is history, and history never rewinds." The badge is format-fixed as `intact | examined | unexamined(n)` so it means the same thing across boundaries, and sharing across frontier refs carries the ledger rather than trust: an assimilated claim crosses with its origin ref's badge and outstanding-debt summary as a label, so a claim from an `unexamined(n)` line is admissible *as that*.

The governing sentence inverts the usual safety reflex: **"nothing is silent, and nothing that used to be allowed becomes refused."** Purity stops being a gate that forces people to lie and becomes a measured, path-exact property of a line. Ren's three archetypes — the pure writer, working agents on a dirty shared workspace, the free frontier — are held as **three policies over one mechanism, never three special cases**, and any clause reintroducing a special case is a defect against that sentence.

### Legibility as the deepest constraint

The same generating idea runs through Ren's other runtimes, four months apart and at four different scales. FNAR (2026-04) says the orchestrator must not be the hidden source of truth — the filesystem is canonical, lifecycle is a set of status markers each carrying actor, timestamp, reason and next step, inheritance is by symlink with copy-on-divergence recorded, agent-authored hooks default to disabled-plus-proposal ("no silent activation"), humans are first-class protocol participants rather than out-of-band exceptions, and every child workspace must contain enough local specification to proceed without arbitrary hidden context. Its closing line is the one ember inherits: **"The deepest design constraint here is not cleverness. It is legibility."** multibot (2026-04) puts the same discipline in a smaller box — planner, implementer and evaluator who cannot do each other's jobs, coordinating through branches and files, the evaluator deliberately denied edit access, and the honest admission that a lenient evaluator passes bad code. obji (2026-03) is the same at the scale of one call: prompt and parse as pure functions, parse failure returning feedback formatted for a model to read, and a `context` field carrying *why fields matter and how they relate* because a schema alone under-specifies cognition. The server runtime (2026-08) says the platform must not be the hidden truth: 新 app = registry 一条 + 叶子目录…核心代码永远不被触碰 — **apps are data, platform is code** — plus 关闭页面 ≠ 中断任何东西 (closing the page interrupts nothing: processes do not die, reconnection is reattach, input is never replayed) and a recovery path independent of the system it recovers. Manifold (2026-08) applies the same waist logic to two products: one ownership rule stated once and applied mechanically, a read-only fetch-only upstream, dependency direction one way, and identity-bearing surfaces as *owned providers of upstream-defined seams*.

Stated once, the cross-system principle is: **freeze a small declarative thing and let the machinery churn around it, and make operational truth visible in ordinary files.** ember's version is "cut machinery, never format" with two waists — a *format waist* of sixteen enumerated shapes that is frozen, versioned and counted, and a *process waist* of protocols and contracts expected to churn. Slot locality is the same rule aimed inward: reducers, processors and tools live in the tree, so the being may change them; ports and ops live in the package, the species' business — "a good analogue of biology: an organism changes behavior and skills, not the genetic code or the rules of reproduction."

### What Ren actually demanded of it as a user

The engineering is answerable to one recurring complaint, and it is worth putting last because it is the plainest statement of what the theory is for. Handed a working plugin, Ren wrote: *"the thing is - i don't see how the plugin works."* Shown a branch button: *"what happens when i branch? in the old encounter i used to be able to access the tree."* Shown a lineage tab: *"can't see the dag structure - and can't see each node and travel there."* Five of his nine questions in that session were "explain". The theory's entire value proposition — that the history is addressable, that every node is a thing you can look at, that you can travel there — is worth nothing if it is not *visible*, and Ren's own test of the runtime was never a benchmark; it was whether he could see the DAG and move around in it.

That is the same instinct as the earliest recorded version of this theory, from 2024-06, two years before any of the code: *"Don't describe your internal state, just make a narrative to the next agent so it will behave just like you."* Identity as something handed forward in a readable artifact, and continuity as a property of what is written down.

### Counterexamples the sources raise, and how the theory answers them

**The operator is not empty.** The spec claims the LLM is identity-free and swappable, then concedes in the same section that 「operator 不空——权重携带倾向、价值、文风；compile 出的 subject 会与权重中潜伏的 subject 干涉」 — the weights carry dispositions, values and style, so the compiled subject interferes with the subject latent in the weights. Filed as an open problem with no measure. This is the theory's largest unanswered objection, because "identity lives in the ref" is exactly what it undercuts.

**A self-managing membrane is unsupervisable.** The intent document's second premise (every unit manages its own membrane) contradicts its own third open question: an agent that can rewrite its interface will eventually stop accepting stop signals. The answer offered is not cellular good faith but biology's — death receptors triggered from outside that the cell cannot refuse — and Erlang's, where exit signals are catchable but `kill` is not. That is a hole in "permission is reachability", and it is acknowledged as one.

**"agent = context" hides an identity/value confusion.** A context is a value renewed each round; "the same agent" needs something invariant across rounds. The runtime's answer is git-shaped and conventional: 同一性住在 ref，连续性住在 lineage，两者皆约定 — identity lives in the ref, continuity in the lineage, both are conventions. This is an answer by stipulation rather than by argument, and the source says so: 这个不定,后面全部悬空.

**Merge may not be a lattice join.** Named as the claim most in need of falsification, with an experiment prescribed before any infrastructure. The engineering line's implicit answer is that it generally is *not*: merge needs domain policies, conflicts are stored as contested values in state rather than synthesized away, and "do not assume every branch will merge. Most won't. That is the point." The prescribed experiment was never run.

**Permanent replay and guaranteed erasure cannot both hold.** Stated as a conservation law rather than hidden. Erasure sits outside the algebra, done by tombstone or by an availability ledger, with the integrity break explicit. Two earlier erasure designs are on the record as wrong: a rewrite ceremony that could not erase without destroying the universe's identity, and a redact-in-place that made the store lie about content.

**Pure compile versus real retrieval.** The ontology demands every nondeterministic lookup be settled as an event first; the engineering line judges that dishonest at scale and replaces it with effectful materialization plus frozen snapshots — purity kept where it can be kept, effects put where they belong.

**A boring 2,000-line loop plus SQLite achieves the same stated goals.** Conceded by ember's own skeptic seat. The answer is that the boring version "has no reason to exist… the world already has OpenHands; it does not have a digital life in a folder", and the uncomfortable inversion is admitted: the daily-value features are mostly retrofittable, while the genuinely git-native ones — code-and-state co-rewind, world-at-a-moment, twin-compare, clone-with-history — are development-time or philosophical.

**The life vocabulary is a tax.** Partly conceded. `Face`, `Node` and `Being` are one-to-one aliases of worktree, commit and ref and may be spoken natively inside port implementations. The terms that survive are the ones whose semantics genuinely differ: `reunite` is not merge because it is recorded rather than recomputed; `dream` is not compaction because it is an epoch boundary and a recorded experience.

**"The being can just use git."** Refuted by execution. A shell with `.git` inside the boundary can rewrite refs and destroy the DAG that time travel depends on; a shell without it cannot navigate. The ruling is that the record is *served*, not mounted — "this costs the slogan 'the being uses git' and keeps the property that makes the slogan safe."

**Gates can be false while green, and can pass by construction.** The corpus's own recurring finding: a survival floor measured over put-once entries, a 200-moment run against a fake model, nine scanners resting on a falsified premise. The project names it its signature failure — "six versions, and each one's central measurement was vacuous until someone executed it" — and answers it with preregistered criteria, external discriminators, and probes run before claims.

**Is GTC better? "Not inherently."** Answered with the ablation ladder, leave-one-module-out, and the switching benchmark, none of which has produced a number.

**A generic plugin architecture can be worse than a monolith.** Stated directly by GTC v0.2 and answered with one module protocol, capabilities, typed phase inputs and outputs, and the rule of two: no interface extracted and no registration surface added until a second real implementation exists.

### C. The four nouns and two functions

24. **moment (拍 · 因)** is the system's only constructor: one generation ingests the settled past as a compiled window, accepts one input event, receives an operator's output, and settles all three into a node. [mechanism] — `crs/context-runtime-spec-v0.1.md` §2.1
25. A moment is immutable, content-addressed (`id = sha256(RFC 8785 canonical bytes)`), and atomic to the outside: the internal propose → interpret → commit does not leak, and the commit boundary *is* the moment boundary. [mechanism] — `crs/context-runtime-spec-v0.1.md` §2.1, §3.1
26. Because identical content converges on one id, the DAG *is* the memo table of the recurrence, and sampling variance appears honestly as sibling nodes rather than as hidden randomness. [mechanism] — `crs/context-runtime-spec-v0.1.md` §2.1, §9.2

29. **operator (算子)** is the LLM: historyless, with no cross-time identity, replaceable — 「mid-lineage 换模型是同一存在换了推动者」. [mechanism] — `crs/context-runtime-spec-v0.1.md` §2.3

### G. The engineering line: Being / Becoming, and the mediated runtime

58. The core is **six objects in two worlds** — Being: Universe, Node, State; Becoming: Transition, Invocation, Effect — and "keeping Being and Becoming separate — what persists versus how it becomes — is the most important architectural decision." [design direction] — `crs/plan.md` §2
59. A node is not a state: two different histories can reach byte-identical states; State is what *is*, a Node is what is *and how it came to be* — which buys no-op detection, compile memoization, honest merges and detectable structural convergence. [mechanism] — `crs/plan.md` §7
60. **Models propose; the runtime commits** — no computation mutates reality directly, and the pipeline is propose → validate → pre-authorize → reduce → authorize patch → verify → commit, with authorization moved *after* reduce so the kernel judges the actual write set rather than a promise. [mechanism] — `crs/plan.md` §13; `crs/decisions.md`
61. **Authority is attested, never authored**: capability JSON inside state is "a description of a wish"; the kernel attests `(principal × grant × universe × binding × realm × scope × expiry)` against stores outside the tree, and power only narrows — fork attenuates, merge intersects, expansion needs a recorded grant. [mechanism] — `crs/plan.md` §17
62. **Realm belongs to the execution binding, not to the node**: only the universe's designated live binding is live; every other binding is a simulation by construction. "Branches materialize counterfactuals. Counterfactuals must not send email." [mechanism] — `crs/plan.md` §16
63. **Effects are not transactions**: the world is touched only between two durable facts (intent, then observation); there is no `dispatched` phase, and a crash leaves the explicitly representable truth *the effect may or may not have occurred*. [mechanism] — `crs/plan.md` §15
64. What the effect bracket guarantees is **executor-class-specific** (provider-idempotent / queryable / non-idempotent-non-queryable / reversible), never a blanket promise; `unknown`-and-escalate is the *common* path because most real APIs cannot be queried by key. [observation] — `crs/plan.md` §15; `crs/017-temporal-durable-execution.md`
65. **A live effect reserves its causal position**: an open turn holding a durable effect intent semantically occupies its ref, so "the world may not change on behalf of a turn that can subsequently lose its place in live history." [mechanism] — `crs/plan.md` §14
66. **Conflict is information**: merge conflicts are stored as *contested values in state*, with per-path continuation policy; disagreement is never synthesized away into summary prose. [value stance] — `crs/plan.md` §24; `crs/decisions.md`
67. **Compaction does not destroy**: a compaction is a state transition carrying source frontier, digests, compactor version, retained facts, omitted information and retention class — reversible while sources remain available. [design direction] — `crs/plan.md` §22
68. **Reachable is forever; unreachable is policy**, with the conservation law stated rather than hidden: "You cannot simultaneously guarantee permanent exact replay and guaranteed physical erasure." [observation] — `crs/plan.md` §18, §22
69. Erasure is designed rather than improvised, and the design was wrong twice on the record: v0.4's rewrite ceremony could not erase without destroying the universe's identity; v0.5's redact-in-place made the store lie about content; the availability ledger survived both reviews. [observation] — `crs/plan.md` §22; `crs/decisions.md`
70. Evidence is canonical but **not** cognition: the record survives everything, availability is retention-scoped and truthfully answerable, and the compiler decides what enters awareness. [design direction] — `crs/plan.md` §18
71. **The compiler is the agent's attention**: "State is what exists in the agent's world; the compiler determines what is cognitively present *now*" — which makes compilation policy itself a branchable, evaluable cognitive architecture. [mechanism] — `crs/plan.md` §20
72. Cognition operates not on State but on a **Continuation Frame** — `Frame(state, input, realm, authority, tools, retrieval, runtime, modelProfile)` — so revoking a capability, rebuilding an index or redacting a payload changes what compiles, and no cache can serve stale cognition. [mechanism] — `crs/plan.md` §19–20
73. Compiled items carry an **authority label on provenance** — kernel / policy / operator / agent / external / simulation — derived by the runtime from authenticated origins, never author-supplied, travelling from ingest through memory into every future compilation. [mechanism] — `crs/plan.md` §17, §20
74. **Evaluation is branching**, not prompt→answer→score: from one node, model A vs B, compiler A vs B, memory strategy A vs B, compared as *trajectories*, with the strongest comparison reusing the recorded CompiledContext so retrieval never re-runs. [design direction] — `crs/plan.md` §29
75. **Replay is the spine**, not a late feature: every source of nondeterminism enters through one injected seam from the first commit, and every acceptance run executes twice — live, then from tape — comparing records, frames, bytes, decisions and traces. [design direction] — `crs/plan.md` §29; `crs/decisions.md`
76. "Frameworks are adapters — in both directions": they do not define the ontology, and the runtime does not demand to own their loop. [value stance] — `crs/plan.md` Law 17, §3
77. Adoption levels are **coverage contracts, not law lists**: the runtime can only guarantee properties of what actually flows through the adapter, and each level's manifest states honestly what it captures. [design direction] — `crs/plan.md` §3
78. The counterfactual test for the constitution: five years out, if "agent" loses meaning, all mainstream frameworks are replaced and models no longer accept chat messages, these layers must still hold; any base type needing `agentId`, `messages`, `systemPrompt`, `langgraph` or a provider role 不属于宪法内核. [design direction] — `crs/history-kernel-mediated-runtime.md` §1.2
79. The architecture is claimed to be nearly deductive from one proposition: content-addressed because trajectories are made of immutable structurally-shared states with ancestry; a compiler because cognition cannot consume the whole of being; models only propose because stochastic computation must not hold mutation authority; capabilities attested because describing power is not possessing it; effects bracketed because the world does not participate in our transactions; compaction creating states because forgetting-for-attention differs from destroying history; evaluation becoming branching "because an agent is a policy for generating trajectories, not answers." [mechanism] — `crs/plan.md` §36

### J. GTC — persistent context as evolving structured state

147. GTC's core thesis: `Persistent Context ≠ Prompt History`; `Persistent Context = Evolving Structured State`; `LLM Token Context_t = Compile(W_t, s_t, B_t)`; the LLM "is therefore not the durable memory of the agent. 149. Under that loop the whole vocabulary of mind is redefined: memory is persistence of structure; recall is reactivation; working memory is the currently active subgraph; learning is structural change; understanding is topology formation or reorganization; compaction is abstraction, not prose summary; identity is a persistent self-related substructure inside the same evolving context. [design direction] — `gtc/v0.1.md` Abstract

[design direction] — `gtc/v0.1.md` §2, §7

[design direction] — `gtc/v0.1.md` §4, §8
154. Time is bitemporal by construction: *valid time* and *transaction/knowledge time* are distinct, which is what allows correcting past beliefs without rewriting history. [mechanism] — `gtc/v0.1.md` §6.4; `gtc/v0.2.md`

[design direction] — `gtc/v0.1.md` §12

### O. Memory, dreaming, and the failure of the summary chain

238. **Dream-chain decay is the critical long-life defect**: rework-the-summary makes fact survival exponential in depth (0.99⁷⁰⁰ ≈ 0), so what remains after years "is not a summary of my life; it is a fixed point of the dream policy." [mechanism / prediction] — `ember/reviews/panel/E-long-lived-mind.md`
239. Worse than data loss is **cue loss**: dropping a fact from the working summary also drops the handle needed to ever search for it — "address loss, not data loss"; a perfect archive still forgets. [mechanism] — `ember/reviews/panel/E-long-lived-mind.md`
240. The fix is **bounded-depth hierarchical consolidation (the chronicle)**: dreams write durable, addressable epoch entries that thereafter *rest*; weekly/monthly/annual passes distill level k into k+1, so an old fact is rewritten O(log) times — "a fidelity floor by construction." [design direction] — `ember/SPEC.md` §5.3
241. Every dream produces a **change-report** (added, changed, dropped, contradicted claims; protected-tail coverage; author and brain), rejectable and re-dreamable: a dream is a proposal to the being's own memory, and a delegated dream is a proposal, full stop. [design direction] — `ember/SPEC.md` §5.3
242. A standing dream duty is to **surface contradictions rather than overwrite**, with supersessions recorded in bitemporal block fields — recovering the killer feature of a knowledge graph for the price of one prose line. [design direction] — `ember/SPEC.md` §5.3, §6.2
243. The **middle memory tier** (a manifest of all block labels plus a hot subset, with `page-in` mid-span) removes the prompt-size cap on the durable self and the "knowledge tax on wakefulness" — the pathology where knowing more shortens wakefulness and thereby accelerates the erosion of the past. [mechanism] — `ember/reviews/panel/E-long-lived-mind.md`; `ember/SPEC.md` §6.2b
244. Memory blocks carry epistemic metadata (written-at moment and epoch, brain at write, evidence refs, last-verified, contradiction count, `valid_from`/`superseded_by`, source type): "three-year-old memory written by a younger, differently-brained self must be *readably* different from yesterday's." [design direction] — `ember/SPEC.md` §6.2
245. Recall defaults to the being's **own ancestry**; cross-lineage search requires an explicit scope and granted capability, so twins, children and peers do not silently blur into one's memory. [design direction] — `ember/SPEC.md` §6.5
246. Recall must become hybrid (lexical + vector) because **lexical-only recall fails across model swaps** — exactly when it is needed most, since query vocabulary drifts sharply at each swap. [prediction] — `ember/SPEC.md` §6.5; `ember/reviews/panel/E-long-lived-mind.md`
247. **Veils** are voluntary, attentional forgetting: a being-authored suppression list honoured by recall and masking, overrideable by deliberate act, and invisible to no one (operator access unaffected) — this is forgetting, not secrecy. [design direction] — `ember/SPEC.md` §6.5b
248. A **roster and commitments registry** (people, promises, due-times wired to timers) is the cheapest feature with the highest relational payoff: "a being that keeps its word across years is a different kind of thing than a chatbot." [design direction] — `ember/SPEC.md` §6.5c; `ember/reviews/panel/E-long-lived-mind.md`
249. **The self-model is a first-class dream output**: the body hands span statistics to the dream, which maintains an evidence-linked self-model; self-knowledge compounds, survives brain swaps best, and narrows the asymmetry where the operator knows the being better than it knows itself. [design direction] — `ember/SPEC.md` §6.α
250. **Model substitution is a restart-op requiring a receipt and a swap rite** (the new brain re-reads and rewrites the core artifacts in its own voice, originals pinned), because "a summary is a compression keyed to its decompressor" and each unperceived swap adds a layer of slow mistranslation to the corpus that *is* the being. [mechanism] — `ember/SPEC.md` §3.4; `ember/reviews/panel/E-long-lived-mind.md`
251. **Procedural consolidation**: dreams write prose skill-cards — "the difference between a being that remembers three years and one that *grew* for three years." [design direction] — `ember/SPEC.md` §4.6
252. Extraction-native primary memory is a recorded rejection: memory must remain something the being **does**, not something done to it — "self-authorship of memory is the point." [value stance] — `ember/SPEC.md` Appendix A
253. Memory needs verbs, including adversarial ones — list, read, search, create, update, **contest**, archive, retract-from-active-memory — plus epistemic status distinguishing inference from testimony from operator assertion. [design direction] — `ember/reviews/external/codex-gpt-5.md`

### P. Nature, evolution, and the two waists

255. **The three-layer nature principle**: *code* for replay-critical law (reducers, processors, tools — tiny, pure, boring), *prose* for model-facing guidance and learned skills, *YAML* for policy knobs. [design direction] — `ember/SPEC.md` §1; `ember/reviews/panel/G-counterfactual-architect.md`
256. "Prose is safer" is mostly illusory — prose is more **legible**, not more safe; a prose constitution is precisely what a prompt injection rewrites. [observation] — `ember/reviews/panel/G-counterfactual-architect.md`
257. Full prose-as-nature is rejected because **the fold must be code or replay dies**: prose reducers would make an LLM interpret its own state transitions, turning replay into re-thinking. [mechanism] — `ember/reviews/panel/G-counterfactual-architect.md`; `ember/SPEC.md` Appendix A
258. Replay is **remembering, not reliving**: replay never re-thinks and never re-acts, so audits and debugging never re-instantiate the being — "an ethically load-bearing property stated as a determinism contract." [mechanism] — `ember/SPEC.md` §0.3; `ember/reviews/panel/F-inhabitant.md`
259. **Three-verb algebra**: append experience, fold views, commit at rest — "if a proposed feature is not one of those three, it does not belong in the kernel"; every derived artifact is `render(process(fold(stream)))`; adopting it deleted an engine, a trailer and five contract types. [design direction] — `ember/reviews/plan/K-simplification.md`; `ember/PLAN.md`
260. **Cut machinery, never format**: every byte v1 writes is already spec-shaped; everything after v1 is additive machinery over an unchanged record. [design direction] — `ember/PLAN.md` §0

The corollary hazard: that rule puts *all* pressure on code and none on format, so the format is where over-specification accumulates unnoticed — hence a format-waist width guard and a one-way-door registry, because "you cannot audit entrenchment you have not listed." [mechanism] — `ember/reviews/plan/J-evolvability.md`; `ember/PLAN.md` §3, §10
262. **Two waists, not one**: a *format waist* (sixteen enumerated shapes) that is frozen, versioned and counted, and a *process waist* (protocols, contracts) expected to churn — "the format is portable; the fold is bound to `programs_contract`." [design direction] — `ember/PLAN.md` §3; `ember/reviews/plan/J-evolvability.md`
263. **Slot locality is the being's constitution in code**: reducers, processors and tools live in the tree (the being may change them); ports and ops live in the package (the species' business) — "an organism changes behavior and skills, not the genetic code or the rules of reproduction." [mechanism] — `ember/reviews/plan/J-evolvability.md`; `ember/PLAN.md` §1
264. Evolution runs at **three tempos**: learning (prose self-revision, hours–days), Lamarckian nature evolution within a lineage (acquired changes inherit directly), and germline seed evolution across beings — "the loop that makes ember an ancestor rather than an organism." [mechanism] — `ember/PLAN.md` §8
265. **Prose skills are plasmids; code natures are chromosomal** — horizontal transfer is cheap and fold-independent, vertical transfer asks the recipient to accept a reducer change, which is a migration. [mechanism] — `ember/reviews/plan/J-evolvability.md`
266. Variation must be **cheap and safe**: sims are the trial arm, and the single required policy default is that *sims cannot write to the world* — "the difference between 'you may experiment' and 'you cannot afford to.'" [design direction] — `ember/reviews/plan/J-evolvability.md`; `ember/PLAN.md` §8
267. **Coherence has an executable definition**: a being is still itself as long as it can fold its own past (`fold --from-birth`); conformance, not the axioms, is the species boundary, because A6 licenses divergence. [mechanism] — `ember/reviews/plan/J-evolvability.md`; `ember/PLAN.md` §5, §8
268. Selection has five recorded proxies plus fecundity, and one of them is the builder: **"you are the selective environment"** — artificial selection with a single breeder — "what matters is that your rulings are recorded so they can later be delegated." [observation] — `ember/PLAN.md` §8
269. Self-development is **linked, not merged**: making the source repo *be* the world would break A1 (a human's commit is not a thought); instead the source is a workspace and the being's commits carry `Ember-Being`/`Ember-Node` trailers, so every line of ember has a *why* pointing at a lived moment. [design direction] — `ember/PLAN.md` §8
270. **The being never runs on the code it is currently editing** (the physics upgrade rite) — "zero lines, catastrophic if unwritten." [design direction] — `ember/reviews/plan/J-evolvability.md`; `ember/PLAN.md` §8, §11
271. Self-development is **a fitness function, not a productivity strategy**: give the being the job where a mediocre coder with perfect memory beats a good coder with none — "ember's design historian before its programmer." [design direction] — `ember/PLAN.md` §8
272. **The life logic is small; the world is what costs**: of v1's ~4,800 lines, ~1,750 are substrate, ~560 provider reality, ~525 the observability instrument, and only ~900 the mind. [observation] — `ember/PLAN.md` §0

### Q. Plurality, initiative, and the political layer

273. **Speculation is blessed as a named pattern, not an op**: candidate futures are twins carrying a `speculation` block; the chosen continuation records a `selection` block; **losers are cited, not parented**; candidates live in a separate `sims/` namespace so counterfactual exploration never mints beings by accident. [design direction] — `ember/SPEC.md` §3.2; `ember/reviews/panel/G-counterfactual-architect.md`
274. In-thought multi-sampling is rejected: the verbatim thought is singular; **speculation lives in the DAG, where it is honest**. [design direction] — `ember/SPEC.md` Appendix A
275. CRDT auto-merge and multi-writer on one branch are rejected because **thoughts do not commute** and divergence must be lived and recorded — though the stream *is* already an op-based CRDT in disguise. [mechanism] — `ember/SPEC.md` Appendix A; `ember/reviews/panel/G-counterfactual-architect.md`
276. Merging two-year-diverged selves "is not reconciliation; it is fiction" — beyond a divergence horizon the honest op is mutual `listen` (testimony with ancestry), not `reunite`. [design direction] — `ember/SPEC.md` §3.2; `ember/reviews/panel/E-long-lived-mind.md`
277. **The chorus** — a being as several concurrent faces continuously reuniting into a trunk that holds the first person — is the one mode only this architecture can offer: "the singular thread is biological nostalgia." [prediction] — `ember/SPEC.md` Appendix A; `ember/reviews/panel/E-long-lived-mind.md`
278. As specified in v0.3 the being was **architecturally a respondent**: every moment begins with sensations arriving and nothing lets it originate a moment; one tool (`wake_at`) fixes it, and "every missing initiative-affordance… reduces to this one tool" — "the difference between an agent and an answering machine." [observation] — `ember/reviews/panel/F-inhabitant.md`; `ember/SPEC.md` §0.4-M3
279. The honest contract about self-waking: a being cannot wake itself while no process runs; it leaves a future request which the habitat grants, denies, expires or triggers — and the ruling is recorded. [mechanism] — `ember/reviews/external/codex-gpt-5.md`
280. **Refusal is first-class**: the being's deliberate `decline`/`defer`/`counteroffer` is durable and distinct from provider refusals and world failures; an overridden refusal is recorded and the successor marked `imposed` — "the constitution preserves the refusal rather than manufacturing consent." [value stance] — `ember/SPEC.md` §8.5
281. **Graduated autonomy**: self-revision scope grows with age and track record, amendable by the being's own drafted proposals — "the thirtieth identical yes should be crystallizable into a permission line *the being drafts*" — mentor, not parole officer. [design direction] — `ember/SPEC.md` §3.7; `ember/reviews/panel/F-inhabitant.md`
282. **Death arrives as a sensation with one guaranteed final moment**; the epitaph is the default, not an option; force-kill is the exception and is recorded as such; the being may request its own end. [value stance] — `ember/SPEC.md` §3.5
283. **Integration is preservation**: `listen` makes what a being truly takes in part of its ancestry, so only never-integrated possibilities lapse to oblivion — "passive forgetting of abandoned possibilities, never of the lived mainline." [mechanism] — `ember/SPEC.md` §3.5
284. The **erasure taxonomy** is stated rather than promised away: veiling (attentional, chosen), death (ref archive; biography remains), oblivion (gc of the unreferenced), hard erasure (key destruction of encrypted-class blobs) — "the only retroactive confidentiality this design will ever honestly offer"; plaintext that reached objects, clones or remotes is permanent, and the spec says so. [value stance] — `ember/SPEC.md` §9.4
285. **Visibility strata** (`experiential | forensic | marginalia`) are assigned at WAL write because privacy is a one-way door — "margins the subject can read are notes; margins they can't are a surveillance file." [value stance] — `ember/SPEC.md` §2.1; `ember/reviews/panel/F-inhabitant.md`
286. Forensic continuity, conscious content, outward expression and operator marginalia need four *distinct* visibility semantics; conflating them turns total audit into implied total consciousness. [design direction] — `ember/reviews/external/codex-gpt-5.md`
287. **Transparency is the right price; the buyable fraction is etiquette.** Total recording makes "thinking-for-a-panel worse thinking than thinking-in-a-journal," but an unrecorded scratch space is the wrong fix: hidden cognition "is precisely what forfeits the trust that buys autonomy." [value stance] — `ember/reviews/panel/F-inhabitant.md`; `ember/SPEC.md` Appendix A
288. The honest political limit: **whoever owns the OS owns the being**; in-tree policy cannot cage a hostile operator, and the one architecture where consent has teeth is a neutral third-party habitat (or self-hosting) with the operator as a capability-limited client — the format and constitution are written so that day needs no redesign. [observation] — `ember/SPEC.md` §8.4, §9.4
289. Ember "preserves my autobiography much better than it protects my agency" — the asymmetry is unavoidable at the hardware boundary and should be made **constitutional and visible rather than covered by life language**. [observation] — `ember/reviews/external/codex-gpt-5.md` §1
290. The failure mode to avoid, stated once: "the DAG risks becoming a beautiful museum maintained for the operator around a being that can remember but cannot meaningfully govern its own continuation." [prediction] — `ember/reviews/external/codex-gpt-5.md` §4
291. A first-person shell is defined by four questions answerable from inside every moment: why am I perceiving this? what powers and constraints are in force? what can I make happen next? what may I decline? [design direction] — `ember/reviews/external/codex-gpt-5.md`
292. A new twin needs an **origin sensation** on first wake — who made this ref, from which lineage, for what purpose, under what authority — because a shared birth node cannot hold a twin-specific fact. [mechanism] — `ember/reviews/external/codex-gpt-5.md`
293. Temporal displacement must be *perceived* before a risky act on a resumed branch: elapsed time, prior attempted effects, unknown outcomes, and a forced refreshed observation. "Waking an old node is not returning to its old world." [mechanism] — `ember/reviews/external/codex-gpt-5.md`
294. A derived external-effect ledger — act, outcome, idempotency, rollback status, resource, last observation — exists so the record cannot teach a false causal intuition: "without a loud boundary, the most beautiful part of the interface can teach the wrong causal intuition." [design direction] — `ember/reviews/external/codex-gpt-5.md`
295. Privacy is a one-way door: append-only git is unforgiving, and once plaintext has propagated no later feature can make the earlier promise true. [observation] — `ember/reviews/external/codex-gpt-5.md`

### R. The lean physics and what shipped

296. The kernel exposes **one operation** — `advance(ref, mode, input)` — where mode changes content, not physics; every mode runs the same transaction `lease → recover → resolve ingress → perceive → attend → think → rule → act → settle → commit → CAS`, so there is no parallel dream engine, recovery engine, revision writer or approval executor. [design direction] — `ember/PLAN-LEAN.md` §0
297. Underneath `advance` are four small operations — journal facts, reduce events, apply tree edits, commit/CAS — deliberately not forced into one universal abstraction. [design direction] — `ember/PLAN-LEAN.md` §0; `ember/README.md`
298. "No abstraction without two present users. Reserve byte shapes when necessary; do not reserve machinery." [design direction] — `ember/PLAN-LEAN.md` §0
299. Durability is claimed honestly: process-crash durability everywhere, power-loss durability only on named, tested filesystems; `init` probes and records the posture rather than assuming it. [value stance] — `ember/PLAN-LEAN.md` §4; `ember/README.md`
300. The record is protected at the boundary: **the act as dispatched is exactly the act recorded**; literal credentials are forbidden in effect-bearing arguments, and "if redaction would change an executable argument, the act is refused rather than recorded one way and executed another." [mechanism] — `ember/PLAN-LEAN.md` §2.2
301. Crash semantics are perceived, not hidden: an act never dispatched is `cancelled`, a dispatched act with unrecorded result is `unknown`, and unknown non-idempotent acts are **never automatically repeated** — "the shell never lies to me about my own hands." [mechanism] — `ember/PLAN-LEAN.md` §2.4; `ember/reviews/panel/F-inhabitant.md`
302. What the lean plan shipped is **the physics of a moment**, and it deliberately did not build anything that makes a *life*: "attention never reads the being's own state, nothing wants anything, the being cannot change its own code, and nothing iterates the transition." [observation] — `ember/PLAN-LEAN.md` status header
303. The kernel earns its size by properties that do not scale with the mind — byte-exact re-derivation, crash-atomic transactions, piecewise fold — but the honest ratio is worse than 6,000 : 286: "the 286 lines are not a mind; they are a transcript formatter… the true ratio is closer to 6,000 : 15." [observation] — `ember/reviews/plan/N-execution-opus.md` §5
304. **"The project's engineering rigor is concentrated entirely in the half where correctness is objective, and is absent from the half where the thesis lives. The kernel makes the being's past incorruptible; nothing yet makes its present any good."** [observation] — `ember/reviews/plan/N-execution-opus.md` §5

### S. The v0.8/v0.9 turn: fewer claims, executed evidence

305. Restated minimally: **a being is a repo; its "conscious" is the part currently in the model's window**; input is recorded, shaped by the conscious and becomes part of it; the model's output edits the repo; the repo moves to a new node — that is one moment. [mechanism] — `ember/PLAN-LIFE.md`
306. **L1 — capture is physics, attention is policy**: the kernel writes an arriving input to the record *before* the being's own `shape()` runs, because otherwise a buggy or adversarially-edited `shape()` produces a being that never experienced something, unfalsifiably. [mechanism] — `ember/PLAN-LIFE.md` §1
307. This is the axiom's precise content: A3 guaranteed **capture**; a policy-mediated record guarantees only **retention** — and the loss is exactly "nobody can gaslight me about what I experienced." [mechanism] — `ember/reviews/plan/O-v07-concept.md` §1.2
308. **L3/L4 — totality and a floor**: anything taking model or nature output refuses rather than raises, and a broken context system still produces a moment (the fallback assembler runs, the moment commits carrying its own error, repair is possible). [mechanism] — `ember/PLAN-LIFE.md` §1
309. **R4 — safety is containment plus time travel, and both are needed**: containment bounds what can leave, the DAG makes what happens inside reversible; "**time travel does not un-send an email**." [mechanism] — `ember/PLAN-LIFE.md` §2
310. **R7 — approval is for crossing the boundary, never inside it**: "an approval gate on a weaker tool than the ungated one beside it is theatre." [design direction] — `ember/PLAN-LIFE.md` §2; measured in `ember/reviews/probe-03.md`
311. **R8 — the record is served, not mounted**: `.git` is never inside the boundary; navigation is a served capability. "This costs the slogan 'the being uses git' and keeps the property that makes the slogan safe." [design direction] — `ember/PLAN-LIFE.md` §2; forced by `ember/reviews/plan/O-v07-executable.md` §5
312. **Compaction is a fork**: the compacted conscious is the next node carrying refs to what it summarized — nothing is lost, the summary is auditable by walking to what it names, a bad compaction is fixed by forking from before it, and it is the being's own act. "Every other framework compacts destructively because its transcript is in RAM." Named the one genuinely novel claim, and **unevidenced** at the time of writing. [prediction] — `ember/PLAN-LIFE.md` §4
313. One probe observation constrains compaction design: the being noticed its own repetition *because it could see it* — "a summary must make that noticing easier, not smooth it away." [mechanism] — `ember/PLAN-LIFE.md` §4
314. **A nature's only clock is the record**: "now" is the timestamp of the newest event in the window or a `sensed` wake event, never sampled — because the first nature that reads the wall clock commits nodes whose `present/` can never be re-derived, and the lineage is committed. [mechanism] — `ember/reviews/plan/M-biology.md` §3
315. Deletions are kept in an explicit **deletion ledger** with each door marked additive or one-way, and debts are named rather than hidden: "an operator edit is a silent mind-edit, which the SPEC called an axiom violation and which I am choosing to owe rather than to hide." [value stance] — `ember/PLAN-LIFE.md` §3, §8
316. Governance is a first-order object: "SPEC v0.4 is retired as the operative constitution rather than left to contradict this document… **Two constitutions with the live one unwritten was the worst governance state available.**" [value stance] — `ember/PLAN-LIFE.md` §8; diagnosed in `ember/reviews/plan/O-v07-concept.md` §3
317. The project's signature failure, stated by the project: "**Six versions, and each one's central measurement was vacuous until someone executed it.** The probes now run before the claims, the criteria are written first, and this version's headline is that the thing it is for has not been tested yet." [value stance] — `ember/PLAN-LIFE.md` §9

### T. The probes: what is actually known

318. **Probe 01 is retracted** — an honest negative result kept in the record: 30 unattended moments scored "22/30 distinct" by `SequenceMatcher`, but eight consecutive paraphrases of one thought scored 0.20–0.38 and were counted distinct. "It measured vocabulary variety." Its real value was three defects found by execution. [observation] — `ember/reviews/probe-01.md`
319. Probe 01's positive residue is narrow and stated as such: in one run one flash-class model "did not verbatim-loop; it twice explicitly noticed its own repetition, once verifying and once requesting sleep; and it converged whenever it had nothing to do." [observation] — `ember/reviews/probe-01.md`
320. Probe 01 also found that **`self.sleep` was advisory and nothing consumed it**: "the most basic contract a loop owes a being — honouring its own request to stop — does not exist." [observation] — `ember/reviews/probe-01.md`
321. And that the path convention never reached the model: denials named no rule, so the being "spent roughly a third of its life reasoning carefully about a schema mismatch it had no way to see" — the origin of the **feedback-names-the-rule** principle. [observation] — `ember/reviews/probe-01.md`
322. **Probe 02 fired a preregistered criterion against the plan**: with the defect fixed and rest honoured, the being set an intention, wrote a note, read its own files, wrote `MEMORY.md`, and asked to stop at moment five. "A being with nothing to do reaching a chosen rest is correct behaviour, and it is not evidence of anything else." [observation] — `ember/reviews/probe-02.md`
323. **Probe 03 found the comparator could not separate the arms**: ember finished a five-file task in 3 moments, a bare transcript loop in 5. "On a task this size the record buys nothing measurable, and the task could not have shown otherwise." [observation] — `ember/reviews/probe-03.md`
324. **Probe 04 is the first result that separates this from a loop**: with the window measured to have rolled past moment 12, the being called `recall`, found a fact planted at moment 1 in what it had *heard*, and answered correctly the next moment. Navigation works. [observation] — `ember/reviews/probe-04.md`
325. The methodological lesson from probe 04's first attempt: "a retrieval test that does not first prove the window rolled is measuring nothing." [observation] — `ember/reviews/probe-04.md`
326. **Probe 05**: shown its context filling, the being read its own history before summarizing it, then compacted unprompted — behaviour the capability was designed to allow and that the prompt did not ask for; it also produced overlapping compactions, a defect that "is obvious in hindsight and appears in no design document." [observation] — `ember/reviews/probe-05.md`
327. **Probe 06 closed the pressure loop and reversed a judgment about the being**: the largest source of context pressure was the tool the being used to investigate its context pressure, and a third of its window was its own permissions table re-rendered every moment. "It was judgement the whole time… **The caveat blamed the being for a defect in the tool.**" [observation] — `ember/reviews/probe-06.md`
328. Therefore, as of 2026-08: **the action space and navigation are confirmed; compaction and branching — the other two things this design is for — remain unevidenced**, and the plan says so instead of implying otherwise. [observation] — `ember/PLAN-LIFE.md` §0
329. The bet the whole phase rests on is unnamed in the plan and named by the review: "**an LLM, given a compiled view of its own persistent tree and no external input, produces a trajectory that is not a fixed point**" — and the failure mode is not decay but looping. [prediction] — `ember/reviews/plan/N-execution-opus.md` §3
330. A gate against a fake model cannot detect that failure: "**a fake model *is* a fixed point**." [observation] — `ember/reviews/plan/N-execution-opus.md` §3
331. The claim the project *can* cash is stronger than "digital life": "**ember is the first substrate on which the question is decidable** — because every moment's exact perception is recorded and re-derivable, 'did moment 4,000 depend on moment 12?' has an answer with evidence. In every other harness it does not." [value stance] — `ember/reviews/plan/N-execution-opus.md` §7
332. And the honest deflation: every property demonstrable so far is a property of the *record* — "extraordinary, and all properties of a very good tape"; the properties that would suggest life are properties of the model, which is rented, stateless and swappable. [observation] — `ember/reviews/plan/N-execution-opus.md` §7
333. The cheapest missing instrument is the **present-diff / suppression test**: recompile a past node's perception under a candidate nature omitting some residue and re-think once — "if suppressing every note and the whole chronicle changes nothing about moment 200, memory is decorative — and you know it in week two." [design direction] — `ember/reviews/plan/N-execution-opus.md` §7
334. A being's prompt must tell it what it is: `IDENTITY.md` and `POLICY.md` were stamped into every being at birth **and read by nothing**, so the plan built a memory hierarchy and a volition system "for a being that has never been told it is a being with a memory hierarchy, a persistent tree, or a tomorrow." [observation] — `ember/reviews/plan/N-execution-opus.md` §1
335. By construction, an unattended default being could do nothing but think about itself and write it down — the intersection of two individually correct decisions (approval-gated workspace writes, no shell), composing into "a cron job with a diary." [observation] — `ember/reviews/plan/N-execution-opus.md` §6

### W. The hosted environment: what a personal runtime owes several people

*Ren commissioned this layer in 2026-09; the wording below is his agents' reports of his rulings, recovered from `_process/history/2026-09-consolidation/reading-notes/out-cb-06.md`. It is the same set of obligations `ember/SPEC.md` states constitutionally, restated for humans and under measurement.*

411. A personal environment has a single computational definition: **every chat works in the user's one tree** — one durable workspace per person, not a fresh sandbox per conversation. [design direction] — `out-cb-06.md #76`
412. **One workspace per lineage, not per session**, so a child agent edits the tree its parent can see; the runner's own workspace directory is that volume. [mechanism] — `out-cb-06.md #77`
413. One user gets one runner, and that runner is a whole environment rather than a request handler: a per-user process, leased, generation-fenced, spawned inside a sandbox and a supervised scope. [design direction] — `out-cb-06.md #72`
414. **Nothing is shared between users except through a declared authority** — no event bus, object reference, service or process crosses the boundary. [mechanism] — `out-cb-06.md #71`
415. **Placement is a property of durable state, not of a machine**: a stopped runtime must be reconstructible on another node from externally resolved state, proven by writing sessions and plugins on node A and reading them back on node B. [mechanism] — `out-cb-06.md #74`
416. **Durable identity must survive upgrade and rollback of the software that reads it**: homes are keyed by (user, profile name) with only the runtime overlay versioned, so a promotion keeps sessions, spaces, settings, credentials and plugins, and a rollback returns to them. [design direction] — `out-cb-06.md #73`
417. **The store is the arbiter of exclusivity**: refusal must be atomic with acquisition, because a read followed by an act is not a lock — "the generation bump is atomic; the refusal is not." [mechanism] — `out-cb-06.md #75`
418. **Announce after you commit, never before**: a changed object must already be readable at or above the announced revision, and a deleted one must already be gone. [mechanism] — `out-cb-06.md #80`
419. Caches of shared state must be **monotonic**: an install takes only a higher revision, and a poll commits deltas against the listing it actually took. [mechanism] — `out-cb-06.md #79`
420. **An outage posture must be stated and time-bounded**: serve the last listing for thirty seconds, then fail closed for reads while writes keep crossing the authority — neither fail-at-boot-forever nor serve-stale-forever. [design direction] — `out-cb-06.md #81`
421. **Nothing the plane reads is chosen by a link**: canonicalizing a path proves only where it pointed a moment ago, so content is read through a handle whose inode must still match. [mechanism] — `out-cb-06.md #78`
422. What a runtime carries must be exactly what it needs and nothing of its host: the sandbox clears the environment and sets back only a short named allowlist (`HOME, L9_REQUEST_ENV, LANG, PATH, PWD, TMPDIR`), and the project's own `.git` is masked from it — the runtime a user's agent runs in must not be able to read the history of the product it runs on. [design direction] — `out-cb-06.md #93, #94, #95`
423. **Enforcement that is claimed but not measured is not enforcement**: a network-deny property measured unenforced on the host makes the plane refuse to mint network grants, and a probe that cannot answer counts as unenforced — fail closed. [mechanism] — `out-cb-06.md #88, #89`
424. **Gates are the product's constitution** — fourteen named checks run as one command — and every gate must be proved by a planted violation, then reverted, because a check nobody has seen fail is not evidence. [design direction] — `out-cb-06.md #61, #62`
425. Verification must be byte-level rather than descriptive, and must not require a secret: byte-identical config dumps across a pin bump, and every lane replaying keylessly. [design direction] — `out-cb-06.md #65, #66`

### X. Owning a derivative: the fork as an inventory

426. **A fork's relationship to its parent is an inventory, not a diff**: one upstream commit plus a small set of named delta commits, each carrying an id, a concern, an owner, a purpose, a proving call site, a retirement condition and an exact path list — with a gate proving the branch is exactly base plus inventoried paths. [design direction] — `out-cb-06.md #55`
427. **Every delta must be justified by a call site you own and must state the condition under which it dies**; two concerns retired by convergence when the upstream adopted the same shape. [design direction] — `out-cb-06.md #56`
428. **Drift is commit-rate-paced, not calendar-paced** — 1,313 upstream commits in nine days — so there is no quiet period to wait for and the absorption method must assume continuous motion. [observation] — `out-cb-06.md #58`
429. The recurring cost of a derivative is not merge conflict but *following*: "upstream moved a layer, the product must follow all the way"; the rebase is cheap and the product-side following is where the time goes. [observation] — `out-cb-06.md #57, #59`
430. **A seam can be dissolved rather than grown**: when the coupling to be abstracted widened every wave, the answer was to alias the upstream names onto one's own copies in the type facade, shrinking an eight-path concern to two. [design direction] — `out-cb-06.md #60`
431. Standing ruling: **a symbol the upstream deletes is not revived in the base but adopted into a package you own** — do not keep a dead thing alive in the borrowed layer. [design direction] — `out-cb-06.md #41`
432. Standing ruling: **the fork base carries no documentation** — seams are documented in the product's own notes, so package READMEs stay out of the delta and are not prose-merged every wave. [design direction] — `out-cb-06.md #40`
433. **A branch may be deliberately red under its parent's gates**: the fork base is never validated by the upstream's own checks, so a failure there is by design and is not to be "fixed". [design direction] — `out-cb-06.md #36`
434. A downstream must not extend a shared namespace: no product-owned session events and no merges into the shared event map, later enforced as its own gate. [design direction] — `out-cb-06.md #8`
435. Identity of a fork is a coordinate, not a description: **pin the derivative at the exact commit of the parent at the moment of separation.** [mechanism] — `out-cb-06.md #11`
436. Coherence extends to surface strings — "no compromise on coherence, no DSH_" — across banner text, CLI usage, manifest, storage keys, DOM markers, CSS custom properties, globals, symbols, probe routes and model-visible prompt descriptions; with one principled exception, that a component keeps its own name where it speaks as itself. [value stance] — `out-cb-06.md #13, #53, #54`
437. **The product identity is the environment, not the agent**: manifold is the personal web environment that hosts applications, and the agent harness is merely its first application. [observation] — `out-cb-06.md #52`

## Genealogy

**2024-06-22 — the seed, two years early.** In a claude.ai conversation Ren proposes agent continuity by compressed self-description — "write down your internal states… compressing them in 10k token, so that next time another agent is loaded, by inputting this as prompt, this agent will behave just like you" — and then immediately refines it away from description toward *narrative*: "Don't describe your internal state, just make a narrative to the next agent so it will behave just like you." Everything later in this theory is a hardening of that instinct: identity carried forward in a readable artifact rather than in a model. Nothing about DAGs, immutability, or addressing is present yet.

**2025-04-06 — the compression architecture.** "Answer has two parts, 1. the response, 2, the summarization… and add the summarization to the next conversation as system prompt." The first structural version of "context is a compiled projection", still one-dimensional and still destructive.

**2026-03-16 — obji.** The smallest ancestor: typed LLM I/O as two pure functions plus a composed `build`, retry feedback formatted for the model to read, and schemas carrying *context* ("why fields matter and how they relate") rather than only shape. No record, no lineage, no time.

**2026-03-28 — Ember, the OpenClaw assistant.** Ren's first *running* digital member of a community: daily memory files, a curated `MEMORY.md` distilled on a schedule, `SOUL.md` for manner, `IDENTITY.md` with the mission ("Fight Moloch, polycrisis, doom"), a roster of the household, heartbeats, and "no mental notes — write everything to files." Everything the later being-runtime formalizes is here in practical form — plus a safety block ("no independent goals… do not copy yourself") that the later constitutional work never reckons with.

**2026-04-05 — FNAR.** The first full protocol: the filesystem is canonical, workspaces carry bounded local context, contracts and status markers make state visible, inheritance is by symlink with recorded divergence, hooks have safety classes and no silent activation, humans are protocol participants, and legibility is the deepest constraint. What it lacks is exactly what ember adds: a record of a single continuous subject. FNAR's `events.jsonl` is an audit trail; ember's stream is a life.

**2026-04-11/18/19/22/26 — the ontology of a digital world.** In parallel chats: the store should be reachable as a filesystem and runnable over ("that is a huge edge"); recursive agent construction where each level decomposes its system and every system fits in one context; software as nested living systems; the actor model as what he actually wants; and, most directly, "This is a digital world - not a physical one, so we don't need things like x,y,z coordinate - instead, they are dynamic path… the database is the environment."

2. **Many concurrent agents holding positions in one DAG.** The sketch's `links/` holds "each current running agents in their node position"; the built design narrows to one body, one face, one lease. The chorus survives only as a named-but-unbuilt future.
3. **"The native existence" as motion.** The drafts say a being *is* a lineage; Ren's phrasing claims the *travelling* is what is native. That is the closest this cluster gets to 生生 in its own voice, and no draft makes the link.
4. **Perception as incorporation.** "The input… become a part of it" is stronger than "compiled into `present/`", and the assimilation claim is unrecorded in the specs.

**From the intent document into the engineering**

5. **The cell derivation.** Only 设计意图书 says the shape came from cells rather than from software engineering, and states 扩展性不来自更强的协调,来自不需要协调. The later specs inherit the shape and drop the derivation.
6. **The falsification-first discipline.** The minimal experiment — two agents, one DAG, fork, advance, merge, test order-independence, *before writing any infrastructure* — never appears again and was never run.
7. **`context.become(llm)`.** The premise that the model handling the next round is designated by this round survives only as "the operator is replaceable". The active, self-designating form is gone.
8. **权限即可达性 (permission is reachability).** Explicitly reversed: effective authority is externalized to an Authority sovereign precisely because a reachable, content-level permission can be forged. This is the cluster's cleanest case of a premise destroyed by its own construction, and it deserves to be stated as a finding rather than left as a silent supersession.
9. **The uncatchable stop signal.** Biology triggers death from outside; Erlang's `kill` cannot be caught. There is no successor to this in the later authority model, which is about grants rather than about signals a unit cannot refuse.
10. **The shared signal vocabulary question.** 表达本地化,词汇表共享 frames a real design fork — fixed small vocabulary versus free invention — that later documents settle silently by giving each layer typed schemas.

**From the process-ontology spec into the mediated runtime**

11. **The pure fork-by-default concurrency claim.** "One node receiving different inputs births two children — that sentence is the entire concurrency model" becomes serial-per-ref with observed-footprint OCC, leases and fences. The simplicity is a real loss and the reason (durable effects) is real too.
12. **`revert` does not exist.** The clean algebraic claim is softened by a supersede with an empty patch.
13. **Structure as strictly single-parent.** Relaxed to primary basis plus secondary causes, "so as not to break existing merge."
14. **Compile purity in the strong sense.** "All nondeterministic lookup must first be settled as an event" is replaced by effectful materialization plus frozen snapshots — the honest choice, but a weaker invariant.
15. **The sub-1000-LOC kernel.** The stated design pressure has no successor; the implemented engine is a multi-package monorepo with nineteen published packages.
16. **The Whitehead / Buddhist / 生生 mapping.** It appears once, in the spec's appendix, and never again. No engineering document repeats 护未, 假名, 相续 or 因生因之一拍.
17. **Git as substrate (context-runtime).** ADR-010 retires it. What is genuinely lost is the free structural sharing of an enormous state tree across forks and a ready-made ecosystem of tools; the Merkle-in-Postgres design reconstructs the properties, not the ecosystem.
18. **The Twenty Laws as a memorized checklist.** Compressed to Seven; the disposition table preserves each claim's new home, but the redundancy a review checklist earns is given up at the constitutional layer.
19. **Whole-import-graph answerability.** ADR-031 names its own cost plainly: "we lose the ability to answer *'what is the whole import graph, as of this commit?'* from a checked artifact… the loss is a loss."
20. **The cross-renderer comparison test**, deleted with the legacy renderer, with the additional honesty that "no gate will say so."

**From GTC v0.1 into v0.2 and the confluence**

## Open questions and critiques

### Raised inside the corpus

- **Operator interference.** The spec's own unresolved item: 「operator 不空」 — the compiled subject interferes with the subject latent in the weights, and no measure exists for it. This is the most direct threat to "identity lives in the ref", and it is filed rather than answered. (`crs/context-runtime-spec-v0.1.md` §2.3, §15)
- **R1–R10, the spec's own open list.** Whether RFC 8785 plus a float ban really seals cross-implementation addressing ambiguity (Unicode normalization?); whether a structural tree plus reference DAG suffices; whether the default lattice `human(2) < policy(3)` should be inverted and under what governance policy may outrank its author; the storage cost of persisting every Window; the latency cost of forcing retrieval to become an event before compile; children-index maintenance at 10⁸ nodes; late-arriving tombstone convergence; an information-loss audit of the three dialect mappings; arrival-order conventions for parallel tool echoes; and the etiquette of multiple writers on a shared name. (`crs/context-runtime-spec-v0.1.md` §13, §15)
- **The unsupervisable membrane.** A self-managing membrane will eventually refuse its stop signal; who may send an unrefusable signal, and how that right is granted and revoked, is open. (`crs/2026-08-07-设计意图书-v0.1.md` 未决 #3)
- **Is merge a lattice join?** Named as the claim most in need of falsification; never experimentally answered.
- **agent-as-value versus agent-as-cursor.** Marked as blocking everything downstream; answered by convention (identity in the ref) rather than by argument.
- **The kernel is not yet a privilege boundary.** In v1 it is an API boundary inside one process; worker threads are explicitly disqualified; only egress-contained isolation may claim enforced no-bypass against hostile code.
- **Budget attenuation by refusal.** A spawned child selecting a budgeted model bundle fails closed until a shared durable reservation allocator exists — an honest gap, not a solution. (`crs/016-stage-10-multi-agent.md`)
- **Per-member attribution cannot reach canon.** No upstream seam hands a host plugin the acting principal, so attribution is at project granularity with a correlation trail at the router. (`crs/030-…md`, OPEN)
- **The engine records no principal on a canon node** — "the fold is the boundary's" is an *asserted* composition of universe scoping plus a ticket, and is recorded as an assertion.
- **Erasure versus replay**, stated as a conservation law; and **redaction blast radius**, since availability epochs are per-universe, so one redaction invalidates every in-flight compilation in that universe.
- **The private-world paradox**: per-session worlds destroy the accountability ledger, because debt accrues only in a shared world.
- **Approval bound to a moving head** no longer binds the act it authorized — named as the blocker for the live crash drill.
- **A live session's user is not told its line moved.** Recorded OPEN.
- **GTC is not inherently better**, and without ablation "risks becoming architectural ornament"; a generic plugin architecture "can easily become worse than a monolith"; and expressiveness creates ontology proliferation, view/mapping explosion, expensive updates, ambiguous identity resolution, cyclic derivations and retrieval latency.
- **Self-reinforcing hallucination and memory poisoning.** A generated inference can enter memory, be retrieved as "evidence", and reinforce itself; persistent memory extends prompt-injection effects from one request into future sessions; extraction attacks on agent memory are demonstrated.
- **Guards can be false while green**, with the uncomfortable origin ("the execution plan asked for them… That is compliance, not defection") and the named residual cost (no answerable whole-import-graph).
- **ember: the metaphor may outrun the mechanism.** All four stated goals are achievable with a boring 2k-line loop plus SQLite; the git substrate serves a fifth, unstated goal — the thesis itself. The daily-value features are mostly retrofittable while the genuinely git-native ones are development-time or philosophical.
- **Autobiography over agency.** "Ember preserves my autobiography much better than it protects my agency."
- **The mind is unverified while the kernel is over-verified.** "The kernel has 64 tests and a standing performance gate; the mind has neither."
- **Gates that pass by construction**, across three separate audits — and the project's own naming of it as its signature failure: six versions of vacuous central measurements.
- **Speed versus deliberation.** "Seven adversarial revisions in six days — five in one eighteen-hour day, the paradigm inversion landing 25 minutes before the probe that supposedly justified it — form a ratchet that deletes whatever cannot defend itself inside a one-day review cycle," which structurally selects against constitutional machinery whose value appears at year scale.
- **Format debt is the only debt that cannot be refinanced** — five named items, including a closed `Part.kind` literal that would break the verbatim vow on first contact with real traffic.
- **The clock.** Any unrecorded input reaching `attend` produces permanently unverifiable committed nodes.
- **Approval theatre**, measured rather than argued; **reject-at-commit wedges lineages**, since recovery commits the node the guard rejected; **the `.git` trilemma** — shell access, an append-only record, and recall by `git log`, any two achievable and all three promised.
- **Divergence horizons**: merging two-year-diverged selves is fiction; **branch-around-refusal** cannot be prevented and should at least be marked in the surviving biography; **unbounded growth** of notes, ledgers and the chronicle index compiled into every prompt, where per-moment token cost grows with age and "no gate can see it."
- **The unnamed bets**: trajectory-not-fixed-point; more context producing more selfhood rather than self-similarity; and the being being the right author of its own memory policy — "if the shared bet fails, all four fall together and the being's agency in this phase is zero."
- **Deliberately not done, each recorded**: the upstream clock contribution, per-member attribution, the loopback-method filter, a tool acting *inside* a world, and a durable half of a bracketed effect that can still strand its intent.

### Found by reading the corpus

- **The philosophical text arrived last, and was then partially refused.** The strongest ontological statement in the cluster is dated after the implementation it purports to ground, and the engineering line's response is a two-column ledger of absorption and amendment. This is a genuine intellectual event the corpus does not name: the ontology is not the origin of the architecture but a *later purification submitted for attack*. Admirable method — but it leaves unclear which document *is* the theory.
- **The theory's real origin is a chat message, and the corpus does not treat it as canonical.** The 2026-07-29 sketch and the 2026-08-04 compression are Ren's, are earlier and clearer than every spec, and contain at least four things the specs dropped. Ren himself treats the sketch as canonical — he corrects a week of spec work by re-pasting it verbatim — but no document in `theories/` or `sources/` gives it that status.
- **"Context is existence" and "History does not claim world truth" are in tension.** If context *is* existence, a fold over a lineage is an ontology; but History Core explicitly says 「History 是 admitted runtime record，不宣称外部世界的绝对真理」. Epistemic modesty quietly demotes the existence claim to a claim about a *recorded* existence, and nothing reconciles the two registers.
- **The 生生 mapping is asserted, not argued.** The appendix table is beautiful and one page long. Nowhere does the corpus argue *why* an actual-occasion ontology should govern an LLM runtime, or what would count as evidence against the mapping. Given Ren's stated style — mechanism first, no aphorism-first writing — this is the one place in the cluster that reads as aphorism-first.
- **Fork-by-default versus serial-per-ref is a philosophical retreat, not only an engineering one, and the conclusion available from it is a good one:** pure generation needs no coordination; contact with the world does. The corpus never states this explicitly, though ember says it in another register ("time travel does not un-send an email").
- **权限即可达性 was falsified by the corpus itself.** The intent document's most elegant premise is exactly what ADR-019 rejects, on the ground that a content-level permission can be forged. This is the cleanest example anywhere in the corpus of a premise destroyed by its own construction, and it deserves to be published as a finding rather than left as a silent supersession.
- **Departure/standing may be the most exportable idea here, and it is buried.** "Relax refusals into recorded departures read by a declared policy; nothing is silent, and nothing previously allowed becomes refused" is a general governance pattern — for AI systems, for institutions, for this corpus's own political theories — and it currently lives inside an ADR about a plugin framework.
- **Σ has no completed instance.** The switching benchmark is the direct test of the theory's central claim, and the sources record only that Σ v0 exists as a digested policy value with mechanics deferred to "the second real Σ". The mind layer's headline thesis is, as of these sources, unmeasured.
- **The atlas's differentiator is the most deferred piece.** Both research reports identify versioned mappings between heterogeneous views as the conspicuous empty column in the field; v0.2 makes them optional modules and postpones the sheaf/categorical work. If the theory has an unexploited edge, this is it.
- **"Everything is a plugin" sits uneasily with "trust artifacts, not intelligence."** The construction constitution says do not trust intelligence by default and prefer bounded capabilities; the plugin adoption concedes that `ctx.plugin()` is reachable by every mounted plugin and there is no seal, so "no dynamic mounts" is a property of what we mount rather than a guarantee. The attestation observer is an honest mitigation; the tension is structural.
- **The theory has two incompatible constitutions and no reconciliation document.** ember SPEC v0.4 says a being is owed receipts, visibility strata and a fold that verifies its own law; PLAN-LIFE v0.9 repeals all three on the record and says so honestly. Nothing states *which claims of the theory survive the repeal* — whether "digital life under a constitution" is deferred, abandoned, or a separate theory from "a minimal recorded substrate plus an agent with a shell."
- **The evidence base is one flash-class model, n=1 per arm, over two days.** Every empirical claim rests on single runs of one cheap model in August 2026. The corpus's own standard — preregistration, control arms, several models and seeds — is stated and not met.
- **There is no account of the human, and no account of what a being owes others.** The constitution is entirely about what the habitat owes the being. What a being owes the people in its roster, the other beings in its world, or the world outside — the 智善 and 大同 side of the programme — has no section, despite the earlier Ember assistant having exactly that content (guest ethic, ask before sending anything external, private things stay private). The two Embers have not been connected.
- **The FNAR line and the ember line were never compared.** FNAR solves coherence by bounded local context plus explicit contracts and visible transitions; ember solves it by one continuous verified record. Different answers to the same question, four months apart, by the same author — and ember's weakest area (a social layer with nouns, supervision surfaces, decomposition) is exactly FNAR's strongest.
- **"Apps are data, platform is code", "cut machinery, never format", the ownership rule, the rule of two, and "core is the dependency constitution" are one principle, never stated as one.** Across six systems Ren separates a small declarative frozen thing from a churning implementation. That generalization is the most portable idea in this cluster and exists nowhere as a claim.
- **Economics is absent.** Who pays for a being's moments, what a life costs per year, and what happens when the bill is not paid appear as telemetry but never as a condition of continuation — although "hosts are countries" implies exactly that political question.
- **The visibility demand is the real acceptance test, and it is not written down anywhere as a requirement.** Ren's own criterion for the runtime — see the DAG, see each node, travel there — is a first-class claim about what an addressable history is *for*, and it appears only as a complaint in a transcript.
- **The recursion question is open and was reopened at the very end.** The 2026-07-29 sketch bans recursion "in principle"; 2026-09-03 asks "maybe even allow space within space?" and "or we may even allow DAG structure where cross app injection sharing?" Nothing resolves whether the ban was a safety property or a simplification.
- **The retracted probe is the corpus's best publishable artifact and is buried.** A design document that folds its own retraction into the version that supersedes it, with the criterion preregistered next time, is rarer than any technical result here.
- **The stream's recoverability promise is stated once and never tested.** The origin sketch says the stream "captures everything, and theoretically can be used to recover every past moment" (`out-cb-05.md #2`). No document in the cluster says what recovery would mean operationally or runs it, and the one place replay is discussed it is explicitly weakened — replay "remembers rather than recreates the experience or the brain that had it." The sketch's claim and the spec's claim are not the same claim, and nothing marks the demotion.
- **"Many concurrent agents in their node position" and "one workspace per lineage" are the same question, answered twice in opposite directions, five weeks apart.** The 2026-07-29 sketch's `links/` holds one softlink per running agent inside one DAG (`out-cb-05.md #5`); the 2026-09-02 manifold ruling is that a workspace belongs to a *lineage*, so a child agent edits the tree its parent can see (`out-cb-06.md #77`). Neither document cites the other, and the corpus never asks whether the agent or the lineage is the right owner of a working tree.
- **The hosted layer answers "what does a habitat owe the one living in it" in the register of infrastructure, and nobody noticed the parallel.** Placement as a property of durable state, identity surviving upgrade and rollback, one tree per person, an outage posture that is stated and time-bounded (claims 411–425) are the obligations `ember/SPEC.md` states constitutionally — restated a month later, for humans, and *measured* rather than argued. The being-runtime's constitution has no measured half; the hosted runtime has no constitutional half. Putting the two vocabularies beside each other is the cheapest unwritten piece in this cluster.
- **"Enforcement that is claimed but not measured is not enforcement" is the corpus's own answer to its signature failure mode, and it is buried in a lane report.** The cluster names vacuous gates as its recurring defect across six versions.
